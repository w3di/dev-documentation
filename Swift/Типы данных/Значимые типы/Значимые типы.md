## Целочисленные типы

Swift предоставляет знаковые и беззнаковые целочисленные типы фиксированного размера:

| Тип | Размер | Диапазон |
|-----|--------|----------|
| `Int8` | 1 байт | -128 ... 127 |
| `Int16` | 2 байта | -32 768 ... 32 767 |
| `Int32` | 4 байта | -2 147 483 648 ... 2 147 483 647 |
| `Int64` | 8 байт | -9.2 × 10¹⁸ ... 9.2 × 10¹⁸ |
| `UInt8` | 1 байт | 0 ... 255 |
| `UInt16` | 2 байта | 0 ... 65 535 |
| `UInt32` | 4 байта | 0 ... 4 294 967 295 |
| `UInt64` | 8 байт | 0 ... 1.8 × 10¹⁹ |

`Int` и `UInt` — платформо-зависимые: на 64-битных системах это `Int64`/`UInt64`.

```swift
let age: Int = 30          // Int (платформо-зависимый)
let byte: UInt8 = 255      // беззнаковый 8-бит
let big: Int64 = 9_000_000_000_000_000_000  // разделитель _ для читаемости

// Границы типов
print(Int8.min)   // -128
print(Int8.max)   // 127
print(UInt8.max)  // 255

// Литералы в разных системах счисления
let decimal = 42
let binary = 0b101010      // двоичный
let octal = 0o52           // восьмеричный
let hex = 0x2A             // шестнадцатеричный
```

### Переполнение

В отличие от JS (где числа — это `Number`/`BigInt`), Swift **не допускает переполнение** по умолчанию — это runtime crash:

```swift
var x: Int8 = 127
// x += 1  // Fatal error: arithmetic overflow

// Для контролируемого переполнения — overflow-операторы
let y: Int8 = 127 &+ 1  // -128 (wrap around)

// Или проверка
let (result, overflow) = Int8.max.addingReportingOverflow(1)
print(overflow)  // true
```

## Типы с плавающей точкой

| Тип | Размер | Точность |
|-----|--------|----------|
| `Float16` | 2 байта | ~3 десятичных цифры |
| `Float` (`Float32`) | 4 байта | ~7 десятичных цифр |
| `Double` (`Float64`) | 8 байт | ~15 десятичных цифр |
| `Float80` | 10/16 байт | ~18 десятичных цифр (только x86) |

```swift
let pi: Double = 3.141592653589793
let e: Float = 2.71828

// IEEE 754 специальные значения
let inf = Double.infinity
let nan = Double.nan
let smallest = Double.leastNonzeroMagnitude
let epsilon = Double.ulpOfOne  // ~2.22e-16

// NaN не равен ничему, включая себя
print(nan == nan)        // false
print(nan.isNaN)         // true

// Шестнадцатеричные float-литералы
let hex: Double = 0xC.3p0  // 12.1875 (C.3 в hex × 2⁰)
```

### Float vs Double

Swift по умолчанию выводит тип `Double` для дробных литералов:

```swift
let x = 3.14  // Double (type inference)
```

> **Сравнение с JS:** В JavaScript `Number` — это всегда IEEE 754 double (64 бит). В Swift выбор типа явный, а `Float16` полезен для ML-задач и GPU.

## Bool

```swift
let isActive: Bool = true
let isEmpty = false  // type inference → Bool

// В отличие от JS, НИКАКОГО truthy/falsy
// if 1 { }          // Ошибка компиляции!
// if "hello" { }    // Ошибка компиляции!
if isActive { }      // Только Bool

// Логические операции
let a = true && false  // false
let b = true || false  // true
let c = !true          // false

// toggle() — мутирующий метод
var flag = true
flag.toggle()  // false
```

> **Сравнение с JS:** JavaScript имеет концепцию truthy/falsy (`0`, `""`, `null`, `undefined` — все falsy). Swift требует **явный** `Bool` — никаких неявных преобразований.

## Character

`Character` в Swift — это один **Extended Grapheme Cluster** (воспринимаемый человеком символ), который может состоять из нескольких Unicode-скаляров:

```swift
let letter: Character = "A"
let emoji: Character = "🇷🇺"        // два Unicode-скаляра: U+1F1F7 U+1F1FA
let combined: Character = "é"        // e + combining accent = один Character

// Character -> Unicode scalars
let flag: Character = "🇷🇺"
for scalar in flag.unicodeScalars {
    print(scalar.value)  // 127479, 127482
}

// Character занимает разное количество байт, но всегда один графемный кластер
```

## Tuples

Кортежи группируют несколько значений в одно составное значение:

```swift
// Безымянный кортеж
let point = (3, 5)
print(point.0)  // 3
print(point.1)  // 5

// Именованный кортеж
let person = (name: "Alice", age: 30)
print(person.name)  // "Alice"

// Декомпозиция
let (x, y) = point
let (name, _) = person  // _ игнорирует значение

// Тип кортежа
let coordinate: (x: Double, y: Double, z: Double) = (1.0, 2.0, 3.0)

// Кортеж как возвращаемое значение функции
func minMax(array: [Int]) -> (min: Int, max: Int)? {
    guard let first = array.first else { return nil }
    var min = first, max = first
    for value in array.dropFirst() {
        if value < min { min = value }
        if value > max { max = value }
    }
    return (min, max)
}

// Сравнение кортежей (до 6 элементов, если элементы Comparable)
(1, "zebra") < (2, "apple")  // true (сравнивает 1 < 2)
(3, "apple") < (3, "bird")   // true (3 == 3, "apple" < "bird")
```

> **Важно:** Кортежи — значимые типы. Они полезны для временных группировок, но для сложных данных лучше использовать `struct`.

## Значимая семантика

Значимые типы (`struct`, `enum`, tuples, все примитивы) при присваивании и передаче **копируются**:

```swift
var a = [1, 2, 3]
var b = a        // b получает КОПИЮ
b.append(4)
print(a)  // [1, 2, 3] — a не изменился
print(b)  // [1, 2, 3, 4]

struct Point {
    var x: Double
    var y: Double
}

var p1 = Point(x: 0, y: 0)
var p2 = p1     // копия
p2.x = 10
print(p1.x)  // 0 — p1 не затронут
```

### Зачем value semantics?

1. **Предсказуемость** — мутация локальна, нет неожиданных побочных эффектов
2. **Thread safety** — каждый поток работает со своей копией
3. **Простота рассуждений** — нет shared mutable state

> **Сравнение с JS:** В JavaScript объекты и массивы — ссылочные. `const arr = [1,2]; const b = arr; b.push(3)` мутирует и `arr`. В Swift `Array` — значимый тип с COW.

## Stack vs Heap allocation

**Stack:**
- Простые значимые типы (`Int`, `Bool`, небольшие `struct`) размещаются на стеке
- Аллокация/деаллокация — O(1), просто сдвиг указателя стека
- Нет overhead на reference counting

**Heap:**
- Классы всегда на heap
- Значимые типы **могут** попасть на heap если:
  - Захвачены замыканием
  - Используются как existential (`any Protocol`)
  - Содержат ссылочные типы внутри
  - Слишком большие для inline-хранения

```swift
// Stack — быстро
struct SmallStruct {
    var x: Int
    var y: Int
}

// Heap — existential container может аллоцировать на heap
protocol Shape {
    func area() -> Double
}

struct Circle: Shape {
    var radius: Double
    func area() -> Double { .pi * radius * radius }
}

let shape: any Shape = Circle(radius: 5)  // existential → возможна heap-аллокация
let circle = Circle(radius: 5)            // stack
```

### SIL-оптимизации

Компилятор Swift (через SIL — Swift Intermediate Language) активно оптимизирует:
- **Stack promotion** — если компилятор доказывает, что значение не убегает (escape), размещает на стеке даже класс
- **Inline storage** — маленькие existential (до 3 машинных слов) хранятся inline в existential container, без heap-аллокации

## Copy-on-Write

Стандартные коллекции (`Array`, `Dictionary`, `Set`, `String`) используют **Copy-on-Write** для эффективности:

```swift
var a = [1, 2, 3, 4, 5]
var b = a  // НЕ копирует данные! Оба указывают на один буфер

// Копирование происходит только при мутации
b.append(6)  // Теперь b получает свою копию буфера

// Проверка уникальности (используется внутри стандартной библиотеки)
// isKnownUniquelyReferenced(&reference)
```

### Реализация COW для кастомных типов

```swift
final class Storage<T> {
    var value: T
    init(_ value: T) { self.value = value }
}

struct COWWrapper<T> {
    private var storage: Storage<T>

    init(_ value: T) {
        storage = Storage(value)
    }

    var value: T {
        get { storage.value }
        set {
            if !isKnownUniquelyReferenced(&storage) {
                storage = Storage(newValue)
            } else {
                storage.value = newValue
            }
        }
    }
}
```

## Стандартные протоколы

### Equatable

```swift
struct Point: Equatable {
    var x: Double
    var y: Double
    // Компилятор автоматически синтезирует == если все stored properties — Equatable
}

let p1 = Point(x: 1, y: 2)
let p2 = Point(x: 1, y: 2)
print(p1 == p2)  // true
```

### Hashable

```swift
struct User: Hashable {
    var id: Int
    var name: String
    // Автосинтез hash(into:) если все свойства Hashable
}

// Можно использовать в Set и как ключ Dictionary
let users: Set<User> = [User(id: 1, name: "Alice")]
let scores: [User: Int] = [User(id: 1, name: "Alice"): 100]
```

### Comparable

```swift
struct Version: Comparable {
    var major: Int
    var minor: Int
    var patch: Int

    static func < (lhs: Version, rhs: Version) -> Bool {
        (lhs.major, lhs.minor, lhs.patch) < (rhs.major, rhs.minor, rhs.patch)
    }
}

let v1 = Version(major: 1, minor: 2, patch: 0)
let v2 = Version(major: 1, minor: 3, patch: 0)
print(v1 < v2)  // true
```

### Codable (Encodable & Decodable)

```swift
struct Config: Codable {
    var debug: Bool
    var maxRetries: Int
    var endpoint: String
}

// Кодирование в JSON
let config = Config(debug: true, maxRetries: 3, endpoint: "/api")
let data = try JSONEncoder().encode(config)

// Декодирование из JSON
let decoded = try JSONDecoder().decode(Config.self, from: data)

// Кастомные ключи
struct APIResponse: Codable {
    var userId: Int
    var firstName: String

    enum CodingKeys: String, CodingKey {
        case userId = "user_id"
        case firstName = "first_name"
    }
}
```

## MemoryLayout

`MemoryLayout` позволяет узнать размер, выравнивание и stride типа:

```swift
MemoryLayout<Int>.size        // 8 (на 64-bit)
MemoryLayout<Int>.alignment   // 8
MemoryLayout<Int>.stride      // 8

MemoryLayout<Bool>.size       // 1
MemoryLayout<Bool>.alignment  // 1
MemoryLayout<Bool>.stride     // 1

MemoryLayout<Int16>.size      // 2
MemoryLayout<Int16>.stride    // 2

// Struct с padding
struct Example {
    var a: Bool    // 1 байт
    var b: Int64   // 8 байт
    var c: Bool    // 1 байт
}
MemoryLayout<Example>.size       // 17
MemoryLayout<Example>.stride     // 24 (с padding для выравнивания)
MemoryLayout<Example>.alignment  // 8

// Оптимальный порядок полей
struct OptimizedExample {
    var b: Int64   // 8 байт
    var a: Bool    // 1 байт
    var c: Bool    // 1 байт
}
MemoryLayout<OptimizedExample>.size    // 10
MemoryLayout<OptimizedExample>.stride  // 16
```

### Optional и размер

```swift
MemoryLayout<Int>.size               // 8
MemoryLayout<Optional<Int>>.size     // 9 (8 + 1 tag byte)

// Но для ссылочных типов — spare bits optimization
MemoryLayout<AnyObject?>.size        // 8 (nil = нулевой указатель, без доп. байта)

// Bool? — компилятор использует spare bit pattern
MemoryLayout<Bool>.size              // 1
MemoryLayout<Bool?>.size             // 1 (0 = false, 1 = true, 2 = nil)
```

## Битовые представления

```swift
// Float <-> битовый паттерн
let f: Float = 3.14
let bits = f.bitPattern       // UInt32: 1078523331
let back = Float(bitPattern: bits)  // 3.14

// Double <-> UInt64
let d: Double = -0.0
let dBits = d.bitPattern      // 0x8000000000000000
print(d.sign)                 // .minus
print(d.isZero)               // true

// Int <-> побитовые операции
let value: UInt8 = 0b1010_1100
let highNibble = value >> 4        // 0b0000_1010 = 10
let lowNibble = value & 0x0F      // 0b0000_1100 = 12

// Reinterpret между типами через withUnsafeBytes
var source: UInt32 = 0x41480000
let float = withUnsafeBytes(of: &source) { ptr in
    ptr.load(as: Float.self)
}
print(float)  // 12.5
```

## Сравнение с JavaScript

| Аспект | Swift | JavaScript |
|--------|-------|------------|
| Целые числа | `Int8`...`Int64`, `UInt8`...`UInt64` | `Number` (float64), `BigInt` |
| Дробные | `Float`, `Double`, `Float16`, `Float80` | Только `Number` (float64) |
| Boolean | `Bool` (только `true`/`false`) | `boolean` + truthy/falsy |
| Строковый символ | `Character` (grapheme cluster) | Нет отдельного типа |
| Кортежи | `(Int, String)` — нативный тип | Нет (используют массивы) |
| Value semantics | `struct`, `enum`, tuples | Только примитивы |
| Overflow | Crash (или `&+` для wrap) | Бесшумный переход в `Infinity` |
| Type safety | Строгая, нет implicit conversion | Слабая, implicit coercion |
