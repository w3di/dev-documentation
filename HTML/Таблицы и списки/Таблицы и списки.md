## 1. table — структура и семантика

### Полная структура таблицы

HTML-таблица — один из наиболее семантически структурированных элементов. Полная структура включает множество вложенных элементов, каждый из которых несёт свою семантику.

```html
<table>
  <caption>Квартальные продажи компании за 2025 год (в тыс. руб.)</caption>

  <colgroup>
    <col>
    <col span="4" class="data-columns">
    <col class="total-column">
  </colgroup>

  <thead>
    <tr>
      <th scope="col">Продукт</th>
      <th scope="col">Q1</th>
      <th scope="col">Q2</th>
      <th scope="col">Q3</th>
      <th scope="col">Q4</th>
      <th scope="col">Итого</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <th scope="row">Продукт A</th>
      <td>1,200</td>
      <td>1,350</td>
      <td>1,100</td>
      <td>1,500</td>
      <td>5,150</td>
    </tr>
    <tr>
      <th scope="row">Продукт B</th>
      <td>800</td>
      <td>950</td>
      <td>1,200</td>
      <td>1,100</td>
      <td>4,050</td>
    </tr>
    <tr>
      <th scope="row">Продукт C</th>
      <td>2,000</td>
      <td>2,100</td>
      <td>2,300</td>
      <td>2,500</td>
      <td>8,900</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th scope="row">Всего</th>
      <td>4,000</td>
      <td>4,400</td>
      <td>4,600</td>
      <td>5,100</td>
      <td><strong>18,100</strong></td>
    </tr>
  </tfoot>
</table>
```

### Элемент caption

`<caption>` предоставляет заголовок/описание таблицы. Должен быть первым дочерним элементом `<table>`.

```html
<table>
  <caption>
    Сравнение тарифных планов
    <p class="caption-description">Цены указаны без НДС, актуальны на март 2026</p>
  </caption>
  <!-- ... -->
</table>
```

```css
/* Позиционирование caption */
caption {
  caption-side: top;    /* По умолчанию: сверху */
  caption-side: bottom; /* Снизу таблицы */
  text-align: left;
  font-weight: bold;
  padding: 8px;
}
```

> **Accessibility:** `<caption>` — наиболее важный элемент для accessibility таблиц. Screen readers объявляют caption при входе в таблицу, давая пользователю контекст. Без caption или `aria-label` пользователь не понимает назначение таблицы.

### thead, tbody, tfoot

Секции таблицы определяют логическую группировку строк:

- `<thead>` — заголовочные строки (обычно одна)
- `<tbody>` — основное содержимое (может быть несколько)
- `<tfoot>` — итоговые/суммарные строки

```html
<table>
  <caption>Расписание</caption>

  <thead>
    <tr>
      <th>День</th>
      <th>Утро</th>
      <th>День</th>
      <th>Вечер</th>
    </tr>
  </thead>

  <!-- Несколько tbody для логической группировки -->
  <tbody>
    <tr><th colspan="4">Рабочие дни</th></tr>
    <tr><td>Понедельник</td><td>09:00</td><td>13:00</td><td>18:00</td></tr>
    <tr><td>Вторник</td><td>09:00</td><td>13:00</td><td>18:00</td></tr>
    <tr><td>Среда</td><td>09:00</td><td>13:00</td><td>18:00</td></tr>
    <tr><td>Четверг</td><td>09:00</td><td>13:00</td><td>18:00</td></tr>
    <tr><td>Пятница</td><td>09:00</td><td>13:00</td><td>17:00</td></tr>
  </tbody>

  <tbody>
    <tr><th colspan="4">Выходные</th></tr>
    <tr><td>Суббота</td><td>10:00</td><td>14:00</td><td>16:00</td></tr>
    <tr><td>Воскресенье</td><td colspan="3">Выходной</td></tr>
  </tbody>
</table>
```

> **Порядок в HTML:** Согласно спецификации порядок должен быть: `caption`, `colgroup`, `thead`, `tbody` (или `tr`), `tfoot`. Однако парсеры браузеров исправляют неправильный порядок. В рендеринге `tfoot` всегда отображается внизу, даже если расположен в HTML перед `tbody`.

> **Поведение при печати:** Браузеры повторяют `thead` и `tfoot` на каждой печатной странице при разрыве таблицы — это основная практическая причина использовать эти элементы.

### th — заголовочная ячейка

Элемент `<th>` определяет заголовочную ячейку. В отличие от `<td>`, по умолчанию имеет жирное начертание и центрированный текст.

| Атрибут   | Описание                                             |
|-----------|------------------------------------------------------|
| `scope`   | Определяет, для чего ячейка является заголовком      |
| `abbr`    | Сокращённое описание заголовка                        |
| `headers` | ID заголовков, к которым относится ячейка              |
| `colspan` | Количество колонок, которые занимает ячейка            |
| `rowspan` | Количество строк, которые занимает ячейка              |

Значения `scope`:

| Значение   | Описание                                        |
|------------|-------------------------------------------------|
| `col`      | Заголовок для колонки                            |
| `row`      | Заголовок для строки                             |
| `colgroup` | Заголовок для группы колонок                     |
| `rowgroup` | Заголовок для группы строк (tbody)               |

```html
<thead>
  <tr>
    <th scope="col">Продукт</th>
    <th scope="col" abbr="Кол-во">Количество на складе</th>
    <th scope="col" abbr="Цена">Цена за единицу (руб.)</th>
  </tr>
</thead>
<tbody>
  <tr>
    <th scope="row">Ноутбук XYZ</th>
    <td>42</td>
    <td>89,990</td>
  </tr>
</tbody>
```

### td — ячейка данных

```html
<td>Простое значение</td>

<!-- С объединением ячеек -->
<td colspan="2" rowspan="3">Объединённая ячейка</td>

<!-- С привязкой к заголовкам -->
<td headers="product-col q1-col">1,200</td>
```

### HTMLTableElement API

```javascript
const table = document.querySelector('table');

// Коллекции
table.rows;        // HTMLCollection всех строк
table.tBodies;     // HTMLCollection всех tbody
table.tHead;       // HTMLTableSectionElement или null
table.tFoot;       // HTMLTableSectionElement или null
table.caption;     // HTMLTableCaptionElement или null

// Создание секций
table.createTHead();    // Создаёт/возвращает thead
table.createTBody();    // Создаёт/возвращает tbody
table.createTFoot();    // Создаёт/возвращает tfoot
table.createCaption();  // Создаёт/возвращает caption

// Удаление секций
table.deleteTHead();
table.deleteTFoot();
table.deleteCaption();

// Работа со строками
table.insertRow(index);  // Вставляет строку (index = -1 → в конец)
table.deleteRow(index);  // Удаляет строку

// Работа со строками и ячейками
const row = table.insertRow(-1);
const cell1 = row.insertCell(0);
const cell2 = row.insertCell(1);
cell1.textContent = 'Новая ячейка';
cell2.textContent = 'Ещё одна';

// Индексы
row.rowIndex;     // Индекс строки в таблице
row.sectionRowIndex; // Индекс строки в секции (tbody/thead/tfoot)
cell1.cellIndex;  // Индекс ячейки в строке
```

### CSS для таблиц

```css
/* Схлопывание границ (модель CSS) */
table {
  border-collapse: collapse; /* Объединить границы ячеек */
  /* border-collapse: separate; — по умолчанию, с промежутком */
  /* border-spacing: 2px; — промежуток при separate */

  width: 100%;
  table-layout: fixed; /* Фиксированная ширина колонок (быстрее) */
  /* table-layout: auto; — по умолчанию, ширина по содержимому */
}

th, td {
  padding: 12px 16px;
  border: 1px solid #ddd;
  text-align: left;
  vertical-align: top;
}

thead th {
  background-color: #f5f5f5;
  font-weight: 600;
  position: sticky;
  top: 0;
  z-index: 1;
}

/* Чередование строк */
tbody tr:nth-child(even) {
  background-color: #fafafa;
}

tbody tr:hover {
  background-color: #e8f4f8;
}

/* Горизонтальные линии */
tbody tr {
  border-bottom: 1px solid #eee;
}
```

#### table-layout: fixed vs auto

| Свойство           | `auto` (default)              | `fixed`                        |
|--------------------|-------------------------------|--------------------------------|
| Расчёт ширины      | По содержимому всех ячеек     | По первой строке               |
| Производительность  | Медленно (все ячейки)         | Быстро (только первая строка)  |
| Переполнение        | Ячейки расширяются            | Содержимое обрезается          |
| Рендеринг           | После полной загрузки         | Прогрессивный                  |

```css
/* Для больших таблиц используйте fixed */
table {
  table-layout: fixed;
  width: 100%;
}

/* Управление шириной колонок при fixed layout */
th:nth-child(1) { width: 30%; }
th:nth-child(2) { width: 20%; }
th:nth-child(3) { width: 50%; }

/* Обработка переполнения при fixed */
td {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

> **Performance:** Для таблиц с сотнями строк `table-layout: fixed` значительно быстрее, так как браузер не ждёт загрузки всего содержимого для расчёта ширины колонок. Рендеринг начинается сразу.

## 2. Colspan, rowspan — объединение ячеек

### colspan — объединение по горизонтали

```html
<table>
  <thead>
    <tr>
      <th>Продукт</th>
      <th colspan="2">Цены</th>
      <th>Наличие</th>
    </tr>
    <tr>
      <th></th>
      <th>Оптовая</th>
      <th>Розничная</th>
      <th></th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Товар A</td>
      <td>500</td>
      <td>750</td>
      <td>В наличии</td>
    </tr>
  </tbody>
</table>
```

### rowspan — объединение по вертикали

```html
<table>
  <thead>
    <tr>
      <th>Отдел</th>
      <th>Сотрудник</th>
      <th>Должность</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row" rowspan="3">Разработка</th>
      <td>Иванов А.</td>
      <td>Senior Developer</td>
    </tr>
    <tr>
      <!-- th с rowspan=3 занимает это место -->
      <td>Петрова Б.</td>
      <td>Middle Developer</td>
    </tr>
    <tr>
      <!-- th с rowspan=3 занимает это место -->
      <td>Сидоров В.</td>
      <td>Junior Developer</td>
    </tr>
    <tr>
      <th scope="row" rowspan="2">Дизайн</th>
      <td>Козлова Г.</td>
      <td>UI Designer</td>
    </tr>
    <tr>
      <td>Новикова Д.</td>
      <td>UX Researcher</td>
    </tr>
  </tbody>
</table>
```

### Gotchas при объединении ячеек

> **Gotcha 1:** При использовании `rowspan` или `colspan` количество ячеек в строке должно быть согласованным. Если заголовочная строка имеет 4 колонки, и одна ячейка данных занимает `colspan="2"`, в этой строке должно быть 3 элемента `<td>`/`<th>`.

> **Gotcha 2:** `rowspan="0"` означает "до конца rowgroup (tbody/thead/tfoot)", а не "ноль строк". Это полезно, но плохо поддерживается.

> **Gotcha 3:** Пересечение `rowspan` и `colspan` может создать "дыры" в таблице, если расчёт неверен. Браузер не выдаёт ошибку — просто рендерит некорректную таблицу. Используйте визуальные инструменты или табличные редакторы для проектирования сложных таблиц.

```html
<!-- Ошибка: "дыра" в таблице -->
<table>
  <tr>
    <td rowspan="2">A</td>
    <td>B</td>
    <td>C</td>
  </tr>
  <tr>
    <td>D</td>
    <td>E</td>
    <!-- Ошибка! A занимает первую колонку, D и E — 2-ю и 3-ю. Лишних нет.
         Но если забыть учесть rowspan и добавить ячейку, получится сдвиг -->
  </tr>
</table>
```

### Программное создание сложных таблиц

```javascript
function createScheduleTable(data) {
  const table = document.createElement('table');
  const thead = table.createTHead();
  const tbody = table.createTBody();

  // Заголовки
  const headerRow = thead.insertRow();
  data.headers.forEach(header => {
    const th = document.createElement('th');
    th.scope = 'col';
    th.textContent = header;
    headerRow.appendChild(th);
  });

  // Данные с учётом объединений
  const occupied = new Set(); // Отслеживаем занятые ячейки

  data.rows.forEach((rowData, rowIndex) => {
    const row = tbody.insertRow();
    let colIndex = 0;

    rowData.forEach(cellData => {
      // Пропускаем занятые ячейки
      while (occupied.has(`${rowIndex}-${colIndex}`)) {
        colIndex++;
      }

      const cell = row.insertCell();
      cell.textContent = cellData.text;

      if (cellData.colspan) cell.colSpan = cellData.colspan;
      if (cellData.rowspan) {
        cell.rowSpan = cellData.rowspan;
        // Помечаем занятые ячейки
        for (let r = 1; r < cellData.rowspan; r++) {
          for (let c = 0; c < (cellData.colspan || 1); c++) {
            occupied.add(`${rowIndex + r}-${colIndex + c}`);
          }
        }
      }

      colIndex += cellData.colspan || 1;
    });
  });

  return table;
}
```

## 3. Accessibility таблиц

### Scope — основа навигации

Атрибут `scope` на `<th>` позволяет screen readers правильно ассоциировать данные с заголовками при навигации по ячейкам.

```html
<table>
  <caption>Результаты экзаменов</caption>
  <thead>
    <tr>
      <th scope="col">Студент</th>
      <th scope="col">Математика</th>
      <th scope="col">Физика</th>
      <th scope="col">Информатика</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Иванов А.</th>
      <td>85</td>
      <td>92</td>
      <td>78</td>
    </tr>
    <tr>
      <th scope="row">Петрова Б.</th>
      <td>91</td>
      <td>88</td>
      <td>95</td>
    </tr>
  </tbody>
</table>
```

При навигации screen reader в ячейке "92" объявит: "Физика, Иванов А., 92".

### Headers — для сложных таблиц

Для таблиц с несколькими уровнями заголовков или нестандартной структурой используется атрибут `headers`, который явно указывает ID заголовков.

```html
<table>
  <caption>Продажи по регионам и кварталам</caption>
  <thead>
    <tr>
      <th id="region" rowspan="2" scope="col">Регион</th>
      <th id="sales" colspan="4" scope="colgroup">Продажи</th>
      <th id="total" rowspan="2" scope="col">Итого</th>
    </tr>
    <tr>
      <th id="q1" scope="col">Q1</th>
      <th id="q2" scope="col">Q2</th>
      <th id="q3" scope="col">Q3</th>
      <th id="q4" scope="col">Q4</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th id="moscow" scope="row">Москва</th>
      <td headers="moscow q1 sales">1,200</td>
      <td headers="moscow q2 sales">1,350</td>
      <td headers="moscow q3 sales">1,100</td>
      <td headers="moscow q4 sales">1,500</td>
      <td headers="moscow total">5,150</td>
    </tr>
    <tr>
      <th id="spb" scope="row">Санкт-Петербург</th>
      <td headers="spb q1 sales">800</td>
      <td headers="spb q2 sales">950</td>
      <td headers="spb q3 sales">1,200</td>
      <td headers="spb q4 sales">1,100</td>
      <td headers="spb total">4,050</td>
    </tr>
  </tbody>
</table>
```

> **Когда использовать headers vs scope:** Используйте `scope` для простых таблиц (одноуровневые заголовки). Используйте `headers` для сложных таблиц с множественными уровнями заголовков, объединёнными ячейками или нестандартной структурой. `headers` более надёжен, но более многословен.

### caption vs summary vs aria-describedby

```html
<!-- caption — обязательный заголовок/название -->
<table>
  <caption>Квартальные продажи 2025</caption>
  <!-- ... -->
</table>

<!-- summary — устарел в HTML5! Не используйте -->
<table summary="Таблица показывает продажи по кварталам...">
  <!-- DEPRECATED -->
</table>

<!-- Альтернатива summary: aria-describedby -->
<p id="table-desc" class="sr-only">
  Таблица содержит данные о квартальных продажах трёх продуктов.
  Строки — продукты, столбцы — кварталы. Последний столбец — итого.
</p>
<table aria-describedby="table-desc">
  <caption>Квартальные продажи</caption>
  <!-- ... -->
</table>
```

```html
        <th scope="col" id="tue-col">Вторник</th>
```

### Навигация screen reader по таблице

Основные клавиши навигации (NVDA/JAWS):

| Клавиша         | Действие                          |
|-----------------|-----------------------------------|
| `T`             | Перейти к следующей таблице       |
| `Shift+T`       | Перейти к предыдущей таблице      |
| `Ctrl+Alt+→`   | Следующая ячейка в строке          |
| `Ctrl+Alt+←`   | Предыдущая ячейка в строке         |
| `Ctrl+Alt+↓`   | Следующая ячейка в колонке         |
| `Ctrl+Alt+↑`   | Предыдущая ячейка в колонке        |

> **Тестирование:** Всегда проверяйте сложные таблицы с реальным screen reader. Ошибки в `scope`/`headers` легко допустить, и они критически влияют на понимание таблицы незрячими пользователями.

### Чеклист доступности таблиц

1. `<caption>` описывает содержимое таблицы
2. `<th>` с `scope` для всех заголовочных ячеек
3. `headers` для сложных таблиц с объединёнными ячейками
4. Таблица НЕ используется для layout (только для данных)
5. Пустые ячейки содержат `—` или `&nbsp;`, не оставлены пустыми
6. `aria-describedby` для пояснений к сложным таблицам
7. Таблица обёрнута в `<div role="region" tabindex="0">` для scroll overflow
8. Цветовой контраст заголовков и данных достаточен

## 4. Responsive таблицы

### Паттерн 1: Горизонтальный скролл

Наиболее простой и надёжный паттерн:

```html
<div class="table-wrapper" role="region" aria-labelledby="table-caption" tabindex="0">
  <table>
    <caption id="table-caption">Данные о продажах</caption>
    <!-- ... -->
  </table>
</div>
```

```css
.table-wrapper {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch; /* Плавный скролл на iOS */
  max-width: 100%;
}

/* Индикатор скролла */
.table-wrapper {
  position: relative;
}

.table-wrapper::after {
  content: '';
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  width: 40px;
  background: linear-gradient(to right, transparent, rgba(255,255,255,0.8));
  pointer-events: none;
  opacity: 1;
  transition: opacity 0.3s;
}

/* Скрыть индикатор, если нет скролла */
.table-wrapper:not(.has-scroll)::after {
  opacity: 0;
}
```

```javascript
// Определение необходимости скролла
const wrapper = document.querySelector('.table-wrapper');
const table = wrapper.querySelector('table');

function checkScroll() {
  if (table.offsetWidth > wrapper.offsetWidth) {
    wrapper.classList.add('has-scroll');
  } else {
    wrapper.classList.remove('has-scroll');
  }
}

window.addEventListener('resize', checkScroll);
checkScroll();
```

### Паттерн 2: Стековый (карточный) layout

Преобразование таблицы в стопку карточек на мобильных:

```html
<table class="responsive-table">
  <thead>
    <tr>
      <th>Имя</th>
      <th>Email</th>
      <th>Должность</th>
      <th>Город</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td data-label="Имя">Иванов Алексей</td>
      <td data-label="Email">ivanov@example.com</td>
      <td data-label="Должность">Senior Developer</td>
      <td data-label="Город">Москва</td>
    </tr>
    <tr>
      <td data-label="Имя">Петрова Мария</td>
      <td data-label="Email">petrova@example.com</td>
      <td data-label="Должность">UX Designer</td>
      <td data-label="Город">Санкт-Петербург</td>
    </tr>
  </tbody>
</table>
```

```css
@media (max-width: 768px) {
  .responsive-table thead {
    /* Визуально скрываем, но доступно для screen readers */
    position: absolute;
    width: 1px;
    height: 1px;
    padding: 0;
    margin: -1px;
    overflow: hidden;
    clip: rect(0, 0, 0, 0);
    border: 0;
  }

  .responsive-table tr {
    display: block;
    margin-bottom: 16px;

    border-bottom: none;

```

> **Accessibility:** Стековый паттерн сохраняет `<thead>` визуально скрытым, но доступным для screen readers. Атрибут `data-label` используется только для визуального отображения. Screen reader по-прежнему навигирует по таблице стандартным способом.

```html
      <th class="priority-low">Дата регистрации</th>
    </tr>
  </thead>
  <tbody>
    <tr>
```

```css
@media (max-width: 480px) {
```

### Паттерн 5: Sticky Header

```css

  top: 0;
  background: white;
  box-shadow: 0 1px 0 #ddd;
  z-index: 1;
}
```

> **Gotcha:** `position: sticky` на `<thead>` не работает в некоторых браузерах, когда `border-collapse: collapse` установлен на `<table>`. Решение — применять sticky к `<th>` напрямую и использовать `box-shadow` вместо `border-bottom`.

## 5. col и colgroup — стилизация колонок

### Базовое использование

`<colgroup>` и `<col>` позволяют применять стили к целым колонкам без использования классов на каждой ячейке.

```html
<table>
  <caption>Бюджет проекта</caption>

  <colgroup>
    <col class="col-category">
    <col class="col-planned">
    <col class="col-actual">
    <col class="col-diff">
  </colgroup>

  <thead>
    <tr>
      <th scope="col">Категория</th>
      <th scope="col">План</th>
      <th scope="col">Факт</th>
      <th scope="col">Разница</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Разработка</th>
      <td>500,000</td>
      <td>480,000</td>
      <td>-20,000</td>
    </tr>
  </tbody>
</table>
```

```css
.col-category { width: 200px; }
.col-planned  { width: 150px; background-color: #f0f7ff; }
.col-actual   { width: 150px; background-color: #f0fff0; }
.col-diff     { width: 150px; background-color: #fff0f0; }
```

### Группировка колонок

```html
<colgroup>
  <!-- Одна колонка -->
  <col>

  <!-- Группа из 4 колонок с одним стилем -->
  <col span="4" class="quarter-columns">

  <!-- Одна колонка -->
  <col class="total-column">
</colgroup>
```

### Допустимые CSS-свойства для col

Спецификация ограничивает CSS-свойства, применимые к `<col>`:

| Свойство           | Поддержка | Примечание                                    |
|--------------------|-----------|-----------------------------------------------|
| `width`            | Да        | Устанавливает ширину колонки                   |
| `background`       | Да        | Фон колонки (ниже фона ячеек)                  |
| `border`           | Да        | Только при `border-collapse: collapse`          |
| `visibility`       | Да        | Только `collapse` для скрытия                   |

> **Ограничение:** Стили на `<col>` имеют низкий приоритет. Стили на `<td>` и `<th>` перезаписывают стили `<col>`. Background `<col>` виден только если ячейка не имеет своего фона (прозрачный). Порядок слоёв: table → colgroup → col → tbody → tr → td.

```css
/* Скрытие колонки */
.hidden-col {
  visibility: collapse; /* Скрывает колонку, пространство освобождается */
}
```

> **Gotcha:** `visibility: collapse` на `<col>` должен работать аналогично `display: none`, но поведение нестабильно между браузерами. Chrome может не корректно пересчитывать ширину. Для надёжного скрытия колонок лучше использовать CSS на ячейках: `td:nth-child(3), th:nth-child(3) { display: none; }`.

### Подсветка колонки при наведении

```css
/* CSS-only подсветка колонки (через col hover) */
col {
  transition: background-color 0.2s;
}

col:hover {
  background-color: rgba(52, 152, 219, 0.1);
}
```

> **Примечание:** `col:hover` работает, но hover зона — это фон между ячейками. На практике hover на `<col>` ненадёжен. Для реальной подсветки колонок используйте JavaScript:

```javascript
const table = document.querySelector('table');

table.addEventListener('mouseover', (e) => {
  const cell = e.target.closest('td, th');
  if (!cell) return;

  const colIndex = cell.cellIndex;
  table.querySelectorAll(`td:nth-child(${colIndex + 1}), th:nth-child(${colIndex + 1})`)
    .forEach(c => c.classList.add('highlight'));
});

table.addEventListener('mouseout', (e) => {
  table.querySelectorAll('.highlight')
    .forEach(c => c.classList.remove('highlight'));
});
```

## 6. Неупорядоченные списки ul

### Семантика

`<ul>` представляет неупорядоченный список элементов, где порядок не имеет значения. Каждый элемент — `<li>`.

```html
<ul>
  <li>JavaScript</li>
  <li>TypeScript</li>
  <li>Python</li>
  <li>Go</li>
</ul>
```

### Вложенные списки

```html
<ul>
  <li>
    Frontend
    <ul>
      <li>
        JavaScript
        <ul>
          <li>React</li>
          <li>Vue</li>
          <li>Angular</li>
        </ul>
      </li>
      <li>CSS</li>
      <li>HTML</li>
    </ul>
  </li>
  <li>
    Backend
    <ul>
      <li>Node.js</li>
      <li>Python</li>
      <li>Go</li>
    </ul>
  </li>
</ul>
```

> **Важно:** Вложенный `<ul>` (или `<ol>`) должен находиться ВНУТРИ `<li>`, а не рядом с ним. Неправильное размещение — между `</li>` и `<li>` — невалидно и может сломать accessibility.

```html
<!-- НЕПРАВИЛЬНО -->
<ul>
  <li>Frontend</li>
  <ul>
    <li>React</li>
  </ul>
  <li>Backend</li>
</ul>

<!-- ПРАВИЛЬНО -->
<ul>
  <li>
    Frontend
    <ul>
      <li>React</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
```

### Стилизация маркеров

```css
/* Типы маркеров */
ul { list-style-type: disc; }      /* По умолчанию: заполненный круг */
ul { list-style-type: circle; }    /* Пустой круг */
ul { list-style-type: square; }    /* Квадрат */
ul { list-style-type: none; }      /* Без маркера */

/* Кастомные маркеры */
ul { list-style-type: '→ '; }     /* Символ */
ul { list-style-type: '\2714 '; } /* Unicode символ ✔ */

/* Изображение как маркер */
ul { list-style-image: url('bullet.svg'); }

/* Позиция маркера */
ul { list-style-position: outside; } /* По умолчанию: за пределами контента */
ul { list-style-position: inside; }  /* Внутри контентной области */

/* Современный способ: ::marker */
li::marker {
  color: #3498db;
  font-size: 1.2em;
  content: '▸ ';
}

/* Разные маркеры по уровню вложенности */
ul { list-style-type: disc; }
ul ul { list-style-type: circle; }
ul ul ul { list-style-type: square; }
```

### Псевдоэлемент ::marker

```css
li::marker {
  color: #e74c3c;
  font-weight: bold;
  content: counter(list-item) ') '; /* Нумерация для ul через CSS */
}

/* Ограниченные свойства ::marker */
/* Поддерживаются: color, content, direction, font-*,
   unicode-bidi, white-space, text-combine-upright,
   animation-*, transition-* */
```

### Удаление стилей списка

```css
/* При list-style: none убирается семантика списка в Safari VoiceOver */
ul {
  list-style: none;
  padding: 0;
  margin: 0;
}

/* Решение: добавить role="list" в HTML */
```

```html
<!-- При удалении list-style в Safari нужен role="list" -->
<ul role="list" class="no-bullets">
  <li>Элемент</li>
</ul>
```

> **Gotcha:** Safari VoiceOver удаляет семантику списка при `list-style: none`. Это осознанное решение Apple — они считают, что стилизованные списки обычно используются не как семантические списки. Для сохранения семантики добавьте `role="list"` на `<ul>`.

## 7. Упорядоченные списки ol

### Базовая структура

`<ol>` представляет упорядоченный список, где порядок элементов значим.

```html
<ol>
  <li>Подготовить окружение</li>
  <li>Установить зависимости</li>
  <li>Настроить конфигурацию</li>
  <li>Запустить приложение</li>
</ol>
```

### Атрибут start

Определяет начальное число нумерации.

```html
<!-- Продолжение нумерации -->
<ol start="5">
  <li>Шаг 5</li>
  <li>Шаг 6</li>
  <li>Шаг 7</li>
</ol>
```

### Атрибут reversed

Обратный порядок нумерации (от большего к меньшему).

```html
<!-- Топ-5 (обратный отсчёт) -->
<h2>Топ 5 языков программирования 2026</h2>
<ol reversed>
  <li>Go</li>        <!-- 5 -->
  <li>Rust</li>      <!-- 4 -->
  <li>TypeScript</li><!-- 3 -->
  <li>Python</li>    <!-- 2 -->
  <li>JavaScript</li><!-- 1 -->
</ol>
```

### Атрибут type

Определяет тип нумерации.

| Значение | Описание                    | Пример              |
|----------|-----------------------------|----------------------|
| `1`      | Десятичные числа (default)  | 1, 2, 3, 4          |
| `a`      | Строчные латинские буквы    | a, b, c, d          |
| `A`      | Заглавные латинские буквы   | A, B, C, D          |
| `i`      | Строчные римские цифры      | i, ii, iii, iv      |
| `I`      | Заглавные римские цифры     | I, II, III, IV      |

```html
<ol type="I">
  <li>Введение</li>
  <li>Основная часть
    <ol type="1">
      <li>Глава 1
        <ol type="a">
          <li>Подраздел a</li>
          <li>Подраздел b</li>
        </ol>
      </li>
      <li>Глава 2</li>
    </ol>
  </li>
  <li>Заключение</li>
</ol>
```

### Атрибут value на li

Переопределяет номер конкретного элемента. Последующие элементы нумеруются от этого значения.

```html
<ol>
  <li>Первый</li>          <!-- 1 -->
  <li>Второй</li>          <!-- 2 -->
  <li value="10">Десятый</li> <!-- 10 -->
  <li>Одиннадцатый</li>    <!-- 11 -->
</ol>
```

### CSS нумерация (CSS Counters)

CSS Counters дают полный контроль над нумерацией:

```css
/* Кастомная нумерация через counters */
ol.custom {
  list-style: none;
  counter-reset: custom-counter;
  padding-left: 0;
}

ol.custom li {
  counter-increment: custom-counter;
  padding-left: 40px;
  position: relative;
  margin-bottom: 8px;
}

ol.custom li::before {
  content: counter(custom-counter, decimal-leading-zero) '.';
  position: absolute;
  left: 0;
  font-weight: bold;
  color: #3498db;
}

/* Вложенная нумерация: 1.1, 1.2, 2.1 и т.д. */
ol.nested {
  list-style: none;
  counter-reset: section;
}

ol.nested li {
  counter-increment: section;
}

ol.nested li::before {
  content: counters(section, '.') ' ';
  font-weight: bold;
}
```

```html
<ol class="nested">
  <li>Введение
    <ol class="nested">
      <li>Предисловие</li>         <!-- 1.1 -->
      <li>Благодарности</li>       <!-- 1.2 -->
    </ol>
  </li>
  <li>Основы
    <ol class="nested">
      <li>Переменные</li>          <!-- 2.1 -->
      <li>Типы данных</li>         <!-- 2.2 -->
      <li>Операторы</li>           <!-- 2.3 -->
    </ol>
  </li>
</ol>
```

### Accessibility ordered list

```html
<!-- Screen reader объявляет: "list, 5 items" при входе -->
<!-- И номер каждого элемента при навигации -->
<ol>
  <li>Шаг первый</li>   <!-- "1. Шаг первый" -->
  <li>Шаг второй</li>   <!-- "2. Шаг второй" -->
</ol>

<!-- Для CSS-нумерованных списков убедитесь, что role="list" сохранён -->
<ol role="list" class="custom-numbered">
  <li>Элемент</li>
</ol>
```

## 8. Списки определений dl

### Базовая структура

`<dl>` — список определений (description list). Состоит из пар терминов (`<dt>`) и определений (`<dd>`).

```html
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language — язык гипертекстовой разметки</dd>

  <dt>CSS</dt>
  <dd>Cascading Style Sheets — каскадные таблицы стилей</dd>

  <dt>JavaScript</dt>
  <dd>Скриптовый язык программирования для создания интерактивных веб-страниц</dd>
</dl>
```

### Множественные dt и dd

```html
<!-- Несколько терминов для одного определения -->
<dl>
  <dt>HTML</dt>
  <dt>HyperText Markup Language</dt>
  <dd>Язык гипертекстовой разметки для создания веб-страниц</dd>
</dl>

<!-- Один термин с несколькими определениями -->
<dl>
  <dt>JavaScript</dt>
  <dd>Скриптовый язык программирования (ECMAScript)</dd>
```

## 9. Accessibility списков

### Role list

Браузеры автоматически назначают роли спискам:

| Элемент | Роль по умолчанию | Screen Reader      |
|---------|-------------------|--------------------|
| `<ul>`  | `list`            | "list, N items"    |
| `<ol>`  | `list`            | "list, N items"    |
| `<li>`  | `listitem`        | "N of N, text"     |
| `<dl>`  | Нет специальной*  | Зависит от SR      |
| `<dt>`  | `term`            | "term: text"       |
| `<dd>`  | `definition`      | "definition: text" |

> *Примечание: `<dl>` не имеет стандартной ARIA-роли `list`. Screen readers обрабатывают его по-разному. NVDA может объявить "definition list", VoiceOver может не объявлять его как список.

### aria-label для списков

```html
<!-- Навигационный список с именем -->
<nav aria-label="Основная навигация">
  <ul>
    <li><a href="/">Главная</a></li>
    <li><a href="/catalog">Каталог</a></li>
    <li><a href="/about">О нас</a></li>
  </ul>
</nav>

<!-- Список с контекстом -->
<h2 id="ingredients-heading">Ингредиенты</h2>
<ul aria-labelledby="ingredients-heading">
  <li>Мука — 500 г</li>
  <li>Яйца — 3 шт.</li>
  <li>Молоко — 250 мл</li>
</ul>
```

### Навигация по спискам в screen readers

| Screen Reader | Переход к списку | Перебор элементов      |
|---------------|------------------|------------------------|
| NVDA          | `L`              | `I` (следующий item)   |
| JAWS          | `L`              | `I`                    |
| VoiceOver     | `VO+Command+L`   | Стрелки                |

### Роли для кастомных списков

```html

  </article>

    <h3>Заголовок новости 2</h3>
```

### Проблемы accessibility со списками

```html
<!-- Проблема 1: использование br вместо списка -->
<!-- НЕПРАВИЛЬНО -->
<p>
  Молоко<br>
  Хлеб<br>
  Яйца<br>
</p>

<!-- ПРАВИЛЬНО -->
<ul>
  <li>Молоко</li>
  <li>Хлеб</li>
  <li>Яйца</li>
</ul>

<!-- Проблема 2: вложенные ссылки в li -->
<!-- НЕПРАВИЛЬНО: двойная ссылка -->
<li>
  <a href="/page">
    <h3><a href="/page">Заголовок</a></h3>
  </a>
</li>

<!-- ПРАВИЛЬНО -->
<li>
  <a href="/page">
    <h3>Заголовок</h3>
  </a>
</li>

<!-- Проблема 3: пустые li -->
<!-- НЕПРАВИЛЬНО -->
<ul>
  <li></li>
  <li>Элемент</li>
</ul>

<!-- Screen reader объявит: "bullet" для пустого элемента -->
```

### Чеклист доступности списков

1. Используйте `<ul>` для неупорядоченных данных, `<ol>` для упорядоченных
2. Каждый `<li>` содержит значимое содержимое
3. Вложенные списки находятся внутри `<li>`
4. `role="list"` добавлен при `list-style: none` (для Safari)
5. Навигационные списки обёрнуты в `<nav>` с `aria-label`
6. Длинные списки имеют заголовок через `aria-labelledby`
7. Не используются списки для визуальной разметки (отступы, маркеры)
8. `<dl>` используется для семантических пар термин-определение

## 10. Практические паттерны

### Когда таблица vs CSS Grid

| Сценарий                      | Используйте       | Причина                                    |
|-------------------------------|--------------------|--------------------------------------------|
| Табличные данные (отчёты)     | `<table>`          | Семантика, accessibility, связь данных      |
| Layout страницы               | CSS Grid/Flexbox   | Таблицы для layout — антипаттерн            |
| Карточки товаров              | CSS Grid           | Не табличные данные                         |
| Расписание/календарь          | `<table>`          | Двумерные связанные данные                   |
| Сравнение тарифов             | `<table>`          | Данные с заголовками строк и колонок         |
| Dashboard с виджетами         | CSS Grid           | Layout, не данные                           |
| Форма с полями в сетке        | CSS Grid           | Layout формы                                |
| Результаты поиска             | `<ul>` / `<ol>`    | Список элементов, не двумерные данные        |
| Breadcrumbs                   | `<nav>` + `<ol>`   | Упорядоченная навигация                      |

> **Правило:** Если данные имеют отношения строка↔колонка (каждая ячейка определяется пересечением заголовка строки и заголовка колонки), это таблица. Если элементы просто визуально расположены в сетке, используйте CSS Grid.

```javascript
// Обработка сортировки
function sortTable(table, columnIndex, direction) {
  const tbody = table.tBodies[0];
  const rows = Array.from(tbody.rows);

  rows.sort((a, b) => {
    const aText = a.cells[columnIndex].textContent.trim();
    const bText = b.cells[columnIndex].textContent.trim();

    const comparison = aText.localeCompare(bText, 'ru', { numeric: true });
    return direction === 'ascending' ? comparison : -comparison;
  });

  // Перемещаем строки (без создания новых элементов)
  rows.forEach(row => tbody.appendChild(row));

  // Обновляем aria-sort
  table.querySelectorAll('th[aria-sort]').forEach(th => {
    th.setAttribute('aria-sort', 'none');
  });

  const th = table.querySelectorAll('th')[columnIndex];
  th.setAttribute('aria-sort', direction);

  // Объявляем изменение для screen readers
  const liveRegion = document.getElementById('sort-announcement');
  liveRegion.textContent = `Таблица отсортирована по ${th.textContent.trim()}, ${
    direction === 'ascending' ? 'по возрастанию' : 'по убыванию'
  }`;
}
```

### Виртуализированные списки/таблицы

Для огромных списков (тысячи элементов) используйте виртуализацию с правильной accessibility-разметкой:

```html
<!-- Контейнер виртуализированного списка -->
<div
  role="list"
  aria-label="Список товаров"
  aria-rowcount="10000"
  style="height: 600px; overflow-y: auto;"
>
  <!-- Только видимые элементы рендерятся -->
  <div role="listitem" aria-rowindex="1" style="transform: translateY(0px);">
    Товар 1
  </div>
  <div role="listitem" aria-rowindex="2" style="transform: translateY(40px);">
    Товар 2
  </div>
  <!-- ... -->
</div>
```

> **Важно:** `aria-rowcount` указывает общее количество элементов, а `aria-rowindex` — позицию каждого элемента. Это позволяет screen readers сообщать пользователю полный размер списка, даже если рендерится только часть элементов.

### Резюме: принципы выбора

| Нужно отобразить          | Элемент | Почему                                          |
|---------------------------|---------|--------------------------------------------------|
| Табличные данные           | `table` | Двумерные связи данных                            |
| Перечень элементов         | `ul`    | Порядок не важен                                  |
| Пошаговая инструкция       | `ol`    | Порядок важен                                     |
| Термины и определения      | `dl`    | Семантическая пара ключ-значение                  |
| Навигация                  | `nav > ul` | Навигационный контекст                          |
| Breadcrumbs                | `nav > ol` | Упорядоченная иерархия                          |
| Результаты поиска          | `ol`    | Ранжированные результаты                          |
| Теги/категории             | `ul`    | Неупорядоченная коллекция                         |
| Характеристики товара      | `dl`    | Пары свойство-значение                            |
| FAQ                        | `dl`    | Пары вопрос-ответ                                 |
| Лента новостей             | `ul` или `div[role="feed"]` | Коллекция статей              |
| Пагинация                  | `nav > ul` | Навигация по страницам                          |
