# Переменные (Variables)

> Переменные в Sass позволяют хранить значения и переиспользовать их.
> В отличие от CSS Custom Properties, Sass-переменные компилируются и исчезают из итогового CSS.

## 1. Синтаксис

Переменные объявляются как `$имя: значение` и могут быть объявлены в любом месте таблицы стилей.

```scss
$base-color: #c6538c;
$border-dark: rgba($base-color, 0.88);

.alert {
  border: 1px solid $border-dark;
}
```

---

## 2. Sass-переменные vs CSS-переменные

| Характеристика | Sass-переменные | CSS-переменные |
|---|---|---|
| Компиляция | Компилируются и исчезают | Остаются в CSS |
| Значения | Одно значение в момент времени | Разные значения для разных элементов |
| Поведение | Императивное (более ранние использования сохраняют свои значения) | Декларативное |
| Динамика | Статические (compile-time) | Динамические (runtime) |
| Область видимости | Лексическая (файл/блок) | Каскадная (DOM-дерево) |

```scss
$variable: value 1;
.rule-1 { value: $variable; }    // value 1

$variable: value 2;
.rule-2 { value: $variable; }    // value 2
```

## 3. Именование

Дефисы и подчеркивания взаимозаменяемы: `$font-size` и `$font_size` -- одна и та же переменная.

**Рекомендации по именованию:**
- Используйте kebab-case: `$primary-color`, `$base-font-size`
- Группируйте по назначению: `$color-primary`, `$color-secondary`
- Для тем и конфигурации добавляйте префикс: `$theme-bg`, `$config-breakpoint`

## 4. Значения по умолчанию (!default)

`!default` присваивает значение только если переменная еще не определена или равна `null`:

```scss
$black: #000 !default;
$border-radius: 0.25rem !default;
```

Это позволяет конфигурировать модули при подключении:

```scss
@use 'library' with (
  $black: #222,
  $border-radius: 0.1rem
);
```

Только переменные верхнего уровня с `!default` можно конфигурировать таким образом.

### Когда использовать !default

- В библиотеках и переиспользуемых модулях -- для всех конфигурируемых переменных
- В компонентах -- для значений, которые могут быть переопределены при подключении
- **Не используйте** в прикладном коде, где значение не предполагает переопределения

## 5. Область видимости (Scope)

**Глобальные переменные** -- объявлены на верхнем уровне файла, доступны везде после объявления.

**Локальные переменные** -- объявлены внутри блока `{}`, доступны только в этом блоке.

```scss
$global-variable: global value;

.content {
  $local-variable: local value;
  global: $global-variable;    // Работает
  local: $local-variable;      // Работает
}

.sidebar {
  global: $global-variable;    // Работает
  // local: $local-variable;   // Ошибка -- вне области видимости
}
```

---

## 6. Затенение (Shadowing)

Локальная переменная с тем же именем, что и глобальная, создает отдельный экземпляр, не перезаписывая родительское значение:

```scss
$variable: global value;

.content {
  $variable: local value;
  value: $variable;        // local value
}

.sidebar {
  value: $variable;        // global value
}
```

---

## 7. Флаг !global

`!global` модифицирует переменную в глобальной области из локального контекста:

```scss
$variable: first global value;

.content {
  $variable: second global value !global;
  value: $variable;       // second global value
}

.sidebar {
  value: $variable;       // second global value
}
```

**Ограничение:** `!global` можно использовать только для установки переменной, уже объявленной на верхнем уровне. Нельзя объявлять новую переменную через `!global`.

---

## 8. Область видимости в управлении потоком

Переменные в `@if`, `@each`, `@for`, `@while` **НЕ создают теневые копии** -- они присваивают значение существующим переменным внешней области:

```scss
$dark-theme: true !default;
$primary-color: #f8bbd0 !default;
$accent-color: #6a1b9a !default;

@if $dark-theme {
  $primary-color: darken($primary-color, 60%);
  $accent-color: lighten($accent-color, 60%);
}

.button {
  background-color: $primary-color;  // Затемненное значение
  border: 1px solid $accent-color;
}
```

> **Важно:** Это ключевое отличие от блоков `{}` в правилах стилей и миксинах, где создается новая область видимости.

## 9. Расширенные возможности

### Проверка существования

```scss
@use "sass:meta";
@debug meta.variable-exists("my-var");         // Текущая область
@debug meta.global-variable-exists("my-var");  // Глобальная область
```

### Динамические имена через карты

Интерполяция в именах переменных НЕ поддерживается. Вместо этого используйте карты (maps):

```scss
@use "sass:map";

$theme-colors: (
  "success": #28a745,
  "info": #17a2b8,
  "warning": #ffc107,
);

.alert {
  background-color: map.get($theme-colors, "warning");
}
```

### Паттерн конфигурационных карт

```scss
// _config.scss
$breakpoints: (
  "sm": 576px,
  "md": 768px,
  "lg": 992px,
  "xl": 1200px,
) !default;

// Использование
@mixin respond-to($breakpoint) {
  $value: map.get($breakpoints, $breakpoint);
  @if $value {
    @media (min-width: $value) { @content; }
  } @else {
    @error "Unknown breakpoint: #{$breakpoint}";
  }
}
```
