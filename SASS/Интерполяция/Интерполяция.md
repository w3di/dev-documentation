# Интерполяция (Interpolation)

> Интерполяция `#{}` позволяет встраивать SassScript-выражения в любое место
> CSS-вывода: селекторы, имена свойств, значения и комментарии.

## 1. Синтаксис

Интерполяция записывается как `#{выражение}`. Внутри фигурных скобок может быть любое SassScript-выражение.

```scss
$name: "card";
.#{$name} {
  // Компилируется в: .card { ... }
}
```

---

## 2. Где можно использовать

| Контекст | Пример |
|---|---|
| Селекторы в правилах стилей | `.icon-#{$name} { ... }` |
| Имена свойств в объявлениях | `#{$property}: value` |
| Значения Custom Properties | `--color: #{$var}` |
| CSS at-правила | `@media #{$query} { ... }` |
| Объявления `@extend` | `@extend #{$selector}` |
| CSS `@import` | `@import #{$url}` |
| Строки (в кавычках и без) | `"path/#{$file}"` |
| Специальные функции | `url("/icons/#{$name}.svg")` |
| Имена CSS-функций | `#{$fn}(args)` |
| Громкие комментарии | `/* #{$comment} */` |

---

## 3. Примеры

### В селекторах и свойствах

```scss
@mixin corner-icon($name, $top-or-bottom, $left-or-right) {
  .icon-#{$name} {
    background-image: url("/icons/#{$name}.svg");
    position: absolute;
    #{$top-or-bottom}: 0;
    #{$left-or-right}: 0;
  }
}

@include corner-icon("mail", top, left);
// .icon-mail { background-image: url("/icons/mail.svg"); position: absolute; top: 0; left: 0; }
```

### В @media

```scss
$breakpoint: 768px;
@media (min-width: #{$breakpoint}) {
  .container { max-width: 720px; }
}
```

### Генерация классов

```scss
$sizes: (sm: 576px, md: 768px, lg: 992px);

@each $name, $value in $sizes {
  .container-#{$name} {
    max-width: $value;
  }
}
```

## 4. В SassScript

Интерполяция внутри SassScript создает **некавыченную строку** (unquoted string). Это полезно для генерации динамических имен:

```scss
@mixin inline-animation($duration) {
  $name: inline-#{unique-id()};

  @keyframes #{$name} {
    @content;
  }

  animation-name: $name;
  animation-duration: $duration;
  animation-iteration-count: infinite;
}
```

## 5. Важные предупреждения

### Не используйте интерполяцию для значений свойств

```scss
// Плохо
color: #{$accent};

// Хорошо
color: $accent;
```

Интерполяция для значений не нужна и вредна -- она теряет типовую информацию.

### Не используйте интерполяцию с числами

```scss
// Плохо -- создает строку, а не число!
width: #{$width}px;

// Хорошо -- создает число с единицей
width: $width * 1px;
```

`#{$width}px` создает **строку** `"100px"`, а не число `100px`. С такой строкой невозможно выполнять математические операции.

### Строки в кавычках теряют кавычки

```scss
$str: "hello";
content: #{$str};  // content: hello (без кавычек!)
```

Для контролируемого преобразования используйте `string.unquote()` или `string.quote()`.
