# Миксины (@mixin и @include)

> Миксины -- один из главных инструментов переиспользования в Sass.
> Они позволяют определить блок стилей один раз и подключать его в любом месте,
> с параметрами, значениями по умолчанию и блоками контента.

## 1. Основы

Миксины определяются через `@mixin`, подключаются через `@include`:

```scss
@mixin reset-list {
  margin: 0;
  padding: 0;
  list-style: none;
}

@mixin horizontal-list {
  @include reset-list;
  li {
    display: inline-block;
    margin: { left: -2px; right: 2em; }
  }
}

nav ul { @include horizontal-list; }
```

Имена миксинов, как и все идентификаторы Sass, трактуют дефисы и подчеркивания одинаково: `reset-list` = `reset_list`.

## 2. Аргументы

### Обязательные аргументы

```scss
@mixin rtl($property, $ltr-value, $rtl-value) {
  #{$property}: $ltr-value;
  [dir=rtl] & { #{$property}: $rtl-value; }
}

.sidebar { @include rtl(float, left, right); }
```

### Необязательные аргументы (значения по умолчанию)

```scss
@mixin replace-text($image, $x: 50%, $y: 50%) {
  text-indent: -99999em;
  overflow: hidden;
  background: { image: $image; repeat: no-repeat; position: $x $y; }
}
```

Значения по умолчанию могут ссылаться на предыдущие аргументы.

### Именованные аргументы

Позволяют передавать аргументы в произвольном порядке:

```scss
.avatar { @include square(100px, $radius: 4px); }
```

## 3. Произвольные аргументы

### Позиционные (`...`)

```scss
@mixin order($height, $selectors...) {
  @for $i from 0 to length($selectors) {
    #{nth($selectors, $i + 1)} {
      position: absolute;
      height: $height;
      margin-top: $i * $height;
    }
  }
}
```

### Именованные (`meta.keywords()`)

```scss
@use "sass:meta";

@mixin syntax-colors($args...) {
  @each $name, $color in meta.keywords($args) {
    pre span.stx-#{$name} { color: $color; }
  }
}

@include syntax-colors($string: #080, $comment: #800, $variable: #60b);
```

### Передача произвольных аргументов

Списки и карты можно "развернуть" при вызове:

```scss
$form-selectors: "input.name", "input.address", "input.zip" !default;
@include order(150px, $form-selectors...);
```

## 4. Блоки контента (@content)

Миксины могут принимать целые блоки стилей:

```scss
@mixin hover {
  &:not([disabled]):hover {
    @content;
  }
}

.button {
  border: 1px solid black;
  @include hover {
    border-width: 2px;
  }
}
```

### Передача аргументов в @content (Dart Sass 1.15.0+)

```scss
@mixin media($types...) {
  @each $type in $types {
    @media #{$type} {
      @content($type);
    }
  }
}

@include media(screen, print) using ($type) {
  h1 {
    font-size: 40px;
    @if $type == print { font-family: Calluna; }
  }
}
```

### Область видимости @content

Блоки контента имеют **лексическую область видимости** -- видят переменные области, где были включены, а не области миксина:

```scss
$color: red;

@mixin test {
  $color: blue;
  @content;
}

.box {
  @include test {
    color: $color;  // red -- видит внешнюю переменную, не миксина
  }
}
```

## 5. Indented Syntax

В Indented Syntax используются сокращения `=` для определения и `+` для подключения:

```sass
=reset-list
  margin: 0
  padding: 0
  list-style: none

nav ul
  +reset-list
```

## Практические паттерны

### Медиа-запросы

```scss
@mixin respond-to($breakpoint) {
  @if $breakpoint == "sm" {
    @media (min-width: 576px) { @content; }
  } @else if $breakpoint == "md" {
    @media (min-width: 768px) { @content; }
  } @else if $breakpoint == "lg" {
    @media (min-width: 992px) { @content; }
  }
}

.sidebar {
  width: 100%;
  @include respond-to("md") { width: 50%; }
  @include respond-to("lg") { width: 33.3%; }
}
```

### Типографика

```scss
@mixin font($size, $weight: 400, $line-height: 1.5) {
  font-size: $size;
  font-weight: $weight;
  line-height: $line-height;
}

h1 { @include font(2rem, 700, 1.2); }
```

### Миксин vs функция vs @extend

| Инструмент | Когда использовать |
|---|---|
| `@mixin` | Блоки стилей с параметрами, `@content`, несемантическое переиспользование |
| `@function` | Вычисление и возврат одного значения |
| `@extend` | Семантическая связь ("является"), без параметров |
