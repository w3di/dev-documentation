# Функции (@function)

> Функции в Sass определяют переиспользуемые операции над значениями.
> В отличие от миксинов, функции возвращают одно значение и не генерируют CSS напрямую.

## 1. Основы

Функции определяют переиспользуемые операции над значениями. Должны содержать `@return`.

```scss
@function pow($base, $exponent) {
  $result: 1;
  @for $_ from 1 through $exponent {
    $result: $result * $base;
  }
  @return $result;
}

.sidebar { width: pow(2, 10) * 1px; } // width: 1024px
```

### Правила

- Имена функций не могут начинаться с `--`
- Дефисы и подчеркивания взаимозаменяемы
- Функции должны быть **чистыми** (без побочных эффектов). Для побочных эффектов используйте миксины

---

## 2. Аргументы

Такие же, как у миксинов: обязательные, необязательные, именованные, произвольные.

```scss
@function invert($color, $amount: 100%) {
  @return color.invert($color, $weight: $amount);
}
```

### Произвольные аргументы

```scss
@function sum($numbers...) {
  $total: 0;
  @each $number in $numbers {
    $total: $total + $number;
  }
  @return $total;
}

.box { width: sum(10px, 20px, 30px); } // 60px
```

---

## 3. @return

`@return` завершает функцию и возвращает значение. Допускает ранний возврат:

```scss
@function str-insert($string, $insert, $index) {
  @if string.length($string) == 0 {
    @return $insert;     // Ранний возврат
  }
  $before: string.slice($string, 0, $index);
  $after: string.slice($string, $index);
  @return $before + $insert + $after;
}
```

> **Каждая ветка функции должна содержать `@return`.** Sass выдаст ошибку, если функция завершится без возврата.

---

## 4. CSS-функции

Нераспознанные вызовы функций компилируются в обычные CSS-функции:

```scss
.box { filter: blur(5px); }  // Sass не знает blur(), передает как есть
```

> **Осторожно:** Опечатки в именах функций молча компилируются в CSS. Используйте CSS-линтеры!

## 5. Функции как значения

Функции можно получить как значения через `meta.get-function()` и вызвать через `meta.call()`:

```scss
@use "sass:list";
@use "sass:meta";
@use "sass:string";

@function remove-where($list, $condition) {
  $new-list: ();
  $separator: list.separator($list);
  @each $element in $list {
    @if not meta.call($condition, $element) {
      $new-list: list.append($new-list, $element, $separator: $separator);
    }
  }
  @return $new-list;
}

$fonts: Tahoma, Geneva, "Helvetica Neue", Helvetica, Arial, sans-serif;

.content {
  @function contains-helvetica($string) {
    @return string.index($string, "Helvetica");
  }
  font-family: remove-where($fonts, meta.get-function("contains-helvetica"));
}
// font-family: Tahoma, Geneva, Arial, sans-serif;
```

## Практические примеры

### Конвертация единиц

```scss
@use "sass:math";

@function px-to-rem($px, $base: 16px) {
  @return math.div($px, $base) * 1rem;
}

h1 { font-size: px-to-rem(32px); } // 2rem
```

### Работа с цветами

```scss
@use "sass:color";

@function tint($color, $percentage) {
  @return color.mix(white, $color, $percentage);
}

@function shade($color, $percentage) {
  @return color.mix(black, $color, $percentage);
}

.box { background: tint(#036, 20%); }
```

### Z-index менеджмент

```scss
@use "sass:map";

$z-layers: (
  "modal": 100,
  "dropdown": 50,
  "header": 30,
  "default": 1,
);

@function z($layer) {
  $value: map.get($z-layers, $layer);
  @if $value == null {
    @error "Unknown z-index layer: #{$layer}";
  }
  @return $value;
}

.modal { z-index: z("modal"); } // z-index: 100
```
