# Операторы (Operators)

> Sass поддерживает операторы равенства, сравнения, числовые, строковые и булевы.
> Правила сравнения зависят от типа данных, а единицы автоматически конвертируются.

## 1. Порядок приоритета

От высшего к низшему:

| Приоритет | Операторы |
|---|---|
| 1 (высший) | Унарные: `not`, `+`, `-`, `/` |
| 2 | Умножение/деление: `*`, `/`, `%` |
| 3 | Сложение/вычитание: `+`, `-` |
| 4 | Сравнение: `>`, `>=`, `<`, `<=` |
| 5 | Равенство: `==`, `!=` |
| 6 | Логическое И: `and` |
| 7 | Логическое ИЛИ: `or` |
| 8 (низший) | Присваивание: `=` |

Скобки `()` переопределяют приоритет.

## 2. Операторы равенства

`==` и `!=` -- правила сравнения зависят от типа:

| Тип | Правило |
|---|---|
| Числа | Одинаковое значение и единицы (или конвертируемые): `96px == 1in` |
| Строки | Кавыченные и некавыченные с одинаковым содержимым равны: `"Helvetica" == Helvetica` |
| Цвета | В одном пространстве с одинаковыми каналами, или legacy с одинаковыми RGBA |
| Списки | Одинаковое содержимое; запятые != пробелы; скобки != без скобок |
| Карты | Одинаковые ключи и значения |
| Булевы и null | Равны только самим себе |
| Функции | Равны по ссылке (определены в одном месте) |

---

## 3. Операторы сравнения

`<`, `<=`, `>`, `>=` -- сравнивают числа с автоматической конвертацией совместимых единиц:

```scss
@debug 100 > 50;       // true
@debug 10px < 17px;    // true
@debug 96px >= 1in;    // true
@debug 1000ms <= 1s;   // true
```

**Безразмерные числа** совместимы с любыми: `@debug 100 > 50px;` -- true.

**Несовместимые единицы** вызывают ошибку: `@debug 100px > 10s;` -- Error.

## 4. Числовые операторы

`+`, `-`, `*`, `%` -- стандартная математика с автоматической конвертацией единиц:

```scss
@debug 10s + 15s;      // 25s
@debug 1in - 10px;     // 0.8958333333in
@debug 5px * 3px;      // 15px*px
@debug 1in % 9px;      // 0.0625in
@debug 100px + 50;     // 150px  (безразмерные совместимы)
```

### Деление через math.div()

Оператор `/` устарел для деления. Используйте `math.div()`:

```scss
@use 'sass:math';
@debug math.div(1, 2);           // 0.5
@debug math.div(100px, 5px);     // 20
@debug math.div(100px, 5);       // 20px
@debug math.div(100px, 5s);      // 20px/s
```

### Унарные операторы

- `+$expr` -- значение без изменений
- `-$expr` -- отрицательное значение

**Правила для минуса:** Лучшая практика -- пробелы вокруг вычитания, пробел перед (но не после) для отрицания:

```scss
// Вычитание
@debug $a - $b;

// Отрицание
@debug -$value;
```

## 5. Строковые операторы

### Конкатенация (+)

Объединяет два выражения. Если любое из них в кавычках -- результат в кавычках:

```scss
@debug "Helvetica" + " Neue";  // "Helvetica Neue"
@debug sans- + serif;          // sans-serif
@debug "Elapsed time: " + 10s; // "Elapsed time: 10s"
@debug true + " is a boolean"; // "true is a boolean"
```

### Дефис (-)

Создает строку без кавычек с дефисом между значениями. Устаревший синтаксис -- лучше использовать интерполяцию.

---

## 6. Булевы операторы

`not`, `and`, `or` -- слова вместо символов. Порядок: `not` > `and` > `or`.

```scss
@debug not true;        // false
@debug not false;       // true
@debug true and true;   // true
@debug true and false;  // false
@debug true or false;   // true
@debug false or false;  // false
```
