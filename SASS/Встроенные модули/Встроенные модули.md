# Встроенные модули (Built-in Modules)

> Все встроенные модули загружаются через `@use` с префиксом `sass:`.
> Только Dart Sass поддерживает `@use` для встроенных модулей.

## 1. sass:math

```scss
@use "sass:math";
```

### Переменные

| Переменная | Значение | С версии |
|---|---|---|
| `math.$e` | 2.7182818285 | 1.25.0 |
| `math.$pi` | 3.1415926536 | 1.25.0 |
| `math.$epsilon` | Разница между 1 и ближайшим float > 1 | 1.55.0 |
| `math.$max-number` | Максимальное конечное число | 1.55.0 |
| `math.$min-number` | Минимальное положительное число | 1.55.0 |
| `math.$max-safe-integer` | 9007199254740991 | 1.55.0 |
| `math.$min-safe-integer` | -9007199254740991 | 1.55.0 |

### Функции ограничения и округления

| Функция | Описание | Пример |
|---|---|---|
| `math.ceil($number)` | Округление вверх | `math.ceil(4.2)` -> `5` |
| `math.floor($number)` | Округление вниз | `math.floor(4.9)` -> `4` |
| `math.round($number)` | Округление до ближайшего | `math.round(4.5)` -> `5` |
| `math.clamp($min, $number, $max)` | Ограничение диапазоном | `math.clamp(-1, 0, 1)` -> `0` |
| `math.max($number...)` | Максимум из чисел | `math.max(1px, 4px)` -> `4px` |
| `math.min($number...)` | Минимум из чисел | `math.min(1px, 4px)` -> `1px` |

### Функции расстояния

| Функция | Описание |
|---|---|
| `math.abs($number)` | Абсолютное значение |
| `math.hypot($number...)` | Длина n-мерного вектора |

### Экспоненциальные функции

| Функция | Описание | Пример |
|---|---|---|
| `math.log($number, $base: null)` | Логарифм (натуральный по умолчанию) | `math.log(10)` -> `2.302585093` |
| `math.pow($base, $exponent)` | Возведение в степень | `math.pow(10, 2)` -> `100` |
| `math.sqrt($number)` | Квадратный корень | `math.sqrt(100)` -> `10` |

### Тригонометрические функции

| Функция | Описание | Пример |
|---|---|---|
| `math.cos($number)` | Косинус (угол или рад) | `math.cos(100deg)` -> `-0.1736` |
| `math.sin($number)` | Синус | `math.sin(90deg)` -> `1` |
| `math.tan($number)` | Тангенс | |
| `math.acos($number)` | Арккосинус (возвращает deg) | |
| `math.asin($number)` | Арксинус | `math.asin(0.5)` -> `30deg` |
| `math.atan($number)` | Арктангенс | |
| `math.atan2($y, $x)` | Двухаргументный арктангенс | `math.atan2(-1, 1)` -> `135deg` |

### Функции единиц

| Функция | Описание |
|---|---|
| `math.compatible($n1, $n2)` | Совместимы ли единицы |
| `math.is-unitless($number)` | Без единиц? |
| `math.unit($number)` | Строка с единицами |

### Другие функции

| Функция | Описание |
|---|---|
| `math.div($n1, $n2)` | Деление |
| `math.percentage($number)` | Конвертация в проценты (`$n * 100%`) |
| `math.random($limit: null)` | Случайное число (0-1 или 1-$limit) |

## 2. sass:string

```scss
@use "sass:string";
```

| Функция | Описание | Пример |
|---|---|---|
| `string.quote($string)` | Заключить в кавычки | `string.quote(bold)` -> `"bold"` |
| `string.unquote($string)` | Убрать кавычки | `string.unquote("bold")` -> `bold` |
| `string.index($string, $substring)` | Позиция подстроки или `null` | `string.index("Helvetica", "vet")` -> `4` |
| `string.insert($string, $insert, $index)` | Вставка подстроки | `string.insert("Roboto Bold", " Mono", 7)` -> `"Roboto Mono Bold"` |
| `string.length($string)` | Длина строки | `string.length("Helvetica")` -> `9` |
| `string.slice($string, $start, $end: -1)` | Подстрока | `string.slice("Helvetica", 1, 3)` -> `"Hel"` |
| `string.split($string, $separator, $limit)` | Разделение (1.57.0+) | `string.split("a b c", " ")` -> `["a", "b", "c"]` |
| `string.to-upper-case($string)` | В верхний регистр | `string.to-upper-case("bold")` -> `"BOLD"` |
| `string.to-lower-case($string)` | В нижний регистр | `string.to-lower-case("BOLD")` -> `"bold"` |
| `string.unique-id()` | Уникальный CSS-идентификатор | `string.unique-id()` -> `uabtrnzug` |

## 3. sass:color

```scss
@use "sass:color";
```

### Основные функции

| Функция | Описание |
|---|---|
| `color.adjust($color, ...)` | Изменение каналов на фиксированные суммы |
| `color.change($color, ...)` | Установка каналов в новые значения |
| `color.scale($color, ...)` | Масштабирование каналов в % от текущего к max/min |
| `color.mix($color1, $color2, $weight, $method)` | Смешивание двух цветов |
| `color.complement($color, $space)` | Комплементарный цвет (поворот hue на 180) |
| `color.grayscale($color)` | Серая версия цвета |
| `color.invert($color, $weight, $space)` | Инвертирование цвета |

### Функции каналов и пространств

| Функция | Описание |
|---|---|
| `color.channel($color, $channel, $space)` | Значение канала |
| `color.space($color)` | Цветовое пространство как строка |
| `color.to-space($color, $space)` | Конвертация в другое пространство |
| `color.to-gamut($color, $space, $method)` | Приведение к гамме |
| `color.same($color1, $color2)` | Визуально идентичны? |
| `color.is-legacy($color)` | Legacy пространство? (rgb/hsl/hwb) |
| `color.is-missing($color, $channel)` | Канал отсутствует? |
| `color.is-powerless($color, $channel, $space)` | Канал бессилен? |
| `color.ie-hex-str($color)` | Формат #AARRGGBB для IE |

### Примеры

```scss
@debug color.adjust(#6b717f, $red: 15);   // #7a717f
@debug color.scale(#6b717f, $red: 15%);   // rgb(129.2, 113, 127)
@debug color.change(#6b717f, $red: 100);  // #64717f
@debug color.mix(#036, #d2e1dd, $method: rgb);  // #698aa2
```

### Разница adjust vs change vs scale

| Метод | Описание | Пример |
|---|---|---|
| `adjust` | Прибавляет/вычитает фиксированное количество | `adjust($color, $red: +15)` |
| `change` | Устанавливает абсолютное значение | `change($color, $red: 100)` |
| `scale` | Масштабирует % от текущего к max/min | `scale($color, $lightness: +15%)` |

> **Устаревшие функции:** `darken()`, `lighten()`, `saturate()`, `desaturate()`, `opacify()`, `transparentize()`, `adjust-hue()` -- используйте `color.scale()` или `color.adjust()`.

## 4. sass:list

```scss
@use "sass:list";
```

| Функция | Описание | Пример |
|---|---|---|
| `list.append($list, $val, $separator)` | Добавить в конец | `list.append(10px 20px, 30px)` -> `10px 20px 30px` |

| `list.is-bracketed($list)` | В квадратных скобках? | |
| `list.join($list1, $list2, $separator, $bracketed)` | Объединить | `list.join(10px 20px, 30px 40px)` -> `10px 20px 30px 40px` |
| `list.length($list)` | Количество элементов | |
| `list.separator($list)` | Тип разделителя | `space`, `comma`, `slash` |
| `list.nth($list, $n)` | Элемент по индексу | `list.nth(10px 12px 16px, 2)` -> `12px` |
| `list.set-nth($list, $n, $value)` | Заменить элемент | |
| `list.slash($elements...)` | Slash-разделенный список | |
| `list.zip($lists...)` | Объединить по позициям | `list.zip(10px 50px, short mid)` -> `10px short, 50px mid` |

## 5. sass:map

```scss
@use "sass:map";
```

| Функция | Описание |
|---|---|
| `map.get($map, $key, $keys...)` | Значение по ключу (вложенные) |
| `map.has-key($map, $key, $keys...)` | Есть ли ключ |
| `map.keys($map)` | Список ключей |
| `map.values($map)` | Список значений |
| `map.set($map, $key, $value)` | Установить/обновить (вложенные) |
| `map.merge($map1, $map2)` | Слить две карты |
| `map.deep-merge($map1, $map2)` | Рекурсивное слияние вложенных |
| `map.remove($map, $keys...)` | Удалить ключи |
| `map.deep-remove($map, $key, $keys...)` | Удалить из вложенных |

```scss
$fonts: ("Helvetica": ("weights": ("regular": 400, "bold": 700)));

@debug map.get($fonts, "Helvetica", "weights", "regular");  // 400
@debug map.set($fonts, "Helvetica", "weights", "regular", 300);
```

## 7. sass:meta

```scss
@use "sass:meta";
```

### Миксины

| Миксин | Описание |
|---|---|
| `meta.apply($mixin, $args...)` | Вызвать миксин как значение (1.69.0+) |
| `meta.load-css($url, $with: null)` | Загрузить модуль и включить CSS (1.23.0+) |

```scss
@include meta.load-css("dark-theme/code", $with: ("border-contrast": true));
```

### Функции интроспекции

| Функция | Описание |
|---|---|
| `meta.type-of($value)` | Тип: number, string, color, list, map, calculation, bool, null, function, mixin, arglist |
| `meta.inspect($value)` | Строковое представление любого значения |
| `meta.variable-exists($name)` | Переменная существует в текущей области? |
| `meta.global-variable-exists($name, $module)` | Глобальная переменная существует? |
| `meta.function-exists($name, $module)` | Функция существует? |
| `meta.mixin-exists($name, $module)` | Миксин существует? |
| `meta.content-exists()` | У текущего миксина есть @content? |
| `meta.accepts-content($mixin)` | Миксин принимает @content? (1.69.0+) |

### Функции модулей

| Функция | Описание |
|---|---|
| `meta.module-functions($module)` | Карта функций модуля |
| `meta.module-mixins($module)` | Карта миксинов модуля (1.69.0+) |
| `meta.module-variables($module)` | Карта переменных модуля |

### Функции для работы с функциями и вычислениями

| Функция | Описание |
|---|---|
| `meta.get-function($name, $css, $module)` | Получить функцию как значение |
| `meta.get-mixin($name, $module)` | Получить миксин как значение (1.69.0+) |
| `meta.call($function, $args...)` | Вызвать функцию-значение |
| `meta.keywords($args)` | Именованные аргументы как карта |
| `meta.calc-args($calc)` | Аргументы вычисления (1.40.0+) |
| `meta.calc-name($calc)` | Имя функции вычисления (1.40.0+) |

```scss
@debug meta.type-of(10px);          // number
@debug meta.type-of("hello");       // string
@debug meta.inspect(("a": 1));      // ("a": 1)
@debug meta.function-exists("div", "math");  // true
```
