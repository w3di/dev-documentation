## 1. Числа (Numbers)

Числа состоят из числового значения и единиц. Поддерживается научная нотация.

```scss
@debug 100;        // 100
@debug 0.8;        // 0.8
@debug 16px;       // 16px
@debug 5.2e3;      // 5200
@debug 6e-2;       // 0.06
```

Sass НЕ различает целые числа и десятичные: `math.div(5, 2)` возвращает `2.5`.

### Единицы

| Операция | Правило | Пример |
|---|---|---|
| Умножение | Единицы умножаются | `4px * 6px` = `calc(24px * 1px)` |
| Деление | Единицы делятся | `math.div(5px, 2s)` = `calc(2.5px / 1s)` |
| Совместимые | Автоконвертация | `1in + 6px` = `102px` |
| Несовместимые | Ошибка | `1in + 1s` -- Error |
| Безразмерное + единица | Единица наследуется | `100px + 50` = `150px` |

### Отмена единиц

Совместимые единицы в числителе и знаменателе сокращаются:

```scss
@use 'sass:math';
$transition-speed: math.div(1s, 50px);

@mixin move($left-start, $left-stop) {
  transition: left ($left-stop - $left-start) * $transition-speed;
}

.slider { @include move(10px, 120px); } // transition: left 2.2s
```

> **Не используйте `#{$number}px`!** Это создает строку, а не число. Используйте `$number * 1px`.

### Проценты

Проценты НЕ взаимозаменяемы с десятичными числами:
- Конвертация в десятичное: `math.div($percentage, 100%)`
- Конвертация в проценты: `$decimal * 100%`

### Точность

Числа хранятся как 64-битные floating point. В CSS выводятся с точностью до 10 знаков после запятой. Числа в пределах `0.0000000001` от целого считаются целыми.

## 2. Строки (Strings)

Два типа: в кавычках (`"Helvetica Neue"`) и без кавычек (`bold`). Внутренняя структура одинакова.

```scss
@use "sass:string";
@debug string.unquote(".widget:hover");  // .widget:hover
@debug string.quote(bold);              // "bold"
```

### Экранирование

Стандартные CSS-escape коды: `\"`, `\\`, `\a` (перенос строки), `\1F46D` (Unicode).

### Строки в кавычках

- Поддерживают интерполяцию
- Любой символ, кроме `\`, кавычки и переноса строки
- При интерполяции строка в кавычках теряет кавычки

### Строки без кавычек

- Следуют синтаксису CSS-идентификаторов
- Некоторые значения парсятся как другие типы: названия цветов -- как цвета, `null`, `true`, `false` -- как соответствующие типы

> **Рекомендация:** Используйте строки в кавычках, если не пишете конкретное CSS-значение без кавычек.

### Индексы строк

Начинаются с **1** (не с 0). Отрицательные индексы считают с конца: `-1` -- последний символ.

```scss
@debug string.index("Helvetica Neue", "Neue");  // 11
@debug string.slice("Roboto Mono", -4);         // "Mono"
```

## 3. Цвета (Colors)

Sass поддерживает все цветовые пространства CSS:

| Пространство | Синтаксис | Каналы |
|---|---|---|
| `rgb` | `rgb(102 51 153)` или `#663399` | red, green, blue [0-255] |
| `hsl` | `hsl(270 50% 40%)` | hue [0-360]; saturation, lightness [0-100%] |
| `hwb` | `hwb(270 20% 40%)` | hue [0-360]; whiteness, blackness [0-100%] |
| `lab` | `lab(32.4% 38.4 -47.7)` | lightness [0-100%]; a, b [-125 - 125] |
| `lch` | `lch(32.4% 61.2 308.9deg)` | lightness; chroma [0-150]; hue [0-360] |
| `oklab` | `oklab(44% 0.088 -0.134)` | lightness; a, b [-0.4 - 0.4] |
| `oklch` | `oklch(44% 0.16 303.4deg)` | lightness; chroma [0-0.4]; hue [0-360] |
| `srgb` | `color(srgb 0.4 0.2 0.6)` | red, green, blue [0-1] |
| `display-p3` | `color(display-p3 ...)` | red, green, blue [0-1] |

**Устаревшие (legacy) пространства:** `rgb`, `hsl`, `hwb` -- Sass свободно конвертирует между ними.

### Отсутствующие каналы (Missing Channels)

Записываются как `none`. Обычно трактуются как 0, но при смешивании цветов принимают значение другого цвета:

```scss
@use 'sass:color';
$grey: hsl(none 0% 50%);
@debug color.mix($grey, blue, $method: hsl);  // hsl(240, 50%, 50%)
```

### Цветовые функции

Имена каналов -- в кавычках, пространства -- без:

```scss
@use 'sass:color';
$venus: #998099;
@debug color.scale($venus, $lightness: +15%, $space: oklch);
@debug color.mix($venus, midnightblue, $method: oklch);
```

## 4. Списки (Lists)

Последовательности значений, разделенные запятыми, пробелами или слэшами:

```scss
$comma-list: Helvetica, Arial, sans-serif;
$space-list: 10px 15px 0 0;
$bracket-list: [col1-line1, col1-line2];
```

### Особые случаи

- Одноэлементный список: `(<expression>,)` или `[<expression>]`
- Пустой список: `()` или `[]`
- Slash-разделенные списки: `list.slash(1px, 2px, 3px)` -> `1px / 2px / 3px`

### Основные операции

| Операция | Функция | Пример |
|---|---|---|
| Доступ | `list.nth($list, $n)` | Индексы с 1, отрицательные с конца |
| Итерация | `@each $item in $list` | |
| Добавление | `list.append($list, $val)` | Возвращает новый список |
| Поиск | `list.index($list, $value)` | Индекс или `null` |

### Неизменяемость

Списки в Sass **неизменяемы**. Все функции возвращают новые списки. Переменные можно переназначать:

```scss
$prefixes: ();
@each $browser in $browsers {
  $prefixes: list.append($prefixes, map.get($prefixes-by-browser, $browser));
}
```

### Списки аргументов (Argument Lists)

Специальные списки, получаемые при `$args...`. Доступ к именованным аргументам через `meta.keywords()`.

## 5. Карты (Maps)

Карты хранят пары ключ-значение: `(<key>: <value>, <key>: <value>)`.

```scss
$font-weights: ("regular": 400, "medium": 500, "bold": 700);
```

### Правила

- Ключи должны быть уникальны
- Пустая карта: `()` (совпадает с пустым списком)
- Любое значение Sass может быть ключом (используется `==` для сравнения)
- Каждая карта считается списком из двухэлементных подсписков

> **Рекомендация:** Используйте строки в кавычках для ключей (во избежание путаницы с названиями цветов и т.д.).

### Основные операции

```scss
@use "sass:map";

$map: ("a": 1, "b": 2, "c": 3);

@debug map.get($map, "b");     // 2
@debug map.get($map, "d");     // null
@debug map.has-key($map, "a"); // true
@debug map.keys($map);         // "a", "b", "c"
@debug map.values($map);       // 1, 2, 3
@debug map.set($map, "d", 4);  // ("a": 1, "b": 2, "c": 3, "d": 4)
@debug map.merge($map, ("d": 4)); // то же самое
@debug map.remove($map, "b");  // ("a": 1, "c": 3)
```

### Глубокие операции (Dart Sass 1.27.0+)

```scss
$fonts: ("Helvetica": ("weights": ("regular": 400, "bold": 700)));

@debug map.get($fonts, "Helvetica", "weights", "regular");  // 400
@debug map.set($fonts, "Helvetica", "weights", "regular", 300);
@debug map.deep-merge($map1, $map2);   // Рекурсивное слияние
@debug map.deep-remove($map, "key1", "key2");  // Удаление по вложенным ключам
```

### Неизменяемость

Карты неизменяемы, как и списки. Все функции возвращают новые копии.

## 6. Булевы значения (Booleans)

`true` и `false`. Возвращаются операторами сравнения и встроенными функциями.

### Операторы

```scss
@debug true and true;   // true
@debug true and false;  // false
@debug true or false;   // true
@debug not true;        // false
```

### Использование

```scss
@debug if(true, 10px, 30px);   // 10px
@debug if(false, 10px, 30px);  // 30px
```

**Правдивость:** Только `false` и `null` ложны. `""`, `()`, `0` -- все **истинно**!

## 7. null

`null` -- отсутствие значения. Возвращается функциями, когда результата нет.

```scss
@debug string.index("Helvetica Neue", "Roboto");  // null
@debug map.get(("large": 20px), "small");          // null
@debug &;                                           // null (вне стилей)
```

### Поведение

- **В списках:** `null` пропускается в CSS-выводе
- **В свойствах:** Если значение свойства -- `null`, всё свойство исключается из вывода
- **Правдивость:** `null` ложен

```scss
h3 { font: 18px bold map-get($fonts, "sans"); }
// h3 { font: 18px bold; }   (если "sans" нет -- null пропущен)
```

## 8. Вычисления (Calculations)

Представляют CSS-функции `calc()`, `clamp()`, `min()`, `max()` и другие. Sass упрощает их насколько возможно (Dart Sass 1.40.0+).

```scss
@debug calc(400px + 10%);  // calc(400px + 10%)  -- не может упростить
@debug calc(400px / 2);    // 200px               -- может упростить
@debug min(100px, calc(1rem + 10%));  // min(100px, 1rem + 10%)
```

### Упрощение

Sass автоматически упрощает операции с совместимыми единицами. Вложенные `calc()` убираются:

```scss
$width: calc(400px + 10%);
.sidebar {
  width: $width;
  padding-left: calc($width / 4);   // calc((400px + 10%) / 4)
}
```

### Операции с вычислениями

Нельзя использовать обычные SassScript операторы. Пишите внутри `calc()`:

```scss
$width: calc(100% + 10px);
// @debug $width * 2;       // Ошибка!
@debug calc($width * 2);    // calc((100% + 10px) * 2)
```

### Константы (Dart Sass 1.60.0+)

- `pi` -- 3.1415926536
- `e` -- 2.7182818285
- `infinity`, `-infinity`, `NaN`

### Функции вычислений (Dart Sass 1.65.0+)

| Категория | Функции |
|---|---|
| Сравнение | `min()`, `max()`, `clamp()` |
| Округление | `round()`, `mod()`, `rem()` |
| Тригонометрия | `sin()`, `cos()`, `tan()`, `asin()`, `acos()`, `atan()`, `atan2()` |
| Экспоненциальные | `pow()`, `sqrt()`, `hypot()`, `log()`, `exp()` |
| Знак | `abs()`, `sign()` |

## 9. Функции как значения

Функции можно получить как значения и вызвать:

```scss
@use "sass:meta";

$fn: meta.get-function("darken");
@debug meta.call($fn, #036, 20%);  // #001a33

// Миксины тоже (Dart Sass 1.69.0+)
$mx: meta.get-mixin("reset-list");
@include meta.apply($mx);
```
