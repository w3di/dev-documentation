## 1. Основы

Правила стилей выбирают элемент селектором и объявляют свойства:

```scss
.button {
  padding: 3px 10px;
  font-size: 12px;
  border-radius: 3px;
  border: 1px solid #e1e4e8;
}
```

---

## 2. Вложенность (Nesting)

Вместо повторения одних и тех же селекторов, в Sass можно вкладывать правила друг в друга. Sass автоматически комбинирует внешний селектор с внутренним.

```scss
nav {
  ul {
    margin: 0;
    padding: 0;
    list-style: none;
  }

  li { display: inline-block; }

  a {
    display: block;
    padding: 6px 12px;
    text-decoration: none;
  }
}
```

Компилируется в:
```css
nav ul { margin: 0; padding: 0; list-style: none; }
nav li { display: inline-block; }
nav a { display: block; padding: 6px 12px; text-decoration: none; }
```

> **Предупреждение:** Глубокая вложенность увеличивает объем генерируемого CSS и нагрузку на браузер. Рекомендуется не более 3 уровней вложенности.

---

## 3. Списки селекторов

При вложенности списков селекторов (через запятую) каждый сложный селектор вкладывается отдельно, а потом собирается обратно:

```scss
.alert, .warning {
  ul, p {
    margin-right: 0;
    margin-left: 0;
    padding-bottom: 0;
  }
}
// Компилируется в:
// .alert ul, .alert p, .warning ul, .warning p { ... }
```

---

## 4. Комбинаторы селекторов

Комбинаторы можно размещать в конце внешнего селектора, в начале внутреннего или отдельно:

```scss
ul > {
  li { list-style-type: none; }
}

h2 {
  + p { border-top: 1px solid gray; }
}

p {
  ~ {
    span { opacity: 0.8; }
  }
}
```

## 5. Родительский селектор (&)

`&` ссылается на внешний (родительский) селектор при вложенности. Заменяется на соответствующий внешний селектор.

### Основное использование

```scss
.alert {
  &:hover { font-weight: bold; }        // .alert:hover
  [dir=rtl] & { margin-left: 0; }       // [dir=rtl] .alert
  :not(&) { opacity: 0.8; }             // :not(.alert)
}
```

### Добавление суффиксов (BEM)

```scss
.accordion {
  &__copy {
    display: none;
    &--open {
      display: block;
    }
  }
}
// .accordion__copy { display: none; }
// .accordion__copy--open { display: block; }
```

### Ограничения и особенности

- `&` допускается только в начале составных (compound) селекторов. `span&` -- ошибка
- **В SassScript:** `&` возвращает текущий родительский селектор как список списков
- Вне правил стилей `&` равен `null`

```scss
@mixin app-background($color) {
  #{if(&, '&.app-background', '.app-background')} {
    background-color: $color;
  }
}

@include app-background(#036);       // .app-background { ... }
.sidebar { @include app-background(#c6538c); } // .sidebar.app-background { ... }
```

## 6. Объявления свойств

Sass расширяет CSS: значение свойства может быть любым SassScript-выражением.

### Интерполяция в именах свойств

```scss
@mixin prefix($property, $value, $prefixes) {
  @each $prefix in $prefixes {
    -#{$prefix}-#{$property}: $value;
  }
  #{$property}: $value;
}

.gray {
  @include prefix(filter, grayscale(50%), moz webkit);
}
```

### Вложенность свойств

Свойства с общим префиксом можно вкладывать:

```scss
.enlarge {
  font-size: 14px;
  transition: {
    property: font-size;
    duration: 4s;
    delay: 2s;
  }
}
// transition-property: font-size;
// transition-duration: 4s;
// transition-delay: 2s;
```

Можно комбинировать сокращенное значение с вложенными:

```scss
.info-page {
  margin: auto {
    bottom: 10px;
    top: 2px;
  }
}
// margin: auto; margin-bottom: 10px; margin-top: 2px;
```

### Скрытые объявления

Если значение свойства -- `null` или пустая строка без кавычек, Sass не включает это объявление в вывод.

### Custom Properties (CSS-переменные)

Парсятся иначе -- все токены передаются в CSS как есть. Только интерполяция `#{}` вставляет динамические значения:

```scss
$primary: #81899b;
:root {
  --primary: #{$primary};         // --primary: #81899b
  --consumed-by-js: $primary;     // --consumed-by-js: $primary (буквально!)
}
```

## 7. Плейсхолдер-селекторы (%placeholder)

Начинаются с `%`, не генерируют CSS сами по себе, но могут быть расширены через `@extend`:

```scss
%strong-alert {
  font-weight: bold;
}

.alert {
  @extend %strong-alert;
}
```

**Приватные плейсхолдеры** (начинаются с `-` или `_`) доступны только в пределах своего файла.

### Когда использовать

- Плейсхолдеры идеальны для стилей, которые используются только через `@extend`
- Они не генерируют лишний CSS, если не расширены
- Рекомендуемый подход вместо расширения обычных классов
