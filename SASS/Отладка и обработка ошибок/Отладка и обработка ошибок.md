# Отладка и обработка ошибок

> Sass предоставляет три директивы для отладки и обработки ошибок: `@error`, `@warn`, `@debug`,
> а также `@at-root` для управления вложенностью вывода.

---

## Оглавление

1. [@error](#1-error)
2. [@warn](#2-warn)
3. [@debug](#3-debug)
4. [@at-root](#4-at-root)

---

## 1. @error

Останавливает компиляцию с сообщением об ошибке и стек-трейсом:

```scss
@mixin reflexive-position($property, $value) {
  @if $property != left and $property != right {
    @error "Property #{$property} must be either left or right.";
  }
  // ...
}
```

### Вывод в Dart Sass

```
Error: "Property top must be either left or right."
  |
3 |     @error "Property #{$property} must be either left or right.";
  |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  +
  example.scss 3:5   reflexive-position()
  example.scss 19:3  root stylesheet
```

### Когда использовать

- Валидация аргументов функций и миксинов
- Проверка типов значений
- Предотвращение некорректного использования API

```scss
@function get-color($name) {
  @if not map.has-key($colors, $name) {
    @error "Unknown color: #{$name}. Available: #{map.keys($colors)}";
  }
  @return map.get($colors, $name);
}
```

## 2. @warn

Выводит предупреждение **БЕЗ остановки** компиляции:

```scss
$known-prefixes: webkit, moz, ms, o;

@mixin prefix($property, $value, $prefixes) {
  @each $prefix in $prefixes {
    @if not index($known-prefixes, $prefix) {
      @warn "Unknown prefix #{$prefix}.";
    }
    -#{$prefix}-#{$property}: $value;
  }
  #{$property}: $value;
}
```

### Когда использовать

- Предупреждения об устаревших API
- Неоптимальное использование
- Мягкая валидация (не критичные ошибки)

```scss
@mixin old-mixin() {
  @warn "old-mixin() is deprecated. Use new-mixin() instead.";
  @include new-mixin();
}
```

### Подавление предупреждений

В CLI: `--quiet` подавляет все, `--quiet-deps` подавляет предупреждения из зависимостей.

## 3. @debug

Выводит значение выражения с именем файла и номером строки:

```scss
@mixin inset-divider-offset($offset, $padding) {
  $divider-offset: (2 * $padding) + $offset;
  @debug "divider offset: #{$divider-offset}";
  margin-left: $divider-offset;
}
```

Вывод: `test.scss:3 Debug: divider offset: 132px`

### Особенности

- Принимает **любой** тип значения, не ограничен строками
- Вывод аналогичен `meta.inspect()`
- Полезно для отладки сложных вычислений, проверки типов и значений переменных

```scss
@debug type-of($value);        // Проверить тип
@debug length($list);          // Длина списка
@debug map.keys($map);         // Ключи карты
@debug &;                      // Текущий селектор
```

## 4. @at-root

`@at-root` выносит содержимое на корневой уровень документа вместо обычной вложенности:

```scss
@use "sass:selector";

@mixin unify-parent($child) {
  @at-root #{selector.unify(&, $child)} {
    @content;
  }
}

.wrapper .field {
  @include unify-parent("input") { /* ... */ }
  @include unify-parent("select") { /* ... */ }
}
// .wrapper input.field { /* ... */ }
// .wrapper select.field { /* ... */ }
```

### Блочная форма

Для нескольких правил:

```scss
.parent {
  @at-root {
    .child-1 { ... }
    .child-2 { ... }
  }
}
```

### Управление at-правилами

```scss
@media print {
  .page {
    width: 8in;
    @at-root (without: media) { color: #111; }
    @at-root (with: rule) { font-size: 1.2em; }
  }
}
```

| Директива | Описание |
|---|---|
| `@at-root (without: <rules>)` | Исключает указанные правила |
| `@at-root (with: <rules>)` | Исключает все, кроме указанных |
| `rule` | Обозначает правила стилей |
| `all` | Обозначает все at-правила и правила стилей |
