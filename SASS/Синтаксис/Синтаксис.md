## 1. SCSS (.scss)

SCSS -- надмножество CSS: практически любой валидный CSS является валидным SCSS. Использует фигурные скобки `{}` и точки с запятой `;`. Это самый популярный синтаксис благодаря схожести с CSS.

```scss
@mixin button-base() {
  @include typography(button);
  @include ripple-surface;

  display: inline-flex;
  position: relative;
  height: $button-height;
  border: none;

  &:hover {
    cursor: pointer;
  }

  &:disabled {
    color: $mdc-button-disabled-ink-color;
    cursor: default;
    pointer-events: none;
  }
}
```

## 2. Indented Syntax (.sass)

Оригинальный синтаксис Sass. Использует отступы вместо фигурных скобок, а конец строки заменяет точку с запятой. Поддерживает все те же возможности, что и SCSS.

```sass
@mixin button-base()
  @include typography(button)
  @include ripple-surface

  display: inline-flex
  position: relative
  height: $button-height
  border: none

  &:hover
    cursor: pointer

  &:disabled
    color: $mdc-button-disabled-ink-color
    cursor: default
    pointer-events: none
```

В Indented Syntax (начиная с Dart Sass 1.84.0+) поддерживаются многострочные выражения при переносе строк внутри скобок или между ключевыми словами Sass-специфичных @-правил.

### Сравнение синтаксисов

| Характеристика | SCSS | Indented Sass |
|---|---|---|
| Расширение файла | `.scss` | `.sass` |
| Разделители блоков | `{}` | Отступы |
| Разделитель свойств | `;` | Перенос строки |
| Совместимость с CSS | Полная | Нет |
| Миксины (сокращенно) | `@mixin` / `@include` | `=` / `+` |

## 3. Парсинг таблицы стилей

- Sass парсит таблицу стилей из последовательности Unicode code points напрямую, без предварительной токенизации
- Dart Sass поддерживает только UTF-8 кодировку
- При ошибке синтаксиса парсинг немедленно прекращается (в отличие от CSS, который имеет механизмы восстановления после ошибок)

## 4. Структура таблицы стилей

Таблица стилей Sass состоит из серии **выражений (statements)**, которые вычисляются по порядку.

### Универсальные выражения (можно использовать где угодно)

- Объявления переменных (`$var: value`)
- Управление потоком (`@if`, `@each`, `@for`, `@while`)
- `@error`, `@warn`, `@debug`

### CSS-выражения (генерируют CSS-вывод)

- Правила стилей (селектор `{ свойства }`)
- CSS at-правила (`@media`, `@font-face`)
- Использование миксинов (`@include`)
- Правило `@at-root`

### Выражения верхнего уровня (только в корне файла)

- Загрузка модулей (`@use`)
- Импорт (`@import`)
- Определения миксинов (`@mixin`)
- Определения функций (`@function`)

### Выражения (expressions)

Все, что может стоять справа от свойства или объявления переменной:

- Литералы: числа, строки, цвета, булевы, null, списки, карты
- Операции: `==`, `!=`, `+`, `-`, `*`, `/`, `%`, `<`, `>`, `<=`, `>=`, `and`, `or`, `not`
- Переменные (`$var`), вызовы функций, специальные функции (`calc`, `url`), родительский селектор (`&`), `!important`

## 5. Комментарии

### Однострочные (тихие) -- никогда не попадают в CSS

```scss
// Этот комментарий не попадет в CSS
```

### Многострочные (громкие) -- обычно попадают в CSS

```scss
/* Этот комментарий попадет в CSS */

/* Поддерживает интерполяцию: 1 + 1 = #{1 + 1} */

/*! Этот комментарий сохраняется даже в compressed-режиме */
```

> **Правило:** В compressed-режиме (`--style=compressed`) многострочные комментарии удаляются, кроме тех, что начинаются с `/*!`.

### Документационные комментарии (SassDoc)

Пишутся с тремя слэшами `///`, поддерживают аннотации:

```scss
/// Вычисляет степень числа.
///
/// @param {number} $base -- основание
/// @param {integer (unitless)} $exponent -- показатель степени
/// @return {number} $base в степени $exponent
@function pow($base, $exponent) {
  $result: 1;
  @for $_ from 1 through $exponent {
    $result: $result * $base;
  }
  @return $result;
}
```

## 6. Специальные функции

Некоторые CSS-функции имеют специальный парсинг в Sass:

| Функция | Особенность |
|---|---|
| `url()` | Может содержать некавыченные URL, парсится как специальная функция |
| `calc()`, `clamp()`, `min()`, `max()` | Парсятся как вычисления с поддержкой Sass-переменных |
| `element()` | Аналогичный специальный парсинг |

```scss
// Sass-переменные работают внутри calc()
$width: 100px;
.box {
  width: calc($width + 20%);  // calc(100px + 20%)
}
```
