## 1. Политика изменений

- Предупреждения об устаревании выдаются минимум **3 месяца** до изменения
- Изменения выходят с новыми **мажорными версиями**, кроме изменений совместимости с CSS
- `--fatal-deprecation=ID` позволяет трактовать устаревания как ошибки для подготовки
- `--silence-deprecation=ID` подавляет конкретные предупреждения

## 2. Таблица критических изменений

| Изменение | С версии | Описание |
|---|---|---|
| `@import` | 1.80.0 | Устарел, будет удален в 3.0.0 |
| `/` как деление | 1.33.0 | Используйте `math.div()` |
| Legacy JS API | 1.79.0 | Используйте новый JS API |
| Color Functions | 1.79.0 | `darken()`, `lighten()` и др. устарели |
| Mixed Declarations | 1.77.7 | Изменение поведения вложенных объявлений |
| Strict Unary Operators | 1.55.0 | Строгий парсинг унарных операторов |
| Invalid Combinators | 1.54.0 | Ошибка на невалидных комбинаторах |
| Function Units | 1.32.0 | Строгая проверка единиц в функциях |
| CSS Variable Syntax | 1.0.0 | Custom properties парсятся как CSS |
| `null` as alpha | 1.64.3 | `null` в альфа-канале |
| `abs()` percentage | 1.65.0 | `abs()` с процентами |
| Duplicate Variable Flags | 1.62.0 | Дублирование флагов переменных |
| `meta.feature-exists` | -- | Устарела |
| `if()` function | 1.95.0 | Legacy `if()` устарела (CSS имеет свой `if()`) |

## 3. Миграция с @import на @use

### Автоматическая миграция

```bash
npx sass-migrator module --migrate-deps input.scss
```

### Ручная миграция

**До:**
```scss
// _variables.scss
$primary: blue;

// _mixins.scss
@import 'variables';
@mixin button { background: $primary; }

// main.scss
@import 'variables';
@import 'mixins';

.btn { @include button; color: $primary; }
```

**После:**
```scss
// _variables.scss
$primary: blue !default;

// _mixins.scss
@use 'variables';
@mixin button { background: variables.$primary; }

// main.scss
@use 'variables';
@use 'mixins';

.btn { @include mixins.button; color: variables.$primary; }
```

### Ключевые шаги

1. Добавьте `!default` к конфигурируемым переменным
2. Замените `@import` на `@use` с пространствами имен
3. Создайте `_index.scss` с `@forward` для папок
4. Обновите ссылки на переменные/миксины/функции с пространствами имен
5. Сделайте приватными внутренние API (добавьте `_` или `-` префикс)

## 4. Миграция цветовых функций

### Устаревшие -> Современные

```scss
@use "sass:color";

// darken/lighten -> color.adjust или color.scale
// До:
darken($color, 20%)
lighten($color, 20%)
// После:
color.adjust($color, $lightness: -20%)
color.adjust($color, $lightness: 20%)
// Или (рекомендуемый -- более интуитивный):
color.scale($color, $lightness: -20%)
color.scale($color, $lightness: 20%)

// saturate/desaturate
// До:
saturate($color, 20%)
desaturate($color, 20%)
// После:
color.adjust($color, $saturation: 20%)
color.adjust($color, $saturation: -20%)

// adjust-hue
// До:
adjust-hue($color, 30deg)
// После:
color.adjust($color, $hue: 30deg)

// opacify/transparentize
// До:
opacify($color, 0.2)
transparentize($color, 0.2)
// После:
color.adjust($color, $alpha: 0.2)
color.adjust($color, $alpha: -0.2)
```

### Разница adjust vs scale

```scss
$color: hsl(0, 50%, 60%);

// adjust: добавляет фиксированное количество
color.adjust($color, $lightness: -20%)  // lightness: 40%

// scale: масштабирует от текущей позиции к краю
color.scale($color, $lightness: -20%)   // lightness: 48% (20% от 60% до 0%)
```

> `color.scale()` обычно более интуитивен и предсказуем для дизайнеров.

## 5. Деление через math.div()

### До (устарело)

```scss
$half: 100px / 2;          // 50px (деление)
$font: 16px / 24px;        // Неоднозначно: деление или CSS-значение?
```

### После

```scss
@use "sass:math";

$half: math.div(100px, 2);         // 50px
$font: math.div(16px, 24px);       // 0.6666666667
```

### Автоматическая миграция

```bash
npx sass-migrator division input.scss
```

## 6. Подготовка к Sass 3.0

Sass 3.0 удалит все устаревшие функции. Для подготовки:

```bash
# Сделайте все устаревания ошибками
sass --fatal-deprecation=import \
     --fatal-deprecation=slash-div \
     --fatal-deprecation=global-builtin \
     --fatal-deprecation=color-functions \
     src/main.scss dist/main.css
```

### Чек-лист миграции

- [ ] Заменить `@import` на `@use` / `@forward`
- [ ] Заменить `/` на `math.div()`
- [ ] Заменить глобальные функции на модульные (`darken()` -> `color.adjust()`)
- [ ] Заменить глобальные встроенные на `sass:*` модули
- [ ] Обновить JS API на современный (если используется программно)
- [ ] Использовать `sass-migrator` для автоматизации
