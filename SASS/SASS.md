## Быстрый обзор

**Sass (Syntactically Awesome Style Sheets)** -- CSS-препроцессор, добавляющий переменные, вложенность, миксины, функции, модульную систему, условия, циклы и другие возможности поверх CSS.

### Два синтаксиса

| | SCSS (.scss) | Indented (.sass) |
|---|---|---|
| Стиль | Фигурные скобки `{}` и `;` | Отступы и переносы строк |
| Совместимость | Любой CSS -- валидный SCSS | Собственный синтаксис |
| Популярность | Основной в индустрии | Нишевый |

### Ключевые возможности

- **Переменные** (`$var`) с `!default` и `!global`
- **Вложенность** селекторов и свойств, `&` для родительского селектора
- **Миксины** (`@mixin`/`@include`) с аргументами и `@content`
- **Наследование** (`@extend`, `%placeholder`)
- **Функции** (`@function`) и встроенные модули (`sass:math`, `sass:color` и др.)
- **Типы данных**: числа, строки, цвета, списки, карты, булевы, null, вычисления
- **Модульная система** (`@use`, `@forward`) с пространствами имен
- **Управление потоком** (`@if`, `@each`, `@for`, `@while`)
- **Операторы**: арифметические, сравнения, логические, строковые

### Компиляция

```bash
# Dart Sass (рекомендуемый)
npm install -g sass
sass input.scss output.css
sass --watch input.scss:output.css
```
