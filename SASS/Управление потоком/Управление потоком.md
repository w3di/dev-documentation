## 1. @if и @else

### Базовый синтаксис

```scss
@mixin avatar($size, $circle: false) {
  width: $size;
  height: $size;

  @if $circle {
    border-radius: math.div($size, 2);
  }
}
```

### @else и @else if

```scss
@mixin triangle($size, $color, $direction) {
  height: 0;
  width: 0;
  border-color: transparent;
  border-style: solid;
  border-width: math.div($size, 2);

  @if $direction == up {
    border-bottom-color: $color;
  } @else if $direction == right {
    border-left-color: $color;
  } @else if $direction == down {
    border-top-color: $color;
  } @else if $direction == left {
    border-right-color: $color;
  } @else {
    @error "Unknown direction #{$direction}.";
  }
}
```

### Функция if()

Для простых тернарных выражений:

```scss
$color: if($dark-mode, white, black);
@debug if(true, 10px, 30px);   // 10px
@debug if(false, 10px, 30px);  // 30px
```

## 2. Truthiness (правдивость)

> **Ключевое отличие от JavaScript:** Только `false` и `null` ложны.
> Все остальное -- включая пустые строки `""`, пустые списки `()` и `0` -- **истинно**.

```scss
@debug if("", true, false);   // true  (пустая строка истинна!)
@debug if((), true, false);   // true  (пустой список истинен!)
@debug if(0, true, false);    // true  (ноль истинен!)
@debug if(null, true, false); // false
@debug if(false, true, false);// false
```

## 3. @each

Итерация по списку или карте.

### По списку

```scss
$sizes: 40px, 50px, 80px;

@each $size in $sizes {
  .icon-#{$size} {
    font-size: $size;
    height: $size;
    width: $size;
  }
}
```

### По карте (ключ/значение)

```scss
$icons: ("eye": "\f112", "start": "\f12e", "stop": "\f12f");

@each $name, $glyph in $icons {
  .icon-#{$name}:before {
    display: inline-block;
    font-family: "Icon Font";
    content: $glyph;
  }
}
```

### Деструктуризация вложенных списков

```scss
$icons: "eye" "\f112" 12px, "start" "\f12e" 16px, "stop" "\f12f" 10px;

@each $name, $glyph, $size in $icons {
  .icon-#{$name}:before {
    content: $glyph;
    font-size: $size;
  }
}
```

Карты работают как списки списков, что делает возможной деструктуризацию.

## 4. @for

Итерация от одного числа до другого.

### to vs through

- `to` -- **исключает** последнее число
- `through` -- **включает** последнее число

```scss
// through -- включает 3 (итерации: 1, 2, 3)
@for $i from 1 through 3 {
  .item-#{$i} { width: 100px * $i; }
}

// to -- исключает 3 (итерации: 1, 2)
@for $i from 1 to 3 {
  .item-#{$i} { width: 100px * $i; }
}
```

### Пример с цветами

```scss
$base-color: #036;

@for $i from 1 through 3 {
  ul:nth-child(3n + #{$i}) {
    background-color: lighten($base-color, $i * 5%);
  }
}
```

## 5. @while

Выполняет блок пока выражение истинно:

```scss
@use "sass:math";

@function scale-below($value, $base, $ratio: 1.618) {
  @while $value > $base {
    $value: math.div($value, $ratio);
  }
  @return $value;
}

sup { font-size: scale-below(20px, 16px); } // font-size: 12.3609394314px
```

> **Рекомендация:** Обычно лучше использовать `@each` или `@for` для ясности и скорости компиляции. `@while` нужен только для сложных случаев, когда количество итераций заранее неизвестно.

## Практические примеры

### Генерация утилитарных классов

```scss
$spacers: (0: 0, 1: 0.25rem, 2: 0.5rem, 3: 1rem, 4: 1.5rem, 5: 3rem);
$sides: (t: top, r: right, b: bottom, l: left);

@each $size-name, $size-value in $spacers {
  @each $side-name, $side-value in $sides {
    .m#{$side-name}-#{$size-name} {
      margin-#{$side-value}: $size-value;
    }
    .p#{$side-name}-#{$size-name} {
      padding-#{$side-value}: $size-value;
    }
  }
}
```

### Сетка

```scss
@use "sass:math";

$columns: 12;

@for $i from 1 through $columns {
  .col-#{$i} {
    width: math.percentage(math.div($i, $columns));
  }
}
```

### Генерация цветовых тем

```scss
$themes: (
  "light": ("bg": #fff, "text": #333, "primary": #007bff),
  "dark": ("bg": #1a1a1a, "text": #f0f0f0, "primary": #66b2ff),
);

@each $theme-name, $colors in $themes {
  [data-theme="#{$theme-name}"] {
    @each $prop, $value in $colors {
      --color-#{$prop}: #{$value};
    }
  }
}
```
