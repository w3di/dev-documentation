## 1. Основные компоненты

React Native не использует HTML. Каждый RN-компонент маппится на **нативный** компонент платформы:

| React Native | iOS | Android | Web-аналог |
|-------------|-----|---------|------------|
| `<View>` | `UIView` | `android.view.View` | `<div>` |
| `<Text>` | `UITextView` | `TextView` | `<p>` / `<span>` |
| `<Image>` | `UIImageView` | `ImageView` | `<img>` |
| `<ScrollView>` | `UIScrollView` | `ScrollView` | `<div style="overflow: scroll">` |
| `<TextInput>` | `UITextField` | `EditText` | `<input>` |
| `<Pressable>` | `UIControl` | `View + OnClickListener` | `<button>` |

### View

Базовый контейнер. Поддерживает layout (Flexbox), стилизацию, touch handling:

```jsx
<View style={{ flex: 1, backgroundColor: '#fff', padding: 16 }}>
  <View style={{ height: 100, backgroundColor: '#007AFF', borderRadius: 8 }} />
</View>
```

### Text

**Обязателен** для отображения текста. В отличие от веба, текст нельзя поместить напрямую в `View`:

```jsx
// ОШИБКА: текст вне <Text>
<View>Hello</View>

// ПРАВИЛЬНО
<View>
  <Text>Hello</Text>
</View>
```

Текст поддерживает вложенность для стилизации частей:

```jsx
<Text style={{ fontSize: 16 }}>
  Обычный текст <Text style={{ fontWeight: 'bold' }}>жирный</Text> и снова обычный
</Text>
```

### Image

```jsx
// Локальное изображение (require в build time)
<Image source={require('./assets/logo.png')} style={{ width: 100, height: 100 }} />

// Удалённое изображение (ОБЯЗАТЕЛЬНО указать размеры)
<Image
  source={{ uri: 'https://example.com/image.png' }}
  style={{ width: 200, height: 200 }}
  resizeMode="cover"
/>
```

`resizeMode`: `cover` | `contain` | `stretch` | `repeat` | `center`

### TextInput

```jsx
<TextInput
  value={text}
  onChangeText={setText}
  placeholder="Введите текст"
  keyboardType="email-address"  // numeric, phone-pad, etc.
  secureTextEntry={false}
  autoCapitalize="none"         // sentences, words, characters, none
  autoCorrect={false}
  returnKeyType="done"          // go, next, search, send
  onSubmitEditing={handleSubmit}
/>
```

## 2. StyleSheet

### StyleSheet.create()

`StyleSheet.create()` не просто объект со стилями — он валидирует стили при создании и создаёт оптимизированную ссылку:

```jsx
const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 16,
    // typo: 'colr' вызовет предупреждение при создании
  },
});
```

### Почему лучше inline-стилей

| Аспект | Inline стили | StyleSheet.create() |
|--------|-------------|-------------------|
| Создание объекта | Каждый рендер — новый объект | Один раз |
| Валидация | Нет | При создании |
| Читаемость | Засоряет JSX | Отдельно от разметки |
| Производительность | Пересоздание при каждом рендере | Статическая ссылка |

### StyleSheet.flatten()

Объединяет массив стилей в один объект:

```jsx
const combined = StyleSheet.flatten([styles.base, styles.override, { opacity: 0.5 }]);
// { fontSize: 16, color: 'red', opacity: 0.5 }
```

### StyleSheet.compose()

Создаёт составной стиль без слияния (более эффективно, чем flatten):

```jsx
const composed = StyleSheet.compose(styles.base, styles.override);
// Возвращает массив [styles.base, styles.override], не создавая новый объект
```

### Встроенные значения

```jsx
StyleSheet.hairlineWidth  // Минимальная толщина линии на платформе (1px / pixelRatio)
StyleSheet.absoluteFill   // { position: 'absolute', left: 0, right: 0, top: 0, bottom: 0 }
```

## 3. Flexbox в React Native

React Native использует Yoga (C++ Flexbox engine) с **отличиями от веб-CSS**.

### Ключевые отличия

| Свойство | Web CSS (default) | React Native (default) |
|----------|-------------------|----------------------|
| `flexDirection` | `row` | **`column`** |
| `flex` | shorthand (`1 0 auto`) | **только число** (`1`) |
| `alignContent` | `stretch` | `flex-start` |
| Единицы | px, em, rem, %, vw | **dp** (число) и `%` |
| CSS Grid | Да | **Нет** |
| `display` | block, flex, grid... | Только `flex` и `none` |

### flex в React Native

`flex: 1` в RN — это **не** shorthand для `flex: 1 0 auto`. Это единственное число, определяющее пропорцию:

```jsx
<View style={{ flex: 1, flexDirection: 'row' }}>
  <View style={{ flex: 1, backgroundColor: 'red' }} />    {/* 1/3 ширины */}
  <View style={{ flex: 2, backgroundColor: 'blue' }} />   {/* 2/3 ширины */}
</View>
```

### Полный набор Flexbox свойств

```jsx
const styles = StyleSheet.create({
  container: {
    // Направление основной оси
    flexDirection: 'column', // 'row' | 'column' | 'row-reverse' | 'column-reverse'

    // Выравнивание по основной оси
    justifyContent: 'flex-start', // 'center' | 'flex-end' | 'space-between' | 'space-around' | 'space-evenly'

    // Выравнивание по поперечной оси
    alignItems: 'stretch', // 'flex-start' | 'center' | 'flex-end' | 'baseline'

    // Перенос элементов
    flexWrap: 'nowrap', // 'wrap' | 'wrap-reverse'

    // Выравнивание строк при wrap
    alignContent: 'flex-start',

    // Отступы
    padding: 16,           // все стороны
    paddingHorizontal: 16, // left + right (RN-специфичный shorthand)
    paddingVertical: 8,    // top + bottom
    margin: 8,
    marginHorizontal: 8,
    marginVertical: 4,

    // Размеры
    width: 100,
    height: 100,
    minWidth: 50,
    maxWidth: 300,
    minHeight: 50,
    maxHeight: 500,

    // Gap (поддерживается)
    gap: 8,
    rowGap: 8,
    columnGap: 16,
  },

  child: {
    flex: 1,
    flexGrow: 1,
    flexShrink: 0,
    flexBasis: 'auto',
    alignSelf: 'center', // переопределяет alignItems родителя
  },
});
```

## 4. Платформо-специфичный код

### Platform.OS

```jsx
import { Platform } from 'react-native';

if (Platform.OS === 'ios') {
  // iOS-специфичный код
} else if (Platform.OS === 'android') {
  // Android-специфичный код
}
```

### Platform.select()

```jsx
const styles = StyleSheet.create({
  container: {
    ...Platform.select({
      ios: {
        shadowColor: '#000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.25,
        shadowRadius: 4,
      },
      android: {
        elevation: 4,
      },
    }),
  },
});
```

### Platform.Version

```jsx
// Android: API level (число)
if (Platform.OS === 'android' && Platform.Version >= 33) {
  // Android 13+ (API 33)
}

// iOS: строка версии
if (Platform.OS === 'ios' && parseInt(Platform.Version, 10) >= 17) {
  // iOS 17+
}
```

### Платформо-специфичные файлы

```
Button.ios.js      ← используется на iOS
Button.android.js  ← используется на Android
Button.js          ← fallback

// Импорт — всегда без расширения платформы
import Button from './Button'; // Metro автоматически выберет нужный файл
```

## 5. SafeAreaView и Edge-to-Edge

### Проблема

Современные устройства имеют вырезы (notch), скруглённые углы, dynamic island. Контент не должен перекрываться этими элементами.

### SafeAreaView (встроенный)

```jsx
import { SafeAreaView } from 'react-native';

function Screen() {
  return (
    <SafeAreaView style={{ flex: 1 }}>
      <Text>Контент внутри безопасной зоны</Text>
    </SafeAreaView>
  );
}
```

**Ограничение**: встроенный `SafeAreaView` работает только на iOS. Для кроссплатформенного решения используйте `react-native-safe-area-context`.

### react-native-safe-area-context

```jsx
import { SafeAreaProvider, useSafeAreaInsets } from 'react-native-safe-area-context';

// Обернуть корень приложения
function App() {
  return (
    <SafeAreaProvider>
      <Navigation />
    </SafeAreaProvider>
  );
}

// Использовать insets в компонентах
function Screen() {
  const insets = useSafeAreaInsets();

  return (
    <View style={{
      flex: 1,
      paddingTop: insets.top,
      paddingBottom: insets.bottom,
      paddingLeft: insets.left,
      paddingRight: insets.right,
    }}>
      <Text>Адаптивный контент</Text>
    </View>
  );
}
```

## 6. Обработка нажатий

### Pressable (рекомендуемый)

`Pressable` — современный компонент для обработки нажатий, заменяющий `TouchableOpacity`, `TouchableHighlight` и другие:

```jsx
<Pressable
  onPress={() => console.log('pressed')}
  onLongPress={() => console.log('long pressed')}
  onPressIn={() => console.log('press in')}
  onPressOut={() => console.log('press out')}
  hitSlop={10} // увеличение области нажатия (dp)
  android_ripple={{ color: 'rgba(0, 0, 0, 0.1)' }}
  style={({ pressed }) => [
    styles.button,
    pressed && styles.buttonPressed,
  ]}
>
  {({ pressed }) => (
    <Text style={pressed ? styles.textPressed : styles.text}>
      Нажми меня
    </Text>
  )}
</Pressable>
```

### Legacy Touchable-компоненты

| Компонент | Эффект | Статус |
|-----------|--------|--------|
| `Pressable` | Кастомный через style/children function | **Рекомендуемый** |
| `TouchableOpacity` | Уменьшение opacity | Legacy, но широко используется |
| `TouchableHighlight` | Подсветка фона | Legacy |
| `TouchableWithoutFeedback` | Без визуального эффекта | Legacy |

### hitSlop и pressRetentionOffset

```jsx
<Pressable
  hitSlop={20}
  // ↑ Увеличивает область нажатия на 20dp с каждой стороны
  // (элемент 44x44, но тапается как 84x84)

  pressRetentionOffset={{ top: 50, bottom: 50, left: 50, right: 50 }}
  // ↑ Как далеко палец может уйти от кнопки, сохраняя состояние "pressed"
/>
```

## 7. Клавиатура

### KeyboardAvoidingView

```jsx
import { KeyboardAvoidingView, Platform } from 'react-native';

<KeyboardAvoidingView
  style={{ flex: 1 }}
  behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
  keyboardVerticalOffset={Platform.OS === 'ios' ? 64 : 0}
>
  <ScrollView>
    <TextInput placeholder="Поле ввода" />
    <Pressable onPress={submit}>
      <Text>Отправить</Text>
    </Pressable>
  </ScrollView>
</KeyboardAvoidingView>
```

`behavior`:
- `padding` — добавляет paddingBottom (рекомендуется для iOS)
- `height` — уменьшает высоту контейнера (рекомендуется для Android)
- `position` — изменяет position

### Keyboard API

```jsx
import { Keyboard } from 'react-native';

// Скрыть клавиатуру
Keyboard.dismiss();

// Подписка на события
useEffect(() => {
  const showSub = Keyboard.addListener('keyboardDidShow', (e) => {
    console.log('Keyboard height:', e.endCoordinates.height);
  });
  const hideSub = Keyboard.addListener('keyboardDidHide', () => {
    console.log('Keyboard hidden');
  });

  return () => {
    showSub.remove();
    hideSub.remove();
  };
}, []);
```

### ScrollView + клавиатура

```jsx
<ScrollView
  keyboardShouldPersistTaps="handled"
  // 'never' — тап вне input скрывает клавиатуру (default)
  // 'always' — клавиатура не скрывается при тапе
  // 'handled' — скрывается, если тап не на интерактивном элементе
  keyboardDismissMode="on-drag"
  // 'none' | 'on-drag' | 'interactive' (iOS)
/>
```

## 8. Размеры и адаптивность

### Единицы измерения

В React Native все числовые значения — **density-independent pixels (dp)**:

```jsx
// 16 dp, не 16 px
{ fontSize: 16, padding: 8, margin: 4 }
```

dp автоматически масштабируется в зависимости от плотности экрана:
- `1dp = 1px` при density 1 (mdpi)
- `1dp = 2px` при density 2 (xhdpi, iPhone 6-8)
- `1dp = 3px` при density 3 (xxhdpi, iPhone 6+ и выше)

### PixelRatio

```jsx
import { PixelRatio } from 'react-native';

PixelRatio.get();          // 2 или 3 — плотность пикселей
PixelRatio.getFontScale(); // Множитель шрифта (системные настройки доступности)

// Округление до ближайшего пикселя
PixelRatio.roundToNearestPixel(8.4); // 8.333... на 3x экране → 8.333 (25/3)
```

### useWindowDimensions

```jsx
import { useWindowDimensions } from 'react-native';

function ResponsiveComponent() {
  const { width, height, fontScale } = useWindowDimensions();
  // Реагирует на изменение размеров (поворот, split screen)

  const isTablet = width >= 768;
  const columns = isTablet ? 3 : 2;

  return (
    <FlatList
      data={items}
      numColumns={columns}
      key={columns} // FlatList требует новый key при изменении numColumns
      renderItem={renderItem}
    />
  );
}
```

### Dimensions API

```jsx
import { Dimensions } from 'react-native';

// Статичное получение (не обновляется при повороте)
const { width, height } = Dimensions.get('window'); // без system bars
const screen = Dimensions.get('screen');             // полный экран

// Подписка на изменения
Dimensions.addEventListener('change', ({ window, screen }) => {
  console.log('New dimensions:', window.width, window.height);
});
```

Предпочитайте `useWindowDimensions` hook — он реактивный и автоматически вызывает ре-рендер.

## 9. StatusBar

```jsx
import { StatusBar } from 'react-native';

<StatusBar
  barStyle="dark-content"      // 'light-content' | 'dark-content' | 'default'
  backgroundColor="#ffffff"    // только Android
  translucent={true}           // только Android — контент под StatusBar
  hidden={false}
  animated={true}
/>
```

Императивный API:

```jsx
StatusBar.setBarStyle('light-content', true);
StatusBar.setBackgroundColor('#000000', true); // Android
StatusBar.setHidden(true, 'slide');            // 'none' | 'fade' | 'slide'
```

## 10. Сравнение с Web CSS

| Web CSS | React Native | Комментарий |
|---------|-------------|-------------|
| `display: block` | Нет | Только `flex` и `none` |
| `display: grid` | Нет | Только Flexbox |
| `float` | Нет | Используйте Flexbox |
| `position: fixed` | Нет | Используйте `position: 'absolute'` + `SafeAreaView` |
| `z-index` | Ограничен | Работает, но поведение отличается на Android |
| `overflow: scroll` | Нет | Используйте `<ScrollView>` |
| `box-shadow` | Нет | iOS: `shadow*` свойства, Android: `elevation` |
| `border-radius` | `borderRadius` | camelCase, числа в dp |
| `background-image` | Нет | Используйте `<ImageBackground>` |
| `@media queries` | Нет | `useWindowDimensions` + условная логика |
| `transform` | `transform: [{}]` | Массив объектов: `[{ rotate: '45deg' }, { scale: 0.5 }]` |
| `opacity: 0.5` | `opacity: 0.5` | Работает одинаково |
| `font-family` | `fontFamily` | Требует регистрации шрифта в нативном проекте |
| `cursor: pointer` | Нет | Нет курсора на мобильных устройствах |
| `transition` | Нет | Используйте `Animated` API или `Reanimated` |
| `animation` | Нет | Используйте `Animated` API или `Reanimated` |
| `:hover` | Нет | `Pressable` с `onHoverIn`/`onHoverOut` (десктоп) |
| `em`/`rem` | Нет | Только числа (dp) и `%` |
| `calc()` | Нет | Вычисляйте в JS |
| `var()` / CSS variables | Нет | Используйте JS-константы |
| Каскадирование | Нет | Стили не наследуются (кроме `Text`) |

### Наследование стилей

В React Native стили **не каскадируются** от родителя к потомку. Исключение — `<Text>`:

```jsx
// Веб: color наследуется от div
<div style={{ color: 'red' }}>
  <span>Красный текст</span>  {/* Наследует color */}
</div>

// React Native: color НЕ наследуется от View
<View style={{ color: 'red' }}>
  <Text>Текст БЕЗ цвета</Text>  {/* Не наследует */}
</View>

// Но Text наследует от другого Text
<Text style={{ color: 'red' }}>
  <Text>Красный текст</Text>  {/* Наследует color */}
</Text>
```
