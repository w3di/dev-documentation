## 1. Обзор способов хранения

| Решение | Тип данных | Безопасность | Скорость | Когда использовать |
|---------|-----------|-------------|----------|-------------------|
| **AsyncStorage** | Key-Value (строки) | Не зашифровано | Медленно | Настройки, кеш, простые данные |
| **MMKV** | Key-Value (разные типы) | Не зашифровано (есть опция) | **Очень быстро** | Замена AsyncStorage |
| **SecureStore / Keychain** | Key-Value (строки) | **Зашифровано** | Средне | Токены, пароли, ключи |
| **SQLite** | Реляционные данные | Не зашифровано | Быстро | Сложные запросы, большие объёмы |
| **File System** | Файлы | Не зашифровано | Зависит | Файлы, логи, экспорт |

## 2. AsyncStorage

`@react-native-async-storage/async-storage` — простое key-value хранилище на основе нативных решений (SharedPreferences на Android, NSUserDefaults на iOS).

### API

```jsx
import AsyncStorage from '@react-native-async-storage/async-storage';

// Запись
await AsyncStorage.setItem('user_name', 'John');

// Чтение
const name = await AsyncStorage.getItem('user_name'); // 'John' или null

// Удаление
await AsyncStorage.removeItem('user_name');

// Хранение объектов (ручная сериализация)
await AsyncStorage.setItem('user', JSON.stringify({ name: 'John', age: 30 }));
const user = JSON.parse(await AsyncStorage.getItem('user'));

// Множественные операции (batch)
await AsyncStorage.multiSet([
  ['key1', 'value1'],
  ['key2', 'value2'],
]);

const values = await AsyncStorage.multiGet(['key1', 'key2']);
// [['key1', 'value1'], ['key2', 'value2']]

// Все ключи
const allKeys = await AsyncStorage.getAllKeys();

// Очистка
await AsyncStorage.clear();
```

### Ограничения

- **Только строки** — объекты нужно сериализовать вручную (JSON.stringify)
- **Не зашифровано** — данные доступны на rooted/jailbroken устройствах
- **Асинхронный** — каждая операция возвращает Promise
- **Медленный** для больших объёмов данных
- **Лимит размера**: Android ~6MB по умолчанию, iOS — без явного лимита

## 3. MMKV

`react-native-mmkv` — высокопроизводительное key-value хранилище от WeChat (Tencent). **В 30x быстрее AsyncStorage**.

### API

```jsx
import { MMKV } from 'react-native-mmkv';

const storage = new MMKV();

// Синхронная запись (не нужен await!)
storage.set('user.name', 'John');
storage.set('user.age', 30);           // number
storage.set('user.premium', true);     // boolean
storage.set('user.data', jsonString);  // string

// Синхронное чтение
const name = storage.getString('user.name');   // 'John'
const age = storage.getNumber('user.age');     // 30
const premium = storage.getBoolean('user.premium'); // true

// Проверка существования
storage.contains('user.name'); // true

// Удаление
storage.delete('user.name');

// Все ключи
const keys = storage.getAllKeys(); // string[]

// Очистка
storage.clearAll();
```

### Преимущества над AsyncStorage

| Аспект | AsyncStorage | MMKV |
|--------|-------------|------|
| API | Асинхронный (Promise) | **Синхронный** |
| Типы данных | Только string | string, number, boolean, Buffer |
| Скорость | ~10ms на операцию | **~0.01ms** на операцию |
| Шифрование | Нет | Опционально |
| Сериализация | Ручная (JSON) | Встроенная для примитивов |

### Шифрование

```jsx
const encryptedStorage = new MMKV({
  id: 'secure-storage',
  encryptionKey: 'my-encryption-key',
});
```

### Zustand + MMKV

```jsx
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import { MMKV } from 'react-native-mmkv';

const storage = new MMKV();

const zustandStorage = {
  getItem: (name) => storage.getString(name) ?? null,
  setItem: (name, value) => storage.set(name, value),
  removeItem: (name) => storage.delete(name),
};

const useStore = create(
  persist(
    (set) => ({
      theme: 'light',
      setTheme: (theme) => set({ theme }),
    }),
    {
      name: 'app-storage',
      storage: createJSONStorage(() => zustandStorage),
    }
  )
);
```

## 4. Secure Storage

Для хранения **секретных данных** (токены, пароли, API ключи).

### expo-secure-store

```jsx
import * as SecureStore from 'expo-secure-store';

// Запись
await SecureStore.setItemAsync('auth_token', 'eyJhbGc...');

// Чтение
const token = await SecureStore.getItemAsync('auth_token');

// Удаление
await SecureStore.deleteItemAsync('auth_token');
```

Под капотом:
- **iOS**: Keychain Services (аппаратное шифрование через Secure Enclave)
- **Android**: Encrypted SharedPreferences (Android Keystore)

### react-native-keychain

```jsx
import * as Keychain from 'react-native-keychain';

// Сохранение credentials
await Keychain.setGenericPassword('username', 'password');

// Чтение
const credentials = await Keychain.getGenericPassword();
if (credentials) {
  console.log(credentials.username, credentials.password);
}

// Удаление
await Keychain.resetGenericPassword();

// Биометрическая защита
await Keychain.setGenericPassword('user', 'pass', {
  accessControl: Keychain.ACCESS_CONTROL.BIOMETRY_ANY,
  // Потребует Face ID / Touch ID / Fingerprint для доступа
});
```

### Что хранить в Secure Storage

| Хранить | Не хранить |
|---------|-----------|
| Access tokens | Настройки приложения |
| Refresh tokens | Кеш данных |
| Пароли | Флаги onboarding |
| API ключи (если неизбежно) | История поиска |
| Пин-коды | Данные списков |

## 5. SQLite

Для **сложных реляционных данных** и **больших объёмов**.

### expo-sqlite

```jsx
import * as SQLite from 'expo-sqlite';

const db = await SQLite.openDatabaseAsync('myapp.db');

// Создание таблицы
await db.execAsync(`
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
`);

// Вставка
await db.runAsync(
  'INSERT INTO users (name, email) VALUES (?, ?)',
  ['John', 'john@example.com']
);

// Чтение
const users = await db.getAllAsync('SELECT * FROM users WHERE name LIKE ?', ['%John%']);

// Одна запись
const user = await db.getFirstAsync('SELECT * FROM users WHERE id = ?', [1]);
```

### Когда использовать SQLite

- Данные с **связями** (пользователи → посты → комментарии)
- **Сложные запросы** (фильтрация, сортировка, группировка, JOIN)
- **Большие объёмы** (тысячи/десятки тысяч записей)
- **Offline-first** приложения

## 6. File System

### expo-file-system

```jsx
import * as FileSystem from 'expo-file-system';

// Директории
FileSystem.documentDirectory  // постоянное хранение
FileSystem.cacheDirectory     // может быть очищено ОС

// Запись файла
await FileSystem.writeAsStringAsync(
  FileSystem.documentDirectory + 'data.json',
  JSON.stringify(data)
);

// Чтение файла
const content = await FileSystem.readAsStringAsync(
  FileSystem.documentDirectory + 'data.json'
);

// Скачивание файла
const { uri } = await FileSystem.downloadAsync(
  'https://example.com/file.pdf',
  FileSystem.cacheDirectory + 'file.pdf'
);

// Информация о файле
const info = await FileSystem.getInfoAsync(uri);
// { exists: true, size: 1024, modificationTime: 1234567890 }

// Удаление
await FileSystem.deleteAsync(uri);
```

## 7. Сравнительная таблица

| Критерий | AsyncStorage | MMKV | SecureStore | SQLite | FileSystem |
|----------|-------------|------|------------|--------|-----------|
| Тип | Key-Value | Key-Value | Key-Value | Реляционное | Файлы |
| API | Async | **Sync** | Async | Async | Async |
| Шифрование | Нет | Опционально | **Да** | Нет | Нет |
| Скорость | Медленно | **Очень быстро** | Средне | Быстро | Зависит |
| Типы данных | String | String, Number, Bool | String | SQL types | String/Binary |
| Сложные запросы | Нет | Нет | Нет | **Да** (SQL) | Нет |
| Объём данных | Малый | Средний | Малый | **Большой** | **Большой** |
| Для чего | Настройки | Настройки, кеш | Секреты | Данные | Файлы |
