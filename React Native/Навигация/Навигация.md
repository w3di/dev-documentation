## 1. Обзор навигации

В React Native нет встроенного роутера. Основные решения:

| Библиотека | Подход | Рендеринг |
|-----------|--------|-----------|
| **React Navigation** | Императивный + декларативный | JS + Native |
| **Expo Router** | File-based routing | Обёртка над React Navigation |
| **react-native-navigation (Wix)** | Полностью нативный | Native |

React Navigation — стандарт де-факто. Expo Router — рекомендуется для Expo-проектов.

## 2. React Navigation

### Установка

```bash
npm install @react-navigation/native
npm install react-native-screens react-native-safe-area-context
```

### Базовая структура

```jsx
import { NavigationContainer } from '@react-navigation/native';

function App() {
  return (
    <NavigationContainer>
      {/* Навигаторы здесь */}
    </NavigationContainer>
  );
}
```

### Навигация между экранами

```jsx
function HomeScreen({ navigation }) {
  return (
    <View>
      {/* Переход на экран */}
      <Pressable onPress={() => navigation.navigate('Details', { id: 42 })}>
        <Text>Go to Details</Text>
      </Pressable>

      {/* Push — всегда добавляет новый экран в стек */}
      <Pressable onPress={() => navigation.push('Details', { id: 43 })}>
        <Text>Push Details</Text>
      </Pressable>

      {/* Назад */}
      <Pressable onPress={() => navigation.goBack()}>
        <Text>Go Back</Text>
      </Pressable>
    </View>
  );
}

// Получение параметров
function DetailsScreen({ route }) {
  const { id } = route.params;
  return <Text>Details for ID: {id}</Text>;
}
```

### navigate vs push

```
navigate('Details'):
  Если Details уже в стеке → перейти к нему (не создавать новый)
  Если нет → создать и добавить

push('Details'):
  Всегда создаёт новый экземпляр экрана в стеке
```

## 3. Stack Navigator

### Native Stack (рекомендуемый)

Использует нативные анимации переходов (`UINavigationController` на iOS, `Fragment` на Android):

```jsx
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

function AppStack() {
  return (
    <Stack.Navigator
      initialRouteName="Home"
      screenOptions={{
        headerStyle: { backgroundColor: '#007AFF' },
        headerTintColor: '#fff',
        headerTitleStyle: { fontWeight: 'bold' },
        animation: 'slide_from_right', // iOS-style transition
      }}
    >
      <Stack.Screen
        name="Home"
        component={HomeScreen}
        options={{ title: 'Главная' }}
      />
      <Stack.Screen
        name="Details"
        component={DetailsScreen}
        options={({ route }) => ({
          title: `Детали #${route.params.id}`,
          headerBackTitle: 'Назад',
        })}
      />
      <Stack.Screen
        name="Modal"
        component={ModalScreen}
        options={{
          presentation: 'modal',          // модальное представление
          animation: 'slide_from_bottom', // анимация снизу вверх
        }}
      />
    </Stack.Navigator>
  );
}
```

### Анимации перехода

```jsx
// Native Stack анимации
animation: 'default'           // платформенная анимация
animation: 'slide_from_right'  // слайд справа
animation: 'slide_from_left'   // слайд слева
animation: 'slide_from_bottom' // слайд снизу (для модалок)
animation: 'fade'              // fade
animation: 'none'              // без анимации
```

## 4. Tab Navigator

### Bottom Tabs

```jsx
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';

const Tab = createBottomTabNavigator();

function MainTabs() {
  return (
    <Tab.Navigator
      screenOptions={({ route }) => ({
        tabBarIcon: ({ focused, color, size }) => {
          // Иконка для каждого таба
          const iconName = route.name === 'Home' ? 'home' : 'settings';
          return <Icon name={iconName} size={size} color={color} />;
        },
        tabBarActiveTintColor: '#007AFF',
        tabBarInactiveTintColor: 'gray',
        headerShown: false, // скрыть header (если свой внутри)
      })}
    >
      <Tab.Screen name="Home" component={HomeStack} />
      <Tab.Screen name="Search" component={SearchScreen} />
      <Tab.Screen
        name="Profile"
        component={ProfileScreen}
        options={{ tabBarBadge: 3 }} // Badge на табе
      />
    </Tab.Navigator>
  );
}
```

### Material Top Tabs

Свайп-табы сверху (как в Twitter/Instagram):

```jsx
import { createMaterialTopTabNavigator } from '@react-navigation/material-top-tabs';

const TopTab = createMaterialTopTabNavigator();

function ProfileTabs() {
  return (
    <TopTab.Navigator
      screenOptions={{
        tabBarLabelStyle: { fontSize: 14, fontWeight: '600' },
        tabBarIndicatorStyle: { backgroundColor: '#007AFF' },
        swipeEnabled: true,
        lazy: true, // рендерить таб только при переключении
      }}
    >
      <TopTab.Screen name="Posts" component={PostsTab} />
      <TopTab.Screen name="Likes" component={LikesTab} />
      <TopTab.Screen name="Media" component={MediaTab} />
    </TopTab.Navigator>
  );
}
```

## 6. Вложенная навигация

Типичная структура приложения:

```
NavigationContainer
  └── Stack Navigator (Root)
       ├── Screen: Auth (Stack)
       │    ├── Login
       │    └── Register
       └── Screen: Main (Tab)
            ├── Tab: Home (Stack)
            │    ├── Feed
            │    └── PostDetails
            ├── Tab: Search
            └── Tab: Profile (Stack)
                 ├── MyProfile
                 └── EditProfile
```

```jsx
function RootNavigator() {
  const { isAuthenticated } = useAuth();

  return (
    <Stack.Navigator screenOptions={{ headerShown: false }}>
      {isAuthenticated ? (
        <Stack.Screen name="Main" component={MainTabs} />
      ) : (
        <Stack.Screen name="Auth" component={AuthStack} />
      )}
    </Stack.Navigator>
  );
}
```

### Навигация между вложенными навигаторами

```jsx
// Из Home (Tab) перейти в PostDetails (внутри Home Stack)
navigation.navigate('PostDetails', { id: 42 });

// Из любого места перейти на конкретный экран внутри вложенного навигатора
navigation.navigate('Main', {
  screen: 'Profile',
  params: {
    screen: 'EditProfile',
  },
});
```

## 7. Deep Linking

### Конфигурация

```jsx
const linking = {
  prefixes: ['myapp://', 'https://myapp.com'],
  config: {
    screens: {
      Main: {
        screens: {
          Home: {
            screens: {
              Feed: 'feed',
              PostDetails: 'post/:id',
            },
          },
          Profile: 'profile/:userId',
        },
      },
      Auth: {
        screens: {
          Login: 'login',
        },
      },
    },
  },
};

<NavigationContainer linking={linking}>
  <RootNavigator />
</NavigationContainer>
```

### URL Scheme vs Universal Links

| Тип | Формат | Безопасность |
|-----|--------|-------------|
| **URL Scheme** | `myapp://post/42` | Небезопасно — любое приложение может зарегистрировать такую же схему |
| **Universal Links** (iOS) | `https://myapp.com/post/42` | Безопасно — привязано к домену через `apple-app-site-association` |
| **App Links** (Android) | `https://myapp.com/post/42` | Безопасно — привязано к домену через `assetlinks.json` |

**Никогда не передавайте конфиденциальные данные через URL Scheme** — их может перехватить вредоносное приложение.

## 8. Типизация навигации (TypeScript)

```typescript
// Определение типов параметров
type RootStackParamList = {
  Home: undefined;
  Details: { id: number; title: string };
  Modal: { message: string } | undefined;
};

// Типизированный навигатор
const Stack = createNativeStackNavigator<RootStackParamList>();

// Типизированные props экрана
import type { NativeStackScreenProps } from '@react-navigation/native-stack';

type DetailsProps = NativeStackScreenProps<RootStackParamList, 'Details'>;

function DetailsScreen({ route, navigation }: DetailsProps) {
  const { id, title } = route.params; // TypeScript знает типы
  navigation.navigate('Home');         // TypeScript проверяет имя экрана
}

// Использование useNavigation с типизацией
import { useNavigation } from '@react-navigation/native';
import type { NativeStackNavigationProp } from '@react-navigation/native-stack';

type NavigationProp = NativeStackNavigationProp<RootStackParamList>;

function SomeComponent() {
  const navigation = useNavigation<NavigationProp>();
  navigation.navigate('Details', { id: 1, title: 'Test' }); // type-safe
}
```

## 9. Производительность навигации

### Native Stack vs JS Stack

| Аспект | `@react-navigation/stack` | `@react-navigation/native-stack` |
|--------|--------------------------|----------------------------------|
| Анимация | JS Thread | **Native Thread** |
| Производительность | Ниже | **Значительно выше** |
| Кастомизация | Больше | Ограничена платформой |
| Рекомендация | Только если нужна кастомная анимация | **По умолчанию** |

### react-native-screens

`react-native-screens` оптимизирует memory usage, конвертируя экраны в нативные `Fragment` (Android) и `UIViewController` (iOS):

```jsx
// Включается автоматически при использовании native-stack
// Неактивные экраны выгружаются из памяти (detached)
// Активный экран — native view controller
```

### Оптимизации

```jsx
// Lazy-загрузка табов
<Tab.Navigator screenOptions={{ lazy: true }}>
  {/* Контент таба рендерится только при первом переключении */}
</Tab.Navigator>

// Отключение анимации для тяжёлых экранов
<Stack.Screen
  name="HeavyScreen"
  options={{ animation: 'none' }}
/>

// freezeOnBlur — замораживает неактивные экраны
<Tab.Navigator screenOptions={{ freezeOnBlur: true }}>
```

## 10. Expo Router

Expo Router — file-based routing система, построенная поверх React Navigation.

### Структура файлов = структура навигации

```
app/
├── _layout.tsx        → Root Layout
├── index.tsx          → / (Home)
├── about.tsx          → /about
├── (tabs)/
│   ├── _layout.tsx    → Tab Navigator
│   ├── index.tsx      → / (первый таб)
│   ├── search.tsx     → /search
│   └── profile.tsx    → /profile
├── post/
│   ├── [id].tsx       → /post/:id (динамический маршрут)
│   └── _layout.tsx    → Layout для post/*
└── (auth)/
    ├── _layout.tsx    → Auth Layout
    ├── login.tsx      → /login
    └── register.tsx   → /register
```

### Layout файлы

```tsx
// app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      <Stack.Screen name="post/[id]" options={{ title: 'Пост' }} />
      <Stack.Screen name="(auth)" options={{ headerShown: false }} />
    </Stack>
  );
}
```

### Навигация

```tsx
import { Link, useRouter } from 'expo-router';

// Декларативная навигация
<Link href="/post/42">Открыть пост</Link>

// Императивная навигация
const router = useRouter();
router.push('/post/42');
router.replace('/login');  // замена текущего экрана
router.back();             // назад

// Типизированные параметры
import { useLocalSearchParams } from 'expo-router';

function PostScreen() {
  const { id } = useLocalSearchParams<{ id: string }>();
  return <Text>Post ID: {id}</Text>;
}
```

### Преимущества Expo Router

- **File-based routing** — структура папок = структура навигации
- **Deep linking из коробки** — каждый файл автоматически имеет URL
- **TypeScript** — автоматическая типизация маршрутов
- **SEO** — поддержка web (head, meta tags)
- **Universal** — один код для iOS, Android, Web
