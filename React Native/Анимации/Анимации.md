## 1. Обзор анимаций

В React Native три подхода к анимациям:

| Подход | Когда использовать | Поток выполнения |
|--------|--------------------|-----------------|
| `Animated` API | Стандартные анимации (fade, slide, scale) | JS или Native Thread |
| `LayoutAnimation` | Простые layout-изменения | Native Thread |
| `react-native-reanimated` | Сложные gesture-driven анимации, worklets | **UI Thread** |

## 2. Animated API

### Animated.Value

Базовый строительный блок — `Animated.Value`:

```jsx
// Создание (всегда через useRef)
const fadeAnim = useRef(new Animated.Value(0)).current;
// ↑ .current — потому что useRef оборачивает в { current: value }
// Animated.Value создаётся ОДИН раз, не при каждом рендере

// Использование
<Animated.View style={{ opacity: fadeAnim }}>
  <Text>Fade in/out</Text>
</Animated.View>
```

### Animated.ValueXY

Для анимаций по двум осям (drag, pan):

```jsx
const pan = useRef(new Animated.ValueXY({ x: 0, y: 0 })).current;

<Animated.View style={{ transform: pan.getTranslateTransform() }}>
  {/* getTranslateTransform() = [{ translateX: x }, { translateY: y }] */}
</Animated.View>
```

### Анимируемые компоненты

Встроенные: `Animated.View`, `Animated.Text`, `Animated.Image`, `Animated.ScrollView`, `Animated.FlatList`, `Animated.SectionList`.

Кастомный:

```jsx
const AnimatedPressable = Animated.createAnimatedComponent(Pressable);
```

## 3. Типы анимаций

### timing() — линейная/кривая анимация

```jsx
Animated.timing(fadeAnim, {
  toValue: 1,
  duration: 300,           // ms
  easing: Easing.ease,     // кривая ускорения
  delay: 100,              // задержка перед стартом
  useNativeDriver: true,
}).start((finished) => {
  // callback по завершении
  if (finished) console.log('Animation complete');
});
```

Easing кривые:

```jsx
import { Easing } from 'react-native';

Easing.linear          // постоянная скорость
Easing.ease            // аналог CSS ease
Easing.in(Easing.ease) // ускорение в начале
Easing.out(Easing.ease)// замедление в конце
Easing.inOut(Easing.ease) // ускорение + замедление
Easing.bounce          // отскок
Easing.elastic(1)      // упругость
Easing.bezier(0.25, 0.1, 0.25, 1) // кастомная кривая Безье
```

### spring() — физическая пружинная анимация

```jsx
Animated.spring(scaleAnim, {
  toValue: 1,
  // Модель пружины (два API):

  // API 1: Bounciness/Speed (проще)
  friction: 7,     // сопротивление (больше = меньше колебаний)
  tension: 40,     // натяжение (больше = быстрее)

  // API 2: Stiffness/Damping/Mass (точнее)
  // stiffness: 100,  // жёсткость пружины
  // damping: 10,     // затухание
  // mass: 1,         // масса объекта

  useNativeDriver: true,
}).start();
```

### decay() — затухающая анимация

Анимация по инерции с начальной скоростью:

```jsx
Animated.decay(translateX, {
  velocity: 0.5,         // начальная скорость (px/ms)
  deceleration: 0.997,   // коэффициент замедления (0-1, ближе к 1 = медленнее)
  useNativeDriver: true,
}).start();
```

## 4. Композиция анимаций

### sequence() — последовательно

```jsx
Animated.sequence([
  Animated.timing(fadeAnim, { toValue: 1, duration: 200, useNativeDriver: true }),
  Animated.timing(slideAnim, { toValue: 100, duration: 300, useNativeDriver: true }),
  Animated.spring(scaleAnim, { toValue: 1, useNativeDriver: true }),
]).start();
// fade → slide → scale (одна за другой)
```

### parallel() — параллельно

```jsx
Animated.parallel([
  Animated.timing(fadeAnim, { toValue: 1, duration: 300, useNativeDriver: true }),
  Animated.timing(slideAnim, { toValue: 100, duration: 300, useNativeDriver: true }),
]).start();
// fade + slide одновременно
```

### stagger() — с задержкой

```jsx
Animated.stagger(100, [
  Animated.timing(item1, { toValue: 1, duration: 200, useNativeDriver: true }),
  Animated.timing(item2, { toValue: 1, duration: 200, useNativeDriver: true }),
  Animated.timing(item3, { toValue: 1, duration: 200, useNativeDriver: true }),
]).start();
// item1 → (100ms) → item2 → (100ms) → item3
```

### loop() — цикл

```jsx
Animated.loop(
  Animated.sequence([
    Animated.timing(pulseAnim, { toValue: 1.2, duration: 500, useNativeDriver: true }),
    Animated.timing(pulseAnim, { toValue: 1, duration: 500, useNativeDriver: true }),
  ]),
  { iterations: -1 } // -1 = бесконечно
).start();
```

### delay()

```jsx
Animated.sequence([
  Animated.timing(fadeAnim, { toValue: 1, duration: 200, useNativeDriver: true }),
  Animated.delay(500), // пауза 500ms
  Animated.timing(fadeAnim, { toValue: 0, duration: 200, useNativeDriver: true }),
]).start();
```

## 5. Animated.event()

Маппинг нативных событий напрямую на `Animated.Value` без прохождения через JS:

```jsx
const scrollY = useRef(new Animated.Value(0)).current;

<Animated.ScrollView
  onScroll={Animated.event(
    [{ nativeEvent: { contentOffset: { y: scrollY } } }],
    { useNativeDriver: true }
    // ↑ Значение обновляется на Native Thread
    // без передачи каждого кадра скролла в JS
  )}
  scrollEventThrottle={16} // 16ms = 60fps
>
  {content}
</Animated.ScrollView>

// Использование scrollY для параллакс-эффекта
<Animated.Image
  style={{
    transform: [{
      translateY: scrollY.interpolate({
        inputRange: [0, 200],
        outputRange: [0, -100],
      })
    }]
  }}
/>
```

## 6. useNativeDriver

`useNativeDriver: true` — **обязательный параметр** для всех конфигов анимаций.

### Что он делает

Без native driver: JS Thread вычисляет значение → передаёт в Native → обновляет view (каждый кадр).

С native driver: описание анимации отправляется в Native **один раз**, затем Native Thread выполняет её самостоятельно.

### Поддерживаемые свойства

```jsx
// РАБОТАЮТ с useNativeDriver: true
transform: [
  { translateX: anim },
  { translateY: anim },
  { scale: anim },
  { scaleX: anim },
  { scaleY: anim },
  { rotate: anim },      // строка: '45deg'
  { rotateX: anim },
  { rotateY: anim },
  { perspective: anim },
]
opacity: anim

// НЕ РАБОТАЮТ с useNativeDriver: true (нужен пересчёт layout)
width: anim       // ✗
height: anim      // ✗
top/left/...: anim // ✗
padding: anim     // ✗
margin: anim      // ✗
backgroundColor: anim // ✗
borderRadius: anim    // ✗
fontSize: anim        // ✗
```

### Workaround для layout-анимаций

```jsx
// Вместо анимации width — анимация scaleX
const widthAnim = useRef(new Animated.Value(0)).current;

<Animated.View style={{
  width: 200, // фиксированная ширина
  transform: [{ scaleX: widthAnim }], // анимация масштаба
  transformOrigin: 'left', // от левого края
}} />
```

## 7. Интерполяция

`interpolate()` маппит одно значение в другое:

```jsx
const rotation = scrollY.interpolate({
  inputRange: [0, 100],
  outputRange: ['0deg', '360deg'],
});

const backgroundColor = progress.interpolate({
  inputRange: [0, 0.5, 1],
  outputRange: ['rgb(255,0,0)', 'rgb(255,255,0)', 'rgb(0,255,0)'],
});

const opacity = scrollY.interpolate({
  inputRange: [0, 100, 200],
  outputRange: [1, 0.5, 0],
  extrapolate: 'clamp', // не выходить за пределы outputRange
  // 'extend' (default) — продолжить линию
  // 'clamp' — зажать в пределах min/max outputRange
  // 'identity' — значение = inputValue
});
```

### Extrapolation

```
extrapolate: 'extend' (default)
Input:  -50   0   100   150
Output: -0.5  0   1     1.5  ← продолжает линию

extrapolate: 'clamp'
Input:  -50   0   100   150
Output:  0    0   1     1    ← зажимает

extrapolateLeft / extrapolateRight — раздельная настройка
```

## 8. LayoutAnimation

LayoutAnimation — простой API для анимации **layout-изменений** (появление/исчезновение, изменение размеров):

```jsx
import { LayoutAnimation, Platform, UIManager } from 'react-native';

// Android: включить флаг (один раз, в App.tsx)
if (Platform.OS === 'android' && UIManager.setLayoutAnimationEnabledExperimental) {
  UIManager.setLayoutAnimationEnabledExperimental(true);
}

function ExpandableCard() {
  const [expanded, setExpanded] = useState(false);

  const toggle = () => {
    // Вызвать ПЕРЕД setState
    LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut);
    setExpanded(!expanded);
  };

  return (
    <Pressable onPress={toggle}>
      <View style={{ height: expanded ? 200 : 80 }}>
        <Text>Нажми для {expanded ? 'сжатия' : 'расширения'}</Text>
      </View>
    </Pressable>
  );
}
```

### Presets

```jsx
LayoutAnimation.Presets.easeInEaseOut  // плавно
LayoutAnimation.Presets.linear         // линейно
LayoutAnimation.Presets.spring         // пружина
```

### Кастомная конфигурация

```jsx
LayoutAnimation.configureNext({
  duration: 300,
  create: { type: 'easeInEaseOut', property: 'opacity' },
  update: { type: 'spring', springDamping: 0.7 },
  delete: { type: 'easeInEaseOut', property: 'opacity' },
});
```

### Когда использовать

- Добавление/удаление элементов из списка
- Раскрытие/сворачивание секций
- Переключение layout (grid ↔ list)
- Простые изменения размеров

Для gesture-driven или сложных анимаций — используйте Reanimated.

## 9. Reanimated

`react-native-reanimated` — библиотека для **высокопроизводительных анимаций**, работающих на UI Thread.

### Ключевая концепция: Worklets

Worklet — это JS-функция, которая компилируется и выполняется на **UI Thread**, а не на JS Thread:

```jsx
import Animated, {
  useSharedValue,
  useAnimatedStyle,
  withTiming,
  withSpring,
} from 'react-native-reanimated';

function AnimatedBox() {
  const offset = useSharedValue(0);
  // ↑ SharedValue — значение, доступное из JS и UI потоков

  const animatedStyle = useAnimatedStyle(() => {
    // ↑ Эта функция — worklet, выполняется на UI Thread
    return {
      transform: [{ translateX: offset.value }],
    };
  });

  const handlePress = () => {
    offset.value = withSpring(200);
    // ↑ Анимация полностью на UI Thread
  };

  return (
    <Animated.View style={[styles.box, animatedStyle]}>
      <Pressable onPress={handlePress}>
        <Text>Нажми</Text>
      </Pressable>
    </Animated.View>
  );
}
```

### Анимационные функции

```jsx
// Timing (аналог Animated.timing)
offset.value = withTiming(200, {
  duration: 300,
  easing: Easing.bezier(0.25, 0.1, 0.25, 1),
});

// Spring (аналог Animated.spring)
offset.value = withSpring(200, {
  damping: 10,
  stiffness: 100,
  mass: 1,
});

// Decay (аналог Animated.decay)
offset.value = withDecay({
  velocity: velocity.value,
  deceleration: 0.998,
});

// Последовательность
offset.value = withSequence(
  withTiming(100, { duration: 200 }),
  withTiming(0, { duration: 200 }),
);

// Повтор
offset.value = withRepeat(
  withTiming(200, { duration: 500 }),
  -1,   // бесконечно
  true  // reverse
);
```

### Gesture Handler интеграция

```jsx
import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import Animated, { useSharedValue, useAnimatedStyle, withDecay } from 'react-native-reanimated';

function DraggableBox() {
  const translateX = useSharedValue(0);
  const translateY = useSharedValue(0);
  const context = useSharedValue({ x: 0, y: 0 });

  const pan = Gesture.Pan()
    .onStart(() => {
      context.value = { x: translateX.value, y: translateY.value };
    })
    .onUpdate((event) => {
      // Выполняется на UI Thread — 0 задержки
      translateX.value = context.value.x + event.translationX;
      translateY.value = context.value.y + event.translationY;
    })
    .onEnd((event) => {
      translateX.value = withDecay({ velocity: event.velocityX });
      translateY.value = withDecay({ velocity: event.velocityY });
    });

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [
      { translateX: translateX.value },
      { translateY: translateY.value },
    ],
  }));

  return (
    <GestureDetector gesture={pan}>
      <Animated.View style={[styles.box, animatedStyle]} />
    </GestureDetector>
  );
}
```

### Преимущества Reanimated над Animated API

| Аспект | Animated API | Reanimated |
|--------|-------------|-----------|
| Поток выполнения | JS Thread (или native driver) | **UI Thread** (worklets) |
| Layout-анимации | Нет (с native driver) | **Да** |
| Gesture-driven | Ограничено | **Полноценно** |
| Прерывание анимаций | Сложно | Автоматически |
| Условная логика | Нет (на native driver) | **Да** (в worklets) |
| API | Императивный | **Декларативный** (hooks) |

## 10. Производительность анимаций

### Правило: 60 FPS = 16.67ms на кадр

Каждый кадр анимации должен вычислиться и отрисоваться за 16.67ms. Если JS Thread не успевает — кадр пропускается (jank).

### Стратегии

1. **`useNativeDriver: true`** — стандартные анимации opacity/transform
2. **Reanimated worklets** — сложные анимации с логикой
3. **Избегайте layout-анимаций на native driver** — используйте `transform: scale` вместо `width`/`height`
4. **`requestAnimationFrame`** — откладывайте тяжёлую работу до завершения анимации
5. **Не анимируйте во время тяжёлого рендера** — используйте `startTransition` для приоритизации

### Проверка производительности

```
1. Включить Performance Monitor (Dev Menu → Perf Monitor)
2. Запустить анимацию
3. JS FPS и UI FPS должны быть ~60
4. Если JS FPS проседает:
   - Анимация на JS Thread → перевести на native driver
   - Тяжёлый рендер → оптимизировать или отложить
5. Если UI FPS проседает:
   - Слишком много views → упростить иерархию
   - Тяжёлые тени/blur → упростить эффекты
```
