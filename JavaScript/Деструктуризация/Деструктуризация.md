## Деструктуризация объектов

### Базовый синтаксис

```js
const user = { name: 'Alice', age: 30, role: 'admin' };
const { name, age } = user;
// name === 'Alice', age === 30
```

Под капотом движок вызывает `ToObject()` на правой стороне и затем обращается к свойствам по ключам, указанным слева.

### Переименование (aliasing)

Синтаксис `{ source: target }` -- **source** это ключ в объекте, **target** это имя локальной переменной:

```js
const response = { status_code: 200, data: [1, 2, 3] };
const { status_code: statusCode, data: items } = response;
// statusCode === 200, items === [1, 2, 3]
// status_code — НЕ определена как переменная!
```

### Значения по умолчанию

Дефолт используется **только если значение свойства === `undefined`** (не `null`, не `0`, не `''`):

```js
const { a = 10, b = 20, c = 30 } = { a: 1, b: undefined, c: null };
// a === 1   (значение есть)
// b === 20  (undefined -> используется дефолт)
// c === null (null !== undefined, дефолт НЕ применяется!)
```

**Дефолты вычисляются lazily** -- только когда реально нужны:

```js
let counter = 0;
function getDefault() { return ++counter; }

const { x = getDefault(), y = getDefault() } = { x: 1 };
// x === 1, y === 1 (getDefault вызван только 1 раз для y)
// counter === 1
```

### Переименование + дефолт одновременно

```js
const { status: httpStatus = 200 } = {};
// httpStatus === 200
```

### Rest в объектах (`...rest`)

Собирает все оставшиеся **собственные перечисляемые** свойства в новый объект:

```js
const { id, ...metadata } = { id: 1, name: 'Alice', role: 'admin', active: true };
// id === 1
// metadata === { name: 'Alice', role: 'admin', active: true }
```

Порядок свойств в `rest` соответствует порядку перечисления (insertion order для строковых ключей, числовые ключи -- по возрастанию первыми).

Rest **всегда создаёт shallow copy** и **не включает свойства из прототипа**:

```js
const proto = { inherited: true };
const obj = Object.create(proto);
obj.own = 'value';

const { ...copy } = obj;
// copy === { own: 'value' }  (inherited НЕ включён)
```

### Вложенная деструктуризация

```js
const company = {
  name: 'Acme',
  address: {
    city: 'Moscow',
    geo: { lat: 55.75, lon: 37.62 }
  }
};

const {
  name,
  address: {
    city,
    geo: { lat, lon }
  }
} = company;

// name === 'Acme', city === 'Moscow', lat === 55.75, lon === 37.62
// address и geo НЕ объявлены как переменные!
```

**Опасность:** если промежуточное свойство равно `null` или `undefined`, будет `TypeError`:

```js
const { address: { city } } = { address: null };
// TypeError: Cannot destructure property 'city' of null
```

### Computed property names

```js
const key = 'name';
const { [key]: value } = { name: 'Alice' };
// value === 'Alice'

// Динамическая деструктуризация:
function extract(obj, ...keys) {
  return keys.map(k => {
    const { [k]: val } = obj;
    return val;
  });
}
extract({ a: 1, b: 2, c: 3 }, 'a', 'c'); // [1, 3]
```

## Деструктуризация массивов

### Позиционная деструктуризация

Массивная деструктуризация работает через **итератор** (`Symbol.iterator`), а не через индексы напрямую:

```js
const [a, b, c] = [10, 20, 30];
// a === 10, b === 20, c === 30
```

### Пропуск элементов

```js
const [, , third] = [1, 2, 3];
// third === 3

const [first, , , fourth] = [1, 2, 3, 4];
// first === 1, fourth === 4
```

### Rest

```js
const [head, ...tail] = [1, 2, 3, 4, 5];
// head === 1, tail === [2, 3, 4, 5]

// Rest всегда создаёт новый массив:
const [, ...rest] = [1, 2, 3];
// rest === [2, 3]
```

### Swap без временной переменной

```js
let a = 1, b = 2;
[a, b] = [b, a];
// a === 2, b === 1

// Работает и для трёх+ переменных:
let x = 1, y = 2, z = 3;
[x, y, z] = [z, x, y];
// x === 3, y === 1, z === 2
```

Движок создаёт временный массив `[b, a]`, затем деструктуризирует его. Технически `O(n)` по памяти, но для 2-3 элементов это идиоматический подход.

### Деструктуризация из итерируемых объектов

Поскольку массивная деструктуризация использует `Symbol.iterator`, она работает с **любым итерируемым**:

```js
// String
const [first, second] = 'Hello';
// first === 'H', second === 'e'

// Set
const [a, b] = new Set([10, 20, 30]);
// a === 10, b === 20

// Map
const [entry1, entry2] = new Map([['a', 1], ['b', 2]]);
// entry1 === ['a', 1], entry2 === ['b', 2]

// Map с вложенной деструктуризацией:
const [[key1, val1]] = new Map([['a', 1]]);
// key1 === 'a', val1 === 1
```

**Генераторы:**

```js
function* fibonacci() {
  let a = 0, b = 1;
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}

const [f0, f1, f2, f3, f4, f5] = fibonacci();
// f0=0, f1=1, f2=1, f3=2, f4=3, f5=5
// Генератор потребляется ровно до 6-го yield и останавливается
```

### Значения по умолчанию

```js
const [a = 1, b = 2, c = 3] = [10, undefined];
// a === 10, b === 2 (undefined -> дефолт), c === 3 (элемента нет -> undefined -> дефолт)
```

## Деструктуризация в параметрах функций

### Базовое использование

```js
function greet({ name, greeting = 'Hello' }) {
  return `${greeting}, ${name}!`;
}

greet({ name: 'Alice' });              // 'Hello, Alice!'
greet({ name: 'Bob', greeting: 'Hi' }); // 'Hi, Bob!'
```

### Named parameters pattern

Вместо позиционных аргументов -- объект с именованными параметрами:

```js
// Плохо: что означает каждый аргумент?
createUser('Alice', 30, true, false, 'admin');

// Хорошо: самодокументирующийся вызов
function createUser({ name, age, active = true, verified = false, role = 'user' }) {
  return { name, age, active, verified, role };
}

createUser({ name: 'Alice', age: 30, role: 'admin' });
```

### Дефолт для всего объекта параметров

```js
// Если вызвать без аргументов — TypeError!
function bad({ name } /* нет дефолта */) {}
bad(); // TypeError: Cannot destructure property 'name' of undefined

// Решение: дефолтное значение для всего параметра
function good({ name = 'Anonymous' } = {}) {}
good();          // name === 'Anonymous'
good({});        // name === 'Anonymous'
good({ name: 'Alice' }); // name === 'Alice'
```

### Обязательные параметры через default throw

```js
function required(paramName) {
  throw new Error(`Parameter "${paramName}" is required`);
}

function createUser({
  name = required('name'),
  email = required('email'),
  role = 'user'
} = {}) {
  return { name, email, role };
}

createUser({ name: 'Alice' });
// Error: Parameter "email" is required

createUser({ name: 'Alice', email: 'a@b.com' });
// { name: 'Alice', email: 'a@b.com', role: 'user' }
```

Это работает потому, что дефолтные значения вычисляются lazily -- `required('email')` вызывается только когда `email === undefined`.

### Деструктуризация массивов в параметрах

```js
// Координаты как массив
function distance([x1, y1], [x2, y2]) {
  return Math.hypot(x2 - x1, y2 - y1);
}

distance([0, 0], [3, 4]); // 5

// React useState pattern
function Component() {
  const [count, setCount] = useState(0); // массив, не объект
}
```

## Edge Cases

### Деструктуризация `null` и `undefined`

```js
const { a } = null;      // TypeError: Cannot destructure property 'a' of null
const { a } = undefined;  // TypeError
const [x] = null;         // TypeError: null is not iterable
const [x] = undefined;    // TypeError: undefined is not iterable
```

Потому что `null` и `undefined` не могут быть приведены к объекту через `ToObject()`, а для массивной деструктуризации у них нет `Symbol.iterator`.

### Default вычисляется только для `undefined`, НЕ для `null`

Это частый источник багов:

```js
const { value = 'default' } = { value: null };
// value === null, НЕ 'default'!

const { value = 'default' } = { value: undefined };
// value === 'default'

const { value = 'default' } = {};
// value === 'default' (отсутствующее свойство === undefined)
```

Это поведение идентично дефолтным параметрам функций -- дефолт срабатывает только при `undefined`.

### Деструктуризация как выражение (круглые скобки)

При деструктуризации объекта вне объявления `let`/`const`/`var`, движок интерпретирует `{` как начало блока кода:

```js
let a, b;
{ a, b } = { a: 1, b: 2 }; // SyntaxError: Unexpected token '='

// Решение: обернуть в скобки
({ a, b } = { a: 1, b: 2 }); // OK!
// a === 1, b === 2
```

Для массивов эта проблема не существует, потому что `[` не может быть началом блока:

```js
let x, y;
[x, y] = [1, 2]; // OK без скобок
```

### Деструктуризация строк

Строка -- итерируемый объект, поэтому работает массивная деструктуризация:

```js
const [a, b, c] = 'Hi!';
// a === 'H', b === 'i', c === '!'

// Объектная деструктуризация тоже работает (String wrapper):
const { length, 0: first } = 'Hello';
// length === 5, first === 'H'
```

### Деструктуризация чисел и boolean

`ToObject()` оборачивает примитивы:

```js
const { toFixed } = 42;
// toFixed === Number.prototype.toFixed

const { toString: boolStr } = true;
// boolStr === Boolean.prototype.toString

// Но нет собственных свойств:
const { ...rest } = 42;
// rest === {}
```

### Вложенная деструктуризация с дефолтами на каждом уровне

```js
const {
  settings: {
    theme = 'light',
    notifications: {
      email = true,
      push = false
    } = {} // дефолт для notifications целиком
  } = {} // дефолт для settings целиком
} = {};

// theme === 'light', email === true, push === false
// Работает даже при пустом объекте на входе!
```

## Паттерны и практическое применение

### Config objects с дефолтами

```js
function initApp(config = {}) {
  const {
    port = 3000,
    host = 'localhost',
    db: {
      url = 'mongodb://localhost:27017',
      poolSize = 5,
      retryWrites = true
    } = {},
    logging: {
      level = 'info',
      format = 'json',
      transports = ['console']
    } = {}
  } = config;

  console.log(`Starting on ${host}:${port}, DB: ${url}`);
  return { port, host, db: { url, poolSize, retryWrites }, logging: { level, format, transports } };
}

// Работает без аргументов:
initApp();

// С частичным конфигом:
initApp({ port: 8080, db: { url: 'mongodb://prod:27017' } });
```

### React hooks return -- почему массив, а не объект

```js
// useState возвращает массив:
const [count, setCount] = useState(0);
const [name, setName] = useState('');

// Если бы возвращался объект, нужно было бы переименовывать:
const { state: count, setState: setCount } = useState(0);
const { state: name, setState: setName } = useState('');
// Неудобно. Массив позволяет свободно именовать.
```

### API response destructuring

```js
async function fetchUser(id) {
  const {
    data: {
      user: { name, email, profile: { avatar = '/default.png' } = {} }
    },
    status,
    headers: { 'x-request-id': requestId }
  } = await axios.get(`/api/users/${id}`);

  return { name, email, avatar, requestId };
}
```

### Фильтрация свойств объекта (omit pattern)

```js
// Удалить пароль из объекта пользователя:
const user = { id: 1, name: 'Alice', password: 'secret', email: 'a@b.com' };
const { password, ...safeUser } = user;
// safeUser === { id: 1, name: 'Alice', email: 'a@b.com' }

// Обобщённая функция omit:
function omit(obj, ...keys) {
  const keysSet = new Set(keys);
  return Object.fromEntries(
    Object.entries(obj).filter(([k]) => !keysSet.has(k))
  );
}
```

### Pick pattern

```js
function pick(obj, ...keys) {
  return Object.fromEntries(
    keys.filter(k => k in obj).map(k => [k, obj[k]])
  );
}

const user = { id: 1, name: 'Alice', email: 'a@b.com', role: 'admin' };
pick(user, 'name', 'email'); // { name: 'Alice', email: 'a@b.com' }
```

### Conditional destructuring

```js
// Деструктуризация результата, который может быть разной формы:
const result = await fetchData();

if (result.ok) {
  const { data: { items, total } } = result;
  // ...
} else {
  const { error: { code, message } } = result;
  // ...
}

// Или с помощью try/catch для безопасной деструктуризации:
function safeParse(json) {
  try {
    const { data, error } = JSON.parse(json);
    return { data, error, ok: !error };
  } catch {
    return { data: null, error: 'Invalid JSON', ok: false };
  }
}
```

### Итерация Map с деструктуризацией

```js
const userRoles = new Map([
  ['alice', 'admin'],
  ['bob', 'editor'],
  ['charlie', 'viewer']
]);

for (const [username, role] of userRoles) {
  console.log(`${username}: ${role}`);
}

// С entries():
const scores = { math: 95, physics: 87, chemistry: 92 };
for (const [subject, score] of Object.entries(scores)) {
  console.log(`${subject}: ${score}`);
}
```

### Вложенная деструктуризация массива массивов

```js
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

const [[a, , c], , [g]] = matrix;
// a === 1, c === 3, g === 7

// Транспонирование с деструктуризацией:
const pairs = [[1, 'a'], [2, 'b'], [3, 'c']];
const keys = pairs.map(([k]) => k);   // [1, 2, 3]
const values = pairs.map(([, v]) => v); // ['a', 'b', 'c']
```
