### Изменение содержимого

- **Свойство `textContent`**: Изменяет текстовое содержимое элемента.

- **Свойство `innerHTML`**: Изменяет HTML-содержимое элемента. Позволяет добавлять HTML-теги.

- **Свойство `outerHTML`**: Изменяет HTML-содержимое элемента вместе с самим элементом.

### Изменение атрибутов

- **Метод `setAttribute`**: Устанавливает значение атрибута.

- **Метод `getAttribute`**: Получает значение атрибута.

- **Метод `removeAttribute`**: Удаляет атрибут.
  
- **Метод `hasAttribute`**: Проверяет, существует ли у элемента указанный атрибут. Возвращает `true` или `false`.


### Изменение стилей

- **Свойство `style`**: Позволяет изменять стили элемента напрямую через JavaScript.

- **Свойство `classList`**: Возвращает объект `DOMTokenList` для управления классами элемента. Имеет методы `add`, `remove`, `toggle`, `contains`.

- **Метод `window.getComputedStyle(element)`**: Получает объект `CSSStyleDeclaration`, содержащий все вычисленные стили для элемента. Это метод объекта `window`, а не самого элемента.
