## 1. font-family — семейства шрифтов и font stacks

### Родовые семейства (generic families)

Каждый браузер имеет настройки по умолчанию для generic families. Они ВСЕГДА должны быть последним значением в font stack.

| Generic family | Описание | Типичные шрифты |
|---|---|---|
| `serif` | С засечками | Times New Roman, Georgia |
| `sans-serif` | Без засечек | Arial, Helvetica, Verdana |
| `monospace` | Моноширинный | Courier New, Consolas |
| `cursive` | Рукописный | Comic Sans MS, Brush Script MT |
| `fantasy` | Декоративный | Impact, Papyrus |
| `system-ui` | Системный UI шрифт | -apple-system, Segoe UI |
| `ui-serif` | Системный serif | Платформозависимый |
| `ui-sans-serif` | Системный sans-serif | Платформозависимый |
| `ui-monospace` | Системный mono | Платформозависимый |
| `ui-rounded` | Системный rounded | Платформозависимый |
| `math` | Для математических формул | Latin Modern Math |
| `emoji` | Для эмодзи | Apple Color Emoji, Segoe UI Emoji |
| `fangsong` | Китайский стиль fangsong | Платформозависимый |

### Правила font stack

```css
/* Порядок: предпочтительный → fallback → generic */
body {
  font-family: "Inter", "Helvetica Neue", Arial, sans-serif;
}

/* Кавычки нужны для шрифтов с пробелами или цифрами в начале */
.element {
  font-family: "Times New Roman", Times, serif;
  font-family: "123Font", sans-serif; /* Начинается с цифры — кавычки обязательны */
  font-family: Arial, sans-serif;     /* Без пробелов — кавычки не обязательны */
}
```

### Системный font stack

```css
/* Современный системный стек */
body {
  font-family:
    system-ui,
    -apple-system,         /* Safari на macOS и iOS */
    BlinkMacSystemFont,    /* Chrome на macOS */
    "Segoe UI",            /* Windows */
    Roboto,                /* Android */
    "Helvetica Neue",      /* Старые macOS */
    Arial,                 /* Широкий fallback */
    "Noto Sans",           /* Linux */
    sans-serif,
    "Apple Color Emoji",   /* Emoji на macOS/iOS */
    "Segoe UI Emoji",      /* Emoji на Windows */
    "Noto Color Emoji";    /* Emoji на Linux/Android */
}

/* Монширинный системный стек */
code, pre {
  font-family:
    ui-monospace,
    SFMono-Regular,
    "SF Mono",
    Menlo,
    Consolas,
    "Liberation Mono",
    monospace;
}
```

### Web-safe шрифты

Шрифты, установленные на большинстве ОС:

| Serif | Sans-serif | Monospace |
|---|---|---|
| Times New Roman | Arial | Courier New |
| Georgia | Verdana | Consolas (Win) |
| Palatino Linotype | Trebuchet MS | Monaco (Mac) |
| Book Antiqua | Tahoma | Lucida Console |
| Garamond | Helvetica (Mac) | Menlo (Mac) |

> **Важно:** Понятие "web-safe" устарело с появлением `@font-face` и web fonts, но знание этих шрифтов полезно для формирования fallback стека.

## 2. @font-face — подключение пользовательских шрифтов

### Базовый синтаксис

```css
@font-face {
  font-family: "MyFont";
  src: url("/fonts/myfont.woff2") format("woff2"),
       url("/fonts/myfont.woff") format("woff");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

/* Использование */
body {
  font-family: "MyFont", sans-serif;
}
```

### Форматы шрифтов

| Формат | Расширение | Поддержка | Размер | Рекомендация |
|---|---|---|---|---|
| WOFF2 | `.woff2` | Все современные | Лучшая компрессия | Рекомендуется |
| WOFF | `.woff` | Все включая IE9+ | Хорошая компрессия | Fallback |
| TrueType | `.ttf` | Все | Без компрессии | Редко нужен |
| OpenType | `.otf` | Все | Без компрессии | Редко нужен |
| SVG | `.svg` | Устаревший | Большой | Не использовать |
| EOT | `.eot` | Только IE | Средняя | Не использовать |

```css
/* Минимальный современный набор */
@font-face {
  font-family: "MyFont";
  src: url("/fonts/myfont.woff2") format("woff2");
  /* WOFF2 поддерживается всеми актуальными браузерами */
}

/* С fallback на WOFF */
@font-face {
  font-family: "MyFont";
  src: url("/fonts/myfont.woff2") format("woff2"),
       url("/fonts/myfont.woff") format("woff");
}
```

### unicode-range — загрузка подмножеств

```css
/* Латиница */
@font-face {
  font-family: "MyFont";
  src: url("/fonts/myfont-latin.woff2") format("woff2");
  unicode-range: U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC;
}

/* Кириллица */
@font-face {
  font-family: "MyFont";
  src: url("/fonts/myfont-cyrillic.woff2") format("woff2");
  unicode-range: U+0400-045F, U+0490-0491, U+04B0-04B1, U+2116;
}

/* Эмодзи и символы */
@font-face {
  font-family: "MyFont";
  src: url("/fonts/myfont-symbols.woff2") format("woff2");
  unicode-range: U+2000-206F, U+2070-209F, U+20A0-20CF, U+2100-214F;
}
```

> **Важно:** Браузер загрузит файл шрифта ТОЛЬКО если на странице есть символы из указанного `unicode-range`. Это отличная оптимизация для многоязычных сайтов.

### font-display — стратегия загрузки

| Значение | Block period | Swap period | Поведение |
|---|---|---|---|
| `auto` | Зависит от UA | Зависит от UA | Браузер решает сам |
| `block` | 3s | infinite | Невидимый текст → шрифт (FOIT) |
| `swap` | ~0ms | infinite | Fallback сразу → шрифт (FOUT) |
| `fallback` | ~100ms | ~3s | Короткий FOIT → FOUT или остаётся fallback |
| `optional` | ~100ms | 0s | Использует шрифт только если уже в кеше |

```css
/* Для основного текста — swap (контент важнее) */
@font-face {
  font-family: "Body Font";
  src: url("/fonts/body.woff2") format("woff2");
  font-display: swap;
}

/* Для иконок — block (нельзя показывать символы вместо иконок) */
@font-face {
  font-family: "Icon Font";
  src: url("/fonts/icons.woff2") format("woff2");
  font-display: block;
}

/* Для декоративных заголовков — optional (не критично) */
@font-face {
  font-family: "Fancy Heading";
  src: url("/fonts/fancy.woff2") format("woff2");
  font-display: optional;
}
```

### Оптимизация загрузки шрифтов

```html
<!-- Preload критичных шрифтов -->
<link rel="preload" href="/fonts/body.woff2" as="font" type="font/woff2" crossorigin>

<!-- crossorigin обязателен для шрифтов, даже с того же домена -->
```

```css
/* Борьба с CLS (Cumulative Layout Shift) при font-display: swap */
/* Подбираем fallback-шрифт с похожими метриками */
@font-face {
  font-family: "Adjusted Arial";
  src: local("Arial");
  size-adjust: 106%;        /* Подгоняем размер */
  ascent-override: 90%;     /* Подгоняем ascent */
  descent-override: 22%;    /* Подгоняем descent */
  line-gap-override: 0%;    /* Подгоняем line-gap */
}

body {
  font-family: "MyFont", "Adjusted Arial", sans-serif;
}
```

### Подключение нескольких начертаний

```css
/* Отдельные @font-face для каждого weight/style */
@font-face {
  font-family: "Inter";
  src: url("/fonts/Inter-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "Inter";
  src: url("/fonts/Inter-Italic.woff2") format("woff2");
  font-weight: 400;
  font-style: italic;
  font-display: swap;
}

@font-face {
  font-family: "Inter";
  src: url("/fonts/Inter-Bold.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}

/* Диапазон весов для Variable Font */
@font-face {
  font-family: "Inter Variable";
  src: url("/fonts/Inter-Variable.woff2") format("woff2-variations");
  font-weight: 100 900; /* Диапазон */
  font-style: normal;
  font-display: swap;
}
```

## 3. font-size — размер шрифта и стратегии

### Единицы измерения для font-size

```css
.element {
  font-size: 16px;      /* Абсолютный размер в пикселях */
  font-size: 1em;       /* Относительно font-size родителя */
  font-size: 1rem;      /* Относительно font-size <html> */
  font-size: 100%;      /* Эквивалент 1em для font-size */
  font-size: 2vw;       /* 2% ширины viewport */
  font-size: medium;    /* Ключевое слово (= ~16px в большинстве браузеров) */
  font-size: larger;    /* Относительное ключевое слово */
}
```

### Проблема em — каскадное умножение

```css
/* Проблема каскада с em */
.parent {
  font-size: 1.2em; /* 16px * 1.2 = 19.2px */
}
.parent .child {
  font-size: 1.2em; /* 19.2px * 1.2 = 23.04px — не 1.2 от корня! */
}
.parent .child .grandchild {
  font-size: 1.2em; /* 23.04px * 1.2 = 27.648px */
}

/* Решение: rem не каскадируется */
.parent {
  font-size: 1.2rem; /* 16px * 1.2 = 19.2px */
}
.parent .child {
  font-size: 1.2rem; /* 16px * 1.2 = 19.2px — всегда от корня! */
}
```

### Стратегия 62.5%

```css
/* Трюк 62.5% — упрощаем конвертацию rem ↔ px */
html {
  font-size: 62.5%; /* 16px * 0.625 = 10px */
}

body {
  font-size: 1.6rem; /* 10px * 1.6 = 16px — возвращаем нормальный размер */
}

h1 { font-size: 3.2rem; }  /* 32px */
h2 { font-size: 2.4rem; }  /* 24px */
h3 { font-size: 2.0rem; }  /* 20px */
p  { font-size: 1.6rem; }  /* 16px */
small { font-size: 1.2rem; } /* 12px */
```

> **Осторожно:** Стратегия 62.5% ломает ожидания сторонних библиотек, которые рассчитывают на `1rem = 16px`. Также проблематична для accessibility — пользовательские настройки `font-size` в браузере работают некорректно.

### Рекомендуемая стратегия — утилитарная шкала

```css
:root {
  --font-size-xs: 0.75rem;    /* 12px */
  --font-size-sm: 0.875rem;   /* 14px */
  --font-size-base: 1rem;     /* 16px */
  --font-size-lg: 1.125rem;   /* 18px */
  --font-size-xl: 1.25rem;    /* 20px */
  --font-size-2xl: 1.5rem;    /* 24px */
  --font-size-3xl: 1.875rem;  /* 30px */
  --font-size-4xl: 2.25rem;   /* 36px */
  --font-size-5xl: 3rem;      /* 48px */
}

body { font-size: var(--font-size-base); }
h1 { font-size: var(--font-size-4xl); }
h2 { font-size: var(--font-size-3xl); }
```

### Accessibility и font-size

```css
/* ПЛОХО: фиксированный px не реагирует на пользовательские настройки */
html { font-size: 16px; } /* Пользователь увеличил шрифт в браузере → игнорируется */

/* ХОРОШО: rem/% реагируют на настройки */
html { font-size: 100%; } /* Пользовательские настройки работают */
```

## 4. line-height — межстрочный интервал и inline layout

### Unitless vs единицы измерения

```css
.element {
  /* Безразмерное значение — РЕКОМЕНДУЕТСЯ */
  line-height: 1.5;
  /* Вычисляется: font-size * 1.5
     Наследуется как множитель, пересчитывается для каждого потомка */

  /* С единицами — НЕ РЕКОМЕНДУЕТСЯ для наследования */
  line-height: 24px;   /* Фиксированная высота */
  line-height: 1.5em;  /* Вычисляется один раз и наследуется как px */
  line-height: 150%;   /* Тоже вычисляется один раз */
}
```

### Критическая разница при наследовании

```css
/* unitless — пересчитывается для каждого элемента */
.parent {
  font-size: 16px;
  line-height: 1.5; /* 16px * 1.5 = 24px */
}
.parent .child {
  font-size: 32px;
  /* line-height = 32px * 1.5 = 48px ✓ Корректно */
}

/* em/% — вычисляется один раз и передаётся как computed value */
.parent {
  font-size: 16px;
  line-height: 1.5em; /* Computed: 24px */
}
.parent .child {
  font-size: 32px;
  /* line-height = 24px (наследовано) ✗ Текст налезает друг на друга */
}
```

### Half-leading модель

Браузер распределяет свободное пространство (leading) поровну над и под строкой текста:

```
line-height = 24px
font-size = 16px
leading = 24px - 16px = 8px
half-leading = 4px сверху + 4px снизу

┌─────────────────────┐
│  4px (half-leading)  │
│  ─── ascent ───────  │
│  Текст строки        │
│  ─── descent ──────  │
│  4px (half-leading)  │
└─────────────────────┘
```

### leading-trim (text-box-trim / text-box-edge)

Новое свойство для удаления лишнего пространства, добавляемого half-leading.

```css
/* Удаление half-leading */
h1 {
  /* Обрезаем верхний и нижний half-leading */
  text-box-trim: both;
  text-box-edge: cap alphabetic;
  /* cap — верхняя граница заглавных букв
     alphabetic — базовая линия */
}

/* Shorthand (в разработке) */
h1 {
  text-box: cap alphabetic;
  /* Эквивалент trim: both + edge: cap alphabetic */
}

/* Только верхний leading */
.trim-start {
  text-box-trim: start;
  text-box-edge: cap alphabetic;
}

/* Только нижний leading */
.trim-end {
  text-box-trim: end;
  text-box-edge: cap alphabetic;
}
```

> **Зачем это нужно:** Half-leading добавляет непредсказуемые отступы вокруг текста, что усложняет точное выравнивание с другими элементами (иконки, границы, другие компоненты).

### Практические рекомендации

```css
/* Рекомендуемые line-height для разных контекстов */
body {
  line-height: 1.5;      /* Основной текст — хорошая читаемость */
}

h1, h2, h3 {
  line-height: 1.2;      /* Заголовки — компактнее */
}

.compact-ui {
  line-height: 1.25;     /* UI-элементы — плотная вёрстка */
}

.code {
  line-height: 1.6;      /* Код — чуть больше для читаемости */
}

/* Вертикальный ритм */
:root {
  --baseline: 1.5rem; /* 24px при 16px font-size */
}

p {
  margin-bottom: var(--baseline);
  line-height: 1.5; /* = var(--baseline) при font-size: 1rem */
}
```

## 5. font-weight — насыщенность шрифта

### Числовые значения

| Значение | Общее название | Ключевое слово |
|---|---|---|
| 100 | Thin / Hairline | — |
| 200 | Extra Light / Ultra Light | — |
| 300 | Light | — |
| 400 | Normal / Regular | `normal` |
| 500 | Medium | — |
| 600 | Semi Bold / Demi Bold | — |
| 700 | Bold | `bold` |
| 800 | Extra Bold / Ultra Bold | — |
| 900 | Black / Heavy | — |

### bolder и lighter

Относительные ключевые слова работают по таблице:

```css
/* bolder — увеличивает вес относительно родителя */
.parent { font-weight: 400; }
.parent .child { font-weight: bolder; } /* → 700 */

/* lighter — уменьшает вес */
.parent { font-weight: 700; }
.parent .child { font-weight: lighter; } /* → 400 */
```

| Наследуемый вес | bolder | lighter |
|---|---|---|
| 100-299 | 400 | 100 |
| 300-399 | 400 | 100 |
| 400-499 | 700 | 100 |
| 500-599 | 700 | 100 |
| 600-699 | 900 | 400 |
| 700-799 | 900 | 400 |
| 800-899 | 900 | 700 |
| 900 | 900 | 700 |

### Font matching algorithm

Когда запрашиваемый `font-weight` недоступен в шрифте, браузер использует алгоритм подбора:

```
Запрошен 500:
  → 500 есть? Использовать.
  → 600 есть? Использовать.
  → 700 есть? Использовать.
  → ... вверх до 900
  → 400 есть? Использовать.
  → 300 есть? Использовать.
  → ... вниз до 100

Запрошен 400:
  → 400 есть? Использовать.
  → 500 есть? Использовать.
  → 300 есть? Использовать.
  → 200, 100, 600, 700, 800, 900
```

### Faux bold — синтетическое жирное начертание

```css
/* Если шрифт не содержит bold начертания, браузер создаёт faux bold */
.element {
  font-family: "Шрифт без bold";
  font-weight: 700;
  /* Браузер ИСКУССТВЕННО утолщает штрихи — выглядит плохо */
}

/* Предотвращение faux bold/italic */
.element {
  font-synthesis: none;
  /* Запрещает браузеру создавать синтетические начертания */
  /* Также: font-synthesis-weight: none; font-synthesis-style: none; */
}
```

## 6. font-variant и OpenType features

### font-variant подсвойства

```css
.element {
  /* Капитель (малые заглавные) */
  font-variant-caps: small-caps;        /* Строчные → малые заглавные */
  font-variant-caps: all-small-caps;    /* Все → малые заглавные */
  font-variant-caps: petite-caps;       /* Ещё меньше */
  font-variant-caps: unicase;           /* Смешанный регистр */
  font-variant-caps: titling-caps;      /* Титульные заглавные */

  /* Числовые варианты */
  font-variant-numeric: lining-nums;        /* Цифры на базовой линии */
  font-variant-numeric: oldstyle-nums;      /* Цифры с выносными элементами */
  font-variant-numeric: proportional-nums;  /* Пропорциональная ширина */
  font-variant-numeric: tabular-nums;       /* Равная ширина (для таблиц) */
  font-variant-numeric: diagonal-fractions; /* Дроби по диагонали: 1/2 → ½ */
  font-variant-numeric: stacked-fractions;  /* Дроби в столбик */
  font-variant-numeric: ordinal;            /* Порядковые: 1st → 1ˢᵗ */
  font-variant-numeric: slashed-zero;       /* Ноль с чертой: 0 → Ø */

  /* Лигатуры */
  font-variant-ligatures: common-ligatures;       /* fi, fl, ff */
  font-variant-ligatures: discretionary-ligatures; /* ct, st (декоративные) */
  font-variant-ligatures: historical-ligatures;    /* ſt и подобные */
  font-variant-ligatures: contextual;              /* Контекстные подстановки */
  font-variant-ligatures: no-common-ligatures;     /* Отключить стандартные */

  /* Альтернативы */
  font-variant-alternates: stylistic(salt);
  font-variant-alternates: swash(swsh);
  font-variant-alternates: historical-forms;

  /* Восточноазиатские */
  font-variant-east-asian: jis78;
  font-variant-east-asian: simplified;
  font-variant-east-asian: proportional-width;

  /* Позиция */
  font-variant-position: sub;  /* Нижний индекс */
  font-variant-position: super; /* Верхний индекс */
}
```

### font-feature-settings — низкоуровневый контроль

```css
.element {
  /* Прямой доступ к OpenType features через 4-символьные тэги */
  font-feature-settings:
    "kern" 1,   /* Кернинг */
    "liga" 1,   /* Стандартные лигатуры */
    "dlig" 1,   /* Декоративные лигатуры */
    "smcp" 1,   /* Малые заглавные */
    "onum" 1,   /* Старинные цифры */
    "tnum" 1,   /* Табулярные цифры */
    "frac" 1,   /* Дроби */
    "zero" 1,   /* Перечёркнутый ноль */
    "ss01" 1,   /* Стилистический набор 1 */
    "ss02" 1;   /* Стилистический набор 2 */

  /* 0 или off отключает фичу, 1 или on включает */
  font-feature-settings: "liga" 0; /* Отключить лигатуры */
}
```

> **Рекомендация:** Предпочитайте `font-variant-*` свойства вместо `font-feature-settings`, так как высокоуровневые свойства каскадируются независимо, а `font-feature-settings` — это единый набор, который перезаписывается целиком.

### Практические применения

```css
/* Табулярные цифры в таблицах — числа выравниваются по столбцам */
.data-table td {
  font-variant-numeric: tabular-nums lining-nums;
}

/* Дроби в рецептах */
.recipe-measurements {
  font-variant-numeric: diagonal-fractions;
  /* "1/2 стакана" → "½ стакана" */
}

/* Код — отключить лигатуры (fl, fi не нужны), перечёркнутый ноль */
code {
  font-variant-ligatures: none;
  font-variant-numeric: slashed-zero;
}

/* Юридические тексты — малые заглавные */
.legal-entity {
  font-variant-caps: all-small-caps;
  letter-spacing: 0.05em; /* Малые заглавные лучше с tracking */
}
```

## 8. text-overflow — обрезка текста

### Однострочное обрезание

```css
/* Три обязательных свойства для ellipsis */
.truncate {
  white-space: nowrap;     /* 1. Запрещаем перенос */
  overflow: hidden;        /* 2. Скрываем вылезающий текст */
  text-overflow: ellipsis; /* 3. Добавляем "..." */
}

/* text-overflow значения */
.element {
  text-overflow: clip;     /* Просто обрезает (default) */
  text-overflow: ellipsis; /* Заменяет на "..." */
  text-overflow: "→";     /* Кастомная строка (плохая поддержка) */
  text-overflow: fade;     /* Плавное затухание (экспериментальное) */
}
```

### Многострочное обрезание (-webkit-line-clamp)

```css
/* Обрезка после N строк */
.multiline-truncate {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;   /* Количество видимых строк */
  overflow: hidden;
  /* text-overflow: ellipsis НЕ нужен — line-clamp добавляет "..." сам */
}
```

> **Важно:** Несмотря на `-webkit-` префикс, `-webkit-line-clamp` работает во всех современных браузерах. Стандартная версия `line-clamp` находится в разработке.

### Gotchas с text-overflow

```css
/* text-overflow работает ТОЛЬКО с overflow: hidden/scroll/auto */
/* НЕ работает с overflow: visible */

/* text-overflow НЕ вызывает обрезку — только задаёт индикатор */
/* Обрезка происходит из-за overflow: hidden */

/* Для flex-детей нужен min-width: 0 */
.flex-container {
  display: flex;
}
.flex-child {
  min-width: 0; /* Без этого truncate не работает! */
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Для grid-детей тоже */
.grid-container {
  display: grid;
  grid-template-columns: 1fr;
}
.grid-child {
  min-width: 0;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

### Кастомные решения для многострочного обрезания

```css
/* CSS-only fade-out эффект (без "...") */
.fade-out {
  max-height: 4.5em; /* line-height * количество строк */
  overflow: hidden;
  position: relative;
}

.fade-out::after {
  content: "";
  position: absolute;
  bottom: 0;
  right: 0;
  left: 0;
  height: 1.5em; /* Высота одной строки */
```

## 9. white-space — обработка пробелов

### Все значения

| Значение | Пробелы | Новые строки | Перенос строк | Пробелы в конце |
|---|---|---|---|---|
| `normal` | Сжимаются | Игнорируются | Авто | Удаляются |
| `nowrap` | Сжимаются | Игнорируются | Нет | Удаляются |
| `pre` | Сохраняются | Сохраняются | Нет | Сохраняются |
| `pre-wrap` | Сохраняются | Сохраняются | Авто | Висят |
| `pre-line` | Сжимаются | Сохраняются | Авто | Удаляются |
| `break-spaces` | Сохраняются | Сохраняются | Авто | Переносятся |

```css
/* normal — стандартное поведение */
.normal { white-space: normal; }
/* "  Hello    World  \n  Foo  " → "Hello World Foo" */

/* nowrap — как normal, но без переноса */
.nowrap { white-space: nowrap; }
/* Текст выходит за пределы контейнера */

/* pre — как тег <pre>, сохраняет всё */
.pre { white-space: pre; }
/* Точное отображение как в исходнике */

/* pre-wrap — сохраняет пробелы, но переносит при необходимости */
.pre-wrap { white-space: pre-wrap; }
/* Лучший выбор для отображения пользовательского ввода */

/* pre-line — сохраняет переводы строк, сжимает пробелы */
.pre-line { white-space: pre-line; }
/* Полезно для текста с ручными переносами */

/* break-spaces — как pre-wrap, но пробелы в конце строки переносятся */
.break-spaces { white-space: break-spaces; }
/* Пробелы в конце строки не "висят" за пределами контейнера */
```

### Новый синтаксис (Level 4) — два отдельных свойства

```css
.element {
  /* white-space-collapse — обработка пробелов */
  white-space-collapse: collapse;     /* = normal (сжимает) */
  white-space-collapse: preserve;     /* Сохраняет пробелы */
  white-space-collapse: preserve-breaks; /* Сохраняет только \n */
  white-space-collapse: break-spaces; /* Сохраняет, переносит */

  /* text-wrap — перенос строк */
  text-wrap: wrap;     /* Авто перенос */
  text-wrap: nowrap;   /* Без переноса */
  text-wrap: balance;  /* Балансировка длины строк (для заголовков) */
  text-wrap: pretty;   /* Оптимизация переносов (меньше «вдов» и «сирот») */
  text-wrap: stable;   /* Стабильный при редактировании */
}

/* text-wrap: balance — выравнивает длину строк в заголовках */
h1, h2, h3 {
  text-wrap: balance;
  /* Вместо:
     "Очень длинный заголовок который переносится на
     последнюю строку неудачно"
     Получим:
     "Очень длинный заголовок
     который переносится равномерно" */
}

/* text-wrap: pretty — улучшает переносы для длинных текстов */
p {
  text-wrap: pretty;
  /* Избегает одиноких слов на последней строке */
}
```

## 10. word-break и overflow-wrap — перенос слов

### word-break

```css
.element {
  /* normal — разрыв только в естественных точках (пробелы, дефисы) */
  word-break: normal;

  /* break-all — разрешает разрыв ВНУТРИ любого слова */
  word-break: break-all;
  /* Aggressively breaks even short words — подходит для CJK-подобного поведения */

  /* keep-all — запрещает разрыв для CJK (китайский, японский, корейский) */
  word-break: keep-all;
  /* Для не-CJK текста ведёт себя как normal */

  /* break-word (УСТАРЕЛО — используйте overflow-wrap: anywhere) */
  word-break: break-word;
}
```

### overflow-wrap (ранее word-wrap)

```css
.element {
  /* normal — длинные слова могут выходить за контейнер */
  overflow-wrap: normal;

  /* break-word — разрывает длинные слова если они не помещаются */
  overflow-wrap: break-word;
  /* Сначала пытается перенести на следующую строку,
     и ТОЛЬКО если слово длиннее строки — разрывает его */

  /* anywhere — как break-word, но учитывается при min-content */
  overflow-wrap: anywhere;
  /* Разница: min-content ширина может быть меньше самого длинного слова */
}
```

### Разница между break-all и break-word

```css
/* break-all — разрывает ВЕЗДЕ, даже если слово помещается */
.break-all {
  word-break: break-all;
}
/* "Hello World Superlongword" в узком контейнере:
   "Hell
    o Wo
    rld
    Supe
    rlon
    gwor
    d" */

/* overflow-wrap: break-word — разрывает только не помещающиеся слова */
.break-word {
  overflow-wrap: break-word;
}
/* "Hello World Superlongword" в узком контейнере:
   "Hello
    World
    Superl
    ongwor
    d" */
```

### hyphens — автоматическая расстановка переносов

```css
.element {
  /* Обязательно указать lang для работы hyphens */
  hyphens: auto;
  /* Браузер расставляет переносы по словарю */
}

/* Для русского языка */
html { lang: "ru"; }
p {
  hyphens: auto;
  -webkit-hyphens: auto; /* Safari */
}

/* Значения */
.element {
  hyphens: none;   /* Переносы запрещены */
  hyphens: manual; /* Только по &shy; и ­ (default) */
  hyphens: auto;   /* Автоматические переносы */
}

/* Мягкий перенос в HTML */
/* ответ&shy;ственность → ответ-ственность (при необходимости) */
```

### Комбинированный подход для длинного текста

```css
/* Надёжное предотвращение overflow для пользовательского контента */
.user-content {
  overflow-wrap: break-word;   /* Разрыв длинных слов */
  word-break: break-word;     /* Fallback для старых браузеров */
  hyphens: auto;               /* Переносы с дефисами */
}

/* Для URL-ов и технических строк */
.url-text {
  word-break: break-all;      /* Агрессивный разрыв для URL */
}
```

## 11. Variable Fonts — вариативные шрифты

Variable fonts — это один файл шрифта, содержащий непрерывный диапазон начертаний. Вместо отдельных файлов для Regular, Bold, Italic получаем один файл с осями вариации.

### Подключение Variable Font

```css
@font-face {
  font-family: "Inter Variable";
  src: url("/fonts/InterVariable.woff2") format("woff2-variations"),
       url("/fonts/InterVariable.woff2") format("woff2") tech("variations");
  font-weight: 100 900;   /* Диапазон по оси weight */
  font-stretch: 75% 125%; /* Диапазон по оси width (если есть) */
  font-style: oblique 0deg 10deg; /* Диапазон по оси slant */
  font-display: swap;
}
```

### Зарегистрированные оси (registered axes)

| Тег | Ось | CSS-свойство | Диапазон |
|---|---|---|---|
| `wght` | Weight (насыщенность) | `font-weight` | 1-999 |
| `wdth` | Width (ширина) | `font-stretch` | 50%-200% |
| `ital` | Italic (курсив) | `font-style: italic` | 0 или 1 |
| `slnt` | Slant (наклон) | `font-style: oblique Xdeg` | -90 до 90 |
| `opsz` | Optical Size | `font-optical-sizing` | Зависит от шрифта |

```css
/* Управление через CSS-свойства */
.element {
  font-weight: 450;        /* Любое значение в диапазоне, не только 100-900 */
  font-stretch: 87%;       /* Любой процент ширины */
  font-style: oblique 8deg; /* Любой угол наклона */
  font-optical-sizing: auto; /* Автоматический optical size */
}

/* Управление через font-variation-settings (низкоуровневый) */
.element {
  font-variation-settings:
    "wght" 450,
    "wdth" 87,
    "slnt" -8,
    "opsz" 16;
}
```

### Кастомные оси

Шрифтовые дизайнеры могут добавлять свои оси (обозначаются заглавными буквами):

```css
/* Recursive — шрифт с кастомными осями */
.element {
  font-variation-settings:
    "MONO" 0,      /* Пропорциональный ↔ моноширинный */
    "CASL" 0.5,    /* Степень "рукописности" */
    "wght" 400,
    "slnt" 0,
    "CRSV" 0;      /* Автоматический курсив */
}

/* Анимация осей! */
@keyframes weight-pulse {
  from { font-variation-settings: "wght" 300; }
  to { font-variation-settings: "wght" 800; }
}

.pulsing-text {
  animation: weight-pulse 2s ease-in-out infinite alternate;
}
```

### Анимация Variable Fonts

```css
/* Плавное изменение веса при hover */
.interactive-text {
  font-weight: 400;
  transition: font-weight 300ms ease;
}

.interactive-text:hover {
  font-weight: 700;
  /* Variable font плавно интерполирует! */
}

/* Через font-variation-settings */
.element {
  font-variation-settings: "wght" 400, "wdth" 100;
  transition: font-variation-settings 500ms ease;
}

.element:hover {
  font-variation-settings: "wght" 700, "wdth" 120;
}
```

> **Важно:** `font-variation-settings` перезаписывается целиком. При анимации через `transition` обе стороны должны иметь одинаковый набор осей.

### Преимущества Variable Fonts

```
Обычные шрифты (отдельные файлы):
  Regular.woff2    → 25KB
  Italic.woff2     → 27KB
  Bold.woff2       → 26KB
  BoldItalic.woff2 → 28KB
  Light.woff2      → 24KB
  Итого:           → 130KB (5 файлов, 5 HTTP-запросов)

Variable Font:
  Variable.woff2   → 75KB (1 файл, 1 запрос, ВСЕ начертания)
```

## 12. Fluid Typography — отзывчивая типографика

### Проблема фиксированных размеров

```css
/* Жёстко заданные breakpoints — скачки при переходе */
h1 { font-size: 24px; }

@media (min-width: 768px) {
  h1 { font-size: 36px; } /* Скачок с 24 на 36 при 768px */
}

@media (min-width: 1200px) {
  h1 { font-size: 48px; } /* Скачок с 36 на 48 при 1200px */
}
```

### Решение: clamp()

```css
/* clamp(минимум, предпочтительный, максимум) */
h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
  /* Минимум: 24px (1.5rem)
     Растёт: 4% ширины viewport
     Максимум: 48px (3rem) */
}
```

### Формула fluid typography

```
preferred = min + (max - min) * (viewport - minViewport) / (maxViewport - minViewport)

Преобразование в clamp:
font-size: clamp(minSize, calc(a + b * 1vw), maxSize)

Где:
  a = minSize - minViewport * slope
  b = slope = (maxSize - minSize) / (maxViewport - minViewport)
```

```css
/* Пример: 16px при 320px viewport → 24px при 1200px viewport */
/* slope = (24 - 16) / (1200 - 320) = 8 / 880 = 0.00909 */
/* a = 16 - 320 * 0.00909 = 16 - 2.909 = 13.091px ≈ 0.818rem */
/* b = 0.909vw */

h1 {
  font-size: clamp(1rem, 0.818rem + 0.909vw, 1.5rem);
}
```

### Полная система fluid typography

```css
:root {
  /* Fluid font sizes */
  --step--2: clamp(0.6944rem, 0.6496rem + 0.2239vw, 0.8333rem);
  --step--1: clamp(0.8333rem, 0.7634rem + 0.3497vw, 1.0417rem);
  --step-0:  clamp(1rem, 0.8913rem + 0.5435vw, 1.3021rem);
  --step-1:  clamp(1.2rem, 1.0344rem + 0.828vw, 1.6276rem);
  --step-2:  clamp(1.44rem, 1.1942rem + 1.229vw, 2.0345rem);
  --step-3:  clamp(1.728rem, 1.3717rem + 1.7817vw, 2.5431rem);
  --step-4:  clamp(2.0736rem, 1.5672rem + 2.5318vw, 3.1789rem);
  --step-5:  clamp(2.4883rem, 1.7798rem + 3.5426vw, 3.9736rem);

  /* Fluid spacing (тот же принцип) */
  --space-xs: clamp(0.25rem, 0.2065rem + 0.2174vw, 0.375rem);
  --space-s:  clamp(0.5rem, 0.4348rem + 0.3261vw, 0.6875rem);
  --space-m:  clamp(0.75rem, 0.6413rem + 0.5435vw, 1.0625rem);
  --space-l:  clamp(1rem, 0.8478rem + 0.7609vw, 1.4375rem);
  --space-xl: clamp(1.5rem, 1.2826rem + 1.087vw, 2.125rem);
}

body { font-size: var(--step-0); }
h1 { font-size: var(--step-5); }
h2 { font-size: var(--step-4); }
h3 { font-size: var(--step-3); }
h4 { font-size: var(--step-2); }
h5 { font-size: var(--step-1); }
h6 { font-size: var(--step-0); }
small { font-size: var(--step--1); }
```

### Viewport-based с ограничениями

```css
/* Без ограничений — текст может стать слишком маленьким/большим */
h1 {
  font-size: 5vw; /* ОПАСНО: при 320px = 16px, при 4K = 96px! */
}

/* С clamp — безопасно */
h1 {
  font-size: clamp(2rem, 5vw, 4rem);
  /* Никогда меньше 32px, никогда больше 64px */
}

/* Альтернатива clamp через min/max */
h1 {
  font-size: min(max(2rem, 5vw), 4rem);
  /* Эквивалент clamp(2rem, 5vw, 4rem) */
}
```

> **Accessibility:** `clamp()` с `vw` единицами может игнорировать пользовательское масштабирование. Рекомендуется всегда включать `rem` в preferred значение: `clamp(1rem, 0.8rem + 0.5vw, 1.5rem)`.

## 13. Единицы измерения глубоко — полный разбор

### Абсолютные единицы

| Единица | Описание | Соотношение |
|---|---|---|
| `px` | CSS-пиксель | Базовая единица |
| `cm` | Сантиметры | 1cm = 37.795px |
| `mm` | Миллиметры | 1mm = 3.7795px |
| `Q` | Четверть миллиметра | 1Q = 0.945px |
| `in` | Дюймы | 1in = 96px |
| `pc` | Пики | 1pc = 16px |
| `pt` | Пункты | 1pt = 1.333px |

### CSS px vs device pixel

```
CSS pixel (px) — абстрактная единица
Device pixel — физический пиксель экрана
Device Pixel Ratio (DPR) = device pixels / CSS pixels

iPhone 14 Pro:
  Экран: 2556 × 1179 device pixels
  DPR: 3
  CSS viewport: 852 × 393 CSS pixels
  1 CSS px = 3×3 = 9 device pixels

MacBook Pro Retina:
  Экран: 3024 × 1964 device pixels
  DPR: 2
  CSS viewport: 1512 × 982 CSS pixels
  1 CSS px = 2×2 = 4 device pixels
```

> **Важно:** `1px` в CSS НЕ равен 1 физическому пикселю на экране. На Retina-дисплеях `1px` может занимать 4 (DPR=2) или 9 (DPR=3) физических пикселей. Это дизайнерская абстракция для обеспечения одинаковых размеров на экранах с разной плотностью.

### Относительные единицы — шрифтовые

```css
/* em — относительно font-size родителя (или самого элемента для font-size) */
.parent { font-size: 20px; }
.child {
  font-size: 1.5em;    /* 20px * 1.5 = 30px */
  padding: 1em;         /* 30px * 1 = 30px (от СВОЕГО font-size) */
  margin: 2em;          /* 30px * 2 = 60px */
}

/* rem — всегда относительно font-size <html> */
html { font-size: 16px; }
.anything {
  font-size: 1.25rem;   /* 16px * 1.25 = 20px */
  padding: 1rem;         /* 16px * 1 = 16px */
  margin: 2rem;          /* 16px * 2 = 32px */
}

/* ch — ширина символа "0" в текущем шрифте */
.readable-width {
  max-width: 65ch; /* Оптимальная ширина для чтения */
}

/* ex — высота строчной буквы "x" */
.vertical-align-hack {
  vertical-align: 0.5ex; /* Выравнивание по высоте строчных */
}

/* ic — ширина символа "水" (CJK water ideograph) */
.cjk-content {
  width: 20ic; /* Для CJK текста */
}

/* cap — высота заглавной буквы */
.cap-aligned {
  height: 1cap; /* Высота заглавной буквы */
}

/* lh — computed line-height текущего элемента */
.element {
  margin-bottom: 1lh; /* Отступ равен одной строке */
}

/* rlh — computed line-height корневого элемента (<html>) */
.element {
  margin-bottom: 1rlh; /* Отступ равен строке корневого элемента */
}
```

### Viewport единицы

```css
/* Классические viewport единицы */
.element {
  width: 50vw;   /* 50% ширины viewport */
  height: 50vh;  /* 50% высоты viewport */
  font-size: 5vmin; /* 5% от МЕНЬШЕГО из vw/vh */
  padding: 2vmax;   /* 2% от БОЛЬШЕГО из vw/vh */
}
```

### Проблема vh на мобильных

На мобильных устройствах адресная строка (URL bar) появляется и исчезает при скролле, изменяя видимую высоту. Классический `vh` не учитывает это.

```css
/* Три варианта vh для мобильных */
.element {
  /* lvh — Large Viewport Height: максимальная высота (без URL bar) */
  height: 100lvh;

  /* svh — Small Viewport Height: минимальная высота (с URL bar) */
  height: 100svh;

  /* dvh — Dynamic Viewport Height: текущая реальная высота */
  height: 100dvh;
  /* Динамически меняется при появлении/скрытии URL bar */
}
```

| Единица | Описание | Соответствующие |
|---|---|---|
| `svw`, `svh` | Small viewport | `svi`, `svb`, `svmin`, `svmax` |
| `lvw`, `lvh` | Large viewport | `lvi`, `lvb`, `lvmin`, `lvmax` |
| `dvw`, `dvh` | Dynamic viewport | `dvi`, `dvb`, `dvmin`, `dvmax` |

```css
/* Hero-секция на мобильном */
.hero {
  /* Плохо — не учитывает URL bar */
  height: 100vh;

  /* Лучше — svh (не перекрывается URL bar) */
  height: 100svh;

  /* Или dvh (точно заполняет видимую область) */
  height: 100dvh;

  /* Fallback для старых браузеров */
  height: 100vh;
  height: 100dvh;
}
```

### Logical viewport единицы

```css
.element {
  /* vi — 1% inline размера viewport (зависит от writing-mode) */
  width: 50vi;
  /* В LTR/RTL: 50vi = 50vw */
  /* В vertical writing: 50vi = 50vh */

  /* vb — 1% block размера viewport */
  height: 50vb;
  /* В LTR/RTL: 50vb = 50vh */
  /* В vertical writing: 50vb = 50vw */
}
```

### Container Query единицы

Container Query единицы зависят от размера ближайшего container query контейнера, а не viewport.

```css
.container {
  container-type: inline-size;
}

.child {
  /* cqw — 1% ширины контейнера */
  font-size: 3cqw;

  /* cqh — 1% высоты контейнера (нужен container-type: size) */
  padding: 2cqh;

  /* cqi — 1% inline-размера контейнера */
  width: 50cqi;

  /* cqb — 1% block-размера контейнера */
  height: 50cqb;

  /* cqmin — min(cqi, cqb) */
  font-size: 5cqmin;

  /* cqmax — max(cqi, cqb) */
  font-size: 5cqmax;
}
```

### Процентные единицы — от чего считаются

```css
.parent {
  width: 400px;
  height: 200px;
  font-size: 16px;
  line-height: 24px;
}

.child {
  width: 50%;        /* 200px — от width родителя */
  height: 50%;       /* 100px — от height родителя (ТОЛЬКО если задана!) */
  padding: 10%;      /* 40px — от WIDTH родителя (даже для padding-top/bottom!) */
  margin: 5%;        /* 20px — от WIDTH родителя (даже для margin-top/bottom!) */
  font-size: 150%;   /* 24px — от font-size родителя */
  line-height: 150%; /* 36px — от font-size САМОГО элемента */
  transform: translateX(50%); /* от СВОИХ размеров */
}
```

> **Gotcha:** `padding-top: 10%` и `padding-bottom: 10%` вычисляются от ШИРИНЫ родителя, не от высоты. Это по спецификации. Этот трюк раньше использовался для создания aspect-ratio: `padding-top: 56.25%` = 16:9. Сейчас лучше использовать `aspect-ratio: 16/9`.

| Категория | Единицы | Относительно |
|---|---|---|
| Абсолютные | `px`, `cm`, `mm`, `in`, `pt`, `pc`, `Q` | Фиксированные |
| Шрифтовые | `em`, `rem`, `ch`, `ex`, `ic`, `cap`, `lh`, `rlh` | Шрифт |
| Viewport | `vw`, `vh`, `vmin`, `vmax`, `vi`, `vb` | Окно браузера |
| Small viewport | `svw`, `svh`, `svmin`, `svmax`, `svi`, `svb` | Мин. viewport |
| Large viewport | `lvw`, `lvh`, `lvmin`, `lvmax`, `lvi`, `lvb` | Макс. viewport |
| Dynamic viewport | `dvw`, `dvh`, `dvmin`, `dvmax`, `dvi`, `dvb` | Текущий viewport |

### Математические функции CSS

```css
.element {
  /* calc() — вычисления с разными единицами */
  width: calc(100% - 2rem);
  font-size: calc(1rem + 0.5vw);

  /* min() — выбирает наименьшее значение */
  width: min(90%, 1200px);
  /* Эквивалент max-width: 1200px при width: 90% */

  /* max() — выбирает наибольшее значение */
  width: max(300px, 50%);
  /* Эквивалент min-width: 300px при width: 50% */

  /* clamp(min, preferred, max) */
  font-size: clamp(1rem, 2.5vw, 2rem);
  /* Эквивалент: max(1rem, min(2.5vw, 2rem)) */

  /* Вложенные вычисления */
  width: min(max(300px, 50%), 1200px);
  padding: clamp(1rem, calc(1rem + 2vw), 3rem);
}

/* round() — округление */
.element {
  width: round(100px, 8px);       /* 104px (ближайший кратный 8) */
  width: round(up, 100px, 8px);   /* 104px (вверх) */
  width: round(down, 100px, 8px); /* 96px (вниз) */
}

/* mod() и rem() — остаток от деления */
.element {
  /* mod(a, b) — остаток с знаком делителя */
  margin-left: mod(18px, 5px); /* 3px */

  /* rem(a, b) — остаток с знаком делимого */
  margin-left: rem(18px, 5px); /* 3px */
}

/* abs() и sign() */
.element {
  width: abs(-100px);   /* 100px */
  /* sign() возвращает -1, 0 или 1 */
}

/* Тригонометрические функции */
.element {
  transform: rotate(atan2(3, 4));   /* Арктангенс */
  width: calc(sin(45deg) * 100px);  /* Синус */
  height: calc(cos(45deg) * 100px); /* Косинус */
}

/* Экспоненциальные функции */
.element {
  width: calc(pow(2, 3) * 1px);     /* 8px */
  width: calc(sqrt(16) * 1px);      /* 4px */
  width: calc(log(8, 2) * 10px);    /* 30px */
}
```
