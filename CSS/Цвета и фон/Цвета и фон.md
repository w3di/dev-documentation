## 1. Цветовые модели — hex, rgb, hsl

### Hex-нотация

```css
.element {
  /* 6-значный hex — полная запись */
  color: #ff6633;         /* R=FF, G=66, B=33 */

  /* 3-значный hex — сокращение (каждый символ дублируется) */
  color: #f63;            /* = #ff6633 */

  /* 8-значный hex — с альфа-каналом */
  color: #ff663380;       /* Последние 2 цифры = alpha (80 = 50%) */

  /* 4-значный hex — сокращение с альфа */
  color: #f638;           /* = #ff663388 */
}
```

> **Альфа в hex:** `00` = полностью прозрачный (0%), `FF` = полностью непрозрачный (100%), `80` = примерно 50%. Конвертация: `alpha_hex = round(alpha_decimal * 255)`.

### rgb() / rgba()

```css
.element {
  /* Старый синтаксис с запятыми */
  color: rgb(255, 102, 51);
  color: rgba(255, 102, 51, 0.5);

  /* Новый синтаксис (CSS Color Level 4) — пробелы и / для альфа */
  color: rgb(255 102 51);
  color: rgb(255 102 51 / 0.5);
  color: rgb(255 102 51 / 50%);

  /* Процентные значения */
  color: rgb(100% 40% 20%);
  color: rgb(100% 40% 20% / 50%);

  /* none — означает 0 для данного канала */
  color: rgb(none 102 51);  /* = rgb(0 102 51) */
}
```

> **Важно:** В новом синтаксисе `rgba()` и `rgb()` — синонимы. `rgba()` не устарела, но `rgb()` теперь тоже принимает альфа-канал через `/`.

### hsl() / hsla()

HSL (Hue, Saturation, Lightness) — более интуитивная модель для работы с цветом.

```css
.element {
  /* Старый синтаксис */
  color: hsl(15, 100%, 60%);
  color: hsla(15, 100%, 60%, 0.5);

  /* Новый синтаксис */
  color: hsl(15 100% 60%);
  color: hsl(15 100% 60% / 0.5);

  /* Hue принимает разные единицы угла */
  color: hsl(15deg 100% 60%);
  color: hsl(0.04turn 100% 60%);
  color: hsl(0.26rad 100% 60%);
}
```

### Цветовой круг HSL — Hue

```
0°/360° = Красный
30°     = Оранжевый
60°     = Жёлтый
120°    = Зелёный
180°    = Циан
240°    = Синий
270°    = Фиолетовый
300°    = Магента
330°    = Розовый
```

### Практическое применение HSL

```css
/* Генерация палитры оттенков одного цвета */
:root {
  --hue: 220;  /* Синий */
  --color-50:  hsl(var(--hue) 90% 97%);
  --color-100: hsl(var(--hue) 85% 92%);
  --color-200: hsl(var(--hue) 80% 82%);
  --color-300: hsl(var(--hue) 75% 70%);
  --color-400: hsl(var(--hue) 70% 58%);
  --color-500: hsl(var(--hue) 65% 48%);
  --color-600: hsl(var(--hue) 70% 38%);
  --color-700: hsl(var(--hue) 75% 28%);
  --color-800: hsl(var(--hue) 80% 20%);
  --color-900: hsl(var(--hue) 85% 12%);
}

/* Смена темы — меняем только hue */
.theme-green { --hue: 140; }
.theme-red   { --hue: 0; }
.theme-purple { --hue: 270; }
```

> **Проблема HSL:** Человеческое восприятие яркости нелинейно. Жёлтый (`hsl(60, 100%, 50%)`) выглядит значительно светлее, чем синий (`hsl(240, 100%, 50%)`), хотя оба имеют одинаковую lightness 50%. Эту проблему решают LCH и OKLCH.

### hwb() — Hue, Whiteness, Blackness

```css
.element {
  /* hwb(hue whiteness blackness / alpha) */
  color: hwb(15 10% 10%);
  color: hwb(15 10% 10% / 0.8);

  /* whiteness + blackness > 100% — нормализуются */
  color: hwb(0 50% 80%);
  /* Нормализация: w=50/(50+80)=38.5%, b=80/(50+80)=61.5% */
}
```

## 2. Новые цветовые пространства — lab, lch, oklch, oklab, display-p3

### Почему нужны новые пространства

sRGB (используемый в `rgb()`, `hsl()`, `hex`) покрывает только ~35% видимого человеком цветового спектра. Современные экраны (Display P3, Rec. 2020) способны отображать значительно больше цветов.

### Гамуты (цветовые охваты)

```
Видимый спектр человека: 100%
Rec. 2020: ~75%
Display P3: ~50%  ← iPhone, MacBook, современные мониторы
sRGB: ~35%        ← Стандартный веб
```

### lab() — CIE Lab

```css
.element {
  /* lab(lightness a-axis b-axis / alpha) */
  /* L: 0 (чёрный) — 100 (белый) */
  /* a: отрицательный=зелёный, положительный=красный */
  /* b: отрицательный=синий, положительный=жёлтый */
  color: lab(50% 40 59.5);
  color: lab(50% 40 59.5 / 0.5);
}
```

### lch() — CIE LCH (Lightness, Chroma, Hue)

```css
.element {
  /* lch(lightness chroma hue / alpha) */
  /* L: 0-100 — perceptually uniform lightness */
  /* C: 0-~150 — насыщенность (chroma) */
  /* H: 0-360 — оттенок (hue, в градусах) */
  color: lch(50% 70 56);
  color: lch(50% 70 56 / 0.8);
}
```

### oklch() — улучшенная LCH (рекомендуемая)

OKLCH исправляет проблемы LCH с оттенками синего и предлагает лучшую перцептивную равномерность.

```css
.element {
  /* oklch(lightness chroma hue / alpha) */
  /* L: 0 (чёрный) — 1 (белый) или 0%-100% */
  /* C: 0 — ~0.4 (насыщенность) */
  /* H: 0-360 (оттенок) */
  color: oklch(0.7 0.15 150);
  color: oklch(70% 0.15 150 / 80%);
}
```

### Почему OKLCH — лучший выбор для дизайн-систем

```css
/* Проблема HSL: одинаковая lightness выглядит по-разному */
.hsl-yellow { color: hsl(60 100% 50%); }   /* Выглядит ОЧЕНЬ светлым */
.hsl-blue   { color: hsl(240 100% 50%); }  /* Выглядит ОЧЕНЬ тёмным */

/* OKLCH: одинаковая lightness = одинаковая воспринимаемая яркость */
.oklch-yellow { color: oklch(0.8 0.15 90); }
.oklch-blue   { color: oklch(0.8 0.15 260); }
/* Оба цвета воспринимаются одинаково светлыми */
```

```css
/* Палитра на OKLCH с перцептивно равномерной яркостью */
:root {
  --brand-hue: 250;
  --brand-50:  oklch(0.97 0.02 var(--brand-hue));
  --brand-100: oklch(0.93 0.04 var(--brand-hue));
  --brand-200: oklch(0.86 0.08 var(--brand-hue));
  --brand-300: oklch(0.76 0.12 var(--brand-hue));
  --brand-400: oklch(0.66 0.17 var(--brand-hue));
  --brand-500: oklch(0.55 0.20 var(--brand-hue));
  --brand-600: oklch(0.47 0.18 var(--brand-hue));
  --brand-700: oklch(0.38 0.15 var(--brand-hue));
  --brand-800: oklch(0.30 0.12 var(--brand-hue));
  --brand-900: oklch(0.22 0.08 var(--brand-hue));
}
```

### oklab() — для смешивания и интерполяции

```css
.element {
  /* oklab(lightness a-axis b-axis / alpha) */
  /* L: 0-1, a: ~-0.4 to ~0.4, b: ~-0.4 to ~0.4 */
  color: oklab(0.7 -0.05 0.12);
  color: oklab(0.7 -0.05 0.12 / 50%);
}
```

### color() — доступ к широким гамутам

```css
.element {
  /* Display P3 — цвета за пределами sRGB */
  color: color(display-p3 1 0.2 0.1);
  color: color(display-p3 1 0.2 0.1 / 0.8);

  /* sRGB (эквивалент rgb) */
  color: color(srgb 1 0.4 0.2);

  /* sRGB Linear (без гамма-коррекции) */
  color: color(srgb-linear 1 0.13 0.03);

  /* Rec. 2020 */
  color: color(rec2020 0.9 0.3 0.1);

  /* A98 RGB (Adobe RGB) */
  color: color(a98-rgb 0.9 0.4 0.2);

  /* ProPhoto RGB */
  color: color(prophoto-rgb 0.8 0.3 0.1);

  /* XYZ */
  color: color(xyz 0.5 0.3 0.1);
  color: color(xyz-d50 0.5 0.3 0.1);
  color: color(xyz-d65 0.5 0.3 0.1);
}
```

### Gamut mapping — что если цвет не отображается

```css
/* Этот Display P3 цвет ярче, чем возможно в sRGB */
.vibrant {
  color: color(display-p3 1 0 0);
  /* На sRGB-мониторе: браузер МАППИТ в ближайший sRGB цвет */
  /* На P3-мониторе: отображается ярко-красный, выходящий за sRGB */
}

/* Проверка поддержки широкого гамута */
@media (color-gamut: p3) {
  .element {
    color: color(display-p3 1 0 0);
  }
}

/* Fallback */
.element {
  color: rgb(255 0 0);                  /* sRGB fallback */
  color: color(display-p3 1 0 0);       /* P3 если поддерживается */
}
```

## 3. color-mix() — смешивание цветов

### Синтаксис

```css
.element {
  /* color-mix(in colorspace, color1, color2) */
  /* По умолчанию 50/50 */
  color: color-mix(in srgb, red, blue);
  /* = фиолетовый (смесь красного и синего в sRGB) */

  /* С указанием пропорций */
  color: color-mix(in srgb, red 75%, blue 25%);
  /* 75% красного, 25% синего */

  /* Если указана только одна пропорция */
  color: color-mix(in srgb, red 30%, blue);
  /* 30% красного, 70% синего (дополнение до 100%) */

  /* Сумма больше 100% — нормализуется */
  color: color-mix(in srgb, red 80%, blue 60%);
  /* 80/140 ≈ 57% красного, 60/140 ≈ 43% синего */
}
```

### Цветовое пространство интерполяции

Пространство интерполяции сильно влияет на результат смешивания:

```css
/* Смешивание синего и жёлтого */
.srgb    { color: color-mix(in srgb, blue, yellow); }
/* Результат: серый (sRGB интерполяция через серый) */

.oklch   { color: color-mix(in oklch, blue, yellow); }
/* Результат: яркий зелёный (через цветовой круг) */

.oklab   { color: color-mix(in oklab, blue, yellow); }
/* Результат: приятный серо-зелёный */

.hsl     { color: color-mix(in hsl, blue, yellow); }
/* Результат: зелёный (через HUE 180°) */

.lab     { color: color-mix(in lab, blue, yellow); }
/* Результат: розоватый (артефакт CIE Lab) */
```

> **Рекомендация:** Для большинства задач используйте `in oklch` — он даёт наиболее предсказуемые и визуально приятные результаты.

### Hue interpolation method

Для цветовых пространств с hue (hsl, hwb, lch, oklch) можно указать метод интерполяции оттенка:

```css
.element {
  /* shorter — по короткой дуге (default) */
  color: color-mix(in oklch shorter hue, red, blue);

  /* longer — по длинной дуге */
  color: color-mix(in oklch longer hue, red, blue);

  /* increasing — по возрастанию hue */
  color: color-mix(in oklch increasing hue, red, blue);

  /* decreasing — по убыванию hue */
  color: color-mix(in oklch decreasing hue, red, blue);
}
```

### Практические применения

```css
/* Осветление/затемнение цвета */
:root {
  --brand: oklch(0.6 0.2 250);
  --brand-light: color-mix(in oklch, var(--brand), white 30%);
  --brand-dark: color-mix(in oklch, var(--brand), black 30%);
}

/* Создание полупрозрачной версии */
:root {
  --brand: #3366ff;
  --brand-alpha: color-mix(in srgb, var(--brand), transparent 50%);
  /* Эквивалент rgba(51, 102, 255, 0.5) */
}

/* Hover-состояние */
.button {
  background: var(--brand);
}
.button:hover {
  background: color-mix(in oklch, var(--brand), black 15%);
}
.button:active {
  background: color-mix(in oklch, var(--brand), black 25%);
}

/* Тематизация через CSS custom properties */
:root {
  --surface: white;
  --text: black;
}

.dark-theme {
  --surface: oklch(0.15 0 0);
  --text: oklch(0.9 0 0);
}

.card {
  background: color-mix(in oklch, var(--surface), var(--text) 5%);
  /* Чуть темнее фона в светлой теме, чуть светлее в тёмной */
}
```

## 4. Relative Color Syntax — модификация цветов

Relative Color Syntax позволяет создавать новый цвет на основе существующего, модифицируя его каналы.

### Синтаксис

```css
.element {
  /* from <color> <function>(channel-modifications) */

  /* Изменение альфа-канала */
  --base: #3366ff;
  color: rgb(from var(--base) r g b / 0.5);
  /* Берём r, g, b из --base, устанавливаем alpha = 0.5 */

  /* Изменение lightness в oklch */
  --base: oklch(0.6 0.2 250);
  color: oklch(from var(--base) 0.8 c h);
  /* L=0.8, C и H из --base */

  /* Вычисления с каналами */
  color: oklch(from var(--base) calc(l + 0.2) c h);
  /* Увеличиваем lightness на 0.2 */
}
```

### Примеры модификаций

```css
:root {
  --brand: oklch(0.6 0.2 250);
}

/* Осветление */
.lighter {
  color: oklch(from var(--brand) calc(l + 0.15) c h);
}

/* Затемнение */
.darker {
  color: oklch(from var(--brand) calc(l - 0.15) c h);
}

/* Уменьшение насыщенности (desaturate) */
.muted {
  color: oklch(from var(--brand) l calc(c * 0.5) h);
}

/* Увеличение насыщенности */
.vivid {
  color: oklch(from var(--brand) l calc(c * 1.5) h);
}

/* Комплементарный цвет (противоположный на цветовом круге) */
.complement {
  color: oklch(from var(--brand) l c calc(h + 180));
}

/* Аналогичные цвета */
.analogous-1 {
  color: oklch(from var(--brand) l c calc(h + 30));
}
.analogous-2 {
  color: oklch(from var(--brand) l c calc(h - 30));
}

/* Триадные цвета */
.triad-1 {
  color: oklch(from var(--brand) l c calc(h + 120));
}
.triad-2 {
  color: oklch(from var(--brand) l c calc(h + 240));
}

/* Полупрозрачная версия */
.semi-transparent {
  background: oklch(from var(--brand) l c h / 0.3);
}

/* Инверсия цвета в RGB */
.inverted {
  color: rgb(from var(--brand) calc(1 - r) calc(1 - g) calc(1 - b));
}
```

### Использование в HSL

```css
:root {
  --color: hsl(220 80% 50%);
}

/* Изменение оттенка */
.shifted-hue {
  color: hsl(from var(--color) calc(h + 60) s l);
}

/* Пастельная версия */
.pastel {
  color: hsl(from var(--color) h 40% 80%);
}

/* Тёмный вариант с сохранением оттенка и насыщенности */
.dark-variant {
  color: hsl(from var(--color) h s 25%);
}
```

### Генерация палитры через Relative Color Syntax

```css
:root {
  --brand: oklch(0.55 0.2 250);

  /* Автоматическая палитра */
  --brand-50:  oklch(from var(--brand) 0.97 calc(c * 0.1) h);
  --brand-100: oklch(from var(--brand) 0.93 calc(c * 0.2) h);
  --brand-200: oklch(from var(--brand) 0.86 calc(c * 0.4) h);
  --brand-300: oklch(from var(--brand) 0.76 calc(c * 0.6) h);
  --brand-400: oklch(from var(--brand) 0.66 calc(c * 0.85) h);
  --brand-500: oklch(from var(--brand) l c h);
  --brand-600: oklch(from var(--brand) calc(l - 0.08) calc(c * 0.9) h);
  --brand-700: oklch(from var(--brand) calc(l - 0.17) calc(c * 0.75) h);
  --brand-800: oklch(from var(--brand) calc(l - 0.25) calc(c * 0.6) h);
  --brand-900: oklch(from var(--brand) calc(l - 0.33) calc(c * 0.4) h);
}
```

## 5. Named colors, currentColor, system colors

### Named colors — 147 именованных цветов

CSS определяет 147 именованных цветов. Некоторые полезные:

```css
.element {
  color: transparent;     /* rgba(0, 0, 0, 0) — полностью прозрачный */
  color: currentColor;    /* Наследует computed value color */
  color: inherit;         /* Наследует от родителя (не то же самое!) */

  /* Популярные named colors */
  color: black;           /* #000000 */
  color: white;           /* #ffffff */
  color: red;             /* #ff0000 */
  color: blue;            /* #0000ff */
  color: green;           /* #008000 (НЕ #00ff00!) */
  color: lime;            /* #00ff00 */
  color: gray;            /* #808080 */
  color: grey;            /* #808080 (оба написания валидны) */
  color: orange;          /* #ffa500 */
  color: tomato;          /* #ff6347 */
  color: cornflowerblue;  /* #6495ed */
  color: rebeccapurple;   /* #663399 */
}
```

> **Gotcha:** `green` = `#008000`, а не `#00ff00`. Чистый зелёный — это `lime`. Это историческая особенность CSS.

### currentColor

`currentColor` — это значение свойства `color` текущего элемента. Это единственная CSS «переменная», которая существовала до Custom Properties.

```css
.element {
  color: #3366ff;
  border: 2px solid currentColor;  /* = #3366ff */
  box-shadow: 0 2px 4px currentColor; /* = #3366ff */
}

/* Наследуется через color */
.parent {
  color: red;
}
.child {
  /* color наследуется = red */
  border: 1px solid currentColor; /* red */
  background: currentColor;       /* red */
}

/* Свойства, где currentColor — default */
.element {
  color: blue;
  border-color: /* currentColor по умолчанию */;
  text-decoration-color: /* currentColor по умолчанию */;
  outline-color: /* currentColor по умолчанию */;
  column-rule-color: /* currentColor по умолчанию */;
}

/* Полезный паттерн: иконки, следующие за цветом текста */
.icon {
  fill: currentColor; /* SVG-иконка наследует color */
}

/* Цвет ссылки для всего блока */
.link-card {
  color: var(--link-color);
}
.link-card .title,
.link-card .icon,
.link-card .border {
  /* Все автоматически используют цвет ссылки через currentColor */
}
```

### System colors (системные цвета)

```css
.element {
  /* Системные цвета — адаптируются к ОС и теме */
  color: CanvasText;        /* Цвет текста по умолчанию */
  background: Canvas;       /* Цвет фона по умолчанию */

  color: LinkText;          /* Цвет ссылок */
  color: VisitedText;       /* Цвет посещённых ссылок */

  color: ButtonText;        /* Текст на кнопках */
  background: ButtonFace;   /* Фон кнопок */
  border-color: ButtonBorder; /* Граница кнопок */

  color: FieldText;         /* Текст в полях ввода */
  background: Field;        /* Фон полей ввода */

  color: Mark;              /* Фон выделенного текста */
  color: MarkText;          /* Цвет выделенного текста */

  color: HighlightText;     /* Текст при ::selection */
```

## 7. Градиенты — linear, radial, conic

### linear-gradient()

```css
.element {
  /* Направление + цвета */
  background: linear-gradient(to right, red, blue);
  background: linear-gradient(to bottom right, red, blue);
  background: linear-gradient(45deg, red, blue);
  background: linear-gradient(0.25turn, red, blue);

  /* Несколько цветовых остановок */
  background: linear-gradient(to right, red, orange, yellow, green, blue);

  /* Конкретные позиции остановок */
  background: linear-gradient(to right, red 0%, blue 100%);
  background: linear-gradient(to right, red 30%, blue 70%);

  /* Резкая граница (без перехода) */
  background: linear-gradient(to right, red 50%, blue 50%);

  /* Цвет с двумя позициями (цветовая полоса) */
  background: linear-gradient(to right,
    red 0% 33%,     /* Красная полоса 0-33% */
    white 33% 67%,  /* Белая полоса 33-67% */
    blue 67% 100%   /* Синяя полоса 67-100% (флаг Франции) */
  );

  /* Градиент в новых цветовых пространствах */
  background: linear-gradient(in oklch to right, red, blue);
  /* oklch-интерполяция — яркие промежуточные цвета */

  background: linear-gradient(in oklch shorter hue to right, red, blue);
  background: linear-gradient(in oklch longer hue to right, red, blue);
}
```

### Направления linear-gradient

```
to top         = 0deg     ↑
to right       = 90deg    →
to bottom      = 180deg   ↓ (по умолчанию)
to left        = 270deg   ←
to top right   = ~45deg   ↗
to bottom left = ~225deg  ↙
```

> **Gotcha:** `to top right` НЕ равно `45deg`. `to top right` гарантирует, что градиент идёт точно в угол элемента, даже если он не квадратный. `45deg` всегда создаёт линию под 45 градусов.

## 8. background-size — cover, contain, авто

### Все значения

```css
.element {
  /* Ключевые слова */
  background-size: auto;           /* Оригинальный размер */
  background-size: cover;          /* Покрывает всю область (может обрезать) */
  background-size: contain;        /* Вписывается целиком (могут быть пустоты) */

  background-size: 200px 100px;    /* Ширина и высота */
  background-size: 50% 50%;        /* % от контейнера */
  background-size: 200px auto;     /* Фиксированная ширина, авто высота */
  background-size: auto 100px;     /* Авто ширина, фиксированная высота */

  /* Для нескольких фонов */
  background-size: cover, 50px 50px, contain;
}
```

### cover vs contain

```
┌──────────────────┐      ┌──────────────────┐
│ ┌──────────────┐ │      │                  │
│ │              │ │      │  ┌──────────┐    │
│ │    COVER     │ │      │  │ CONTAIN  │    │
│ │ (обрезано)   │ │      │  │(вписано) │    │
│ │              │ │      │  └──────────┘    │
│ └──────────────┘ │      │                  │
└──────────────────┘      └──────────────────┘
  Заполняет всё,            Видно всё,
  часть изображения         но есть пустые области
  может быть обрезана
```

```css
/* Hero-секция — cover */
.hero {
  background: url('hero.jpg') center / cover no-repeat;
  min-height: 100vh;
}

/* Логотип — contain */

  width: 200px;
  height: 60px;
}
```

### Shorthand background

Порядок в shorthand `background`:
```
background: [color] [image] [position] / [size] [repeat] [attachment] [origin] [clip]
```


## 9. background-position — позиционирование фона

### Синтаксис

```css
.element {
  /* Ключевые слова */
  background-position: center;         /* 50% 50% */
  background-position: top;            /* 50% 0% */
  background-position: right bottom;   /* 100% 100% */
  background-position: left center;    /* 0% 50% */

  /* Числовые значения (от левого верхнего угла) */
  background-position: 100px 50px;     /* X=100px, Y=50px */
  background-position: 50% 25%;        /* X=50%, Y=25% */

  /* 4-значный синтаксис — offset от указанного края */
  background-position: right 20px bottom 10px;
  /* Отступ 20px от правого края и 10px от нижнего */

  background-position: left 10% top 20%;
  /* 10% от левого края, 20% от верхнего */
}
```

### Как работают проценты

Проценты в `background-position` работают неочевидно:

```
background-position: X% Y%

Позиция = (контейнер_размер - изображение_размер) * процент

Пример: контейнер 400px, изображение 200px, position: 50%
  Позиция = (400 - 200) * 0.5 = 100px
  Изображение начинается на 100px → его центр на 200px = центр контейнера

Пример: position: 25%
  Позиция = (400 - 200) * 0.25 = 50px

Пример: position: 0%
  Позиция = (400 - 200) * 0 = 0px → левый/верхний край

Пример: position: 100%
  Позиция = (400 - 200) * 1 = 200px → правый/нижний край
```

> **Ключевое различие:** `background-position: 50%` центрирует изображение, а `background-position: 50px` — это абсолютное смещение от левого верхнего угла.

## 11. background-blend-mode и mix-blend-mode

### background-blend-mode — смешивание слоёв фона

```css
.element {
  background-image: url('photo.jpg');
  background-color: #3366ff;
  background-blend-mode: multiply;
  /* Фото смешивается с синим цветом в режиме multiply */
}

/* Смешивание двух изображений */
.element {
  background:
    url('texture.png') center / cover,
    url('photo.jpg') center / cover;
  background-blend-mode: overlay, normal;
}
```

### mix-blend-mode — смешивание элемента с фоном

```css
.overlay-text {
  mix-blend-mode: multiply;
  /* Элемент смешивается со всем, что под ним */
}
```

### Режимы наложения

| Режим | Формула | Описание |
|---|---|---|
| `normal` | Верхний слой | Без смешивания |
| `multiply` | A * B | Затемнение, белый прозрачен |
| `screen` | 1-(1-A)*(1-B) | Осветление, чёрный прозрачен |
| `overlay` | multiply или screen | Контраст (зависит от яркости) |
| `darken` | min(A, B) | Выбирает более тёмный пиксель |
| `lighten` | max(A, B) | Выбирает более светлый пиксель |
| `color-dodge` | A/(1-B) | Сильное осветление |
| `color-burn` | 1-(1-A)/B | Сильное затемнение |
| `hard-light` | multiply или screen | Как overlay, но «жёстче» |
| `soft-light` | Сложная формула | Мягкий свет |
| `difference` | abs(A-B) | Абсолютная разница |
| `exclusion` | A+B-2*A*B | Как difference, но мягче |
| `hue` | H от B, S и L от A | Оттенок верхнего слоя |
| `saturation` | S от B, H и L от A | Насыщенность верхнего слоя |
| `color` | H и S от B, L от A | Цвет верхнего слоя |
| `luminosity` | L от B, H и S от A | Яркость верхнего слоя |

### Практические примеры

```css
/* Тонирование фотографии */
.tinted-photo {
  position: relative;
}
.tinted-photo::after {
  content: '';
  position: absolute;
  inset: 0;
  background: #3366ff;
  mix-blend-mode: color;
  /* Сохраняет яркость фото, но делает его синим */
}

/* Текст, адаптирующийся к фону */
.adaptive-text {
  mix-blend-mode: difference;
  color: white;
  /* Текст всегда контрастен с фоном */
}

/* Duotone-эффект */
.duotone {
  background: #1a1a2e;
}
.duotone img {
  filter: grayscale(100%);
  mix-blend-mode: luminosity;
}

/* Knock-out текст (текст как «вырез» в фоне) */
.knockout {
  background: url('photo.jpg') center / cover;
  color: white;
  mix-blend-mode: screen;
  /* Белый текст на фото → текст становится «вырезом» */
}
```

> **Gotcha:** `mix-blend-mode` создаёт новый stacking context. Элемент с `mix-blend-mode` (кроме `normal`) изолируется. Используйте `isolation: isolate` на родителе, чтобы ограничить scope смешивания.

```css
/* Ограничение смешивания */
.card {
  isolation: isolate; /* Элементы внутри смешиваются только между собой */
}
.card .overlay {
  mix-blend-mode: multiply;
  /* Не смешивается с элементами ЗА пределами .card */
}
```

## 12. opacity — прозрачность и альтернативы

### Поведение opacity

```css
.element {
  opacity: 1;    /* Полностью непрозрачный */
  opacity: 0.5;  /* 50% прозрачный */
  opacity: 0;    /* Невидимый, НО занимает место и кликабельный */
}
```

### Ключевые особенности opacity

```css
/* 1. opacity НЕ наследуется, но влияет на ВСЕХ потомков */
.parent {
  opacity: 0.5;
}
.parent .child {
  opacity: 1; /* Не поможет! Дочерний элемент всё равно полупрозрачный */
  /* Итоговая прозрачность = 0.5 * 1 = 0.5 */
}

/* 2. opacity создаёт новый stacking context */
.element {
  opacity: 0.99; /* Даже 0.99 создаёт stacking context */
  /* z-index потомков теперь работает внутри этого контекста */
}

/* 3. opacity: 0 != display: none != visibility: hidden */
.opacity-zero {
  opacity: 0;
  /* Элемент невидим, но занимает место, кликабелен, читается screen reader */
}
.display-none {
  display: none;
  /* Элемент полностью удалён из layout, не кликабелен, не читается */
}
.visibility-hidden {
  visibility: hidden;
  /* Элемент невидим, занимает место, НЕ кликабелен, НЕ читается */
}
```

### Альтернативы opacity для прозрачности цвета

```css
/* Проблема: хотим полупрозрачный ФОН, но непрозрачный текст */

/* ПЛОХО */
.card {
  background: white;
  opacity: 0.8; /* Текст тоже стал полупрозрачным! */
}

/* ХОРОШО: прозрачность только для цвета */
.card {
  background: rgb(255 255 255 / 0.8);     /* rgba */
  /* Или */
  background: hsl(0 0% 100% / 80%);       /* hsla */
  /* Или */
  background: oklch(1 0 0 / 0.8);         /* oklch с альфа */
  /* Или */
  background: color-mix(in srgb, white, transparent 20%);
  /* Текст остаётся полностью непрозрачным */
}

/* Альтернатива для border */
.element {
  border: 2px solid rgb(0 0 0 / 0.1);
  /* Полупрозрачная граница без влияния на контент */
}

/* Альтернатива для тени */
.element {
  box-shadow: 0 4px 12px rgb(0 0 0 / 0.15);
}
```

## 13. Filters — filter и backdrop-filter

### filter — фильтры на элементе

Фильтры применяются к элементу и всему его содержимому (включая потомков).

```css
.element {
  /* Размытие */
  filter: blur(5px);                /* Гауссово размытие */

  /* Яркость */
  filter: brightness(1.5);          /* > 1 = ярче, < 1 = темнее */
  filter: brightness(150%);

  /* Контрастность */
  filter: contrast(2);              /* > 1 = больше контраста */
  filter: contrast(200%);

  /* Обесцвечивание */
  filter: grayscale(100%);          /* 100% = полностью ч/б */
  filter: grayscale(0.5);           /* 50% — частичное обесцвечивание */

  /* Сдвиг оттенка */
  filter: hue-rotate(90deg);        /* Поворот цветового круга */

  /* Инверсия */
  filter: invert(100%);             /* Негатив */
  filter: invert(1);

  /* Прозрачность (через фильтр) */
  filter: opacity(50%);             /* Как opacity, но работает через GPU */
  filter: opacity(0.5);

  /* Насыщенность */
  filter: saturate(200%);           /* > 100% = более насыщенный */
  filter: saturate(0);              /* = grayscale(100%) */

  /* Сепия */
  filter: sepia(100%);              /* Полная сепия */
  filter: sepia(0.5);

  /* Тень (применяется к альфа-маске элемента!) */
  filter: drop-shadow(4px 4px 8px rgba(0,0,0,0.3));
  /* В отличие от box-shadow, учитывает ФОРМУ элемента (PNG, SVG) */
}
```

### Комбинирование фильтров

```css
.element {
  /* Фильтры применяются последовательно (порядок важен) */
  filter: contrast(1.2) brightness(1.1) saturate(1.3);

  /* Тёмная тема через инверсию */
  filter: invert(1) hue-rotate(180deg);
  /* invert(1) = негатив, hue-rotate(180deg) = возвращает цвета обратно */
  /* Результат: тёмный фон, светлый текст, правильные цвета */
}
```

### drop-shadow vs box-shadow

```css
/* box-shadow — прямоугольная тень по border-box */
.box-shadow {
  box-shadow: 4px 4px 8px rgba(0,0,0,0.3);
  /* Тень всегда прямоугольная (с учётом border-radius) */
}

/* drop-shadow — тень по ФОРМЕ содержимого */
.drop-shadow {
  filter: drop-shadow(4px 4px 8px rgba(0,0,0,0.3));
  /* Для PNG с прозрачностью — тень по контуру объекта */
  /* Для SVG — тень по форме SVG */
  /* Для элементов с clip-path — тень по clip-path */
}
```

### backdrop-filter — фильтры на фоне ЗА элементом

`backdrop-filter` применяет фильтры не к самому элементу, а к тому, что видно сквозь него.

```css
/* Эффект «frosted glass» (матовое стекло) */
.glassmorphism {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 16px;
}

/* Затемнённый оверлей с размытием */
.modal-backdrop {
  position: fixed;
  inset: 0;
  background: rgba(0, 0, 0, 0.3);
  backdrop-filter: blur(10px);
  -webkit-backdrop-filter: blur(10px);
}

/* Шапка сайта с размытием */
.header {
  position: sticky;
  top: 0;
  background: rgba(255, 255, 255, 0.8);
  backdrop-filter: blur(12px) saturate(150%);
  -webkit-backdrop-filter: blur(12px) saturate(150%);
}
```

> **Важно:** `backdrop-filter` требует, чтобы элемент или его фон был хотя бы частично прозрачным, иначе эффект не виден (фон перекрывает его). Также `backdrop-filter` создаёт новый stacking context.

### Побочные эффекты filter

```css
.element {
  filter: blur(5px);
  /* Побочные эффекты: */
  /* 1. Создаёт новый stacking context */
  /* 2. Создаёт новый containing block для position: fixed потомков */
  /* 3. Содержимое за пределами blur вылезает за видимую область */
}

/* Решение для overflow при blur */
.blur-container {
  overflow: hidden;
  padding: 20px; /* Компенсируем blur-радиус */
}
.blur-container .blurred {
  filter: blur(10px);
  margin: -20px; /* Убираем компенсацию */
}
```

### SVG фильтры через url()

```css
.element {
  /* Кастомный SVG-фильтр */

  filter: url('filters.svg#noise');
}
```

## 14. accent-color и color-scheme

### accent-color — стилизация нативных элементов форм

`accent-color` задаёт акцентный цвет для нативных элементов управления браузера.

```css
/* Глобальный акцентный цвет */
:root {
  accent-color: #3366ff;
}

/* Или для конкретных элементов */
input[type="checkbox"] {
  accent-color: #ff6633;
}

input[type="radio"] {
  accent-color: green;
}

input[type="range"] {
  accent-color: #9933ff;
}

progress {
  accent-color: #00cc88;
}
```

### Какие элементы поддерживают accent-color

| Элемент | Что окрашивается |
|---|---|
| `<input type="checkbox">` | Фон отмеченного состояния |
| `<input type="radio">` | Внутренний круг выбранного состояния |
| `<input type="range">` | Трек и thumb |
| `<progress>` | Заполненная часть |
| `<select>` | Зависит от браузера |

> **Важно:** `accent-color` автоматически подбирает контрастный цвет для галочки/индикатора (белый или чёрный) в зависимости от яркости акцентного цвета.

### color-scheme — светлая и тёмная тема

`color-scheme` указывает браузеру, какие цветовые схемы поддерживает страница или элемент. Это влияет на отрисовку нативных элементов (scrollbars, form controls, system colors).

```css
/* На уровне страницы */
:root {
  color-scheme: light dark;
  /* Страница поддерживает обе темы, браузер использует системную */
}

/* Только светлая */
:root {
  color-scheme: light;
}

/* Только тёмная */
:root {
  color-scheme: dark;
}

/* На уровне элемента */
.dark-section {
  color-scheme: dark;
  /* Scrollbars, inputs, selects в этой секции будут тёмными */
}

/* Через meta-тег (лучше для предотвращения flash) */
/* <meta name="color-scheme" content="light dark"> */
```

### Что меняет color-scheme

```css
/* Когда color-scheme: dark, браузер автоматически: */
/*   - Делает фон страницы тёмным */
/*   - Делает текст светлым */
/*   - Scrollbars становятся тёмными */
/*   - Form controls (input, select, textarea) становятся тёмными */
/*   - System colors (Canvas, CanvasText и т.д.) переключаются */

:root {
  color-scheme: light dark;
}

/* Ваши custom styles переопределяют defaults */
body {
  background: var(--bg-color);
  color: var(--text-color);
}
```

### Комбинация accent-color + color-scheme для тёмной темы

```css
:root {
  color-scheme: light dark;
  accent-color: #667eea;
}

/* Тёмная тема */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a2e;
    --text: #eee;
    --surface: #16213e;
    accent-color: #8b9cf7; /* Более яркий акцент для тёмного фона */
  }
}

/* Светлая тема */
@media (prefers-color-scheme: light) {
  :root {
    --bg: #ffffff;
    --text: #1a1a2e;
    --surface: #f5f5f5;
    accent-color: #4c5fd5;
  }
}
```

### light-dark() — функция для dual-theme значений

```css
:root {
  color-scheme: light dark;
}

.element {
  /* light-dark(значение_для_light, значение_для_dark) */
  color: light-dark(#1a1a2e, #f0f0f0);
  background: light-dark(#ffffff, #1a1a2e);
  border-color: light-dark(#ddd, #333);
}

/* Эквивалент через media query */
.element {
  color: #1a1a2e;
  background: #ffffff;
}
@media (prefers-color-scheme: dark) {
  .element {
    color: #f0f0f0;
    background: #1a1a2e;
  }
}
```

### Полная система тёмной темы

```css
:root {
  color-scheme: light dark;
  accent-color: oklch(0.6 0.2 260);

  /* Семантические токены */
  --color-bg-primary: light-dark(oklch(1 0 0), oklch(0.15 0 0));
  --color-bg-secondary: light-dark(oklch(0.97 0 0), oklch(0.2 0.01 250));
  --color-text-primary: light-dark(oklch(0.15 0 0), oklch(0.93 0 0));
  --color-text-secondary: light-dark(oklch(0.4 0 0), oklch(0.7 0 0));
  --color-border: light-dark(oklch(0.85 0 0), oklch(0.3 0 0));
  --color-accent: light-dark(oklch(0.55 0.2 260), oklch(0.7 0.18 260));
}

body {
  background: var(--color-bg-primary);
  color: var(--color-text-primary);
}

.card {
  background: var(--color-bg-secondary);
  border: 1px solid var(--color-border);
}

a {
  color: var(--color-accent);
}
```
