## 1. Принципы адаптивного дизайна

### Три столпа Responsive Web Design (Ethan Marcotte, 2010)

1. **Fluid Grids** — размеры в процентах/fr, а не фиксированных пикселях
2. **Flexible Images** — изображения масштабируются внутри контейнера
3. **Media Queries** — применение стилей в зависимости от характеристик устройства

### Intrinsic Design (Jen Simmons)

Современная эволюция RWD — **Intrinsic Design**: компоненты сами определяют своё поведение на основе доступного пространства, без жёстких breakpoints.

```css
/* Intrinsic: сетка адаптируется сама, без media queries */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(300px, 100%), 1fr));
  gap: 1rem;
}
```

### Fluid vs Adaptive

| Подход | Описание | Как работает |
|--------|----------|-------------|
| **Fluid** | Плавное масштабирование | %, vw, fr, clamp() |
| **Adaptive** | Дискретные breakpoints | @media с фиксированными точками |
| **Intrinsic** | Компонент сам решает | Container queries, minmax(), auto-fit |

## 2. Media Queries

### Синтаксис

```css
/* Базовый синтаксис */
@media media-type and (media-feature) {
  /* стили */
}

/* Media types */
@media screen { }   /* Экран */
@media print { }    /* Печать */
@media all { }      /* Всё (по умолчанию) */

/* Логические операторы */
@media screen and (min-width: 768px) { }          /* AND */
@media (min-width: 768px), (orientation: portrait) { } /* OR (запятая) */
@media not print { }                                /* NOT */
@media not (color) { }                             /* NOT с feature */
```

### Media Features — полный список

#### Размеры viewport

```css
/* Ширина */
@media (width: 768px) { }        /* Точно 768px (редко используется) */
@media (min-width: 768px) { }    /* >= 768px */
@media (max-width: 767px) { }    /* <= 767px */

/* Range syntax (Media Queries Level 4) */
@media (width >= 768px) { }      /* Современный синтаксис */
@media (768px <= width <= 1024px) { }  /* Диапазон */
@media (width < 768px) { }

/* Высота */
@media (min-height: 600px) { }
@media (height >= 600px) { }

/* Aspect ratio */
@media (aspect-ratio: 16/9) { }
@media (min-aspect-ratio: 1/1) { }  /* Ширина >= высоты */
```

#### Характеристики устройства

```css
/* Ориентация */
@media (orientation: portrait) { }    /* Высота > ширины */
@media (orientation: landscape) { }   /* Ширина > высоты */

/* Плотность пикселей */
@media (resolution: 2dppx) { }       /* Retina */
@media (min-resolution: 2dppx) { }   /* 2x и выше */
@media (-webkit-min-device-pixel-ratio: 2) { } /* Safari fallback */

/* Hover capability */
@media (hover: hover) { }     /* Устройство поддерживает hover (мышь) */
@media (hover: none) { }      /* Нет hover (тач) */
@media (any-hover: hover) { } /* Хотя бы один input с hover */

/* Pointer */
@media (pointer: fine) { }    /* Точный указатель (мышь) */
@media (pointer: coarse) { }  /* Грубый указатель (палец) */
@media (pointer: none) { }    /* Нет указателя */
```

#### Пользовательские предпочтения

```css
/* Тёмная/светлая тема */
@media (prefers-color-scheme: dark) { }
@media (prefers-color-scheme: light) { }

/* Уменьшенное движение */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* Повышенный контраст */
@media (prefers-contrast: more) { }
@media (prefers-contrast: less) { }
@media (prefers-contrast: custom) { }

/* Прозрачность */
@media (prefers-reduced-transparency: reduce) { }

/* Forced colors (Windows High Contrast Mode) */
@media (forced-colors: active) {
  /* Используйте system colors: Canvas, CanvasText, LinkText, etc. */
  .button {
    border: 2px solid ButtonText;
  }
}

/* Уменьшенное потребление данных */
@media (prefers-reduced-data: reduce) {
  .hero { background-image: none; }
}

/* Color gamut */
@media (color-gamut: p3) {
  :root { --brand: oklch(0.7 0.25 145); }
}
@media (color-gamut: srgb) {
  :root { --brand: #00cc66; }
}
```

### @media внутри HTML

```html
<!-- Условная загрузка CSS -->
<link rel="stylesheet" href="base.css">
<link rel="stylesheet" href="desktop.css" media="(min-width: 1024px)">
<link rel="stylesheet" href="print.css" media="print">

<!-- Важно: браузер загружает ВСЕ стили, но с низким приоритетом для несовпадающих -->
```

## 3. Mobile-first vs Desktop-first

### Mobile-first (рекомендуемый подход)

```css
/* Базовые стили для мобильных */
.container {
  padding: 1rem;
  display: flex;
  flex-direction: column;
}

/* Расширяем для планшетов */
@media (min-width: 768px) {
  .container {
    padding: 2rem;
    flex-direction: row;
  }
}

/* Расширяем для десктопа */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}
```

### Desktop-first

```css
/* Базовые стили для десктопа */
.container {
  max-width: 1200px;
  margin: 0 auto;
  display: flex;
  flex-direction: row;
}

/* Сужаем для планшетов */
@media (max-width: 1023px) {
  .container {
    padding: 2rem;
  }
}

/* Сужаем для мобильных */
@media (max-width: 767px) {
  .container {
    padding: 1rem;
    flex-direction: column;
  }
}
```

### Почему Mobile-first лучше

| Аспект | Mobile-first | Desktop-first |
|--------|-------------|---------------|
| **Производительность** | Мобильные грузят минимум CSS | Мобильные грузят все стили + overrides |
| **Progressive Enhancement** | Да — добавляем фичи | Graceful Degradation — убираем |
| **Приоритет контента** | Фокус на сути | Может быть перегружен |
| **Сложность CSS** | min-width: добавляем | max-width: переопределяем |

## 4. Breakpoints — стратегии выбора

### Популярные breakpoints

```css
/* Tailwind CSS defaults */
/* sm: 640px, md: 768px, lg: 1024px, xl: 1280px, 2xl: 1536px */

/* Bootstrap 5 */
/* sm: 576px, md: 768px, lg: 992px, xl: 1200px, xxl: 1400px */

/* Content-first (рекомендуемый подход) */
/* Не привязывайтесь к устройствам — смотрите, где ломается макет */
```

### Content-first breakpoints

```css
/* ПЛОХО: привязка к конкретным устройствам */
@media (min-width: 375px) { }  /* iPhone */
@media (min-width: 768px) { }  /* iPad */
@media (min-width: 1440px) { } /* MacBook Pro */

/* ХОРОШО: breakpoints на основе контента */
.card-grid {
  display: grid;
  grid-template-columns: 1fr;
}

/* Когда помещается 2 карточки (карточка ~300px + gap) */
@media (min-width: 650px) {
  .card-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Когда помещается 3 карточки */
@media (min-width: 960px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

### CSS Custom Properties для breakpoints

```css
/* Нельзя использовать var() в media queries! */
@media (min-width: var(--breakpoint-md)) { }  /* НЕ РАБОТАЕТ */

/* Но можно использовать @custom-media (пока не поддерживается без PostCSS) */
@custom-media --tablet (min-width: 768px);
@media (--tablet) { }

/* Решение — CSS Custom Properties для значений внутри media queries */
:root {
  --content-width: 100%;
  --sidebar-display: none;
}

@media (min-width: 768px) {
  :root {
    --content-width: 70%;
    --sidebar-display: block;
  }
}
```

## 5. Container Queries

### Основная концепция

Media queries отвечают на вопрос: «Какого размера **viewport**?»
Container queries отвечают на вопрос: «Какого размера **контейнер** компонента?»

### Синтаксис

```css
/* 1. Объявляем containment context */
.card-container {
  container-type: inline-size; /* Отслеживаем ширину */
  container-name: card;        /* Именуем (опционально) */
  /* Или shorthand: */
  container: card / inline-size;
}

/* 2. Пишем container query */
@container card (min-width: 400px) {
  .card {
    display: flex;
    flex-direction: row;
  }
}

@container card (min-width: 600px) {
  .card {
    grid-template-columns: 1fr 2fr;
  }
}
```

### container-type

| Значение | Описание |
|----------|----------|
| `normal` | Не является query container (по умолчанию) |
| `inline-size` | Отслеживает inline-size (ширину в horizontal writing mode) |
| `size` | Отслеживает и inline-size, и block-size |

> **Важно:** `container-type: inline-size` создаёт **containment** для layout, style, и inline-size. Это значит, что элемент не может зависеть от размера своих детей по inline-axis (аналогично `contain: inline-size layout style`).

### Container Query Units

```css
/* Единицы относительно размера ближайшего query container */
.card-title {
  font-size: clamp(1rem, 3cqi, 2rem); /* cqi = 1% inline-size контейнера */
}
```

| Unit | Описание |
|------|----------|
| `cqw` | 1% ширины контейнера |
| `cqh` | 1% высоты контейнера |
| `cqi` | 1% inline-size контейнера |
| `cqb` | 1% block-size контейнера |
| `cqmin` | Меньшее из cqi и cqb |
| `cqmax` | Большее из cqi и cqb |

### Container Queries vs Media Queries

```css
/* Media Query: компонент знает про viewport */
@media (min-width: 768px) {
  .card { flex-direction: row; }
}
/* Проблема: если .card в узком sidebar на wide viewport — сломается */

/* Container Query: компонент знает только про свой контейнер */
@container (min-width: 400px) {
  .card { flex-direction: row; }
}
/* Работает правильно в sidebar, main content, modal — везде */
```

### Style Queries (экспериментально)

```css
/* Запрос стиля контейнера (поддержка в Chrome 111+) */
@container style(--theme: dark) {
  .card {
    background: #1a1a1a;
    color: white;
  }
}

@container style(--layout: compact) {
  .card {
    padding: 0.5rem;
  }
}
```

## 6. Viewport Units

### Классические viewport units

```css
.hero {
  height: 100vh;  /* 100% высоты viewport */
  width: 100vw;   /* 100% ширины viewport (включая scrollbar!) */
}

.square {
  width: 50vmin;   /* 50% меньшей стороны viewport */
  height: 50vmin;
}

.banner {
  font-size: 10vmax; /* 10% большей стороны viewport */
}
```

### Проблема 100vh на мобильных

На мобильных устройствах `100vh` включает пространство **за** адресной строкой браузера. Когда пользователь скроллит и адресная строка скрывается, видимая область увеличивается — но `100vh` остаётся прежним.

```
┌─────────────────┐
│  Address Bar     │
├─────────────────┤
│                  │
│   100vh = full   │ ← Включая скрытую за address bar область
│   viewport       │
│                  │
│                  │
└─────────────────┘
```

### Новые viewport units (решение)

```css
/* svh — Small Viewport Height (адресная строка показана) */
/* lvh — Large Viewport Height (адресная строка скрыта) */
/* dvh — Dynamic Viewport Height (меняется при скролле) */

.hero {
  /* Старый подход с fallback */
  height: 100vh;
  height: 100dvh; /* Динамически адаптируется */
}

.sticky-footer {
  min-height: 100svh; /* Минимальная (с адресной строкой) */
}
```

| Unit | Описание | Когда использовать |
|------|----------|-------------------|
| `svh`/`svw` | Small viewport (минимальный) | Когда элемент должен точно помещаться |
| `lvh`/`lvw` | Large viewport (максимальный) | Фоновые элементы |
| `dvh`/`dvw` | Dynamic viewport (текущий) | Hero sections, fullscreen layouts |
| `vi`/`vb` | Logical viewport inline/block | Интернационализация |

### 100vw и горизонтальный scrollbar

```css
/* ПРОБЛЕМА: 100vw включает scrollbar → горизонтальный скролл */
.full-width {
  width: 100vw; /* Шире видимой области на ширину scrollbar! */
}

/* РЕШЕНИЕ 1: overflow-x */
body {
  overflow-x: hidden; /* Грубо, но работает */
}

/* РЕШЕНИЕ 2: используем 100% вместо 100vw */
.full-width {
  width: 100%;
}

/* РЕШЕНИЕ 3: CSS scrollbar-gutter (modern) */
html {
  scrollbar-gutter: stable; /* Резервирует место под scrollbar */
}
```

## 7. Fluid Typography

### Формула fluid typography

```css
/* Старый подход: фиксированные значения на breakpoints */
h1 { font-size: 1.5rem; }
@media (min-width: 768px) { h1 { font-size: 2rem; } }
@media (min-width: 1200px) { h1 { font-size: 3rem; } }

/* Fluid подход: плавное масштабирование */
h1 {
  font-size: clamp(1.5rem, 1rem + 2vw, 3rem);
  /*          min      preferred       max  */
}
```

### Как работает clamp()

```css
font-size: clamp(MIN, PREFERRED, MAX);

/* Эквивалент: */
font-size: max(MIN, min(PREFERRED, MAX));

/* Пример: clamp(1rem, 0.5rem + 2vw, 2rem) */
/* На 320px viewport: 0.5rem + 6.4px ≈ 14.4px → min 16px (1rem) */
/* На 768px viewport: 0.5rem + 15.36px = 23.36px → 23.36px */
/* На 1920px viewport: 0.5rem + 38.4px = 46.4px → max 32px (2rem) */
```

### Формула расчёта preferred value

```
preferred = MIN_SIZE + (MAX_SIZE - MIN_SIZE) * (100vw - MIN_VIEWPORT) / (MAX_VIEWPORT - MIN_VIEWPORT)
```

Для `clamp(1rem, ?, 2rem)` при min-viewport 320px и max-viewport 1200px:

```css
/* preferred = 1rem + (2rem - 1rem) * (100vw - 320px) / (1200px - 320px) */
/* preferred = 1rem + 1rem * (100vw - 320px) / 880px */
/* preferred ≈ 0.636rem + 1.136vw */

h1 {
  font-size: clamp(1rem, 0.636rem + 1.136vw, 2rem);
}
```

### Fluid spacing system

```css
:root {
  /* Fluid spacing scale */
  --space-xs: clamp(0.25rem, 0.2rem + 0.25vw, 0.5rem);
  --space-sm: clamp(0.5rem, 0.4rem + 0.5vw, 1rem);
  --space-md: clamp(1rem, 0.8rem + 1vw, 2rem);
  --space-lg: clamp(1.5rem, 1rem + 2.5vw, 4rem);
  --space-xl: clamp(2rem, 1rem + 5vw, 6rem);

  /* Fluid font scale */
  --text-sm: clamp(0.875rem, 0.8rem + 0.25vw, 1rem);
  --text-base: clamp(1rem, 0.9rem + 0.5vw, 1.25rem);
  --text-lg: clamp(1.25rem, 1rem + 1vw, 1.75rem);
  --text-xl: clamp(1.5rem, 1rem + 2vw, 2.5rem);
  --text-2xl: clamp(2rem, 1rem + 3vw, 4rem);
}

h1 { font-size: var(--text-2xl); }
h2 { font-size: var(--text-xl); }
p { font-size: var(--text-base); }
.section { padding: var(--space-lg) var(--space-md); }
```

## 8. Responsive Images в CSS

### background-image и media queries

```css
.hero {
  background-image: url('hero-mobile.jpg');
  background-size: cover;
  background-position: center;
}

@media (min-width: 768px) {
  .hero {
    background-image: url('hero-tablet.jpg');
  }
}

@media (min-width: 1200px) {
  .hero {
    background-image: url('hero-desktop.jpg');
  }
}

/* С учётом Retina */
@media (min-width: 1200px) and (min-resolution: 2dppx) {
  .hero {
    background-image: url('hero-desktop@2x.jpg');
  }
}
```

### image-set() для resolution switching

```css
.hero {
  background-image: url('hero-1x.jpg'); /* Fallback */
  background-image: image-set(
    url('hero-1x.webp') type('image/webp') 1x,
    url('hero-2x.webp') type('image/webp') 2x,
    url('hero-1x.jpg') 1x,
    url('hero-2x.jpg') 2x
  );
}
```

### object-fit для img и video

```css
/* Адаптивное изображение в фиксированном контейнере */
.thumbnail {
  width: 200px;
  height: 200px;
  overflow: hidden;
}

.thumbnail img {
  width: 100%;
  height: 100%;
  object-fit: cover;          /* Заполняет, обрезая лишнее */
  object-position: center;    /* Центрирует обрезку */
}
```

| Значение | Описание |
|----------|----------|
| `fill` | Растягивает (default, деформирует) |
| `contain` | Вписывает целиком (могут быть полосы) |
| `cover` | Заполняет, обрезая лишнее |
| `none` | Без масштабирования |
| `scale-down` | Как none или contain — что меньше |

## 9. aspect-ratio

### Основное использование

```css
/* Фиксированное соотношение сторон */
.video-wrapper {
  aspect-ratio: 16 / 9;
  width: 100%;
  /* height вычисляется автоматически */
}

.square {
  aspect-ratio: 1;  /* 1/1 */
  width: 200px;
}

.portrait-card {
  aspect-ratio: 3 / 4;
}
```

### Замена padding-top hack

```css
/* СТАРЫЙ подход: padding-top hack */
.video-container {
  position: relative;
  padding-top: 56.25%; /* 9/16 * 100% */
  height: 0;
}
.video-container iframe {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
}

/* НОВЫЙ подход: aspect-ratio */
.video-container {
  aspect-ratio: 16 / 9;
  width: 100%;
}
.video-container iframe {
  width: 100%;
  height: 100%;
}
```

### aspect-ratio и overflow

```css
/* aspect-ratio — предпочтительный, не абсолютный */
.card {
  aspect-ratio: 1;
  width: 200px;
  /* Если контент не помещается, элемент РАСШИРИТСЯ */
  /* aspect-ratio — это preferred ratio, а не constraint */
}

/* Чтобы обрезать: */
.card {
  aspect-ratio: 1;
  width: 200px;
  overflow: hidden; /* Теперь контент обрезается */
}

/* Или min-height: 0 для flex/grid items */
.grid-item {
  aspect-ratio: 1;
  min-height: 0;
  overflow: hidden;
}
```

## 10. Мобильные особенности

### 300ms tap delay

```css
/* Современные браузеры убирают 300ms delay при наличии viewport meta */
/* <meta name="viewport" content="width=device-width"> */

/* Дополнительно: */
html {
  touch-action: manipulation; /* Убирает delay, отключает double-tap zoom */
}
```

### :hover на тачскринах

```css
/* ПРОБЛЕМА: :hover "залипает" на тачскринах после tap */
.button:hover {
  background: blue; /* На мобильных остаётся после tap */
}

/* РЕШЕНИЕ: hover только для устройств с мышью */
@media (hover: hover) {
  .button:hover {
    background: blue;
  }
}

/* Или более гранулярно */
@media (hover: hover) and (pointer: fine) {
  /* Точно десктоп с мышью */
  .tooltip:hover .tooltip-text {
    display: block;
  }
}
```

### Safe Area Insets (iPhone notch)

```css
/* Для устройств с вырезом (notch, Dynamic Island) */
body {
  padding: env(safe-area-inset-top)
           env(safe-area-inset-right)
           env(safe-area-inset-bottom)
           env(safe-area-inset-left);
}

/* Или для конкретных элементов */
.bottom-nav {
  padding-bottom: calc(1rem + env(safe-area-inset-bottom));
}

/* Необходим viewport-fit=cover */
/* <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover"> */
```

### Масштабирование input на iOS

```css
/* iOS автоматически зумит input с font-size < 16px */
/* РЕШЕНИЕ: минимум 16px для мобильных */
input, select, textarea {
  font-size: 16px;
}

/* Или через media query */
@media (pointer: coarse) {
  input, select, textarea {
    font-size: max(16px, 1rem);
  }
}
```

### Мобильная клавиатура и viewport

```css
/* Когда мобильная клавиатура открыта, viewport уменьшается */
/* dvh/svh учитывают это, а vh — нет */

.chat-input {
  position: fixed;
  bottom: 0;
  /* Проблема с vh: не учитывает клавиатуру */
  /* bottom: calc(100vh - 100%) — старый хак */
}

/* Современное решение: Virtual Keyboard API */
/* navigator.virtualKeyboard.overlaysContent = true; */
/* Затем используем CSS env() */
.chat-input {
  bottom: env(keyboard-inset-height, 0px);
  transition: bottom 0.2s;
}
```

### Responsive Grid с auto-fit

```css
/* Автоматическая сетка без media queries */
.auto-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(250px, 100%), 1fr));
```

### Container Query компонент

```css
/* Карточка, которая адаптируется к контейнеру, а не viewport */
.card-wrapper {
  container: card / inline-size;
}

.card {
  display: grid;
  gap: 1rem;
  padding: 1rem;
}

/* Вертикальная на узком контейнере */
@container card (max-width: 399px) {
  .card {
    grid-template-columns: 1fr;
  }
  .card img {
    aspect-ratio: 16 / 9;
    object-fit: cover;
  }
}

/* Горизонтальная на широком */
@container card (min-width: 400px) {
  .card {
    grid-template-columns: 200px 1fr;
    align-items: start;
  }
}

/* С дополнительными деталями на очень широком */
@container card (min-width: 700px) {
  .card {
    grid-template-columns: 300px 1fr auto;
  }
  .card-actions {
    display: flex;
    flex-direction: column;
  }
}
```

> **Container Queries — будущее responsive design.** Вместо глобальных breakpoints каждый компонент адаптируется к своему контексту. Это делает компоненты по-настоящему переиспользуемыми.
