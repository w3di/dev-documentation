# BigInt

## Суть

- **BigInt** — примитивный тип для целых чисел, способных расти практически бесконечно (вплоть до доступной памяти системы).
- Литерал задаётся суффиксом `n`:

```
42n   // BigInt 42, не обычное число 42
```

- BigInt хранится в отдельном «пространстве» и **не является IEEE-числом**, в отличие от всех остальных чисел JavaScript.

## Важные нюансы

- BigInt и обычные числа **плохо смешиваются** — это полностью разделённые сущности.
- Поэтому важно уметь различать число и BigInt. Для этого `typeof` (на момент записи) возвращает строку `"bigint"`.

## Главное

- BigInt — примитив для сколь угодно больших целых чисел, литерал с суффиксом `n` (например, `42n`).
- Это не IEEE-число; BigInt и обычные числа не смешиваются.
- `typeof 42n` возвращает `"bigint"`.
