# Inferencing (вывод типов) в TypeScript и Flow

## Границы возможностей

- Инструменты сообщают лишь то, что известно на **compile time**; о поведении в реальном runtime они сказать не могут — только надеются, что это «не укусит».

## Сходство TypeScript и Flow

- В рассматриваемых примерах синтаксис **идентичен** между TypeScript и Flow (есть лишь мелкие нюансы). В целом инструменты гораздо более похожи, чем можно ожидать.

## Static type inference без аннотаций

- Без единой аннотации оба инструмента делают **inferencing**.
- Пример: переменной `teacher` присвоена строка → инструмент выводит намерение «эта переменная должна хранить только строки». При попытке позже присвоить не-строку — **ошибка** о недопустимом присваивании. Это их best guess.

```js
var teacher = "Kyle";
teacher = 42;   // ошибка: присваивание неверного типа
```

## Static types: позиция автора

- Часть разработчиков считает главной проблемой **случайное** присваивание переменной значения не того типа; для них static types важны.
- Автор: за 20+ лет ни разу баг не возник из-за случайного присваивания числа переменной, хранившей строку. Он делает это **намеренно**, но не случайно. Для него это не та проблема.
- Если у вас баги именно из-за переошибочных переприсваиваний — эта возможность полезна.
- **Static types** — это допущение, что переменная имеет тип на основе попавшего в неё значения. В JavaScript переменные типа не имеют; это «накладывается» сверху как доп. требование.

## Явные аннотации типов

- Тип можно аннотировать явно: `teacher` — это `string`.
- Ошибка будет та же, но уже **не догадка**: явно заявлено, что переменная должна хранить только строки, и попытка положить не-строку — нарушение.

```ts
var teacher: string = "Kyle";
teacher = 42;   // ошибка: ожидался string
```

## Главное

- Без аннотаций TS/Flow делают **static type inference** (best guess), с аннотациями — проверяют явно заявленный тип; в обоих случаях недопустимое присваивание даёт ошибку.
- Static types = «переменная имеет тип», что чуждо JavaScript (там типы у значений, не у переменных) и полезно лишь тем, у кого баги идут от случайных переприсваиваний.
