# Резюме: как избегать corner cases с `==`

## Правила безопасного использования `==`

`==` можно использовать, но **избегать** в следующих сценариях:

1. **Избегать `==`, если любая из сторон может быть `0`, пустой строкой `""` или строкой только из whitespace.** Здесь много corner cases, которые могут «укусить».
   - Если можно — реструктурировать код так, чтобы такие значения не сравнивались; это в любом случае лучший код.
2. **Не использовать `==` с non-primitives.** Даже identity-сравнение по ссылке, хотя и работает, делать через `==` не стоит — слишком близко к «краю». Только triple equals.
   - `==` применять **только для коэрсии среди примитивов**.
3. **Никогда не делать `== true` / `== false`.** Полагаться на неявный **ToBoolean** (лучший результат). Если строго нужны именно `true`/`false` — `===`.

## Главное

- Список запретов короткий: не сравнивать `0`/`""`/whitespace, не сравнивать non-primitives, не делать `== true`/`== false`.
- Любой разработчик, который изучит этот список, сможет осознанно избегать проблем и ясно выражать намерение в коде.
