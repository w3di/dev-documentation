# Abstract Operation: ToNumber

## Назначение

- **ToNumber** вызывается всякий раз, когда нужна числовая операция, а числа нет. Содержит много угловых случаев.

## Строки

- `"0"` → `0`, `"-0"` → `-0` (знак сохраняется).
- Обрезаются ведущие/хвостовые пробелы и ведущие нули: `"009"` → `9`.
- Корректно обрабатываются числа с плавающей точкой и другие основания (например, hex).
- **Корень всех зол** (root of all coercion evil): пустая строка `""` → `0`.
  - По мнению автора, это ошибка: пустая строка означает отсутствие строкового значения, поэтому должна была давать NaN, а не реальное число `0`.

## Другие примитивы

- `false` → `0`, `true` → `1` (исторически из bit-wise представления; автор считает, что корректнее был бы NaN).
- `null` → `0`.
- `undefined` → `NaN`.
- Непоследовательность: `undefined` даёт NaN, а `null` — `0` (хотя оба «пустые»).

## Объекты: через ToPrimitive с hint number

- ToNumber объекта вызывает ToPrimitive с hint `number` → сначала `valueOf()`, затем `toString()`.
- По умолчанию `valueOf` массива/объекта возвращает сам объект (`return this`), то есть не примитив, поэтому фактически используется `toString()`.
- Итог: «числовое приведение» объекта сводится к его строковому приведению — получается примитивная строка, к которой затем применяется дальнейшее приведение.

### Примеры

- `[""]` (массив с пустой строкой) → toString даёт `""` → ToNumber → `0`.
- `["0"]` → `0`; `["-0"]` → `-0`.
- `[null]` и `[undefined]` → `0`: внутри массива сериализуются в пустую строку, а `""` → `0` («корень зла»).
- Вложенный пустой массив также сериализуется в `""` → `0`.
- Обычный объект → `toString` даёт `"[object Object]"` → ToNumber → `NaN` (разумно).
- Если переопределить `valueOf`, вернётся заданное значение: `valueOf` → `3` даёт ToNumber → `3`.

## Главное

- ToNumber: `""` → `0` («корень всех зол»), `false` → `0`, `true` → `1`, `null` → `0`, `undefined` → `NaN`.
- ToNumber объекта идёт через ToPrimitive(hint number): `valueOf()` → `toString()`, но дефолтный `valueOf` возвращает this, поэтому используется `toString()`.
- Поэтому числовое приведение объекта по факту сводится к строковому: `[null]`, `[undefined]`, `[""]` → `0`; обычный объект → `NaN`.
- Переопределённый `valueOf` позволяет задать собственное числовое представление.
