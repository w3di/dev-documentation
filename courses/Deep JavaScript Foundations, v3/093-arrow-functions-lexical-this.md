# Arrow Functions и Lexical This

## Поведение lexical this

- **arrow function** (стрелочная функция) демонстрирует **lexical this** — поведение, при котором `this` берётся из охватывающей области видимости.
- Пример: метод `ask` объекта `workshop` передаёт в `setTimeout` callback-стрелку; внутри неё `this` корректно указывает на `workshop`.

## Что НА самом деле означает lexical this

- Распространённое заблуждение: будто стрелочная функция «hard-bound к this родителя». **Это неверно.**
- Правильная модель: **arrow function вообще не определяет свой `this`**. В стрелочной функции нет ключевого слова `this` как такового.
- Поэтому `this` внутри стрелки ведёт себя как **обычная переменная** и **лексически разрешается** в ближайшей охватывающей области видимости, где `this` определён.
- Если вложить стрелки на 5 уровней, разрешение `this` поднимается вверх по областям до первой функции, которая определяет `this`, и использует её `this`.

## Разбор примера

1. Внутри стрелки на строке 5 нет своего `this`.
2. Поднимаемся на один уровень — это функция `ask` (`workshop` — объект, а не функция, поэтому не считается).
3. `this` функции `ask` задаётся её **call site** (строка 10).
4. Когда callback вызывается позже, он **замкнут (closed over)** на родительскую область, где `this` указывал на `workshop`.

## Подтверждение из спецификации

- Спецификация: arrow function не определяет локальные привязки для `arguments`, `super`, `this`, `new.target`.
- То есть в стрелке нет своего `this` — это факт из спеки, а не интерпретация.

## Доказательство: new на стрелке

- `new` приоритетнее hard-bound функции и переопределяет её `this`.
- Если бы стрелка была hard-bound, `new` над ней переопределял бы `this`.
- На деле `new` над стрелочной функцией бросает **исключение** — стрелку нельзя вызывать через `new`.
- Это доказывает: стрелка — не hard-bound функция, а функция без собственного `this`.

## Главное

- Arrow function не имеет собственного `this`; `this` внутри неё разрешается лексически по областям видимости.
- Это не hard binding: `new` над стрелкой бросает исключение.
- Согласно спецификации, стрелка не определяет `this`, `arguments`, `super`, `new.target`.
