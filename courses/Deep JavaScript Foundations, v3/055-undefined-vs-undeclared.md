# Undefined vs Undeclared

## Определения

- **undefined** — переменная существует, но в данный момент не имеет значения.
  - Она могла никогда не иметь значения, или раньше имела, а теперь нет.
  - Главное: переменная объявлена (есть шарик), просто значение отсутствует.
- **undeclared** — переменная никогда не была формально объявлена ни в одном доступном scope.
  - Шарика для неё нет вообще.
  - В strict mode source-ссылка на такую переменную всегда даёт ReferenceError.

## Ключевое различие

- undefined: переменная существует, но без значения.
- undeclared: переменной не существует (нет объявления).
- Несмотря на схожесть слов, это разные понятия, их нельзя смешивать.

## Предупреждение

- JS сам путает эти понятия в части сообщений об ошибках и выводов, выдавая undeclared как будто это undefined — это исторически плохая идея.
- Важно держать концепции раздельно: undeclared — не существует; undefined — существует, но без значения.

## Главное

- undefined = переменная объявлена, но без значения; undeclared = переменная нигде не объявлена.
- В strict mode обращение (source) к undeclared переменной даёт ReferenceError.
- Не путать эти понятия, несмотря на то что JS в некоторых сообщениях их смешивает.
