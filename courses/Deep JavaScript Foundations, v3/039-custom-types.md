# Custom Types (пользовательские типы)

## Типы для параметров и возвращаемых значений

- Более мощное применение — типизация **параметров функций** и **return values**.
- Можно определять **custom types**: например, объектный тип со свойством `name` типа `string`.

```ts
type student = { name: string };

function getName(studentRec: student): string {
    return studentRec.name;
}

var firstStudent: student = { name: "Frank" };
var firstStudentName: string = getName(firstStudent);
```

## Как работает проверка

- В примере выше ошибок нет.
- Инструмент знает: `studentRec` — объект с `name: string`, значит `studentRec.name` возвращает `string`; при присваивании строки (строка 9) всё корректно.

## Что именно гарантируется

- Основная гарантия — **корректность присваиваний**: правильные ли типы присваиваются.
- **Параметр функции похож на переменную:** «принимать только числа» = «эта переменная хранит только числа».

## Замечание автора про практику

- На практике автор задавал бы параметры скорее как **union types** (например, разрешить строки, числа и `null`), т. к. редко нужна столь жёсткая привязка к одной конкретной структуре.

```ts
function f(x: string | number | null) { /* ... */ }
```

- Тем не менее инструмент даёт полезные гарантии, если ваша проблема — именно misassignments типов.

## Главное

- Можно определять **custom types** и применять их к параметрам и return values, получая проверку корректности типов.
- На практике полезны **union types** для меньшей жёсткости; основная ценность — гарантии против misassignments.
