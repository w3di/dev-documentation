# Упражнение: equality (`findAll`)

## Задача

- Написать утилиту **`findAll`**, которая ищет в массиве все значения, **coercively equal** заданному тестовому значению, но по особым правилам (не просто `==`).
- `findAll` возвращает массив со всеми подходящими значениями.

## Правила coercive-сопоставления

1. **Exact matches** включаются всегда (использовать `Object.is`).
2. **Строки** (кроме пустой и whitespace-only — их игнорировать) могут coercively совпадать с числами.
3. **Числа** (кроме `NaN` и обеих бесконечностей) могут совпадать со строками.
   - **Важно:** аккуратно с `-0` — он ломает несколько тест-кейсов.
4. `null` совпадает с `undefined` и наоборот.
5. **Boolean** совпадает только с Boolean (`true` только с `true`; не со строкой `"true"`, не с числом `1`).
6. Любой **non-primitive** (объекты) — сопоставление **только по identity** (никакой структурной проверки).

## Примеры ожидаемого поведения

- `findAll(-0, values)` → массив с единственным `-0`.
- `findAll("0", values)` → находит и обычный `0`, и строку `"0"`.

- В `ex.js` есть набор test cases и вспомогательная функция внизу, проверяющая, что массивы содержат одинаковые значения (даже в разном порядке).
- Полезно пройтись по test cases, чтобы понять требования readme.
- Реализация — несколько `if`-веток для обработки всех правил.

## Главное

- Цель — реализовать **безопасное подмножество** coercive-сопоставления, явно исключив corner cases.
- Ключевые правила: exact (`Object.is`), строка↔число (без пустых/whitespace, `NaN`, бесконечностей), `null`↔`undefined`, Boolean только с Boolean, объекты — только по identity; особое внимание `-0`.
