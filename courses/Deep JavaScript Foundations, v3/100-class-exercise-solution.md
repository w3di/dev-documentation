# Решение упражнения: class

## Шаги

1. Тела методов почти не меняются — меняется только организация вокруг них.
2. Объект заменяется на `class Workshop`.
3. Свойства-данные переносятся в **constructor**:
   ```js
   constructor() {
     this.currentEnrollment = [];
     this.studentRecords = [];
   }
   ```
4. Остальные методы становятся методами класса; запятые между ними убираются.
5. This-aware методы остаются без изменений (они корректно работают с `this` экземпляра).

## Вынос хелперов в parent class

- Не this-aware функции `sortByName` и `printRecord` не относятся к `Workshop` — выносятся в parent class `Helpers`.
- `Helpers` не нуждается в `constructor`.
- `Workshop extends Helpers`.

## Важно про super в child-конструкторе

- Если в child определён свой `constructor`, нужно **первым делом** вызвать `super()`, чтобы родительский конструктор создал объект `this`.
- Если свой child-конструктор не определять — `super()` вызывается автоматически.

## Инстанцирование

```js
var deepJS = new Workshop();
```

- Через **constructor класса экземпляр обязательно создаётся с `new`**.
- Сравнение: фабрика `defineWorkshop` была обычной функцией и вызывалась без `new`; class constructor требует `new`.

## Главное

- Тела методов сохраняются; данные переносятся в `constructor`, методы — в класс.
- Не this-aware хелперы выносятся в parent `Helpers`, child вызывает `super()` первым в своём конструкторе.
- Экземпляр класса создаётся через `new`.
