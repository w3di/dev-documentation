# Паттерн IIFE

## Идея IIFE

- Вместо переменной в скобки можно поместить само function expression и сразу его вызвать.
- **IIFE** (Immediately Invoked Function Expression — немедленно вызываемое функциональное выражение) — термин, введённый в JavaScript в 2010 году.
- Function expression создаёт scope и тут же исполняется: запускается один раз и исчезает — эфемерная конструкция, нужная только ради scope.

```js
(function anotherTeacher(){
  // ...
})();
```

## Почему это не function declaration

- Слово `function` не является первым в инструкции — внешние скобки синтаксически превращают объявление в выражение.
- Альтернативно выражение создают unary-операторы перед `function`: `+`, `-`, `~`, а также `void` и `delete`.
- Обычное function declaration, даже если бы исполнялось, всё равно загрязнило бы внешний scope именем; превращение в expression этого избегает — имя `anotherTeacher` не попадает во внешний scope.

## Именованные IIFE

- IIFE часто пишут анонимными, но рекомендация прежняя: **никаких анонимных function expressions**, включая IIFE.
- Любой IIFE имеет цель — её стоит отразить в имени.
- Если осмысленное имя подобрать не удаётся, используют слово `IIFE` (заглавными) — оно появится в stack trace, что лучше анонимной функции.

## Передача значений

- IIFE — обычная функция, поэтому в неё можно передавать значения через параметры, избегая лишних присваиваний.

## IIFE для превращения statement в expression

- IIFE — это expression, поэтому он позволяет поставить statement в позицию выражения.
- Пример: присвоить переменной результат с `try/catch`-фолбэком. `try/catch` — statement и не работает в позиции выражения.
- Обычный обходной приём — объявить переменную и присвоить ей дважды, но это не показывает явно, что присваивание одно.
- IIFE оборачивает `try/catch` в expression и делает однократность присваивания очевидной.

```js
var teacher = (function getTeacher(){
  try { return fetchTeacher(); }
  catch (err) { return "Kyle"; }
})();
```

## Главное

- IIFE — function expression, немедленно вызванное ради создания одноразового scope без загрязнения внешнего.
- Выражением функцию делают окружающие скобки или unary-оператор перед `function`.
- IIFE лучше именовать (хотя бы `IIFE`); также он превращает statement в expression (например, `try/catch` при присваивании).
