# Решение: полифил Object.is

## Проверка наличия реализации

- Используется Boolean-coercion: `if (!Object.is)`. Здесь это уместно, так как `Object.is` либо функция (truthy), либо `undefined` — промежуточных вариантов нет.
- На время упражнения добавляется `|| true`, чтобы своя функция всегда определялась.

## Проверка на -0 без встроенных средств

- Идея: сложение/вычитание нуля не помогает отличить -0 (`-0 + 0` → `0`, `-0 - 0` → `-0`).
- Деление помогает: `1 / 0 === Infinity`, а `1 / -0 === -Infinity`.
- Нужно сперва убедиться, что значение — один из двух нулей, иначе `-Infinity` на входе даст ложное срабатывание.

```
function isItNegZero(v) {
  return v == 0 && (1 / v) == -Infinity;
}
```

- `Infinity` — встроенный идентификатор языка.

## Проверка на NaN без встроенных средств

- Ключ: NaN — единственное значение, не равное самому себе.

```
function isItNaN(v) {
  return v !== v;
}
```

## Сборка Object.is

1. Закэшировать признаки -0 для обоих аргументов (чтобы не вызывать проверку дважды).
2. Если хотя бы один из аргументов — -0, вернуть `true`, только если оба -0 (иначе `===` солгал бы).
3. Иначе, если оба аргумента — NaN, вернуть `true`.
4. Иначе вернуть результат `x === y`.

```
if (!Object.is || true) {
  Object.is = function Object_is(x, y) {
    var xNegZero = isItNegZero(x);
    var yNegZero = isItNegZero(y);

    if (xNegZero || yNegZero) {
      return xNegZero && yNegZero;
    }
    else if (isItNaN(x) && isItNaN(y)) {
      return true;
    }
    else {
      return x === y;
    }
  };
}
```

- При запуске все assert-проверки печатают `true`.

## Главное

- -0 определяется приёмом `v == 0 && 1/v === -Infinity`.
- NaN определяется приёмом `v !== v` (единственное значение, не равное себе).
- Логика Object.is: оба -0 → true; оба NaN → true; иначе `===`.
