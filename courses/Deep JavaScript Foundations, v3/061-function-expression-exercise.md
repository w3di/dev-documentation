# Упражнение: функциональные выражения

## Постановка задачи

- Цель — практика именованных функций и функциональных выражений.
- Используются записи о зачислении студентов на воркшоп (student enrollment records).
- Принцип: использовать функции везде, где возможно — `map`, `filter`, `find` вместо классических `for`-циклов.
- Упражнение состоит из двух частей:
  - **Часть 1**: написать function declarations и named function expressions по инструкции.
  - **Часть 2**: переписать те же функции как arrow functions.
- Поведение в обеих частях одинаково; различается только стиль кода — для сравнения читаемости «бок о бок».
- Решения частей рекомендуется хранить в отдельных файлах.

## Что нужно реализовать

- В файле `ex.js` заготовлены три функции (stubs) с известными параметрами: `printRecords`, `paidStudentsToEnroll`, `remindUnpaid`.
- Функции уже вызываются; ожидаемый вывод указан в комментарии — результат должен совпасть с ним.
- Данные студентов хранятся в массиве `studentRecords`.

### `printRecords(ids)`

1. Принимает массив ID студентов (например, `currentEnrollment`).
2. Получает запись каждого студента по ID (подсказка — `array.find`).
3. Сортирует по имени студента по возрастанию (`array.sort` с кастомной функцией сравнения).
4. Печатает каждую запись в консоль: имя, ID и статус оплаты (paid / not paid).

### `paidStudentsToEnroll()`

1. Просматривает все записи студентов.
2. Находит тех, кто оплатил (paid), но ещё не зачислен (их ID нет в `currentEnrollment`).
3. Собирает эти ID.
4. Возвращает **новый** массив: ранее зачисленные ID плюс новые (исходный массив не изменяется).

### `remindUnpaid(ids)`

1. Принимает список ID студентов.
2. Фильтрует его, оставляя только тех, чьи записи в статусе unpaid.
3. Передаёт отфильтрованный список в `printRecords`.

## Главное

- Задача — управление записями студентов через функциональные методы массивов вместо циклов.
- Часть 1 — обычные функции, часть 2 — те же функции в виде arrow functions, для сравнения читаемости.
- Поведение неизменно: ключевые методы — `find`, `sort`, `filter`, `map`, `includes`.
