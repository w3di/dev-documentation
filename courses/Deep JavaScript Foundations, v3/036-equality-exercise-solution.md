# Решение упражнения: `findAll`

## Сигнатура и каркас

- Параметры: `match` (значение для сопоставления) и `arr` (список значений).
- Завести пустой массив результата, пройти `for..of` по `arr`, подходящие значения класть в результат, вернуть его.

```js
function findAll(match, arr) {
    var ret = [];
    for (let v of arr) {
        // проверки ниже
    }
    return ret;
}
```

## Шаг 1: exact match через `Object.is`

- Самый простой случай — строго одинаковые значения.

```js
if (Object.is(match, v)) {
    ret.push(v);
}
```

- Этим уже корректно обрабатывается в т. ч. `-0` для exact-случая.

## Шаг 2: `null` ↔ `undefined`

- `null` и `undefined` coercively равны друг другу и **больше ничему**, поэтому здесь безопасен `== null` без риска corner cases (`-0` и пр.).

```js
else if (match == null && v == null) {
    ret.push(v);
}
```

## Шаг 3: Boolean — только строго с Boolean

- Если `match` — Boolean, то и `v` должен быть Boolean, причём **тем же самым**.
- Сначала сузить surface area через `typeof`, затем сравнить значения.

```js
else if (typeof match == "boolean" && typeof v == "boolean") {
    if (match == v) {
        ret.push(v);
    }
}
```

- **Нюанс:** хотя обычно `==` с Boolean избегают, здесь оба операнда заведомо Boolean (типы совпали), поэтому `==` делает то же, что `===` — безопасно.

## Шаг 4: строка → число

- `match` — строка, но не пустая и не whitespace-only (`match.trim() != ""`), а `v` — число.
- **Важно:** при коэрсии числа в строку теряется знак `-0`, поэтому `-0` в позиции `v` нужно исключить, иначе совпадение потеряется.

```js
else if (
    typeof match == "string" && match.trim() != "" &&
    typeof v == "number" && !Object.is(v, -0)
) {
    if (match == v) {
        ret.push(v);
    }
}
```

- Внешний `if` устранил corner cases — внутренний `==` теперь безопасен.

## Шаг 5: число → строка

- `match` — число, но **не** `NaN`, **не** `Infinity`, **не** `-Infinity`, и **не** `-0`.
- `v` — строка, не пустая и не whitespace-only (`v.trim() != ""`).

```js
else if (
    typeof match == "number" &&
    !Number.isNaN(match) &&
    match != Infinity && match != -Infinity &&
    !Object.is(match, -0) &&
    typeof v == "string" && v.trim() != ""
) {
    if (match == v) {
        ret.push(v);
    }
}
```

## Ключевой вывод (стиль кода)

- Коэрсия **безопасна**, когда corner cases устранены и это **очевидно** в коде.
- Намеренный стиль: внешний `if` устраняет corner cases → внутри ясно виден `==`, которому можно доверять.
- Немного дублирования и явности делают код понятнее, чем максимальное «умное» сокращение.

## Вопрос: можно ли через `filter`?

- Да. Логику сопоставления можно оформить как **predicate function** (возвращает `true`/`false`) и применить `values.filter(predicate)` вместо ручного `push`. Полностью валидный вариант.

## Главное

- Структура решения: `Object.is` (exact) → `null`/`undefined` → Boolean строго → строка↔число с исключением пустых/whitespace, `NaN`, бесконечностей и `-0`.
- `-0` — главная ловушка: теряет знак при коэрсии в строку, поэтому исключается через `Object.is(x, -0)`.
- Паттерн «внешний `if` устраняет corner cases, внутренний `==` безопасен» — иллюстрация безопасной осознанной коэрсии.
