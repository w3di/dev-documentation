# Compilation: повторение на краевых случаях

## Пример с пустым внутренним scope

```js
var teacher = "Kyle";              // 1

function otherClass() {            // 3
    teacher = "Suzy";              // 4 (нет var!)
    topic = "React";               // 5 (нет var!)
    console.log("Welcome!");       // 6
}

otherClass();                      // 9
console.log(teacher);              // 11
console.log(topic);                // 12
```

## Проход 1: компиляция

1. Строка 1: `teacher` → красный шарик в красном ведре. (На компиляции «не слышали»; «слышали» будет только при выполнении.)
2. Строка 3: `otherClass` → красный шарик + синее ведро.
3. Внутри `otherClass` нет ни одного `var` — строки 4, 5, 6 НЕ являются formal declarations → синих шариков не создаётся.
4. Синее ведро существует, но пусто (без шариков).
5. Больше formal declarations нет → компиляция завершена.

## Проход 2: выполнение

1. Строка 1: target `teacher` → да → красный шарик ← `"Kyle"`.
2. Функции «не существуют» как исполняемый код → переход к строке 9.
3. Строка 9: source `otherClass` → да → красный шарик содержит функцию (синий scope) → вызов → строка 4.
4. Строка 4: target `teacher` → в синем scope НЕТ (он пуст) → поднимаемся на уровень вверх → глобальный scope, target `teacher` → да → **красный** шарик.
   - Важно: внутри синего scope мы обращаемся к красному шарику. Здесь нет shadowing, потому что `teacher` не объявлен внутри `otherClass`.
   - Присваивание `"Suzy"` перезаписывает значение `"Kyle"` — это та же переменная (тот же шарик).

## Главное

- Formal declaration требует ключевого слова (`var`/`let`/`const`/`function`); присваивание без объявления (строки 4–5) не создаёт шарик в текущем scope.
- Если переменная не объявлена в текущем scope, target-ссылка ищет её во внешних scope (поднимаясь вверх).
- При присваивании к внешней переменной из вложенного scope это та же переменная — её значение перезаписывается (shadowing нет, так как нет локального объявления).
