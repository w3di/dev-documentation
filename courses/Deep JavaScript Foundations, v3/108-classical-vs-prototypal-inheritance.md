# Classical vs Prototypal Inheritance

## Classical inheritance (классическое наследование)

- В class-ориентированных языках (C++, Java и др.).
- При инстанцировании класса (`Workshop`) поведение концептуально (а иногда и физически) **копируется** вниз в экземпляры.
- При создании child class (`AnotherWorkshop extends Workshop`) — снова копирование вниз.
- При инстанцировании child class — ещё копии.
- Направление стрелок: слева направо, сверху вниз — потому что это **copy operations** (операции копирования).

## Prototypal «inheritance»

- Есть объект `Workshop.prototype`.
- Объекты (`deepJS`, `reactJS`) **линкуются** к `Workshop.prototype`.
- `AnotherWorkshop.prototype` линкуется к `Workshop.prototype`; `JSRecentParts` линкуется к `AnotherWorkshop.prototype`.
- Направление стрелок: справа налево, снизу вверх — потому что это **linkage** (связь), а не copy.

## Почему термин «prototypal inheritance» вводит в заблуждение

- Слово «prototypal» для большинства не несёт конкретного смысла — его просто ассоциируют со странной системой.
- Слово «inheritance» несёт сильный багаж: мозг запрограммирован думать о наследовании как о **copy-отношениях**.
- Соединив непонятное «prototypal» с нагруженным «inheritance», по сути перевернули смысл слова на противоположный (линковка вместо копирования).
- Аналогия Kyle: назвать яблоко «красным апельсином» — название не меняет суть вещи, лишь добавляет путаницы.

## Корень 20-летней путаницы

- 20+ лет JS-разработчики недоумевали, почему классы в JavaScript работают не так, как в других языках.
- Причина: системы фундаментально различны (linkage vs copy), но об этом редко говорили прямо.
- Вместо принятия прототипной системы и динамической природы `this` индустрия «потакала» эмоциональной привязанности к class-паттерну.
- На JavaScript наслаивали сложность ради синтаксического сахара, чтобы он «выглядел как классы» — то есть всё лучше «приклеивали» (duct tape) к виду классов, хотя по сути это не классы.

## Главное

- Classical inheritance = копирование вниз (стрелки слева-направо, сверху-вниз); prototypal = линковка вверх (стрелки справа-налево, снизу-вверх).
- Термин «prototypal inheritance» вводит в заблуждение: «inheritance» подразумевает copy, а на деле это linkage — обратное по смыслу.
- Главная путаница JS возникла из попыток выдать прототипную (linkage) систему за классовую (copy) и наслоить на неё class-сахар.
