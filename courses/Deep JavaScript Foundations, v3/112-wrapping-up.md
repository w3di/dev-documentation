# Итоги курса

## Призыв знать свой JavaScript

- Если карьера связана с JavaScript, разумно действительно знать язык.
- Быть любопытным, задавать вопросы, понимать **почему** код работает — чтобы иметь шанс починить его, когда он сломается.
- Относиться к языку серьёзно: периодически читать спецификацию (spec), строить корректную **mental model** (ментальную модель).
- Через понимание инструмента — эффективнее доносить свои идеи и намерения в коде.

## Материалы для углубления

- Серия книг **You Don't Know JS** (все шесть книг доступны на GitHub) как ресурс, дополняющий курс.
- Три книги, релевантные этому курсу:
  - **Scope & Closures**
  - **This & Object Prototypes**
  - **Types & Grammar**

## Главное

- Глубокое понимание JavaScript (почему код работает) — основа для отладки и ясной коммуникации намерений.
- Полезные практики: читать spec, строить корректную mental model, сохранять любопытство.
- Для углубления — книги You Don't Know JS: Scope & Closures, This & Object Prototypes, Types & Grammar.
