# Плюсы static typing (TypeScript / Flow)

> Субъективные оценки автора, не объективный список.

## Преимущества

1. **Типы становятся очевидными в коде.** Большое улучшение по сравнению с кодом, где поведение операции непонятно и неопределённо.
2. **Знакомость (familiarity).** Дизайн TS/Flow «идёт по течению» статической типизации других языков; синтаксис близок к Java, C++. Приходя в систему, разработчик оказывается не в совершенно новом мире типов.
3. **Огромная популярность.** Особенно у TypeScript: крупные open-source проекты массово переходят на него. Сильное community, корпоративная поддержка (TypeScript — Microsoft, Flow — Facebook). Это не мимолётная мода — инвестиция в изучение окупится надолго: много документации, импульса, экосистемы.
   - Пример разумного применения: если работаешь в Microsoft .NET shop, пишешь C# на бэкенде, а затем нужен JavaScript — логично использовать TypeScript, чтобы не было ментального переключения «из типизированного мира в нетипизированный».
4. **Сложность и проработанность (sophistication).** Инструменты очень хороши в своём деле: TS/Flow способны вывести типы даже из намеренно запутанного кода.

## Главное

- Сильные плюсы: типы становятся очевидными; знакомый синтаксис из типизированных языков; огромная популярность и поддержка; высокая проработанность вывода типов.
- Есть сценарии, где их применение однозначно оправдано (например, команды, уже работающие в типизированной экосистеме).
