# Default Binding

## Что такое default binding

- **default binding** (привязка по умолчанию) — четвёртый и последний способ привязки `this`, fallback, когда не сработал ни один из трёх остальных.
- Срабатывает при обычном вызове функции: нет контекстного объекта, нет `.call`, нет `.bind`, нет `new`.

## Поведение в зависимости от режима

- В **non-strict mode** (sloppy mode) `this` по умолчанию указывает на **global object**.
  - Поэтому при чтении свойства печатается значение глобальной переменной (например, `teacher` со значением `Kyle`).
- В **strict mode** `this` остаётся **undefined**.
  - Обращение к свойству на `undefined` даёт **TypeError**.

## Почему strict mode делает this = undefined

- Вызывать this-aware функцию без какого-либо `this` — почти наверняка ошибка программиста.
- Это так же плохо, как авто-создание глобальных переменных.
- В sloppy mode привязка к global object — почти никогда не то, что нужно.
- Strict mode сигнализирует об ошибке: проблема не в обращении `this.x`, а в том, что функция вызвана без `this`. Нужно использовать один из трёх других способов (`new`, `.call`/`.apply`/`.bind`, контекстный объект).

## Итог: четыре способа привязки this

- Всего существует ровно **4 способа** вызова функции, определяющих `this`. Других нет.
- Чтобы узнать, на что указывает `this`, **нельзя смотреть на саму функцию** — нужно смотреть на **call site** (место и способ вызова).
- Каждый вызов: «как именно вызвана функция» определяет, на что укажет `this`.

## Главное

- Default binding — fallback, когда не сработали `new`, `call`/`apply`/`bind` и контекстный объект.
- Non-strict: `this` = global object; strict: `this` = undefined (часто TypeError).
- `this` определяется не функцией, а call site — способом вызова.
