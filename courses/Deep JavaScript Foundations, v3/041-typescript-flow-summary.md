# Резюме по TypeScript и Flow

## Сравнение инструментов

- Для изучения сходств и (особенно) различий TypeScript и Flow автор рекомендует статью, где оба проекта разобраны бок о бок по большому списку характеристик [?].

## Итоговая оценка

- TypeScript и Flow **полезны**: многим помогают решать проблемы с типами и делать типы более очевидными.
- Главная фрустрация автора — в **экосистеме**: сообщество сразу прыгает к мысли «это единственный вариант».

## Ложная дилемма

- Преподносится выбор из двух крайностей:
  1. Полностью игнорировать типы и использовать `===` для защиты.
  2. Наслаивать поверх JavaScript целую систему (TypeScript/Flow), что, по мнению автора, **не в ДНК JavaScript**.
- Автор хотел бы видеть **что-то промежуточное** между этими крайностями.

## Главное

- TS/Flow реально помогают делать типы очевидными, но навязывается ложная дилемма «или `===` везде, или полноценная типовая надстройка».
- Нужен промежуточный вариант между этими крайностями.
