# Abstract Operation: ToString

## Назначение

- **ToString** берёт любое значение и даёт его строковое представление. Почти любое значение имеет какое-либо строковое представление.

## Примитивы

- Большинство — ожидаемо: `null` → `"null"`, `undefined` → `"undefined"`, `true`/`false`, числа с плавающей точкой, `0`.
- **Угловой случай**: `-0` «лжёт» — ToString для `-0` даёт `"0"` (знак теряется).

## Объекты: через ToPrimitive с hint string

- ToString объекта вызывает ToPrimitive с hint `string` → сначала `toString()`, затем `valueOf()`.

### Массивы

- У массивов есть стандартный `toString`, сериализующий содержимое **без квадратных скобок**.
- Пустой массив `[]` → пустая строка `""` (по мнению автора, плохое решение — нельзя отличить от других значений, дающих `""`).
- **Странность**: `null` и `undefined` внутри массива при сериализации опускаются (позиция через запятую сохраняется, но сами значения не выводятся как `"null"`/`"undefined"`) — непоследовательность.
- Из-за угловых случаев такую сериализацию массивов не стоит использовать в программах (разве что в dev-консоли).

### Объекты

- Стандартный `toString` объекта (`Object.prototype`) даёт `"[object Object]"`.
- Непоследовательность: у массивов скобки убрали, а у объектов оставили.
- Внутри `[object ...]` стоит **string tag** (по умолчанию `Object`).
- String tag можно переопределить через ES6-symbol **Symbol.toStringTag** [?] (`toStringTag`) — изменить, например, на `"my favorite number"`. Это метапрограммирование.
- Если переопределить сам метод `toString`, можно полностью контролировать строковое представление объекта.
- Полезный приём: определить `toString` (например, как getter), возвращающий `JSON.stringify` объекта — это удобнее, чем `[object Object]`, в dev-консоли. В обычном коде такое метапрограммирование применяется редко.

## Главное

- ToString даёт строковое представление любого значения; `-0` «лжёт», давая `"0"`.
- ToString объекта идёт через ToPrimitive(hint string): `toString()` → `valueOf()`.
- Сериализация массивов теряет скобки, а `null`/`undefined` внутри опускаются — ненадёжно для кода.
- Стандартный объект даёт `"[object Object]"`; toString и string tag можно переопределить.
