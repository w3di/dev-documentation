# Lexical Scope: метафора «здание с лифтом»

## Метафора

- Вложенные scope можно представить как высокое здание с лифтом.
- Поиск переменной = поиск чего-то в здании, когда не знаешь, на каком этаже:
  1. Начинаешь на первом этаже — ищешь там.
  2. Не нашёл — поднимаешься лифтом на следующий этаж.
  3. Повторяешь, пока не найдёшь или не дойдёшь до верхнего этажа.
- На верхнем этаже либо находишь, либо нет — дальше идти некуда.

## Соответствие scope

- **Первый этаж** = текущий scope (где находится ссылка).
- **Верхний этаж** = глобальный scope.
- Поиск идёт по одному этажу за раз: не перепрыгиваем сразу к глобальному scope, поднимаемся последовательно.

## Главное

- Lexical scope как здание: текущий scope — первый этаж, глобальный — верхний.
- Разрешение переменной идёт снизу вверх, по одному уровню (этажу) за раз, без перепрыгивания.
