# Решение упражнения: this

## Шаги рефакторинга

1. Заменить фабрику `defineWorkshop()` на объектный литерал `deepJS = { ... }`.
2. Перенести все функции в объект, используя **concise method form** (краткая запись методов) вместо присваивания свойств-функций.
3. Между методами в литерале нужны запятые (в `class`-синтаксисе их не требуется — это плюс классов).
4. Добавить свойства-данные: `currentEnrollment` и `studentRecords` как пустые массивы (`[]`).
5. Перед каждой ссылкой на свойство данных или на метод поставить `this.` (например, `this.currentEnrollment`, `this.printRecords`, `this.getStudentFromId`).

## Где нужен .bind

- Найти методы, передаваемые как callback (например в `.map`, при сортировке, печати).
- Применить `.bind(this)` к ним, иначе они потеряют привязку `this`.
- В решении связываются: `getStudentFromId`, `sortByName` + `printRecord` (по итогу — см. ниже), `needToEnroll`, `getStudentId`, `notYetPaid`.

## Ключевое правило связывания

- `.bind(this)` нужен **только если метод this-aware** (внутри использует `this.`).
- Методы на namespace, которые не обращаются к `this` (например `sortByName`, `printRecord` — если в них нет `this`-ссылок), **не нужно** связывать. Их `.bind` был бы лишним.
- Простые функции-свойства (не методы) тоже не требуют `this.` и `.bind`.

## Выводы

- Результат работы кода не меняется — это лишь изменение реализации (module pattern → namespace pattern).
- Стиль с `this.` повсюду очень **многословный**; объём `.bind` здесь на грани, за которой такой стиль теряет смысл — для подобного кода module pattern мог бы быть удобнее.
- Namespace/object-create подход оправдан, когда нужно несколько объектов, связанных через prototype chain, с разделёнными обязанностями, а не один «kitchen sink» объект.
- Проблема `this` binding касается не только async-callback и обработчиков событий, но и callback в `array.map`.

## Главное

- Перенести функции в объектный литерал (concise methods), данные — как свойства, доступ через `this.`.
- `.bind(this)` ставить только на this-aware методы, передаваемые как callback; на остальные — не нужно.
