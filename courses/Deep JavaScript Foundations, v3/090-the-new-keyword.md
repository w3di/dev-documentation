# Ключевое слово new

## Что такое new

- **new** — третий способ вызова функции (наряду с вызовом через контекстный объект и через `.call`/`.apply`/`.bind`).
- Несмотря на синтаксис, `new` **не связан с классами**. Это синтаксический трюк, маскирующий вызов под работу с классами.
- Назначение `new` — вызвать функцию с ключевым словом `this`, указывающим на **совершенно новый пустой объект**.
- Тот же результат (вызов в контексте нового пустого объекта) можно получить через `function.call({})`. То есть `new` даёт лишь синтаксический сахар «вызови функцию с новым this».

## Четыре действия new

При вызове функции через `new` (так называемый **constructor call**) происходят 4 шага:

1. Создаётся **новый пустой объект** «из ниоткуда».
2. Этот объект **связывается (linked)** с другим объектом (детали связи — в теме прототипов).
3. Функция вызывается с `this`, указывающим на **новый** объект (не на связанный).
4. Если функция **не возвращает свой собственный объект**, то `new` автоматически возвращает `this`.

## Важный нюанс

- Всю работу делает само ключевое слово `new`, а не функция-конструктор.
- Если поставить `new` перед почти любой функцией (даже пустой), все четыре действия всё равно произойдут. Сама функция как будто «не важна» — `new` использует её, чтобы выполнить эти 4 шага.

## Главное

- `new` — один из 4 способов вызова функции, не имеющий прямого отношения к классам.
- Он создаёт новый пустой объект, связывает его, вызывает функцию с `this` на этом объекте и возвращает его, если функция не вернула свой объект.
