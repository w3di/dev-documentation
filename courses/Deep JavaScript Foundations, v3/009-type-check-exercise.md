# Упражнение: полифил Object.is

## Задание

- Написать собственный **полифил** (polyfill) для утилиты **Object.is** — без подглядывания в существующую реализацию.
- Сигнатура: функция принимает **два параметра** (два значения) и возвращает `true`, только если они в точности одно и то же.
- Обычно для этого хватило бы `===`, но `===` «лжёт» в двух угловых случаях:
  - **NaN** (NaN не равен сам себе);
  - **negative zero** (`-0 === 0` → true).
- Нужно сначала обработать эти два случая, а затем, если они не сработали, вернуть результат `===`.

## Подсказки

- Для NaN можно взять `Number.isNaN`, но стоит попробовать придумать собственную проверку.
- Для -0 тоже придумать собственную проверку (без встроенного `Object.is`).

## Паттерн полифила

- Полифил определяет функцию только если её ещё нет: оборачивается в `if`, проверяющий отсутствие реализации.
- **Важно**: в современной среде `Object.is` уже есть (ES6), поэтому код в `if` не выполнится. На время упражнения `if` нужно отключить (например, добавить `|| true` или закомментировать), но в реальном полифиле так не оставляют.

## Как проверять

- Работа ведётся в файле `ex.js`; в нём набор `console.log`, каждый из которых что-то утверждает.
- Цель: все вызовы, которые должны вернуть `true`, печатают `true`, а должные вернуть `false` — печатают `false`. Тест пройден, когда нет ни одного неверного результата.
- Запуск: напрямую через node из командной строки либо в консоли браузера.
- Решение-подсказка лежит в `ex.fixed.js` в той же директории.

## Главное

- Цель — реализовать `Object.is`: как `===`, но с корректной обработкой NaN и -0.
- Сначала обрабатываются угловые случаи (NaN, -0), затем — обычное `===`.
- Полифил оборачивается в `if (!Object.is)`, который на время упражнения отключается.
