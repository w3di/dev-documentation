# Алгоритм `==`: предпочтение числового сравнения

## `==` предпочитает numeric comparison

- Для строк, чисел и Boolean (clauses 4–7 алгоритма) `==` стремится свести всё к **числам**.
- В четырёх местах вызывается `ToNumber`:
  - тип number vs string → `ToNumber` на строке;
  - аналогично clauses 5 и 6;
  - если один операнд Boolean → `ToNumber` на нём.
- Знание этого факта помогает предсказывать поведение: иногда вместо сравнения двух строк реально сравниваются два числа.

## Пример: число vs строка

```js
var workshopEnrollment1 = 16;
var workshopEnrollment2 = "16";

workshopEnrollment1 == workshopEnrollment2   // строка → число, сравнение чисел
```

- При `===` пришлось бы вручную приводить к числам (иначе разные типы → всегда `false`).
- Если известно, что типы — только number или string (особенно если один точно число), то `==` уместен: абстракция полезна, шум `Number(...)` лишний.
- Это возможно потому, что код спроектирован с ограниченным набором типов (только string и number). С массивами/объектами/Boolean всё было бы сложнее.

## Q&A: а если оба операнда — строки?

- Если **оба** строки → это **один и тот же тип** → алгоритм делает `===` (не приводит к числам).
- `"3.7" == "3.07"` → `false`: строки не идентичны (хотя числа были бы разными в любом случае).
- Whitespace в строках (`" 3" `) — это **не** задача coercion. Нужное тут — **string trimming**/форматирование, а не coercion.
- Coercion — это когда есть строка и число и нужно их сравнить.

## Clauses 8 и 9: ToPrimitive

- Если `==` применён к чему-то, что **не** примитив, вызывается `ToPrimitive`.
- `ToPrimitive` — та самая операция, что вызывает `valueOf`/`toString`.

## Ключевой вывод

- **`==` сравнивает только примитивы.** Если операнд не примитив — он сначала приводится к примитиву.
- С не-примитивами что-то делается только если они **одного типа** — тогда выполняется same-value `===`.
- Алгоритм по сути **рекурсивен**: `==` переприменяет себя, пока не получит два примитива одного типа (или два coercively-равных примитива). Если так и не получилось → `false`.

## Главное

- `==` предпочитает numeric comparison: для number/string/Boolean вызывает `ToNumber`.
- Два операнда одного типа → выполняется `===` (никакого coercion).
- `==` сравнивает только примитивы; не-примитив сначала проходит через `ToPrimitive`.
- Алгоритм рекурсивен: повторяется, пока не сведётся к двум примитивам одного типа, иначе `false`.
