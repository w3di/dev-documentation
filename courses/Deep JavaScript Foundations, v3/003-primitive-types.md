# Примитивные типы

## Миф «всё в JavaScript — объект»

- Утверждение «everything is an object» широко распространено, но **ложно**.
- Например, `false` — не объект.
- Причина мифа: большинство значений *могут вести себя* как объекты (через **boxing** — оборачивание примитива в объект), но это не делает их объектами.
- Спецификация — источник истины: то, что значение ведёт себя определённым образом в коде, не отменяет того, что говорит спецификация (аналогия с учёным: важно понимать, *почему* яблоко падает).

## Список примитивных типов

Спецификация в самом начале перечисляет типы:

```
undefined, null, boolean, string, symbol, number, object
```

- **undefined** — тип с единственным значением `undefined`.
- **string** — примитивные строки (литералы в одинарных/двойных кавычках), не объект `String` как в Java.
- **number** — все числа JavaScript (с оговоркой — см. ниже).
- **boolean** — два значения `true` и `false`; в JavaScript это реальные значения особого типа (не просто 0 и 1), ведущие себя иначе, чем другие типы.
- **symbol** — добавлен в ES6; используется для создания псевдо-приватных (не реально приватных, а «скрытых») ключей объектов. Чаще встречается во фреймворках, чем в обычном коде.
- **object** — тип с множеством подтипов; именно из-за подтипов и boxing возникает путаница.

## Что такое «тип»

- Указывая `x = 42` или `x = "42"`, разработчик выражает **разное намерение** относительно ожидаемого поведения значения.
- **Тип** — это набор внутренних характеристик, которые ожидаются от значения (арифметика для чисел, доступ к символам для строк).

## Пограничные случаи

- **Необъявленные переменные** — спецификация не определяет это как тип, но у них есть предсказуемое поведение, поэтому условно («в кавычках») можно считать типом.
- **null** — JavaScript называет его типом, но он не в основном списке из-за исторического бага (см. далее).
- **function** — не указан в списке; рассматривается как **подтип объекта** («callable objects» — вызываемые объекты).
- **array** — числовая индексация, авто-обновляемое свойство `length`, методы; лучшая ментальная модель — **подтип объекта** со специальной числовой индексацией.

## BigInt (на момент записи)

- На момент записи **BigInt** (большие целые числа) был на stage 3 и почти наверняка должен был войти в язык как новый примитивный тип.
- Уже реализован в V8 (Chrome, Node). Гарантий нет, но вероятность ~95%.

## Ключевой принцип: типы у значений, а не у переменных

- В отличие от C++ и Java, в JavaScript (и других динамически типизированных языках) **типы есть у значений, а не у переменных**.
- Поэтому корректнее говорить о **value types** (типы значений).
- Главное: большинство этих значений — **не объекты**; они могут иметь объектоподобное поведение по требованию, но объектами не являются.

## Главное

- Утверждение «всё — объект» ложно; примитивы лишь могут вести себя как объекты через boxing.
- Примитивные типы по спецификации: `undefined, null, boolean, string, symbol, number, object`.
- `null` — исторически особый, `function` и `array` — подтипы объекта, BigInt — будущий примитив.
- В JavaScript типы принадлежат значениям, а не переменным.
