# ToBoolean: truthy и falsy значения

## Что такое ToBoolean

- **ToBoolean** — abstract operation (спецификация, раздел 7.1.2).
- Срабатывает каждый раз, когда значение не-Boolean типа используется в месте, где требуется Boolean.
- В отличие от `ToPrimitive`, `ToNumber`, `ToString` — это не алгоритм, а простой **lookup** (поиск по таблице).
- Единственный вопрос: входит ли значение в список **falsy** или нет.

## Список falsy-значений

- Спецификация задаёт короткий фиксированный список значений, которые при приведении к Boolean дают `false` (**falsy**):

```
""        // пустая строка
0, -0     // оба нуля
null
NaN
false
undefined
```

- Если значение **не** входит в этот список — оно всегда **truthy** (приводится к `true`).
- Список truthy-значений бесконечен. Примеры truthy: непустая строка, число (кроме нулей и NaN), объект, массив, `true`, функция.

## Важный нюанс: никакой другой coercion не вызывается

- ToBoolean **не** вызывает `ToPrimitive`, `ToNumber`, `ToString` и т.п. Только проверка по списку.
- Пример: пустой массив `[]` приводится к Boolean.
  - Массива нет в списке falsy → значит, он **truthy**.
  - При этом неважно, что `[]` мог бы стать пустой строкой или нулём — приведения не происходит.
- Нельзя переопределить результат через `toString` или иной способ: проверяется только наличие в списке.

## Главное

- ToBoolean — это lookup, а не алгоритм: значение либо в списке falsy, либо truthy.
- Falsy-список: `""`, `0`, `-0`, `null`, `NaN`, `false`, `undefined`. Его стоит запомнить наизусть.
- Всё, что не falsy, — truthy; никакого вложенного coercion (ToNumber/ToString) при этом не выполняется.
