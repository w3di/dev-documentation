# Упражнение: class

## Суть задания

- Рефакторинг **namespace-объекта** (this-aware код) в **class**-синтаксис.
- Использовать `class extends` (наследование).

## Ключевая идея

- В namespace есть функции, которые **не this-aware** — это вспомогательные helpers, не относящиеся именно к `workshop`.
- Создать **parent class** `Helpers` с этими хелперами.
- Создать **child class** `Workshop extends Helpers`, который наследует хелперы (композиция через наследование).
- Хелперы не нужно `bind`, т.к. они не this-aware.

## Что нужно сделать

1. Превратить методы объекта с `this.`-ссылками в методы класса.
2. Сохранить работоспособность мест, где раньше требовался `bind`.
3. Инстанцировать класс и использовать.

## Замечание о структурировании

- Разбиение на отдельные this-aware объекты/классы — про **separation of concerns** (разделение ответственности), а не про размер/читабельность.
- Полезный ориентир — single responsibility principle: если сущность делает много разного, возможно, это несколько разных сущностей. Принцип не зависит от выбора classes/modules.

## Главное

- Перевести namespace в class; не this-aware хелперы вынести в parent class `Helpers`, наследуемый `Workshop`.
- Разделение на классы — ради разделения ответственности.
