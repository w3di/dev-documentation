# Prototypal Class (под сахаром)

## Что скрыто под class-синтаксисом

- «Старая школа» — **prototypal class** — то, как выглядел бы код до сахара `class`.
- Структура:
  - функция `Workshop` играет роль конструктора;
  - методы добавляются на `Workshop.prototype`;
  - объекты создаются через `new`.
- Это «водопровод» (plumbing) под синтаксисом классов.

## Зачем это знать

- Так код больше не пишут: для классов почти всегда используют `class`-синтаксис.
- Но важно понимать механику: где находятся **связи (linkages)**, поскольку это не копии.
- Копирование — плохая ментальная модель; нужна модель **связывания**, чтобы понимать, почему классы ломаются и ведут себя не так, как ожидалось.

## Главное

- Под `class`-сахаром лежит prototypal-класс: функция-конструктор + методы на `.prototype` + `new`.
- Понимание этих связей нужно, чтобы иметь верную ментальную модель (связывание, не копирование).
