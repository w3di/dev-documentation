# Lexical scope и dynamic scope

## Lexical scope

- **Lexical scope** (лексический scope) — модель, при которой вложенность scope определяется заранее, на этапе компиляции/парсинга.
- Термин «lexical» имеет тот же корень, что и **lexing** — первая стадия парсинга.
- Связан с решениями автора (author-time decision): какую функцию вложить в какую и какой переменной принадлежит ссылка — всё определяется на compile time.
- Не зависит от того, что происходит во время выполнения программы (run time).
- Это доминирующая модель: подавляющее большинство языков лексически scoped.
- JavaScript на 100% лексически scoped, несмотря на свои нюансы.

## Dynamic scope

- **Dynamic scope** (динамический scope) — противоположная модель: scope зависит от условий run time.
- Встречается редко — в нескольких академических языках и режимах.
- Самый известный пример — Bash script (интерпретируемый, не компилируемый, что согласуется с отсутствием compile-time модели scope).

## Ключевое противопоставление

- Lexical scope: фиксированный, предсказуемый, не зависит от run time.
- Dynamic scope: подразумевает, что динамические условия программы влияют на разрешение scope.

## Главное

- Lexical scope определяется на этапе компиляции по тексту программы и неизменен в run time.
- Dynamic scope определяется условиями выполнения; в JavaScript его нет.
- JavaScript — полностью лексически scoped язык.
