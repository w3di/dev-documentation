# Ключевое слово this

## Главное заблуждение

- `this` — пожалуй, самая запутанная фича JavaScript, хотя на деле проще, чем кажется.
- **Важно:** не пытаться переносить поведение `this` из других языков — это «багаж», мешающий понять `this` в JavaScript. Нужно смотреть, что делает именно JavaScript.

## Определение

- `this` функции ссылается на **execution context** (контекст выполнения) данного вызова.
- Контекст определяется **полностью тем, как функция вызвана**, а не тем, как она определена.
- **Контринтуитивно:** по определению функции нельзя понять, на что укажет `this`. Значение имеет только **способ вызова** (invocation).

## this как dynamic scope

- `this` — это версия **dynamic scope** в JavaScript: способ иметь гибкое, переиспользуемое поведение/контекст.
- Отличие от dynamic scope: разрешается не по тому, **откуда** вызвано (границы scope), а по тому, **как** вызвана функция.

```js
var workshop = {
    teacher: "Kyle",
    ask(question) {
        console.log(this.teacher, question);
    }
};
```

- Функцию, использующую `this` (this-aware), можно вызвать разными способами и подать разные context-объекты.
- Например, `ask.call(someContext, ...)` — «выполни функцию, используя этот объект как `this`».
- Это и есть динамическая, гибкая переиспользуемость — ради неё `this` и существует: вызывать функции в разных контекстах.

## Четыре способа вызова функции

- В JavaScript есть **четыре разных способа вызвать функцию**, и каждый по-своему отвечает на вопрос, чему равен `this`. Эти четыре способа и нужно выучить.

## Метафора «какое здание?»

- В lexical scope мы шли от текущего scope вверх к global (поднимались по «зданию»).
- С `this` тоже идём «снизу здания», но главный вопрос — **какое именно здание (контекст)**.
- Аналогия: «встретимся в офисе 317» → первый вопрос «но в каком здании?». Сначала нужно понять контекст, потом искать в нём.
- Правила `this` как раз отвечают на вопрос «какое здание».

## Главное

- `this` ссылается на **execution context** и определяется тем, **как** функция вызвана, а не как определена.
- Это аналог **dynamic scope** — механизм гибкого, переиспользуемого контекста.
- Существует **четыре** способа вызова функции; каждый задаёт `this` по-своему.
