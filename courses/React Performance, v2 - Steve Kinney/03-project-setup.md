# Project Setup (Настройка проекта)

## Материалы курса

- Доступны полные **notes** лектора, включая «director's cut» — дополнительный материал, не вошедший в основной поток.
- Структура заметок: высокоуровневые тезисы + расширенный материал с дополнительными **code examples** и более глубокими разборами концепций.
- **Appendix** (внизу) содержит бонусный материал, например миграцию приложения с pre-React compiler на **React compiler** (на занятии разбираться, скорее всего, не будет — но доступно как дополнительное чтение).

## Репозиторий

Репозиторий курса: https://github.com/stevekinney/react-performance

1. Склонировать репозиторий и выполнить `npm install`.
2. Ветка `main` — актуальная версия.
3. Лектор работает в ветке **live coding**.
4. Есть отдельная ветка с **completed examples** — готовые решения всех лабораторных (на занятии выполняются не все labs, выбор зависит от хода обсуждения).

## Главное

- Помимо основных заметок доступен расширенный материал и appendix с бонусными темами (в т.ч. миграция на React compiler).
- В репозитории три ориентира: `main` (актуальная), live coding (ход занятия), completed examples (готовые решения).
