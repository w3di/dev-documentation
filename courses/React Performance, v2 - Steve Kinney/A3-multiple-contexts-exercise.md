# Multiple Contexts Exercise — раздел Context (архивный курс v1)

> Дополнение из старого курса (archive). Темы нет в v2.

## Задание

- Приложение посложнее (фейковый соцсеть/блог: users, posts; comments — вложенный массив внутри post). CRUD без редактирования.
- Контекст уже разбит на **stateContext** и **actionsContext**, action creators лениво биндятся на dispatch (утилита взята из Redux). По идее всё должно работать — но не работает: добавление поста заставляет мигать **список users**, хотя они не связаны.

## Диагноз

- В **stateContext** свалены `posts` **и** `users` в один объект → `value={{ posts, users }}` снова **новый объект каждый раз**.
- Любое изменение (добавили пост) → новый объект состояния → ре-рендер всех потребителей, включая несвязанный список users.

## Решение: ещё один контекст

- Паттерн «удваиваем» продолжается → нужен **третий контекст**: отдельно для `posts`, отдельно для `users`, отдельно для actions.
- «Good news: паттерн работает. Bad news: паттерн работает» — он масштабируется добавлением контекстов, и это повод задуматься, всегда ли так делать (vs механически следовать совету из курса).
- Кастомные хуки (`useUsers`, `usePosts`, `useDispatch`) спасают: переименование через F2 в VS Code обновляет все файлы, абстракции облегчают правки (хотя «двигают проблему»).

## Побочные находки (не запланированные)

- Через инструменты находятся ре-рендеры, не заложенные специально (5–6 проблем в приложении, часть «посажена» нарочно, часть случайна).
- Пример: функция, вызываемая «на лету» при `map` users, провоцировала лишние ре-рендеры — иногда решается **push state down** для конкретного куска.

## Главное

- Если в одном контексте лежат несколько кусков state (`posts` + `users`) — `value` снова новый объект, и несвязанные части ре-рендерятся вместе.
- Решение масштабируется добавлением отдельных контекстов на каждый независимый кусок (+ кастомные хуки), но стоит критически оценивать, не плодишь ли лишнюю сложность.
- Инструменты профилирования выявляют и **незапланированные** ре-рендеры — полезно регулярно смотреть.
