# Fallback Content with Suspense (React.lazy) — раздел Suspense (архивный курс v1)

> Дополнение из старого курса (archive). Тема Suspense на практике, которой нет в v2.

## Что такое Suspense (контекст)

- Suspense — набор API; на момент записи доступна только **часть**.
- **Suspense data fetching** (показать loading, пока нет данных, потом заполнить) ещё **не зашипован** для обычных приложений — доступен только в опинионированных фреймворках (Next.js, Remix).
- Доступен сегодня — **загрузка компонентов** (code splitting): грузить не весь app сразу, а прогрессивно.

## Зачем code splitting

- Не нужны все компоненты всех страниц сразу: одни страницы (глубокие admin/preferences) посещают редко — не клади их в initial bundle.
- **Cost of JavaScript**: JS-файл 100 КБ грузится **дольше**, чем картинка 100 КБ — картинку просто рисуют, а JS надо ещё скомпилировать и выполнить. Поэтому важен не только размер скачивания.
- Идея: дать минимум для старта, остальное подгружать прогрессивно (не «весь app каждый раз», как обновление iOS-приложения).

## React.lazy + Suspense

```js
import { lazy, Suspense } from 'react';

const Editor = lazy(() => import('./editor'));

// внутри рендера:
if (isEditing) {
  return (
    <Suspense fallback={<LoadingIndicator />}>
      <Editor />
    </Suspense>
  );
}
```

- **`lazy`** — как «buddy memo», встроен. Принимает функцию, возвращающую **import-промис**.
- **`import()`** — функция, возвращающая promise, грузит ES-модули динамически (работает не только для React-компонентов).
- **`<Suspense>`** — компонент-граница (как error boundary) с обязательным `fallback` (loading-индикатор; может быть хоть `<p>loading</p>`). Пока import-промис не зарезолвится — показывает fallback, потом — компонент.
- Демо: код редактора **не** был в исходном bundle, подгрузился по требованию (при `isEditing`). Для наглядности замедление через искусственный `simulateNetwork` (на localhost иначе мгновенно).

## Прогрессивные улучшения

1. Шаг 1: грузить компонент, когда он нужен (например, редактор — только при клике Edit, если им почти не пользуются).
2. Шаг 2: запускать import-промис заранее, например **на hover** кнопки Edit — «и рыбку съесть».

## Когда применять

- Очень лёгкий performance-выигрыш с минимальным downside (если инфраструктура не слишком старая; работает на современном вебе через `import()`).
- На вопрос «memo на всё или разбить app на части?» — разбиение часто ценнее. Но сначала базовое: если app не на **CDN** — сделать это первым делом.
- Откладывание загрузки второстепенного («главное событие» vs остальное) — частый недооценённый большой выигрыш.

## Главное

- Сегодня из Suspense доступна загрузка компонентов (code splitting); data fetching — только в фреймворках.
- `React.lazy(() => import('...'))` + `<Suspense fallback={...}>` грузит компонент по требованию, показывая fallback до резолва import-промиса.
- Размер JS важен не только из-за скачивания, но и из-за компиляции/выполнения (cost of JavaScript).
- Можно усложнять прогрессивно (preload на hover); разбиение app — недооценённый большой выигрыш, но сперва базовое (CDN).
