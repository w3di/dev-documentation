# Часть 25. ToPrimitive coercion

## Неожиданная возможность

- Кажется невозможным вычесть один Date-объект из другого: `time2 - time1`.
- Тем не менее это работает благодаря **ToPrimitive** (приведение объекта к примитиву).
- ToPrimitive автоматически приводит оба объекта к примитиву — в данном случае к числу (значению скрытого `[[DateValue]]`), а не к позиции в памяти.

## Пример сравнения времени

```js
const time1 = new Date(); // 1.8 трлн мс
// 1 секунда
const time2 = new Date(); // 1.8 трлн + 1000 мс

if (time2 - time1 < 2000) {
  console.log("accident"); // сработает
}
```

- `time2` и `time1` — адреса в памяти (условно `10002`, `10001`).
- Оператор `-` (математика) запускает ToPrimitive с режимом **ToNumber**.
- `time2` → `1.8` трлн + `1000`, `time1` → `1.8` трлн; разность = `1000` мс < `2000` → срабатывает условие.
- Перед этим демонстрируется удаление ранее добавленных через `[]` свойств `Jan` (показ того, что Date — обычные объекты, и закрепление gotcha со square bracket assignment).

## Зачем

- Позволяет делать математику над объектами и вытаскивать скрытое `[[DateValue]]`.
- На практике у Date есть и методы для доступа к этому числу, но сама способность трактовать объект как примитив — отдельная мощная возможность.

## Как это возможно: @@toPrimitive

- Механизм — скрытое свойство **@@toPrimitive** (Symbol.toPrimitive).
- При `time2 - time1` математика видит объекты и не смотрит на их адреса, а ищет способ привести их к числу.
- JavaScript автоматически проверяет на обоих объектах наличие скрытого свойства `@@toPrimitive`, в котором лежит функция (код) с инструкциями, как привести объект к примитиву (конкретно к числу).
- Функция `Date` гарантировала, что в возвращаемый объект автоматически добавлено скрытое `@@toPrimitive`.
- При вычитании запускается ToPrimitive, выполняется эта функция, и она возвращает: на одной стороне `1.8` трлн + `1000`, на другой `1.8` трлн; затем выполняется математика.
- То есть JavaScript хранит на объекте инструкции, как привести его к числовому `[[DateValue]]`.

## Уточнения (вопросы из зала)

- **Что определяет режим (number или string)?** Оператор. Здесь математика → режим number. ToPrimitive получает аргумент-режим — строку `"number"`. (Далее будет написана функция ToPrimitive с условием `if (hint === "number")`.)
- **Как @@toPrimitive назначается объектам?** `@@toPrimitive` добавлен в JavaScript в 2015 году (ES6) — через 20 лет после создания языка. Поэтому он не может быть на всех объектах автоматически (это сломало бы старый код).
- В данном случае `@@toPrimitive` автоматически добавлен к объекту, возвращаемому функцией `Date` (вместе со скрытым `[[DateValue]]`).
- На свои объекты `@@toPrimitive` можно добавить вручную. Но это не обычное свойство (оно скрытое), и непонятно, как его записать, — ведь это не строка. Тема продолжается.

## Главное

- ToPrimitive автоматически приводит объект к примитиву; режим (ToNumber/ToString) задаёт оператор и передаётся как hint-аргумент.
- Математический оператор над Date-объектами запускает ToPrimitive → ToNumber и возвращает значение скрытого `[[DateValue]]`.
- Механизм работает через скрытое свойство `@@toPrimitive` (Symbol.toPrimitive), хранящее функцию приведения; его автоматически добавляет функция `Date`.
- `@@toPrimitive` появился в ES6 (2015), поэтому есть не у всех объектов — но его можно добавить на свои.
