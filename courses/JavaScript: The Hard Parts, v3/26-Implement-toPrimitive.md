# Часть 26. Реализация @@toPrimitive

## Попытка привести свой объект к числу

- Данные: `userStored` и `userSubmitted` — оба `{ name: "Will", ID: 105 }`.
- Попытка форсировать приведение унарным `+` (или `Number()`) перед каждым объектом не работает.
- JavaScript не приводит обычный объект к числу, даже если на нём есть `105`, — возвращается `NaN`.

## Нюанс NaN

- `NaN` — это значение типа number, но каждое `NaN` уникально: `NaN !== NaN`.
- Это не специфика JavaScript (то же в Python и др.): нечисловые данные, попавшие в `NaN`, имели «разный путь», поэтому считаются разными.

## Цель: вручную задать @@toPrimitive

- Нужно вручную добавить на объекты скрытое свойство **@@toPrimitive** с функцией, описывающей, как привести объект к числу.

```js
function coerce() {
  return 105;
}
```

- `coerce` нужно прикрепить к `userStored` и `userSubmitted` так, чтобы при приведении объекта она выполнялась.
- Проблема: нельзя написать `userStored.@@toPrimitive = coerce` — это скрытое свойство, его нельзя вписать напрямую (как нельзя написать `time1.dateValue`).

## Symbol — способ адресовать скрытый label

- Метки таких скрытых свойств хранятся во встроенном объекте **Symbol**.
- Это новый тип данных (не строка): его нельзя записать буквально; `console.log` показывает лишь строковое представление.
- При этом он необходим для добавления скрытых свойств в объекты, которые JavaScript умеет находить, но которые разработчик не может вписать руками.
- На объекте `Symbol` есть метки. Среди них — `Symbol.toPrimitive`: обычная строковая метка `toPrimitive`, под которой хранится скрытая метка `@@toPrimitive`.

```js
console.log(Symbol.toPrimitive); // Symbol(Symbol.toPrimitive) — само значение не видно
```

- Сослаться на скрытую метку можно через `Symbol.toPrimitive` (доступ к свойству объекта `Symbol`). Это вычисляется в скрытую метку `@@toPrimitive`.

## Добавление @@toPrimitive через square brackets

```js
const userStored = { name: "Will", ID: 105 };
const userSubmitted = { name: "Will", ID: 105 };

function coerce() {
  return 105;
}

userStored[Symbol.toPrimitive] = coerce;
userSubmitted[Symbol.toPrimitive] = coerce;
```

- Square bracket notation позволяет задать имя свойства по ссылке, а не вписать его строкой вручную.
- `userStored[Symbol.toPrimitive]` ищет в объекте `Symbol` метку `toPrimitive`, получает скрытую метку `@@toPrimitive` и под ней сохраняет функцию `coerce`.
- На `Symbol` есть целый список таких именованных скрытых меток, дающих тонкий контроль над поведением объектов (например, при приведении к примитиву).
- Метка уникальна, как уникально имя-строка.

## Результат

```js
function onSubmit() {
  if (+userStored === +userSubmitted) {
    // ...
  }
}
```

- Унарный `+` запускает ToPrimitive (режим number).
- JavaScript для `userStored` проверяет наличие скрытого `@@toPrimitive`, находит его и выполняет `coerce` — новый execution context, результат `105`.
- То же для `userSubmitted` → `105`.
- `105 === 105` → `true`.
- Достигнут ручной контроль над пайплайном object-to-primitive coercion через встроенный механизм Symbol.

## Главное

- Обычный объект не приводится к числу (`NaN`); каждое `NaN` уникально (`NaN !== NaN`).
- Чтобы управлять приведением, на объект добавляют скрытое свойство `@@toPrimitive` с функцией; напрямую по имени его не записать.
- Метки скрытых свойств берутся из встроенного объекта `Symbol` (например, `Symbol.toPrimitive`) и присваиваются через square bracket notation: `obj[Symbol.toPrimitive] = fn`.
- После этого приведение объекта (унарный `+` и т.п.) выполняет нашу функцию, давая полный ручной контроль над coercion.
