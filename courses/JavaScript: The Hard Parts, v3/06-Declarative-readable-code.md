# Часть 6. Функции как first-class objects и декларативный код

## Почему функцию можно передавать как данные

- В JavaScript функции — **first-class objects** (объекты первого класса): они *просто объекты*, с дополнительной способностью быть вызванными (called / invoked / run).
- Поэтому функции сосуществуют с любыми другими объектами и могут:
  - присваиваться переменным/меткам (популярный стиль объявления — см. arrow functions);
  - быть свойствами объектов — тогда функция называется **method** (метод);
  - передаваться как входные значения в другие функции (как объект — можно, значит и функцию можно);
  - **возвращаться** как output из другой функции.
- Возврат функции из функции даёт самую «непонятную» фичу JavaScript — **closure** (замыкание). [Тема продолжается далее.]

## Higher-order function vs callback — разбор

- **higher-order function** — внешняя («грандиозная») функция, принимающая или возвращающая другую функцию; в примере — `copyArrayAndManipulate`.
- **callback function** — маленькая функция, вставляемая внутрь; в примере — `multiplyBy2`.
- Никакого спец-ключевого слова для HOF не нужно — нет ничего внутренне особенного; «higher-order function» и «callback» — просто термины.

## Imperative vs declarative

- **imperative** (императивный) стиль — пошаговое описание *как* делать (внутренности `copyArrayAndManipulate`: перебрать элементы, изменить, push).
- **declarative** (декларативный) стиль — описание *что* хочешь получить; читается легче: «возьми эти данные и примен– трансформацию к каждому элементу».
- Под любым declarative-кодом всё равно лежит imperative-реализация (как именно это делается). Declarative — про читаемость при использовании.
- callback и higher-order functions упрощают код, поддерживают DRY, делают его читаемее. Особенно с `filter`, `reduce`. Популярны на собеседованиях.

## Связь с асинхронностью

- Callbacks — основа асинхронного JavaScript, что делает язык мощным как «язык веба»: выполнение множества задач, общение с другими компьютерами.
- Они лежат под **promises** и **async/await**. [Тема продолжается далее.]

## Главное

- Функции в JS — first-class objects: их можно присваивать, делать методами, передавать и возвращать.
- Возврат функции из функции порождает closure.
- HOF не требуют спец-синтаксиса; это просто роли: внешняя (HOF) и вставляемая (callback).
- Declarative-код читаемее imperative, но всегда опирается на imperative под капотом.
