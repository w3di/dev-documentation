# Часть 42. Prototype chain

## Проблема подхода userCreator
- Каждый объект пользователя получает собственную копию функции `increment` прямо на себе.
- При 100 объектах — 100 копий `increment`; при 100 функциях (decrement, log in, log out, display, add profile pic, add username, delete) — копии каждой на каждом объекте.
- Плюс: понятно, где функция (легко осмысливать). Минус: огромный расход памяти (нарушена эффективность/производительность).
- Данные различаются (Ari/3 против J/5) — это оправдано; функциональность же одинакова, копии бессмысленны.

## Желаемое решение
- Хранить функцию в единственном экземпляре (одна копия).
- Не передавать ссылку на функцию в каждый объект, а чтобы JavaScript сам знал место для поиска.
- Хранить `increment` на отдельном объекте, например `userFunctionStore` (хранилище функций).
- При обращении `userOne.increment` интерпретатор:
  1. ищет `increment` на `userOne`;
  2. не найдя — не «паникует», а поднимается к объекту-хранилищу и находит `increment` там;
  3. использует функцию оттуда.
- Аналогично для `user2.increment` и любого `userN`.
- Эту возможность даёт **prototype chain** (цепочка прототипов).

## Как связать объекты — Object.create
- Вместо литерала пустого объекта `newUser` создаётся через `Object.create`.
- `Object.create` всегда возвращает пустой объект.
- Аргумент, передаваемый в `Object.create` (например, `userFunctionStore`), НЕ добавляется в новый объект как свойство — объект остаётся пустым.
- Но возникает скрытая связь (hidden bond) между новым объектом и `userFunctionStore` — объектом, полным функций.
- Любой объект, созданный через `Object.create` с этой скрытой связью, получает доступ к функциям из хранилища.

## Главное
- Подход с копированием функций в каждый объект расточителен по памяти, хотя удобен для осмысления.
- prototype chain позволяет хранить общую функцию в одном объекте-хранилище и находить её через скрытую связь, если на самом объекте функции нет.
- `Object.create(userFunctionStore)` возвращает пустой объект со скрытой связью с хранилищем функций — основа механизма цепочки прототипов.

> Тема продолжается: детали prototype chain, `__proto__` и lookup по цепочке.
