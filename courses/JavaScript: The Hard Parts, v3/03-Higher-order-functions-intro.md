# Часть 3. Зачем нужны функции: обобщение и higher-order functions

## Проблема: повторяющиеся функции

- Понимание higher-order functions (функций высшего порядка) позволяет освоить про-уровневые функции `map`, `filter`, `reduce` и писать более **declarative** (декларативный — описывающий *что* сделать, а не *как*) и читаемый код.
- Пример проблемы — отдельные функции под каждое число:

```js
function tenSquared() { return 10 * 10; }
function nineSquared() { return 9 * 9; }
function eightSquared() { return 8 * 8; }
```

- Это нарушает принцип **DRY** (Don't Repeat Yourself — не повторяйся).

## Решение 1: обобщение через parameter

- Функцию можно **generalize** (обобщить), чтобы сделать **reusable** (переиспользуемой), оставив данные TBD (to be determined — «определится позже»).
- Это делает **parameter** (параметр) — placeholder (заполнитель/метка), который заполняется реальными данными при вызове:

```js
function squareNum(num) { return num * num; }
squareNum(10); // 100
squareNum(9);  // 81
squareNum(8);  // 64
```

- **parameter** определяет, *какие данные* применить функциональность к при вызове; **argument** (аргумент) — фактический вход, передаваемый при запуске.

## Решение 2: обобщение части кода (функциональности)

- Идея: оставить TBD не только данные, но и часть **functionality** (функциональности/кода) — заполнять её при вызове. Это даёт ещё более обобщённые и переиспользуемые функции.
- Это и есть **higher-order functions** — где часть функциональности определяется только при вызове.
- Важный исторический нюанс: в Java, C++ возможность задавать поведение функции после её определения (а не только данные) не была встроенной до 2010-х; её можно было «хакнуть», но как встроенной фичи не существовало. Не стоит воспринимать higher-order functions как должное.

## Главное

- Отдельная функция под каждый случай нарушает DRY.
- parameter обобщает функцию по **данным**: placeholder, заполняемый аргументом при вызове.
- higher-order functions обобщают функцию по **функциональности**: часть кода задаётся при вызове.
- Это фундамент для `map`, `filter`, `reduce` и читаемого декларативного кода.
