# Часть 12. Вызов функции внутри функции: открытый вопрос

## Код

```js
function outer() {
  let counter = 0;
  function add1() { counter++; }
  add1();
}
outer();
```

- Функция `add1` здесь и **определена**, и **вызвана** внутри `outer`.

## Разбор выполнения

1. В global memory объявляется `outer`. На call stack — `global`.
2. `outer()` (по `()`) → новый execution context, добавляется на call stack.
3. В local memory `outer`: `counter = 0` (объявлена через `let`), затем объявляется `add1` (только код, не запуск).
4. `add1()` → новый execution context поверх `outer` на call stack. (По завершении `add1` вернёмся в `outer` — потому что он ниже в стеке.)
5. Внутри `add1` строка `counter++` = найти `counter`, прибавить 1.
   - Сначала ищем в local memory `add1` — не находим.
   - Идём дальше и находим `counter` в `outer` → прибавляем 1.
6. `add1` завершается, pop со стека → возврат в `outer`; кода больше нет → pop `outer` → возврат в `global`.

## Открытый вопрос — суть closure

- Почему, не найдя `counter` в `add1`, JavaScript нашёл его в `outer`? Есть две возможные причины, и пока их **нельзя различить**:
  1. потому что `add1` **выполняется внутри** `outer` (логика по call stack), **или**
  2. потому что `add1` **определён/сохранён внутри** `outer` (логика по месту определения).
- Здесь функция вызвана там же, где определена, поэтому причину не отличить.
- Ответ на этот вопрос — суть **closure**. Подсказка: *где определена функция, определяет, к каким данным она имеет доступ при вызове*.

## Как проверить гипотезу

- Нужно **вызвать `add1` не там, где она определена**. Способ: в конце `outer` вернуть `add1` (а не вызывать внутри), сохранить в глобальную метку и запустить уже в global.
- При возврате `add1` контекст `outer` закроется (pop со стека). Поведение покажет, что определяет доступ к данным: место определения или место вызова. [Эксперимент — в следующей части.]

## Главное

- Когда `counter` не найден в local memory `add1`, он находится в `outer` — но причина неоднозначна (вызов внутри `outer` vs определение внутри `outer`).
- Различить можно, только вызвав функцию вне места её определения.
- Для этого `add1` возвращают из `outer` и запускают в global; контекст `outer` при этом закрывается.
- Ответ на этот вопрос и есть основа closure: доступ к данным определяется местом определения функции.
