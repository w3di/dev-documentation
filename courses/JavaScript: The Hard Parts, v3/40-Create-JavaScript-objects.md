# Часть 40. Создание объектов в JavaScript

## Принцип инкапсуляции
- Объекты хранят функции вместе с их связанными данными — это **encapsulation** (инкапсуляция).
- Инкапсуляция помещает данные и функциональность в одно место и меняет способ осмысления кода.
- Цель (dream): не искать функциональность по всей кодовой базе, а вызывать её прямо «справа от точки» на данных объекта, например `userOne.increment()`.

## Способ 1: object literal
- В памяти создаётся `userOne` — **object** (объект) со свойствами:
  - `name` — строка `"Ari"`;
  - `score` — `3`;
  - `increment` — функция.
- Функция, хранимая на объекте, называется **method** (метод). Метод не запускается при сохранении — он лишь сохраняется.
- Это синтаксис **object literal** (литерал объекта) — объект определяется и оживляется прямо на месте.

### Lookup (поиск) при вызове метода
1. Ищем `userOne` в памяти — находим.
2. Ищем на нём свойство `increment` — находим.
3. Создаётся новый execution context, метод выполняется.

## Способ 2: dot notation
- Создаётся `user2` через **dot notation** (точечная нотация):
1. Объявляется пустой объект.
2. `user2.name = "J"`.
3. `user2.score = 5`.
4. `user2.increment = ` функция (определение).
- Можно также использовать bracket notation (квадратные скобки), но точечная нотация — более повседневный способ.
- Проверка мечты: `user2.increment()` работает — функция доступна справа от точки.

## Способ 3: Object.create
- Создаётся `user3` как результат вызова **`Object.create(null)`**.
- `Object.create` создаёт большой пустой объект, к которому затем добавляются свойства:
  - `name` = `"Tam"`;
  - `score` = `9`;
  - `increment` — определение функции.
- `user3.increment()` также работает.
- `Object.create` важен: позже он даст тонкий контроль (fine-grained control) над характеристиками объекта — это стоит запомнить.

## Главное
- Объекты инкапсулируют данные и функции (методы) в одном месте; функция на объекте называется method.
- Вызов метода — это lookup: сначала ищется объект, затем свойство на нём, после чего создаётся execution context.
- Три способа создания объектов: object literal, dot notation и `Object.create` (последний даст тонкий контроль над объектом в дальнейшем).
