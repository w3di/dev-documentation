# JavaScript: The Hard Parts, v3 — Введение

## Цель и подход курса

- Курс строит **mental models** (ментальные модели — внутренние схемы того, как что-то работает) того, как JavaScript устроен «под капотом».
- Эти же принципы лежат в основе не только JavaScript, но и Node, React, Next, а также других языков: Go, Rust, Haskell.
- JavaScript за десятилетия впитал многие особенности других языков, и наоборот — другие языки переняли черты, впервые ставшие заметными в JS. Поэтому модели **translatable** (переносимы) на другие языки (C, Go и т.д.).
- Принцип визуализации: код, сохранённый в файле, — это **не** его выполнение. На протяжении курса разбирается именно динамическое выполнение кода, строка за строкой («blackboard»-подход).

## Два ключевых навыка инженера

1. **Problem solving** (решение задач) — опирается на понимание работы кода «под капотом».
2. **Technical communication** (техническая коммуникация) — способность объяснить сложное другому человеку. Если можешь объяснить другому — это мера того, понимаешь ли сам.

- Эти навыки определяют **engineering approach** — обоснованные инженерные решения, которые зависят от роста базовых знаний.

## Структура: пять «столпов» сложных частей JS

- **Higher-order functions** (функции высшего порядка) — функции, которые принимают другую функцию и/или возвращают функцию («host a function»).
- **Closure** (замыкание) — следствие возврата функции из функции; связано с **lexical scoping** (лексической областью видимости).
- **Asynchronous JavaScript** (асинхронность) — также связана с передачей функции, но выполнение откладывается и идёт не синхронно с кодом; разбирается через **event loop** (цикл событий).
- **Object-oriented programming (OOP)** — в JS реализовано иначе, чем в классических ООП-языках.
  - Gotcha (подвох): внешне выглядит как обычные ООП-принципы, но под капотом устроено иначе (**prototype chain** — цепочка прототипов).
  - По мере добавления возможностей JS всё больше похож на традиционные ООП-языки; разбираются **class**, а также **private** и **static fields** (приватные и статические поля) — недавно добавленные в JS.
- **Type coercion** (приведение типов) — одна из самых известных особенностей JS.
  - **TypeScript** частично противостоит непредсказуемому приведению типов.
  - Цель — научиться брать **ручной контроль** над приведением типов.
  - Сюда же относятся **Symbols** (символы), которые открывают **metaprogramming** (метапрограммирование) — одну из самых трудных для понимания тем.
## Современные возможности JS

- **Immutable array methods** (неизменяющие методы массивов): классические встроенные методы массивов по умолчанию **изменяли** исходный массив — новые методы решают эту проблему.
- **Promises** (промисы): первые два года не было способа их остановить; рассматривается, как **abort** (прервать) промис.
- **BigInt** (большие целые) — работа с большими числами.
- **Private** и **static fields** в ООП.
- Итог — модерн-JS для чистого, надёжного и легко читаемого кода, разделяемого между членами команды.

## Главное

- Курс даёт понимание выполнения кода «под капотом», а не просто синтаксиса; сохранённый код ≠ выполняемый код.
- Два опорных навыка: problem solving и technical communication.
- Пять столпов: higher-order functions, closure, asynchronicity, OOP (prototype chain / class), type coercion.
- Освоив фундамент, можно разобрать любой новый язык, фреймворк или инструмент, не будучи запертым в рамках ранее изученного.
