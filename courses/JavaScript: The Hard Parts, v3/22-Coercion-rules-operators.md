# Часть 22. Правила и операторы coercion

## Три потока coercion (type coercion — неявное приведение типов)

- Существуют три «воронки», в которые JavaScript автоматически преобразует данные: **ToNumber**, **ToString**, **ToBoolean**.
- Каждая воронка запускается автоматически определённым набором операторов или действий.
- Конкретные правила внутри каждой воронки — это набор соглашений, а не глубокая модель: их проверяют по документации или экспериментом, когда поведение неочевидно.

## ToNumber (приведение к числу)

- `"3"` → `3`, `"-3"` → `-3`, поддерживаются десятичные.
- `true` → `1`, `false` → `0`.
- `null` → `0`.
- `undefined` → `NaN` (значение типа number, но без числового значения).
- `NaN` — это значение типа number; оно специально предусмотрено как полезный инструмент для случаев, когда нечисловое значение нужно представить в числовом контексте. Это не «причуда» JavaScript, а типичный для многих языков приём, заложенный в стандартах.

## ToString (приведение к строке)

- Почти всё можно привести к строковой версии.
- Числа в строку: берётся представление типа, как оно видно в консоли, и возвращается строкой.

## ToBoolean (приведение к логическому)

- «Пустые»/невалидные значения → `false`: `null`, `undefined`, `NaN`, `0`, `""` (пустая строка).
- Всё остальное → `true`.

## Операторы, запускающие coercion

- **Математические операторы** → ToNumber.
- **Унарный `+`** → ToNumber (надёжно).
- **Бинарный `+`** → ToString, если хотя бы один операнд не число; если оба числа — сложение.
- **Реляционные операторы** (`<`, `>` и т.п.) → сначала ToNumber, иначе ToString; при строках сравнение по позиции в Unicode (приблизительно алфавитное).
- **Нестрогое равенство `==`** → coercion в любую сторону (множество вариаций, частично legacy).
- **Условия** (`if`, тернарный и т.п.) → ToBoolean.
- ToString также через: вывод в браузер, шаблонные строки, метод `toString`.

## Важные нюансы

- Часть правил (особенно `==`) не имеет стройной логики — это наследие быстрого выпуска языка в 1995 году.

## Главное

- Три потока coercion — ToNumber, ToString, ToBoolean — запускаются конкретными операторами на их операндах.
- Детали внутри воронок — набор правил для проверки, а не глубокая модель; самые ненадёжные — нестрогое равенство.
- `NaN` — значение типа number без числового значения, штатный инструмент языка.
- Предпочитать явное приведение типов, минимизируя неявные coercion.
