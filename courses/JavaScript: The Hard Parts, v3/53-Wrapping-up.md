# Часть 53. Wrapping up

## Итоги курса: ключевые темы

### Базовые принципы
- Три ядра JavaScript: **memory** (память), **thread** (поток выполнения) и **call stack** (стек вызовов).

### Higher-order functions
- **higher-order functions** (функции высшего порядка) — возможность вызвать функцию, оставив часть её работы «на потом» (TBD) до момента выполнения.
- Как параметры позволяют вставить данные позже, так функции высшего порядка позволяют вставить позже саму функциональность.
- Дали `map`, `filter`, `reduce` без мутации входных данных — без side effects.

### Closure
- Возврат функции из места её определения вместе с **backpack** / **closure** (замыкание) — persistent lexical scope reference data (сохранённые данные лексической области видимости).
- Функции получают связанные с ними persistent data, что делает их близкими к OOP-подходу.
- Позволило строить функции вроде `once` (ограничение повторного запуска), а также iterators и generators (см. курс Functional Programming Hard Parts).

### Type coercion и symbol
- Разобрана **type coercion** (приведение типов) и новый тип данных **symbol**.
- symbol позволяет создавать скрытые свойства/метки на объектах.
- С их помощью можно управлять поведением приведения объекта к числу, не ломая старый код, — благодаря введению нового типа метки (symbol).

### Asynchronicity
- **asynchronicity** (асинхронность) — основа современной веб-разработки.
- Добавлены: **callback queue / task queue** (очередь колбэков/задач), **microtask queue** (очередь микрозадач), web browser features, **event loop** (цикл событий), **promises**.
- Позволяет запускать долгие операции (например, обращения в интернет) не блокируя единственный поток JavaScript.
- Существуют чёткие правила, по которым результат возвращается обратно в JavaScript.

### Object-oriented paradigm
- Суть OOP сведена к одному: держать данные и связанный с ними код вместе, упакованными в объекте.
- Для создания таких объектов много ручной работы автоматизирует the new keyword.
- Дополнительные традиционные OOP-возможности: private fields, static fields, instance-specific fields — для максимально полной эмуляции объектно-ориентированного стиля.

## Главное
- Курс прошёл путь от ядра языка (memory, thread, call stack) через higher-order functions, closure, type coercion/symbol и asynchronicity к эмуляции OOP.
- Понимание внутренней механики JavaScript позволяет осознанно использовать фреймворки и переносить навыки на другие языки.
- Ключ к автономности инженера — умение разбирать систему на составляющие части и понимать, как они работают.
