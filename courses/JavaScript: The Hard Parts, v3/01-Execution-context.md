# Часть 1. Как выполняется код (Execution context)

## Что вообще делает программа

- В программировании всего две вещи: **проходить код построчно** и **сохранять данные** (и иногда их менять).
- **Thread of execution** (поток выполнения) — построчное прохождение кода сверху вниз: берётся строка и выполняется, затем следующая.
- **Memory** (память) — хранилище, где данные сохраняются под метками (labels), чтобы потом к ним обращаться.
- Сохранённый код в файле — это не его выполнение. При запуске включается **JavaScript runtime** (среда выполнения) — приложение, которое интерпретирует код и делает то, что в нём написано.

## Разбор примера построчно

```js
const num = 3;
function multiplyBy2(inputNumber) {
  const result = inputNumber * 2;
  return result;
}
const output = multiplyBy2(num);
const newOutput = multiplyBy2(10);
```

1. `const num = 3` — объявляется **constant** `num`, ему присваивается **value** (значение) `3`; под него выделяется память.
2. `function multiplyBy2(...)` — вся функция целиком сохраняется в памяти (условно как «F»); код функции не выполняется, только сохраняется.
3. Поток перепрыгивает определение функции и доходит до `const output = multiplyBy2(num)`. Сначала `output` **uninitialized** (неинициализирован) — значение ещё неизвестно, потому что функцию надо выполнить.
4. **Parentheses** (круглые скобки) `()` — сигнал, что функцию нужно **выполнить** (вызвать). Термины declaring / evaluating / running / executing / calling / invoking означают здесь одно и то же — запуск функции.
5. Аргумент — `num`, который вычисляется (evaluates) в значение `3`.

## Execution context и local memory

- При вызове функции создаётся **execution context** (контекст выполнения) — «мини-программа»: свой thread of execution + своё хранилище данных.
- Внутри функции создаётся **local memory** (локальная память) — доступна только пока функция выполняется.
- Первое, что происходит при входе в функцию: связывание **argument** (аргумент — фактическое переданное значение) с **parameter** (параметр — метка/идентификатор, принимающий вход).
  - Здесь параметр `inputNumber` получает значение аргумента `3`.
- Далее `result = inputNumber * 2` → `3 * 2` → `6`, сохраняется в local memory.

## Возврат значения

- `return result` возвращает **значение** `result` (число `6`), а не саму переменную. Внутренние метки (`inputNumber`, `result`) забываются.
- Весь вызов `multiplyBy2(num)` **evaluates** (вычисляется) в значение `6`, которое присваивается глобальной метке `output`.
- После возврата execution context закрывается, поток возвращается в **global execution context** (глобальный контекст).
- Второй вызов `multiplyBy2(10)` создаёт **новый** execution context с новой local memory: `inputNumber = 10`, `result = 20`, возвращает `20` в `newOutput`. Каждый вызов — отдельный контекст, прошлые внутренние данные не сохраняются.

## Важные различия в терминологии

- **value** (значение) vs **identifier** (идентификатор — «модное» слово для метки/label).
- **function definition** (определение/объявление функции, по ключевому слову `function`) vs **function call** (вызов — по круглым скобкам `()`).
- При вызове функции создаётся мини-версия всей программы: thread of execution + local memory.

## Главное

- Программа делает две вещи: идёт по коду построчно (thread of execution) и хранит данные (memory).
- Объявление функции лишь сохраняет её код; выполнение запускается круглыми скобками `()`.
- Каждый вызов создаёт собственный execution context с локальной памятью; параметр получает значение аргумента.
- `return` отдаёт **значение**, контекст закрывается, поток возвращается в global execution context.
