# Часть 24. Объекты Date

## Функция Date

- **Date** — встроенная функция JavaScript, доступна сразу при запуске движка.
- Вызывается с ключевым словом `new` (полный разбор `new` — позже).
- Возвращает объект, у которого есть **hidden property** (скрытое свойство) `[[DateValue]]` (`date value`).
- `[[DateValue]]` хранит число миллисекунд, прошедших с полуночи 1 января 1970 года (точка отсчёта; не день изобретения компьютеров).

## Пример: два вызова

```js
const time1 = new Date(); // момент 1
// проходит время
const time2 = new Date(); // момент 2
```

- В примере `time1` соответствует полуночи 15 января 2027 — это ~`1.8` триллиона миллисекунд от 1970.
- Через 1 секунду `time2` = `1.8` трлн + `1000` мс. (Сначала в лекции взяли 3 с → +`3000` мс, затем заменили на 1 с.)
- Каждый вызов возвращает отдельный объект со своим `[[DateValue]]`.

## Желаемое и ограничение

- Хотелось бы напрямую вычесть `time2 - time1` и узнать прошедшее время.
- Но это два объекта, хранящиеся by reference; напрямую сравнивать/вычитать позиции в памяти нельзя, pointer math в JavaScript отсутствует.
- Доступа к `time1[[DateValue]]` напрямую через `time1.dateValue` или `time1["dateValue"]` нет — свойство скрытое. (Доступ есть через специальные методы объекта Date — далее.)

## Объекты Date — обычные объекты

- Это обычные объекты: к ним можно добавлять свойства.
- Хранятся by reference: в `time1`/`time2` лежат ссылки на позиции объектов в heap.

## Напоминание про square bracket notation

```js
const month = "Jan";
time1[month] = true; // ключ берётся из значения month → "Jan"
time2[month] = true;
```

- Внутри `[]` находится не имя свойства буквально, а выражение, которое вычисляется.
- `month` — это не ключ, а указание «найди значение, сохранённое в `month`». Оно вычисляется в строку `"Jan"`, и именно `"Jan"` становится именем свойства.
- Имена свойств (ключи) — всегда строки, даже когда кавычки не видны.
- Результат: на `time1` и `time2` появляется пара `Jan: true`.

## Зачем это показано

- Подтвердить, что Date-объекты — обычные объекты (свойства добавляются как обычно).
- Подготовить к metaprogramming: понадобится square bracket notation, чтобы задать имя свойства, которое нельзя вписать вручную напрямую. Это распространённый «gotcha».

## Цель

- Получить доступ к timestamp, чтобы при submit проверять: если с прошлой отправки прошло меньше, скажем, 2000 мс, — запретить повторную отправку (защита от двойного клика). Способ — далее.

## Главное

- `new Date()` возвращает объект со скрытым свойством `[[DateValue]]` — миллисекунды с 00:00 01.01.1970.
- Объекты Date обычные и хранятся by reference; прямого доступа к `[[DateValue]]` через точку/скобки нет.
- В square bracket notation выражение в `[]` вычисляется и его результат становится строковым ключом — важный нюанс перед темой metaprogramming.
