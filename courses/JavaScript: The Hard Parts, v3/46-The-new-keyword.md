# Часть 46. Ключевое слово new

## Solution 3: ключевое слово, автоматизирующее работу

- Перед вызовом функции вставляется ключевое слово из трёх букв — **the new keyword** (`new`).
- `new` автоматизирует:
  1. создание объекта (the creation of the object);
  2. установку скрытой ссылки на общий store функций (link to a shared store of functions);
  3. возврат объекта из функции (returning out the object).
- `new` НЕ автоматизирует присвоение свойств — это нужно делать вручную.

## Нюанс/проблема new

- Функция, написанная в расчёте на `new`, ожидает автоматического поведения. Если вызвать её без `new`, ничего из автоматики не произойдёт и функция отработает не так, как задумано.
- Это потенциальная ловушка: поведение функции зависит от наличия `new` перед вызовом.

## Как ссылаться на авто-созданный объект

- Внутри тела функции на автоматически созданный объект ссылаются через ключевое слово **this** — то же слово, что и раньше, но здесь это совершенно другой объект (авто-созданный), а не «объект слева от точки».
- Где взять место для общих функций? Раньше вручную создавали `userFunctionStore` и делали bond через `Object.create`. Теперь нужно полагаться на стандартное место, куда объекты из `new`-вызова автоматически ссылаются.

## Интерлюдия: функции — это и функции, и объекты

```js
function multiplyBy2(num) {
  return num * 2;
}
multiplyBy2.stored = 5;

multiplyBy2(3);        // 6  — функциональная часть
multiplyBy2.stored;    // 5  — объектная часть
```

1. `multiplyBy2` объявляется как функция.
2. `multiplyBy2.stored = 5` — создаётся хранимое свойство со значением `5`.
3. В JS функции — одновременно и функции, и **объекты**.
4. Точка (`.`) говорит «обращаться к объектной части». Использование объектной части не ломает функциональную.
5. Скобки (`()`) говорят «обращаться к функциональной части». `multiplyBy2(3)` возвращает `6`.
6. `multiplyBy2.stored` через точку даёт обратно `5` — обе части сосуществуют.

## prototype property функции

- Объектная часть функции не пуста: у неё есть вполне реальное свойство **prototype property** — обычное (не скрытое) свойство `prototype`, которое автоматически является пустым объектом.
- Все функции в JS автоматически также объекты и автоматически имеют на себе свойство `prototype` — большой пустой объект.
- Это НЕ скрытая ссылка `[[Prototype]]` (`__proto__`). `multiplyBy2.prototype` можно явно посмотреть — это пустой объект.

## Использование prototype property вместо function store

- Поскольку у каждой функции по умолчанию есть `prototype` (пустой объект на её объектной части), его можно использовать вместо отдельного `userFunctionStore`.
- У функции `userCreator` тоже есть объектная часть с пустым `prototype`. Если положить туда нужные функции, то объекты, возвращённые из `userCreator`, получат к ним доступ через `userCreator.prototype`.
- Именно туда — в `userCreator.prototype` — JS с ключевым словом `new` помещает (и ищет) общий store функций.

## Что делает new

```js
function userCreator(name, score) {
  this.name = name;
  this.score = score;
}
userCreator.prototype.increment = function () { this.score++; };
userCreator.prototype.login = function () { /* ... */ };

const user1 = new userCreator("Ari", 3);
```

- Раньше: создавали объект `userFunctionStore`, клали туда `increment`, `login`, делали bond через `Object.create`.
- Теперь bond вручную не делается. `new` автоматически создаёт объект и устанавливает его скрытую ссылку.
- Общие функции должны лежать там, куда объект придёт автоматически по prototype chain: это объектная форма функции (`userCreator`), её свойство `prototype` (объект), в которое кладутся функции.

## Главное

- **the new keyword** автоматизирует три вещи: создание объекта, установку скрытой prototype-ссылки на общий store, возврат объекта.
- Внутри функции авто-созданный объект доступен через **this**; присвоение свойств всё равно делается вручную.
- Функции в JS — одновременно функции и объекты: `()` обращается к функциональной части, `.` — к объектной.
- У каждой функции есть свойство **prototype** (пустой объект на её объектной части) — именно туда `new` кладёт и ищет общие методы; это не скрытая ссылка `[[Prototype]]`.
