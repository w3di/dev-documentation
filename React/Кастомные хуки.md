# Кастомные хуки — переиспользование логики с состоянием

> Кастомный хук — это функция JavaScript, имя которой начинается с `use` и которая
> вызывает внутри себя другие хуки React. Это основной механизм извлечения
> и переиспользования stateful-логики между компонентами без изменения
> иерархии компонентов и без HOC/render props.

## 1. Концепция кастомных хуков

До появления хуков переиспользование stateful-логики требовало HOC (Higher-Order Components)
или render props — паттернов, которые усложняют дерево компонентов и создают «wrapper hell».

Кастомные хуки решают эту проблему: логика извлекается в функцию, а каждый компонент,
вызывающий хук, получает **собственную** изолированную копию состояния.

```
Без кастомных хуков:                   С кастомным хуком:

<WithAuth>                             function Profile() {
  <WithTheme>                            const user = useAuth();
    <WithLocale>                         const theme = useTheme();
      <Profile />                        const locale = useLocale();
    </WithLocale>                        return <div>...</div>;
  </WithTheme>                         }
</WithAuth>
                                       // Нет вложенности, логика рядом
// "Wrapper hell"                      // с местом использования
```

**Ключевой принцип:** кастомный хук — это не компонент. Он не рендерит UI.
Он инкапсулирует **логику** (состояние, эффекты, вычисления) и возвращает данные
или функции, которые компонент использует для рендеринга.

## 2. Правила создания и вызова

### Правила именования

- Имя **обязано** начинаться с `use` (например, `useToggle`, `useFetch`)
- React линтер (`eslint-plugin-react-hooks`) использует это соглашение для проверки
  правил хуков
- Если функция не вызывает другие хуки — не называйте её `use...`
  (это введёт линтер в заблуждение)

### Правила вызова (Rules of Hooks применяются и к кастомным хукам)

1. **Только на верхнем уровне** — не внутри условий, циклов, вложенных функций
2. **Только из React-функций** — из компонентов или других кастомных хуков
3. **Порядок вызовов должен быть постоянным** между рендерами

```jsx
// Правильно
function useFormField(initialValue) {
  const [value, setValue] = useState(initialValue);
  const [error, setError] = useState(null);

  function validate() {
    if (!value.trim()) {
      setError('Поле обязательно');
      return false;
    }
    setError(null);
    return true;
  }

  return { value, setValue, error, validate };
}

// Неправильно — условный вызов хука
function useBadHook(condition) {
  if (condition) {
    const [value, setValue] = useState(''); // Нарушение: хук внутри условия
  }
}
```

## 3. Извлечение логики из компонентов (extract custom hook)

Рефакторинг «extract custom hook» — перенос группы связанных `useState`/`useEffect`
из компонента в отдельную функцию.

**До рефакторинга:**

```jsx
function SearchPage() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  useEffect(() => {
    if (!query) return;
    setLoading(true);
    setError(null);

    const controller = new AbortController();
    fetch(`/api/search?q=${query}`, { signal: controller.signal })
      .then(res => res.json())
      .then(data => setResults(data))
      .catch(err => {
        if (err.name !== 'AbortError') setError(err.message);
      })
      .finally(() => setLoading(false));

    return () => controller.abort();
  }, [query]);

  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      {loading && <Spinner />}
      {error && <ErrorMessage message={error} />}
      <ResultList items={results} />
    </div>
  );
}
```

**После рефакторинга:**

```jsx
// useSearch.js — извлечённый кастомный хук
function useSearch(query) {
  const [results, setResults] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  useEffect(() => {
    if (!query) {
      setResults([]);
      return;
    }
    setLoading(true);
    setError(null);

    const controller = new AbortController();
    fetch(`/api/search?q=${query}`, { signal: controller.signal })
      .then(res => res.json())
      .then(data => setResults(data))
      .catch(err => {
        if (err.name !== 'AbortError') setError(err.message);
      })
      .finally(() => setLoading(false));

    return () => controller.abort();
  }, [query]);

  return { results, loading, error };
}

// Компонент стал декларативным
function SearchPage() {
  const [query, setQuery] = useState('');
  const { results, loading, error } = useSearch(query);

  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      {loading && <Spinner />}
      {error && <ErrorMessage message={error} />}
      <ResultList items={results} />
    </div>
  );
}
```

## 4. useToggle — управление boolean-состоянием

Простейший кастомный хук, демонстрирующий принцип инкапсуляции.

```jsx
import { useState, useCallback } from 'react';

function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue);

  const toggle = useCallback(() => setValue(v => !v), []);
  const setTrue = useCallback(() => setValue(true), []);
  const setFalse = useCallback(() => setValue(false), []);

  return { value, toggle, setTrue, setFalse };
}

// Использование
function Accordion({ title, children }) {
  const { value: isOpen, toggle } = useToggle(false);

  return (
    <div className="accordion">
      <button onClick={toggle}>
        {title} {isOpen ? '▲' : '▼'}
      </button>
      {isOpen && <div className="accordion-body">{children}</div>}
    </div>
  );
}
```

## 5. useFetch — загрузка данных

Обобщённый хук для data fetching с обработкой состояний загрузки, ошибок
и отмены запросов.

```jsx
import { useState, useEffect, useRef } from 'react';

function useFetch(url, options = {}) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  // Сохраняем options в ref, чтобы избежать бесконечного цикла useEffect
  const optionsRef = useRef(options);
  optionsRef.current = options;

  useEffect(() => {
    if (!url) return;

    const controller = new AbortController();
    setLoading(true);
    setError(null);

    fetch(url, { ...optionsRef.current, signal: controller.signal })
      .then(response => {
        if (!response.ok) {
          throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }
        return response.json();
      })
      .then(setData)
      .catch(err => {
        if (err.name !== 'AbortError') {
          setError(err);
        }
      })
      .finally(() => setLoading(false));

    return () => controller.abort();
  }, [url]);

  return { data, loading, error };
}

// Использование
function UserProfile({ userId }) {
  const { data: user, loading, error } = useFetch(`/api/users/${userId}`);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error.message} />;
  if (!user) return null;

  return <div><h2>{user.name}</h2><p>{user.email}</p></div>;
}
```

## 6. useLocalStorage — синхронизация с localStorage

Хук, который хранит состояние в `localStorage` и синхронизирует его между вкладками.

```jsx
import { useState, useEffect, useCallback } from 'react';

function useLocalStorage(key, initialValue) {
  // Ленивая инициализация — читаем из localStorage только при первом рендере
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = localStorage.getItem(key);
      return item !== null ? JSON.parse(item) : initialValue;
    } catch {
      return initialValue;
    }
  });

  // Обновляем localStorage при изменении значения
  useEffect(() => {
    try {
      localStorage.setItem(key, JSON.stringify(storedValue));
    } catch (error) {
      console.error(`Ошибка записи в localStorage [${key}]:`, error);
    }
  }, [key, storedValue]);

  // Синхронизация между вкладками через событие storage
  useEffect(() => {
    function handleStorageChange(e) {
      if (e.key === key && e.newValue !== null) {
        setStoredValue(JSON.parse(e.newValue));
      }
    }
    window.addEventListener('storage', handleStorageChange);
    return () => window.removeEventListener('storage', handleStorageChange);
  }, [key]);

  const remove = useCallback(() => {
    localStorage.removeItem(key);
    setStoredValue(initialValue);
  }, [key, initialValue]);

  return [storedValue, setStoredValue, remove];
}

// Использование
function ThemeSwitcher() {
  const [theme, setTheme] = useLocalStorage('app-theme', 'light');

  return (
    <button onClick={() => setTheme(t => t === 'light' ? 'dark' : 'light')}>
      Тема: {theme}
    </button>
  );
}
```

## 7. useDebounce — дебаунсинг значения

Откладывает обновление значения до тех пор, пока пользователь не прекратит ввод
на заданный интервал. Критически важен для оптимизации поисковых запросов.

```jsx
import { useState, useEffect } from 'react';

function useDebounce(value, delay = 300) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    // При каждом изменении value — сбрасываем предыдущий таймер
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}

// Использование — поиск с дебаунсом
function SearchInput() {
  const [query, setQuery] = useState('');
  const debouncedQuery = useDebounce(query, 500);
  const { data: results } = useFetch(
    debouncedQuery ? `/api/search?q=${debouncedQuery}` : null
  );

  return (
    <div>
      <input
        value={query}
        onChange={e => setQuery(e.target.value)}
        placeholder="Поиск..."
      />
      {results && <ResultList items={results} />}
    </div>
  );
}
```

## 8. useMediaQuery — адаптивность

Хук для реагирования на изменение медиа-запросов CSS. Позволяет условно
рендерить компоненты в зависимости от размера экрана.

```jsx
import { useState, useEffect } from 'react';

function useMediaQuery(query) {
  const [matches, setMatches] = useState(() => {
    if (typeof window === 'undefined') return false;
    return window.matchMedia(query).matches;
  });

  useEffect(() => {
    const mediaQuery = window.matchMedia(query);

    function handleChange(e) {
      setMatches(e.matches);
    }

    // Устанавливаем начальное значение
    setMatches(mediaQuery.matches);

    // Подписываемся на изменения
    mediaQuery.addEventListener('change', handleChange);
    return () => mediaQuery.removeEventListener('change', handleChange);
  }, [query]);

  return matches;
}

// Использование
function Navigation() {
  const isMobile = useMediaQuery('(max-width: 768px)');
  const prefersReducedMotion = useMediaQuery('(prefers-reduced-motion: reduce)');

  if (isMobile) {
    return <MobileMenu animated={!prefersReducedMotion} />;
  }
  return <DesktopNavbar />;
}
```

## 9. usePrevious — предыдущее значение

Хук для доступа к значению из предыдущего рендера. Полезен для сравнения
текущего и предыдущего состояния (аналог `componentDidUpdate` из классов).

```jsx
import { useRef, useEffect } from 'react';

function usePrevious(value) {
  const ref = useRef(undefined);

  useEffect(() => {
    ref.current = value;
  });
  // useEffect выполняется ПОСЛЕ рендера,
  // поэтому ref.current содержит предыдущее значение во время рендера

  return ref.current;
}

// Использование — отслеживание изменения счётчика
function Counter() {
  const [count, setCount] = useState(0);
  const prevCount = usePrevious(count);

  return (
    <div>
      <p>Текущее: {count}, Предыдущее: {prevCount ?? 'нет'}</p>
      <p>
        {prevCount !== undefined && (
          count > prevCount ? '📈 Увеличилось' : count < prevCount ? '📉 Уменьшилось' : '= Без изменений'
        )}
      </p>
      <button onClick={() => setCount(c => c + 1)}>+1</button>
      <button onClick={() => setCount(c => c - 1)}>-1</button>
    </div>
  );
}
```

## 10. useOnClickOutside — клик вне элемента

Обрабатывает клик за пределами указанного элемента. Необходим для закрытия
dropdown-меню, модальных окон, поповеров.

```jsx
import { useEffect } from 'react';

function useOnClickOutside(ref, handler) {
  useEffect(() => {
    function listener(event) {
      // Если клик внутри элемента — игнорируем
      if (!ref.current || ref.current.contains(event.target)) {
        return;
      }
      handler(event);
    }

    document.addEventListener('mousedown', listener);
    document.addEventListener('touchstart', listener);

    return () => {
      document.removeEventListener('mousedown', listener);
      document.removeEventListener('touchstart', listener);
    };
  }, [ref, handler]);
}

// Использование
function Dropdown({ onClose }) {
  const dropdownRef = useRef(null);

  useOnClickOutside(dropdownRef, onClose);

  return (
    <div ref={dropdownRef} className="dropdown">
      <ul>
        <li>Пункт 1</li>
        <li>Пункт 2</li>
        <li>Пункт 3</li>
      </ul>
    </div>
  );
}
```

## 11. Композиция хуков

Кастомные хуки могут вызывать другие кастомные хуки, создавая цепочку
переиспользуемых абстракций.

```jsx
// Композиция: useDebounce + useFetch = useDebouncedSearch
function useDebouncedSearch(query, delay = 300) {
  const debouncedQuery = useDebounce(query, delay);
  const { data, loading, error } = useFetch(
    debouncedQuery ? `/api/search?q=${encodeURIComponent(debouncedQuery)}` : null
  );

  return {
    results: data ?? [],
    loading,
    error,
    isDebouncing: query !== debouncedQuery,
  };
}

// Композиция: useLocalStorage + useMediaQuery = useThemePreference
function useThemePreference() {
  const prefersDark = useMediaQuery('(prefers-color-scheme: dark)');
  const [theme, setTheme] = useLocalStorage('theme', null);

  // Если пользователь не выбрал тему вручную — используем системную
  const resolvedTheme = theme ?? (prefersDark ? 'dark' : 'light');

  return { theme: resolvedTheme, setTheme, isSystem: theme === null };
}
```

**Граф зависимостей хуков:**

```
useDebouncedSearch
  ├── useDebounce
  │     ├── useState
  │     └── useEffect
  └── useFetch
        ├── useState
        ├── useEffect
        └── useRef

useThemePreference
  ├── useMediaQuery
  │     ├── useState
  │     └── useEffect
  └── useLocalStorage
        ├── useState
        ├── useEffect
        └── useCallback
```

## 12. Тестирование кастомных хуков

Кастомные хуки нельзя вызывать вне React-компонентов. Для тестирования используется
`renderHook` из `@testing-library/react`.

```jsx
import { renderHook, act } from '@testing-library/react';
import { useToggle } from './useToggle';
import { useDebounce } from './useDebounce';
import { useLocalStorage } from './useLocalStorage';

// Тест useToggle
describe('useToggle', () => {
  it('инициализируется с false по умолчанию', () => {
    const { result } = renderHook(() => useToggle());
    expect(result.current.value).toBe(false);
  });

  it('переключает значение при вызове toggle', () => {
    const { result } = renderHook(() => useToggle(false));

    act(() => {
      result.current.toggle();
    });
    expect(result.current.value).toBe(true);

    act(() => {
      result.current.toggle();
    });
    expect(result.current.value).toBe(false);
  });

  it('принимает начальное значение', () => {
    const { result } = renderHook(() => useToggle(true));
    expect(result.current.value).toBe(true);
  });
});

// Тест useDebounce
describe('useDebounce', () => {
  beforeEach(() => jest.useFakeTimers());
  afterEach(() => jest.useRealTimers());

  it('возвращает начальное значение немедленно', () => {
    const { result } = renderHook(() => useDebounce('hello', 500));
    expect(result.current).toBe('hello');
  });

  it('обновляет значение после задержки', () => {
    const { result, rerender } = renderHook(
      ({ value, delay }) => useDebounce(value, delay),
      { initialProps: { value: 'hello', delay: 500 } }
    );

    rerender({ value: 'world', delay: 500 });
    expect(result.current).toBe('hello'); // ещё не обновилось

    act(() => jest.advanceTimersByTime(500));
    expect(result.current).toBe('world'); // обновилось после задержки
  });
});

// Тест useLocalStorage
describe('useLocalStorage', () => {
  beforeEach(() => localStorage.clear());

  it('возвращает initialValue, если ключа нет в localStorage', () => {
    const { result } = renderHook(() => useLocalStorage('key', 'default'));
    expect(result.current[0]).toBe('default');
  });

  it('сохраняет значение в localStorage', () => {
    const { result } = renderHook(() => useLocalStorage('key', 'default'));

    act(() => {
      result.current[1]('new-value');
    });

    expect(result.current[0]).toBe('new-value');
    expect(JSON.parse(localStorage.getItem('key'))).toBe('new-value');
  });
});
```

## 13. Когда создавать кастомный хук, а когда не стоит

### Создавать кастомный хук стоит, когда:

- Одна и та же комбинация `useState` + `useEffect` повторяется в 2+ компонентах
- Логика компонента разрослась и затрудняет чтение JSX
- Нужно инкапсулировать побочный эффект (подписка, таймер, API-вызов)
- Требуется тестировать логику изолированно от UI

### Не стоит создавать кастомный хук, когда:

- Хук используется только в одном компоненте (преждевременная абстракция)
- Логика не содержит вызовов других хуков (обычная функция лучше)
- Хук становится «универсальным» с десятком параметров (нарушение Single Responsibility)
- Ради соблюдения «паттерна» без практической пользы

### Правило принятия решения

```
Логика содержит useState/useEffect/useRef?
  ├── Нет → обычная функция (не хук)
  └── Да → используется в 2+ компонентах?
        ├── Нет → оставить в компоненте (пока)
        └── Да → извлечь в кастомный хук
```

## 14. Библиотеки готовых хуков

Перед написанием кастомного хука стоит проверить, не реализован ли он
в популярных библиотеках.

| Библиотека | Кол-во хуков | TypeScript | Особенности |
|---|---|---|---|
| **ahooks** (Alibaba) | 60+ | Да | Фокус на production, сложные хуки (useRequest, useInfiniteScroll) |
| **react-use** | 100+ | Да | Самая большая коллекция, включая хуки для сенсоров и анимации |
| **usehooks-ts** | 40+ | Да (native) | Минималистичные, хорошо документированные, SSR-совместимые |
| **@uidotdev/usehooks** | 20+ | Да | Простые, с наглядными демо на ui.dev |
| **@mantine/hooks** | 50+ | Да | Часть экосистемы Mantine UI, качественная реализация |

**Рекомендация:** используйте библиотеки для стандартных хуков (`useDebounce`,
`useLocalStorage`, `useMediaQuery`), а кастомные пишите для бизнес-логики
вашего приложения, которую ни одна библиотека не покроет.
