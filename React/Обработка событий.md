## Синтетические события (SyntheticEvent)

React оборачивает нативные события браузера в объекты `SyntheticEvent` — кроссбраузерную обёртку с единым API.

```jsx
function Button() {
  function handleClick(e) {
    // e — SyntheticEvent, не нативный Event
    console.log(e.type);         // 'click'
    console.log(e.target);       // DOM-элемент
    console.log(e.nativeEvent);  // оригинальный MouseEvent браузера
    e.preventDefault();          // работает кроссбраузерно
  }

  return <button onClick={handleClick}>Клик</button>;
}
```

- **React 17+:** пул событий убран — объект `SyntheticEvent` можно читать асинхронно
- Доступ к нативному событию: `e.nativeEvent`
- Все свойства нативного события доступны на `SyntheticEvent` (`target`, `currentTarget`, `type`, `timeStamp`)

## Именование и передача обработчиков

### Правила именования

- Обработчики событий: `handleClick`, `handleSubmit`, `handleChange`
- Props для обработчиков: `onClick`, `onSubmit`, `onChange`
- Кастомные events в компонентах: `onItemSelect`, `onDelete`, `onToggle`

### Передача функции, не вызов

```jsx
// ✅ Передаём ссылку на функцию
<button onClick={handleClick}>OK</button>

// ❌ Вызываем функцию при рендере — handleClick выполнится сразу!
<button onClick={handleClick()}>OK</button>
```

### Инлайн-обработчик

```jsx
<button onClick={() => alert('Клик!')}>OK</button>

<button onClick={(e) => {
  e.preventDefault();
  handleSubmit(data);
}}>
  Отправить
</button>
```

## Передача аргументов в обработчики

```jsx
function TodoList({ todos, onDelete }) {
  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>
          {todo.text}
          {/* Стрелочная функция для передачи аргумента */}
          <button onClick={() => onDelete(todo.id)}>✕</button>
        </li>
      ))}
    </ul>
  );
}
```

> **Производительность:** стрелочная функция создаётся заново каждый рендер. Для большинства случаев это не проблема. Если список огромный, используйте `useCallback` или React Compiler.

## Делегирование событий в React

React не привязывает обработчики к каждому DOM-элементу. Вместо этого:

- **React 17+:** одна подписка на корневой DOM-контейнер (`root`)
- React использует event delegation — перехватывает все события на корне и маршрутизирует их к нужным компонентам
- Это эффективнее, чем `addEventListener` на каждый элемент

```
DOM:       #root  ← React подписывается здесь
            │
          <div>
          ╱    ╲
     <button>  <button>  ← обработчики не привязаны к DOM
```

Следствие: `e.stopPropagation()` останавливает всплытие **в React-дереве**, а нативное событие уже добралось до корня.

## Всплытие и перехват

### Всплытие (Bubbling)

```jsx
function App() {
  return (
    <div onClick={() => console.log('div')}>
      <button onClick={() => console.log('button')}>
        Клик
      </button>
    </div>
  );
}
// Клик по кнопке: "button" → "div"
```

### Фаза захвата (Capture)

```jsx
<div onClickCapture={() => console.log('div capture')}>
  <button onClick={() => console.log('button')}>Клик</button>
</div>
// "div capture" → "button"
```

### stopPropagation и preventDefault

```jsx
function Form() {
  function handleSubmit(e) {
    e.preventDefault();  // Отменить отправку формы
  }

  return (
    <form onSubmit={handleSubmit}>
      <button onClick={(e) => {
        e.stopPropagation(); // Остановить всплытие к form
        doSomething();
      }}>
        Действие
      </button>
    </form>
  );
}
```

## Типы событий

| Категория | События |
|---|---|
| Мышь | `onClick`, `onDoubleClick`, `onMouseDown`, `onMouseUp`, `onMouseEnter`, `onMouseLeave`, `onMouseMove` |
| Клавиатура | `onKeyDown`, `onKeyUp` (`onKeyPress` — deprecated) |
| Фокус | `onFocus`, `onBlur`, `onFocusCapture` |
| Формы | `onChange`, `onInput`, `onSubmit`, `onReset`, `onInvalid` |
| Касания | `onTouchStart`, `onTouchMove`, `onTouchEnd`, `onTouchCancel` |
| Pointer | `onPointerDown`, `onPointerMove`, `onPointerUp`, `onPointerEnter`, `onPointerLeave` |
| Прокрутка | `onScroll`, `onWheel` |
| Drag & Drop | `onDrag`, `onDragStart`, `onDragEnd`, `onDragEnter`, `onDragLeave`, `onDragOver`, `onDrop` |
| Буфер обмена | `onCopy`, `onCut`, `onPaste` |
| Анимация | `onAnimationStart`, `onAnimationEnd`, `onTransitionEnd` |
| Медиа | `onPlay`, `onPause`, `onEnded`, `onTimeUpdate`, `onVolumeChange` |

## Паттерны обработки событий

### Обработчик в родителе (lifting events)

```jsx
function Parent() {
  function handleItemSelect(id) {
    setSelectedId(id);
  }
  return <ItemList onItemSelect={handleItemSelect} />;
}

function ItemList({ onItemSelect }) {
  return items.map(item => (
    <Item key={item.id} onClick={() => onItemSelect(item.id)} />
  ));
}
```

### Один обработчик для нескольких полей

```jsx
function Form() {
  const [form, setForm] = useState({ name: '', email: '' });

  function handleChange(e) {
    const { name, value } = e.target;
    setForm(prev => ({ ...prev, [name]: value }));
  }

  return (
    <form>
      <input name="name" value={form.name} onChange={handleChange} />
      <input name="email" value={form.email} onChange={handleChange} />
    </form>
  );
}
```

## События и TypeScript

```tsx
function SearchInput() {
  // Типизация обработчиков событий
  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    console.log(e.target.value);
  };

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
  };

  const handleKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if (e.key === 'Enter') submit();
  };

  const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    console.log(e.clientX, e.clientY);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input onChange={handleChange} onKeyDown={handleKeyDown} />
      <button onClick={handleClick}>Поиск</button>
    </form>
  );
}
```

| Тип события | Используется для |
|---|---|
| `React.MouseEvent<T>` | onClick, onMouseEnter и др. |
| `React.ChangeEvent<T>` | onChange на input, select, textarea |
| `React.FormEvent<T>` | onSubmit, onReset |
| `React.KeyboardEvent<T>` | onKeyDown, onKeyUp |
| `React.FocusEvent<T>` | onFocus, onBlur |
| `React.DragEvent<T>` | onDrag, onDrop |
| `React.TouchEvent<T>` | onTouchStart, onTouchEnd |
| `React.PointerEvent<T>` | onPointerDown, onPointerUp |

Где `T` — тип DOM-элемента: `HTMLButtonElement`, `HTMLInputElement`, `HTMLDivElement` и т.д.
