# React Hooks — обзор

## Правила хуков

1. **Не вызывайте хуки внутри циклов, условий или вложенных функций.** Хуки должны вызываться на верхнем уровне компонента или кастомного хука — это гарантирует правильный порядок вызовов между рендерами.
2. **Вызывайте хуки только из функций React** — из функциональных компонентов или из кастомных хуков.

---

## Основные хуки

| Хук | Назначение |
|-----|-----------|
| [[useState]] | Базовый хук для управления состоянием компонента |
| [[useEffect]] | Побочные эффекты: запросы API, подписки, таймеры |
| [[useRef]] | Доступ к DOM-элементам и сохранение значений между рендерами |
| [[useContext]] | Чтение значений контекста без передачи props |
| [[useCallback]] | Мемоизация функций для предотвращения лишних ререндеров |
| [[useMemo]] | Мемоизация вычислений для оптимизации производительности |
| [[useReducer]] | Управление сложным состоянием через reducer-паттерн |

## Хуки для работы с DOM и layout

| Хук | Назначение |
|-----|-----------|
| [[useLayoutEffect]] | Синхронный эффект после DOM-мутаций, до отрисовки |
| [[useImperativeHandle]] | Настройка императивного API для `forwardRef`-компонентов |
| **useInsertionEffect** | Синхронная вставка стилей перед DOM-мутациями (для CSS-in-JS библиотек) |

## Хуки для Concurrent Features

| Хук | Назначение |
|-----|-----------|
| [[useTransition]] | Пометка обновлений как несрочных (transition) |
| [[useDeferredValue]] | Откладывание обновления значения для плавного UI |

## Специализированные хуки

| Хук | Назначение |
|-----|-----------|
| [[useSyncExternalStore]] | Подписка на внешние хранилища данных (Redux, Zustand и др.) |
| **useDebugValue** | Отображение метки в React DevTools для кастомных хуков |
| [[useId]] | Генерация уникальных ID для SSR/accessibility |

## React 19

| Хук | Назначение |
|-----|-----------|
| **use** | Чтение ресурсов (Promise, Context) в рендере |
| **useActionState** | Управление состоянием Server Actions / форм |
| **useFormStatus** | Получение статуса формы (pending) из дочернего компонента |
| **useOptimistic** | Оптимистичные обновления UI |
| [[useEffectEvent]] | Нереактивная логика в эффектах (experimental) |
